# DragonEyeSorter · 龙瞳分拣

基于 **安路飞龙（Dragon）F3P SoC** 的塑胶齿轮在线质检分拣系统。

多规格 POM 齿轮随机摆放流过相机：视觉出每件位置与角度 + 亚像素几何测量（外径 / 孔径 / 齿数 / 偏心），NPU（UINT8 量化 YOLOv8n-cls，逐件 ROI）按缺陷类型 × 轻重分类（现为良品 + 缺料 / 脏污各轻重两级共 5 类，实物测试集板上 99.31%；飞边两级待加），按带位置逐件跟踪。**良品**到抓取线停带 → 6 轴总线舵机机械臂腕旋对准夹起（够不着时倾斜下探）→ 按规格 / 颜色入盒；**不良品**不停带，由侧边导流挡板拦进报废 / 返修盒，存疑件走到带尾复检。PC 经 CAN 当「产线 PLC」下发启停与调速（同一套命令另有网口 Modbus-TCP 从站），HDMI 界面实时显示画面、计数、曲线与参数。

> 2026 全国大学生嵌入式芯片与系统设计竞赛 · 安路赛道 · 选题四（基于安路飞龙 SoC 的智能工业应用系统）。

系统架构与设计原则见 [系统概述](docs/系统概述.md)（总览图 [`figures/fig_architecture.png`](docs/figures/fig_architecture.png)）；硬件型号与接线见 [硬件与接线](docs/硬件与接线.md)；官方要求与倒排见 [提交材料清单](submission/提交材料清单.md)。

## 快速上手

| 步骤 | 做什么 |
|---|---|
| 0. 环境配置（首次必做） | 复制 `.env.example` 为 `.env` 并填本机工具路径 → 跑 `scripts/test_env.ps1` 自检；需要哪些环境、板子一次性配置见 [环境与上手](docs/环境与上手.md) |
| 1. 开发环境 | 工具版本（TD 6.2.1 / FD 2026.1 / FD 自带交叉编译器）、启动链、SD 卡布局见 [开发环境与构建](docs/开发环境与构建.md) |
| 2. 启动板子 | 持久化 SD 卡启动（[sd_image](scripts/sd_image/)），根文件系统改动会保留 |
| 3. 改 PL | TD 编比特流 → [bootbin](scripts/bootbin/) 打包 `BOOT.bin` → 替换 `/mnt/mmcblk0p1/BOOT.bin` → 重启 → 跑 `pl_check.sh` 回归 |
| 4. 改 PS 应用 | `make -C ps all` 交叉编译 → [scripts/deploy](scripts/deploy/) 部署（`-DryRun` 先对比、`-Dest` 先在板上试新版） |
