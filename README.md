# DragonEyeSorter · 龙瞳分拣

基于 **安路飞龙（Dragon）F3P SoC** 的智能产线视觉检测分拣系统。

传送带上的物料进入视觉工位后：PL 实时完成前景定位、尺寸测量与 ROI 提取，NPU 完成 8 类缺陷分类（量化 YOLOv8n）；NG 品由拨叉在线剔除（不停带），良品由 4 轴机械臂吸取码放。Qt 本地屏 + Web 端双 UI，全程计数、追溯、告警。

## 核心特性

- **PL 硬实时图像链路**：MIPI RX → ISP → 灰度 / 高斯 / Sobel / 二值 / 形态学 → 连通域定位 → ROI 双线性缩放，采集 / 预处理 / 显示的实时性由 FPGA 保证，A35 不搬像素
- **NPU 缺陷分类**：量化 YOLOv8n，按物料触发而非逐帧；输入分辨率等参数以实测数据为准
- **物料无关前景定位**：背景差分 + 连通域，不绑定单一物料的几何特征
- **双分拣机构**：拨叉电子齿轮随编码器同步在线剔除（不停带）；机械臂停带精确取放良品
- **多轴运动控制**：4 轴 S 曲线插补、总线舵机 / PWM 双驱动可切换、编码器 QEI + 失步检测、多通道 IO 同步采样
- **双工业总线**：CAN 2.0B（TD 自带 IP）+ RS485 Modbus-RTU 主站，实际驱动外设
- **双 UI + 本地存储**：Qt over framebuffer（HDMI，只画叠加层和控件）+ Web UI（JPU 硬编码 MJPEG），SQLite + NG 图片
- **语音 + LLM 助手（P2）**：LLM 只输出结构化指令、PS 校验后下发，断网降级本地命令词

## 硬件平台

| 部件 | 型号 / 说明 |
|---|---|
| 核心板 | MLK-F3P-DR1M90G（DR1M90GEG400：双核 Cortex-A35 + FPGA + 0.4T NPU） |
| 视觉子卡 | MLK-FEP-VID005 + IMX415（MIPI CSI） |
| 传送带驱动 | 步进电机 + 驱动器，增量编码器测速 / 定位 |
| 机械臂 | 总线舵机 ×4（带电流 / 温度遥测），末端真空吸盘 |
| 剔除机构 | PWM 舵机拨叉（电子齿轮随动） |
| 传感 | 漫反射光电、限位、急停 |
| 总线外设 | CAN 2.0B、RS485 Modbus-RTU |
