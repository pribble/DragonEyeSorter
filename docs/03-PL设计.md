## 资源策略

- 基线：官方 NPU demo（NPU_SOFT + ISP + VDMA + HDMI）已通过 P&R，我们在其上叠加运动控制、双总线与图像算子。
- W1 先塞占位模块跑完整 P&R，拿到资源余量后再定取舍，让数据先于决策。
- 若 LUT 吃紧，预定砍单顺序：尺寸亚像素 → 形态学 → overlay（叠加改由 PS 画到 framebuffer）。

## AXI-Lite 寄存器映射（草案）

基地址 `PL_BASE`，4KB 空间，32 位对齐。**此映射为草案，改动必须同步 PS 侧头文件，同一次提交完成。**

| 偏移 | R/W | 名称 | 说明 |
|---|---|---|---|
| 0x000 | W | `CTRL` | 使能 / 软复位 / 传送带 / 机械臂 / 拨叉 / 驱动模式选择 |
| 0x004 | R | `STATUS` | 就绪 / 急停 / 臂忙 / 拨叉忙 / 限位 / 失步 / 过载 |
| 0x008 | R/W | `IRQ_STAT` / `IRQ_EN` | 推理触发、到位、动作完成、故障 |
| 0x010~0x01C | W/R | `BELT_*` | 目标位置 / 速度 / 加速度 / 当前脉冲计数 |
| 0x020~0x028 | R | `ENC_*` `SLIP_ERR` | 编码器位置 / 带速 / 失步偏差 |
| 0x030~0x048 | W | `ARM_*` | 4 轴目标角 / 运动时长 / 启动插补 / 状态 |
| 0x050~0x07C | R | `ARM_FB_*` | 舵机回读位置 / 电流 / 温度（仅总线模式） |
| 0x080~0x088 | W | `FORK_*` | 拨叉目标角 / 触发位置 / 齿比 |
| 0x090~0x098 | R/W | `IO_*` | 输出（泵/灯）/ 输入（IR/限位/急停）/ 同步时间戳 |
| 0x0A0~0x0AC | R | `VIS_*` | bbox / 测得尺寸 / 前景与 ROI 状态 |
| 0x0B0~ / 0x0C0~ | R/W | `CAN_*` / `RS485_*` | 两路总线 FIFO 与状态 |
| 0x0D0 | R/W | `IMG_PARAM` | 二值 / Sobel 阈值 / 形态学核 |
| 0x100~ | R | `TRACK_QUEUE` | 物料跟踪队列（ID/位置/类别/状态）× 8 槽 |

> 展开的逐位定义随实现细化补入本文件；历史版本见 git。
