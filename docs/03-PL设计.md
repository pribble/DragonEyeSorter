# 03 · PL 设计

> PL 模块划分、官方源码复用、资源策略与 PS-PL 寄存器接口。构建方法见 [09-开发环境与构建](09-开发环境与构建.md)。

## 基线

在官方 NPU demo 工程 `soc_prj`（MIPI RX + ISP + VDMA + HDMI + NPU 软核，已过 P&R）上叠加自研模块。顶层 `src/system_top.v`，PS 与 AXI 互联在块设计 `design_0`。

### 官方源码可复用性（`soc_prj/src/` 清点）

- **明文可改**：`isp/axis_sobel.v`（Sobel）、`isp/matrix_3x3.v` + `shift_ram.v`（3×3 窗口 / 行缓存）、`isp/gray_mean.v`、`ui_isp/` 整套 ISP（含 `image_cut` 裁剪、`bilinear_interpolation.v` 双线性）、`write_fdma/uiFDMA.v`（帧写 DDR）、`MIPI_V2/src/` 解包全链、`pwm.v`（AXI PWM，7 个实例）、`design_0` 里的 AXI4-Lite 从机寄存器模板。
- **加密（不需要改）**：MIPI D-PHY 与 HDMI TMDS 物理层 3 个 `.enc` 文件。
- **官方一行都没有、是我们的贡献点**：运动控制全家桶（步进脉冲 + 加减速、舵机总线主机、QEI、帧锁存、IO 同步）、二值 / 形态学 / CCL / 投影测量 / ROI 缩放 / 张量打包、AXI 寄存器堆。

## 寄存器通道（已实现）

不改块设计：借用 GP0 上 `fvdma_ctrl`（`mipicam`）的 64KB 窗口 `0x8030_0000~0x8030_FFFF`，把它的地址线从 4 位加宽到 16 位，
**偏移 `0x1000~0x1FFF` 引出到 PL 顶层的寄存器总线**（`des_clk` 75MHz / `des_wr` 单周期写脉冲 / `des_waddr` / `des_wdata` / `des_raddr` / `des_rdata`）。
`0x0000~0x0FFF` 仍是厂家寄存器，`mipicam` 驱动照常使用；厂家寄存器的写入已排除我们的地址段。改动文件与原理见 [pl/soc_patch](../pl/soc_patch/)，仿真 [pl/sim/tb_des_axi.v](../pl/sim/tb_des_axi.v)。

**`PL_BASE` = `0x8030_1000`**，当前已实现的寄存器（`des_regs`，在 `system_top.v` 里；板上为 **v5**（10-10 17:35 上板，拍摄锁存 / BRAKE 实测通过，见 log/2026-10-10-相机60fps与PS骨架）：

| 偏移 | R/W | 名称 | 说明 |
|---|---|---|---|
| 0x000 | R | `DES_ID` | 固定 `0x44455301`（"DES" + 版本 01） |
| 0x004 | R | `DES_VERSION` | 1 = 仅寄存器通道（v1 此处为编译日期 `0x20261010`）/ 2 = 接入舵机总线 + 步进 / 3 = 帧起始修正、步进共阴 / 4 = 相机 INCK 改 27MHz（60fps）/ 5 = 拍摄锁存 + 步进 BRAKE |
| 0x008 | R/W | `SCRATCH` | 读写测试 |
| 0x00C | R | `FREE_CNT` | 75MHz 自由计数器（硬件时间戳 / 延迟测量） |
| 0x010 | R/W | `LED_CTRL` | b0 = 接管 LED1，b1 = LED1 亮灭 |
| 0x014 | R | `FRAME_CNT` | ISP 输出帧起始计数（v3 起只看 tuser 上升沿） |
| 0x018 | R | `FRAME_TS` | 最近一次帧起始时的 `FREE_CNT` |
| 0x01C | R | `FRAME_PERIOD` | 最近两次帧起始的间隔（75MHz 计数；60fps ≈ 1,250,000） |
| 0x020 | R | `CAP_SEQ` | 已完成的 DMA 取帧次数（v5） |
| 0x024 | R | `CAP_FCNT` | 写模块开始写这一帧时的 `FRAME_CNT`（v5） |
| 0x028 / 0x02C | R | `CAP_T0` / `CAP_T1` | 开始写 / 完成中断时的 `FREE_CNT`（v5） |
| 0x030 / 0x034 | R | `CAP_POS0` / `CAP_POS1` | 开始写 / 完成中断时的带位置（步进 `POS`，以后换编码器）（v5） |
| 其余 | R | — | 读回 `0xDEADBEEF` |

**拍摄锁存（v5）**：厂家帧写模块 `uidbuf_write` 在真正开始写一帧时翻转 `O_W_start_tgl`，完成中断 `f2p_irq` 上升沿再翻转一次，两路翻转经两级同步进 75MHz 域。
开始时先锁到暂存，完成时才整组更新 `CAP_*` → PS 在 `WaitFinish` 返回后有整整一帧时间去读，不会和下一帧抢。PS 用 `CAP_POS0/1` 按件所在图像行插值，得到该行读出时刻的带位置（卷帘快门）。

### 舵机总线主机 `servo_bus`（`PL_BASE + 0x100`，v2 起已接入顶层上板；⬜ 待 BSS138 + 舵机实物）

[pl/rtl/servo_bus.v](../pl/rtl/servo_bus.v)：115200 8N1 单线半双工，**开漏发送**（只拉低，高电平靠 BSS138 模块上拉），发送期间关闭接收（不收回声），
每次传输后强制留 1 字节时间（约 87µs）的总线换向间隔。PS 只填帧主体，`FF FF` 帧头和校验和由硬件补。

| 偏移 | R/W | 说明 |
|---|---|---|
| 0x100 | W | `CTRL`：b0 发送（自清零）/ b1 等应答 / b2 清状态和计数 / b[14:8] 帧主体字节数（≤64） |
| 0x104 | R | `STATUS`：b0 忙 / b1 完成 / b2 超时 / b3 接收错（校验、长度、帧错）/ b4 应答正确 / b[14:8] 收到字节数 / b[23:16] 舵机状态字节 |
| 0x108 | R/W | 应答超时，单位 µs（默认 3000，从发送结束起算） |
| 0x10C / 0x110 / 0x114 | R | 时间戳（75MHz 计数）：首个起始位 / 最后停止位结束 / 应答收完 —— 测试报告的帧时长与同步误差 |
| 0x118 / 0x11C / 0x120 | R | 计数：超时次数 / 接收错误次数 / 已发帧数 —— 总线稳定性统计 |
| 0x140~0x17F | W/R | 发送缓冲 64 字节：帧主体 `[ID, LEN, INSTR, 参数…]`，字节 i 在第 i/4 个字的 `[8*(i%4)+:8]` |
| 0x180~0x19F | R | 接收缓冲 32 字节：应答去掉 `FF F5` 后的 `[ID, LEN, STATUS, 参数…, CHK]` |

仿真 [pl/sim/tb_servo_bus.v](../pl/sim/tb_servo_bus.v)（`run_sim.sh servo_bus`）用协议文档原例当标准答案：PING、READ 位置、SYNC WRITE、无应答超时、错误校验，19 项全过；
SYNC WRITE 18 字节实测线上时长 1562µs，与理论值一致。

⚠ **协议文档 2.3.6 的 SYNC WRITE 例子校验值印的是 `0x8B`，但按文档自己的公式算应为 `0xBA`**（文档其余 5 个例子都与公式相符）。硬件按公式算。
真舵机上若同步写无反应，先查这里。

### 步进控制 `stepper_ctrl`（`PL_BASE + 0x200`，v2 起已接入顶层上板；⬜ 待 TB6600 实物）

[pl/rtl/stepper_ctrl.v](../pl/rtl/stepper_ctrl.v)：速度模式（传送带连续走、改速度自动平滑过渡）+ 位置模式（梯形加减速，停在精确步数）。
速度用"每时钟前进的步数"Q0.32 定点数表示：`inc = v[步/s] × 2^32 / 75e6`，单位换算由 PS 做。升降速节拍 10kHz。
模块本身输出按 TB6600 共阳接法（PUL 低有效、脉冲 5µs；换向后等 10µs 再发脉冲；ENA 使能时输出高）；**v3 起顶层 `STEP_COMMON_CATHODE=1` 反相为共阴直驱**（PUL 高有效，ENA 高 = 脱机），见 [05](05-硬件与接线.md)。
运动中可以改写 `TARGET`：传送带"停在某步"就是这么做的（减速点自动重算）。v5 起，目标若已落在运动方向身后（写得太晚），会减速停在目标之后（`AT_TARGET` = 0），不再卡在 moving。
`estop` 输入或写 HALT 立即停脉冲（不减速），置 HALTED。速度上限按每秒 5 万步用（5µs 脉冲需 10µs 周期）。

| 偏移 | R/W | 说明 |
|---|---|---|
| 0x200 | W/R | `CTRL`：b0 使能 / b1 启动（脉冲）/ b2 减速停（脉冲）/ b3 立即停（脉冲）/ b4 模式（0 速度，1 位置）/ b5 位置清零（脉冲）/ b6 速度模式方向 |
| 0x204 | R | `STATUS`：b0 运动中 / b1 方向 / b2 到位 / b3 已急停 / b4 已使能 |
| 0x208 | R/W | `TARGET` 目标位置（有符号，步） |
| 0x20C / 0x210 / 0x214 | R/W | `VMAX_INC` 巡航速度 / `ACC_INC` 每节拍速度变化 / `VMIN_INC` 起停速度 |
| 0x218 / 0x21C / 0x220 | R | `POS` 当前位置（有符号）/ `CUR_INC` 当前速度 / `STEPS` 累计步数 |
| 0x224 | R | `BRAKE`：从当前速度减速到停需要的步数（v5；PS 判断"还来不来得及停"） |

仿真 [pl/sim/tb_stepper_ctrl.v](../pl/sim/tb_stepper_ctrl.v)（`run_sim.sh stepper`）用独立脉冲监视器核对：+1000 步与 −200 步精确到位、换向建立时间 ≥10µs、
脉宽 5.0µs、最高速不超、速度模式减速停、HALT / 急停后零脉冲、ENA 极性；v5 加：巡航中 BRAKE > 0、运动中改写目标精确停住、目标改到身后减速停（越过步数 = BRAKE）不卡死，全部通过。

### PL 视觉 `des_vision`（`PL_BASE + 0x300`，v6；🔄 10-11 编译中）

[pl/rtl/des_vision.v](../pl/rtl/des_vision.v)：插在 ISP 输出（128 位 AXI-Stream，每拍 4 个 BGRA 像素，MIPI 字节时钟）与写帧 DMA 之间，不反压。对应赛题领域 3：简单级「单路 1080P 图像 PL 采集；**硬件灰度滤波**」、中级「**PL 硬件边缘检测、尺寸粗测量**」。
- 灰度 BT.601（77R+150G+29B）>>8；一块 ERAM 存两行（480×64 位）组成 3×3 窗口；高斯 [1 2 1;2 4 2;1 2 1]/16、Sobel |Gx|+|Gy|，加法树拆 3 级流水（视频时钟域 TD 不报时序，靠浅逻辑留余量）。
- **显示模式**（下一帧生效，HDMI 60fps 直接看到）：0 原图（1 拍直通）/ 1 灰度 / 2 高斯 / 3 二值（高斯 ≥ 阈值）/ 4 Sobel（饱和到 255）/ 5 边缘（Sobel ≥ 阈值）；处理模式 6 拍延迟、alpha=0。3×3 结果落在中心左一像素、上一行（不加一整行延迟，写帧时序不变）。输出源在帧起始那一拍就按新模式选，每个帧起始恰好传给写帧模块一次。
- **ROI 统计**（每帧起始发布）：二值图在 ROI（或全帧）内的面积、外接框、Σx / Σy（质心）、边缘像素数，以及每帧像素时钟数。PS 每帧把 ROI 设到离光轴最近的零件 → 每件「PL 粗测」（面积等效直径、外接框 mm）进记录，与 PS 亚像素测量并排。
- 仿真 [pl/sim/tb_des_vision.v](../pl/sim/tb_des_vision.v)（`run_sim.sh vision`，32×12 帧、tvalid 随机空拍）：6 种模式逐像素对行为模型、统计量、ROI、写到一半的设置等下一帧、帧起始计数，790 项全过。
- **参数 `LANES`**（10-11 加，布线后备）：4 = 每个像素（默认，行为不变）；2 = 每拍只处理第 0、2 个像素，滤波 / 统计逻辑约减半，处理图 960 宽、每个结果显示在 2 个像素上，统计按处理的像素计（PS `des_vis_read` 按 ACTIVE[27:24] 把面积 / 边缘数 ×4/LANES）。`run_sim.sh vision2` 同样 790 项全过。
- 资源（综合）：1073 LUT + 229 进位 + 1844 FF + 2 ERAM + 13 DSP；整片 slice 87.8% → 90.2%。⚠ 第一次 v6 布线不收敛（3.5h 冲突卡在 130 左右），10-11 14:21 重编中。

|---|---|---|
| 0x300 | R/W | `CTRL`：[2:0] 模式，[8] 全帧统计（忽略 ROI） |
| 0x304 | R/W | `THR`：[7:0] 二值阈值，[26:16] 边缘阈值 |
| 0x308 / 0x30C | R/W | `ROI_X` / `ROI_Y`：[10:0] 起，[26:16] 止（像素 / 行） |
| 0x310 | W | `APPLY`：以上设置在下一帧起始生效 |
| 0x314 | R | `ID` = 0x56495331 |
| 0x320 | R | `SEQ` 已发布统计的帧数 |
| 0x324 / 0x338 | R | `AREA` 亮像素数 / `EDGES` 边缘像素数 |
| 0x328 / 0x32C | R | `BBOX_X` / `BBOX_Y`：[10:0] 最小，[26:16] 最大 |
