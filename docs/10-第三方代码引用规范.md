# 10 · 第三方代码引用规范

> 哪些厂家源码可以放进本仓库、以什么形式放、放在哪。与 [AGENTS.md 硬性约定第 7/9 条](../AGENTS.md)配套。
> 背景盘点日期：2026-10-09（源码许可逐文件核对过，见文末附表）。

## 总原则

1. 本仓库 LICENSE 是 MIT，但它**只覆盖我们自己写的代码**；第三方文件保留其原始许可，不因入库而改变。
2. 厂家源码**不是拷进来就完事**：能入库的也优先走"底板在本机、只入库改动"的模式，减少仓库里非自研代码的比例——这对竞赛评审（PL 贡献要真实）和许可清晰都有利。
3. 本机参考底板统一放仓库外的 `../reference_src/`（73MB，含完整官方工程），**该目录永不入库**（根 `.gitignore` 或 `.zcodeignore` 可加一行 `reference_src/`）。

## 分类结论

### A. 可以直接入库（许可明确允许）

| 源码 | 许可 | 入库位置 | 形式 |
|---|---|---|---|
| face_detection 推理链（推理流水线、YOLOv8/YOLO 后处理、预处理、相机/HDMI 封装，30 个文件） | **MIT**（安路版权头） | `ps/vision/`（已入，作为零件检测改造起点，非冻结第三方） | 保留原版权头，文件头加一行"derived from Anlogic face_detection \<原路径\>"；改动大的可以重写（MIT 允许），重写后就是我们自己的 MIT 代码 |
| 安路内核驱动源码 `mipicam.c`、`anlogic-vdmafb.c`、`anlogic-dynclk.c` | **MIT / GPL-2.0**（安路） | `ps/kernel_modules/`（新增目录） | 仅当我们需要改驱动时才入；原样能用的不入库，板上加载厂家 .ko |
| 安路 GPL-2.0 驱动（cma_mem / hard_npu / soft_npu） | **GPL-2.0** | `ps/kernel_modules/` | 同上；GPL 文件单独目录 + 目录内 README 注明"本目录 GPL-2.0"，避免与 MIT 混淆 |
| JPU 驱动（C&M Chips&Media） | BSD-3 / LGPL-2.1 双许可 | `ps/kernel_modules/jpu_driver/`（如需） | 保留双许可头 |

### B. 修改底板模式（底板入库，只提交改动）

2026-10-09 决定：底板工程**直接入库**（`pl/soc_base/`，soc_prj 完整工程含加密 IP），改动增量仍走 `soc_patch/` 镜像模式。加密 IP 文件仅随底板工程使用，禁止单独提取分发。

| 内容 | 底板（已入库 `pl/soc_base/`） | 入库什么 |
|---|---|---|
| 主线 PL 工程 `soc_prj` | `soc_base/`（TD 6.2.1 完整工程，2026-10-09 入库） | 底板原样入库；我们改过/新增的文件**另入 `pl/soc_patch/`**，按原相对路径镜像：改过的 `system_top.v`、新增 `rtl/axi_lite_regs.v` 等、`constraint/` 增量、`design_0` 若改动则记录 TCL/说明。TD 统一用 6.2.1（2026-10-10 决定，不产生格式升级）；若误用 2026.1/6.2.2 打开，产生的**格式升级 diff 不提交** |
| 官方明文 Verilog 复用（`uiFDMA.v`、`uidbuf.v`、`axis_sobel.v`、`matrix_3x3.v`、`shift_ram.v`、`pwm.v`、ISP 各模块） | 同上 | 官方文件**无版权头**（厂家 demo 预期被修改）。两种做法任选：<br>① 引用不拷贝——soc_patch 说明"覆盖回哪些文件"，底板已在库内直接引用；<br>② 拷贝时在文件头注明"derived from Anlogic soc_prj/src/…；本仓库修改：…"。**推荐 ①**，保持 PL 目录里几乎全是自研代码 |
| FSBL / U-Boot 固定零件 | `scripts/bootbin/parts/`（fsbl.elf、u-boot.elf 已入库，2026-10-09） | 编译产物入库（BOOT.bin 中不随 PL/应用重编而变）；MD5 与重打包验证记录在 docs/log。只有改 FSBL 源码时才把改动 .c 入 `scripts/bootbin/fsbl_patch/` |
| VID006 csiA 基线工程 | `vid006_csiA_imx415_to_hdmi/`（本机 reference） | 同 soc_prj 模式（若最终以它为 PL 基线再入库） |

### C. 禁止入库（只能本机参考）

| 内容 | 原因 |
|---|---|
| **米联客全部培训 demo / 例程**（`fdma_vdma_imx415_training/`、02_peripheral_demo、board_test 等） | 文件头明确 "Copyright (c) MiLianKe, All rights reserved. The reference demo … only used for learning"，无开源许可 → 拷贝入库有版权风险。**可以看、可以学思路，代码必须自己重写**。评审时我们的 PL 贡献也经不起"抄米联客"的质疑 |
| 加密 `.enc.v`（MIPI D-PHY、HDMI TMDS）、`NPU_SOFT_0` / `Video_NPU_0` 加密 IP | 闭源，物理上也读不了 |
| U-Boot、内核 uImage、rootfs、ArmNN/Alnpu 库（`libarmnn.so`） | 厂家二进制，AGENTS.md 第 7 条已排除 |
| `reference_src/` 整个目录 | 参考底板汇总，含上述全部 |
