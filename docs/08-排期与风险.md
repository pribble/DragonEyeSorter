# 08 · 排期与风险

> 进度安排与风险跟踪。

## 排期（约 50 天，末周留缓冲）

| 周 | 目标 | 交付 |
|---|---|---|
| W1 | 验证 + 下单 + 开采数据 | W1 清单全绿；硬件全部下单；布局定死 |
| W2 | 三条线各自打通 | PL：采集显示 + 运动控制骨架；PS：Linux + AXI 读写；数据集 v1 标注完成 |
| W3 | 模型上板 + 预处理流水线 | 自训量化模型上板实测；PL 图像算子链 |
| W4 | 闭环 | 检测 → 跟踪 → 分拣全链路；单总线；保护逻辑 |
| W5 | UI + 存储 + 双总线 | Qt UI；数据库 + NG 图；CAN 并行；Web UI；测试脚本框架 |
| W6 | 冲创新项 | 精度标定、连续运行、插补、语音 + LLM 等 |
| W7 | 收尾，**不写新功能** | 测试报告、作品文档、演示视频、代码整理、缓冲 |

**三条并行关键路径**：① 硬件到货 → 数据采集；② NPU 工具链 → 模型上板；③ PL 视频通路 → 运动控制。任何一条卡住立刻报警，不要闷头等。
