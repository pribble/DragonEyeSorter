# 14 · 板卡初始配置

> 首次使用板子时的网络、SSH、目录初始化。后续部署见 [docs/09-开发环境与构建.md](09-开发环境与构建.md)。

## 硬件连接

### 1. SD 卡与拨码开关

- **SD 卡**：插入厂家预装系统的 SD 卡（或自制的持久化镜像）
- **拨码开关**（板子上 SW1，3 位）：
  - **ON-OFF-OFF** - 从 SD 卡启动（日常使用）
  - OFF-OFF-OFF - 从 eMMC 启动（出厂系统，救生艇，保持原样）

### 2. 网络连接

**推荐方式：直连电脑网口**

- 网线一端插板子的 **PS 网口**（RJ45，靠近 USB 接口那个）
  - 网线接 **PS 网口**（PL 网口需要比特流里有对应网卡逻辑，当前工程不支持）
- 另一端插电脑的有线网口（或 USB 网卡）

**替代方式：通过路由器**

- 板子和电脑都接入同一路由器（有 DHCP）
- 需通过串口或路由器管理界面查看板子获取的 IP

### 3. 串口连接（可选，用于调试和首次配置）

- **USB-TTL 转换器**（3.3V TTL 电平）：
  - TX → 板子 RX（J10 引脚 2，靠近 HDMI 接口）
  - RX → 板子 TX（J10 引脚 3）
  - GND → 板子 GND（J10 引脚 1）
- **串口参数**：115200 8N1，无流控
- **终端软件**：
  - Windows: PuTTY、SecureCRT、MobaXterm
  - Linux/WSL: `screen /dev/ttyUSB0 115200` 或 `minicom`

## PC 端网络配置

### Windows 10/11

#### 选项 A：静态 IP（推荐）

1. 控制面板 → 网络和 Internet → 网络连接
2. 右键"以太网"（或 USB 网卡）→ 属性
3. 双击"Internet 协议版本 4 (TCP/IPv4)"
4. 选择"使用下面的 IP 地址"：
   - IP 地址：`192.168.137.1`
   - 子网掩码：`255.255.255.0`
   - 默认网关：（留空）
   - DNS：（留空或使用当前）
5. 确定，关闭

#### 选项 B：Internet 连接共享（如需板子联网）

1. 控制面板 → 网络连接
2. 右键"WLAN"（你的主网络）→ 属性 → 共享
3. 勾选"允许其他网络用户通过此计算机的 Internet 连接来连接"
4. 家庭网络连接选择"以太网"（连板子那个）
5. 确定

⚠ 共享后以太网会自动改为 `192.168.137.1/24`，与板子固定 IP 方案一致。

### Linux

```bash
# 查看网卡名称
ip link

# 设置静态 IP（临时，重启失效）
sudo ip addr add 192.168.137.1/24 dev eth0  # 替换 eth0 为实际网卡名

# 持久化配置（Ubuntu/Debian）
sudo nano /etc/netplan/01-netcfg.yaml
```

添加：
```yaml
network:
  version: 2
  ethernets:
    eth0:  # 替换为实际网卡名
      addresses:
        - 192.168.137.1/24
```

应用配置：
```bash
sudo netplan apply
```

## 板端网络配置

### 首次登录

**方式 1：通过串口（推荐）**

串口连接后，启动板子，等待启动完成（约 30 秒），出现登录提示：

```
Welcome to Buildroot
buildroot login: root
Password: （默认为空，直接回车；或查看板卡手册）
```

**方式 2：通过临时 DHCP IP（如连接了路由器）**

板子默认通过 DHCP 获取 IP，查看路由器管理界面或用 `nmap` 扫描：

```bash
nmap -sP 192.168.1.0/24  # 替换为路由器网段
```

找到设备名为 "buildroot" 或 MAC 地址为安路板的 IP，然后 SSH 登录。

### 配置固定 IP（持久化）

登录板子后，编辑 dhcpcd 配置：

```bash
# 备份原配置
cp /etc/dhcpcd.conf /etc/dhcpcd.conf.orig

# 追加固定 IP 配置
cat >> /etc/dhcpcd.conf << 'EOF'

# DragonEyeSorter 固定 IP 配置（2026-10-09）
interface eth0
static ip_address=192.168.137.100/24
static routers=192.168.137.1
EOF

# 应用配置（重启网络或重启板子）
reboot
```

重启后，板子固定为 `192.168.137.100`。

### 验证网络连通

**从 PC 端测试**：

```powershell
# Windows PowerShell 或 Linux 终端
ping 192.168.137.100
# 应看到回复：Reply from 192.168.137.100: bytes=32 time<1ms TTL=64
```

**从板子端测试**（通过串口）：

```bash
ping 192.168.137.1  # PC 端 IP
# 应看到回复
```

## SSH 密钥配置

### 1. 生成密钥对（PC 端）

```powershell
# Windows PowerShell（或 WSL/Linux 终端）
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_anlu -C "dragon-eye-sorter"
# 提示输入 passphrase 时可直接回车（无密码），或设置密码增强安全性
```

生成两个文件：
- `~/.ssh/id_ed25519_anlu` - 私钥（仅本机保管）
- `~/.ssh/id_ed25519_anlu.pub` - 公钥（上传到板子）

### 2. 上传公钥到板子

**方式 1：使用 ssh-copy-id（推荐，Linux/WSL/Git Bash）**

```bash
ssh-copy-id -i ~/.ssh/id_ed25519_anlu.pub root@192.168.137.100
# 输入 root 密码（默认为空或查看手册）
```

**方式 2：手动拷贝（Windows PowerShell）**

```powershell
# 读取公钥内容
Get-Content ~/.ssh/id_ed25519_anlu.pub

# 通过串口登录板子，执行：
mkdir -p /root/.ssh
cat >> /root/.ssh/authorized_keys << 'EOF'
<粘贴上面读取的公钥内容>
EOF
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
```

**方式 3：通过 scp（需先密码登录）**

```bash
scp ~/.ssh/id_ed25519_anlu.pub root@192.168.137.100:/tmp/key.pub
ssh root@192.168.137.100
mkdir -p /root/.ssh
cat /tmp/key.pub >> /root/.ssh/authorized_keys
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
rm /tmp/key.pub
exit
```

### 3. 测试免密登录

```powershell
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
# 应直接登录，无需输入密码
```

### 4. 配置 SSH 快捷方式（可选）

**Windows PowerShell / Linux**

编辑 `~/.ssh/config`：

```
Host dragon-eye
    HostName 192.168.137.100
    User root
    IdentityFile ~/.ssh/id_ed25519_anlu
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

之后可简化为：

```bash
ssh dragon-eye
scp myfile dragon-eye:/root/des/
```

### 5. 首次连接警告处理

如果首次连接报错：

```
WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!
```

**原因**：旧 initramfs 系统每次开机重新生成主机密钥。

**解决方法**：

1. 通过串口登录板子，查看当前主机密钥指纹：

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
# 输出类似：256 SHA256:xxxxx... root@buildroot (ED25519)
```

2. PC 端移除旧记录：

```bash
ssh-keygen -R 192.168.137.100
```

3. 重新连接，输入 `yes` 信任新指纹。

⚠ **持久化根分区后主机密钥不再变化**，只需处理一次。

## 板上目录初始化

### 1. 创建工作目录

```bash
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100

# 创建项目目录
mkdir -p /root/des          # 主程序、模型、数据
mkdir -p /root/des/data     # 运行数据（日志、采集图像）
mkdir -p /root/bin          # 工具脚本

# 验证
ls -ld /root/des /root/bin
```

### 2. 验证板上环境

```bash
# 检查内核版本
uname -a
# 应输出：Linux buildroot 6.1.111-rt42 #1 SMP PREEMPT_RT ...

# 检查 ArmNN 库
ls /opt/armnn_lib/lib/libarmnn.so
# 应存在

# 检查 OpenCV
ls /opt/ffmpeg_opencv4.7.0_aarch64/lib/libopencv_core.so.4.7
# 应存在

# 检查可用内存
free -h
# Total 应为 1.9G 左右

# 检查磁盘空间
df -h
# /dev/mmcblk0p2 应有 3.5G 左右可用
```

### 3. 设置时间（板子无 RTC）

板子每次开机时间从 1970-01-01 开始，需手动设置或联网对时。

**方式 1：手动设置**

```bash
date -s "2026-10-15 14:30:00"
date  # 验证
```

**方式 2：联网对时（如 PC 共享了网络）**

```bash
# 板子需能访问外网
ntpdate pool.ntp.org
```

**方式 3：从 PC 同步时间**

在 PC 端（PowerShell）：

```powershell
$timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100 "date -s '$timestamp'"
```

### 4. 配置启动脚本（可选）

如果希望应用开机自启动，编辑 `/etc/init.d/S99des`：

```bash
cat > /etc/init.d/S99des << 'EOF'
#!/bin/sh
case "$1" in
  start)
    echo "Starting DragonEyeSorter..."
    cd /root/des
    # 设置时间（从 PC NTP 或固定值）
    date -s "2026-10-15 09:00:00"
    # 启动主程序（后台运行）
    # ./des_app run --log /root/des/data/app.log &
    ;;
  stop)
    echo "Stopping DragonEyeSorter..."
    killall des_app
    ;;
  *)
    echo "Usage: $0 {start|stop}"
    exit 1
esac
exit 0
EOF

chmod +x /etc/init.d/S99des
```

⚠ 默认注释掉自启动，调试完成后再启用。

## 验证配置

从 PC 端依次验证：

```powershell
# 1. 网络连通
ping 192.168.137.100

# 2. SSH 免密登录
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100 "uname -a"
# 应直接输出内核版本

# 3. SCP 文件传输
echo "test" > test.txt
scp -i ~/.ssh/id_ed25519_anlu test.txt root@192.168.137.100:/root/des/
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100 "cat /root/des/test.txt"
# 应输出 "test"

# 4. 板上库环境
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100 "ls /opt/armnn_lib/lib/libarmnn.so"
# 应无错误
```

全部通过后，板卡初始配置完成。

## 常见问题

### 网络连通问题

**Q: ping 192.168.137.100 超时**

A: 检查清单：
1. 网线是否插在 **PS 网口**（不是 PL 网口）
2. PC 端网卡 IP 是否为 `192.168.137.1/24`（`ipconfig` 查看）
3. 板子是否已配置固定 IP（通过串口登录检查 `/etc/dhcpcd.conf`）
4. 板子是否启动完成（串口看到登录提示）
5. 防火墙是否阻止（临时关闭 Windows 防火墙测试）

---

**Q: 板子 ping 得通，但 SSH 连接超时**

A: 检查：
1. 板上 SSH 服务是否运行：`ps | grep sshd`（通过串口）
2. PC 端防火墙是否阻止 22 端口
3. 板上是否允许 root 登录：检查 `/etc/ssh/sshd_config` 中 `PermitRootLogin` 是否为 `yes`

---

**Q: 网络时好时坏，频繁断连**

A: 
1. 检查网线质量，更换网线测试
2. 检查 USB 网卡驱动（如使用 USB 转网口）
3. 禁用网卡的节能模式：设备管理器 → 网络适配器 → 属性 → 电源管理 → 取消勾选"允许计算机关闭此设备以节约电源"

### SSH 密钥问题

**Q: ssh-copy-id 报 "No such file or directory"**

A: Windows PowerShell 默认无 `ssh-copy-id` 命令，使用：
- Git Bash（安装 Git for Windows 后自带）
- WSL 终端
- 或采用"方式 2：手动拷贝"

---

**Q: SSH 连接仍要求输入密码**

A: 检查：
1. 板上 `/root/.ssh/authorized_keys` 权限：`chmod 600 /root/.ssh/authorized_keys`
2. 板上 `/root/.ssh/` 目录权限：`chmod 700 /root/.ssh`
3. 板上 `/root/` 目录权限：`chmod 755 /root` 或 `700`
4. SSH 命令是否指定了正确的私钥：`ssh -i ~/.ssh/id_ed25519_anlu ...`
5. 板上 SSH 配置是否允许公钥认证：检查 `/etc/ssh/sshd_config` 中 `PubkeyAuthentication yes`

---

**Q: 报 "WARNING: UNPROTECTED PRIVATE KEY FILE!"**

A: 私钥文件权限过宽，修复：

```powershell
# Windows PowerShell
icacls ~/.ssh/id_ed25519_anlu /inheritance:r
icacls ~/.ssh/id_ed25519_anlu /grant:r "$env:USERNAME:(R)"
```

```bash
# Linux/WSL
chmod 600 ~/.ssh/id_ed25519_anlu
```

### 板上操作问题

**Q: /root/des/ 目录不存在**

A: 首次需手动创建：`ssh ... root@192.168.137.100 "mkdir -p /root/des"`

---

**Q: 板上运行命令报 "sh: xxx: not found"**

A: Buildroot 精简系统，许多常见工具不存在（如 `bash`, `apt`, `python`）。使用 BusyBox 提供的精简版本，或自行编译并上传。

---

**Q: 如何安装新软件包？**

A: 板上无包管理器。两种方式：
1. 交叉编译后上传静态链接的二进制
2. 重新构建 Buildroot rootfs（需米联客 Linux 开发包）

---

**Q: 如何持久化板上修改？**

A: 
- 根分区（`/`）已持久化，普通文件修改会保留
- 系统配置文件（如 `/etc/dhcpcd.conf`）已持久化
- 每次修改后建议 `sync` 确保写入磁盘
- 关机前运行 `poweroff` 或先 `sync` 再断电
