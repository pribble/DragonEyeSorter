# 运动控制与分拣

> 接线见 [硬件与接线](硬件与接线.md)。

## 机械臂（6 轴）

德晟 DS-SY15A 串口总线舵机，菊花链，**PL 直驱总线（经 BSS138）**；PS 算 IK 与路径点，PL 管 SYNC WRITE 帧时序与遥测。

| 轴 | 作用 | 说明 |
|---|---|---|
| #1 | 底座偏航 | 横向覆盖 + 决定放哪个料盒 |
| #2 | 大臂俯仰 | 受力最大，电流监测重点 |
| #3 | 小臂俯仰 | |
| #4 | 腕俯仰 | 补偿 #2/#3，保持夹爪垂直向下 |
| #5 | 腕旋转 | 对准视觉给出的物料角度 θ |
| #6 | 夹爪 | 电流 + 位置回读判定是否夹住 |

- 协议：德晟 v4.01，115200 半双工，帧头 `FF FF`；**SYNC WRITE(0x83)** 与 REG WRITE + ACTION 均可广播同步；可回读位置(0x38) / 电流(0x2E) / 温度(0x3F)。
- 抓取确认（P1）：闭合时电流上升且停在该类宽度附近 = 夹住；全闭 + 低电流 = 抓空。
- 安装：侧装优先（与带面等高或更高），正上方倒挂备选；够不着的区域用挡板限定摆放区。
- PWM 双驱动：六舵机信号脚同一电气节点，做 PWM 必须改星型布线 → 降为 P2 对比实验。

### 上电调试（`des_app arm`，仅未接舵机时自测过）

1. **上电前**：逐个量舵机 V+~GND 电阻（C4）；降压模块设 **6.8V、限流约 5A**，舵机链只从 #1 链头进电（#6 夹爪只有固定接口）。电平转换与管脚见 [硬件与接线](硬件与接线.md)（CEP PIN19，经 BSS138）。
2. `des_app arm scan`：6 个舵机都应回应（打印位置 / 电流 / 温度 / 状态位）；全无回应 → 查电源、BSS138 接线、ID 1~6。再用 `desreg sync` 发一帧 SYNC WRITE，核对协议文档该例的校验值（文档印 `0x8B`，按公式应为 `0xBA`，PL 按公式算）。
3. **示教**：`des_app arm torque-off` 后手摆到回零 / 各料盒位置，每次 `des_app arm teach` 把打印的 `[q1..q5]` 填进 `des_app.json` 的 `arm.home_deg` / `arm.bins_deg`，再 `torque-on`。各关节零位（`zero_count`）与方向（`counts_per_deg` 正负）按「`arm read` 打印角度 = 实际几何角度」校。
4. **运动**：先空跑看舵机码（默认只打印），无误再加 `--go`：`arm home --go`（单步 1.5s，故意慢）→ `arm goto <x> <y> --go` → `arm pick <x> <y> [角度] [料盒] --go`。料盒 / 回零姿态超出关节软限位会被拒绝（`plan_pick` 检查）。
5. 夹取确认：闭合后读 #6 位置，比闭合命令差 1.5mm 以上 = 夹住了，完全闭合 = 空抓（阈值 ⚠ 上实物再调）。
6. **手眼标定**（`des_app calib-arm`，⬜ 待实物；须在相机标定 + 关节零位校好后做）：交互式逐点：放标记物让相机定位，再手掰夹爪尖碰标记中心读关节角（正运动学）；≥3 点最小二乘求 `table = base + R(yaw)·arm`（与 `table_to_arm` 同约定），`--marker-h` 给标记物厚度时顺带求带面高度 `belt_z`；结果写 calib.json 的 `arm` 段（load_config 合并、calib-cam 重跑保留）。单测 `test_scheduler` 9 项：±0.4mm 误差下底座 <1mm、朝向 <0.3°、带面 <0.3mm；放错一点残差明显变大；点太少 / 太挤拒绝。

## 传送带跟踪抓取（conveyor tracking）

```
X_now = X_拍摄 + (POS_now − POS_拍摄) · k        Y 不变        θ 由视觉给出
```

- POS 来自编码器（P1）；✅ 已定：主线先用 PL 步进脉冲计数（轻载开环不丢步），编码器后接同一位置接口。
- **帧起始锁存**（P1，`enc_frame_latch`）：PL 在 MIPI 帧起始那一拍锁存带位置并绑定帧号，消除 PS 推理延迟的 ±1~2mm 基准抖动。
- 停带时坐标自动冻结，加减速、反转也自动正确。

### 工位布局（沿带方向，✅ 已采纳）

上料 → 相机视野（检测 + 多帧融合）→ 视野外短跟踪段 → **对射到位线**（抓取线上游 40~60mm）→ **抓取工位**（机械臂侧装，不进相机视野）→ 带尾翻板。视野下游边到抓取线合计 60~80mm。

- **谁触发停带**：跟踪表 + 带位置（"下一个要夹的 OK 件的 X 到达抓取线"），**不是光电**。
- **对射**：到位确认 + X 校正（实测前沿 vs 预测前沿，差值即报告里的"跟踪误差"）+ 异常报警（有边沿无预测 = 视觉漏检；有预测无边沿 = 件丢失）。漏检件补建记录（类别未知）→ 翻板送复检。
- 夹爪下探不得切到光束；光束离带面 ≤5mm。

### 传送带什么时候停

| 情形 | 动作 |
|---|---|
| 下一个 OK 目标（已过间隙检查）到抓取线 | 减速停 → 下探 → 夹 → **抬起即恢复走带** |
| 目标到了、臂还没回来 | 停等 |
| 异常 | 反转回退复检（P2）或放行进复检箱 |
| 安全 / 故障 | 急停；失步 / 打滑 / 卡带；舵机过流 / 过温 / 总线超时；对射长时间被挡；跟踪表溢出 |
| 其他 | 料盒满；UI 暂停；CAN 模拟 PLC 联锁暂停 |
| **不停** | NG / 复检件（翻板在线分流）；机械臂放料、回位期间 |

### 夹取碰到邻件

预防：间隙检查（夹爪张口按该类宽度设，两指占位矩形与邻件外扩区求交，θ 与 θ+90° 都试）+ 垂直下探 / 抬起。发现：抓空 / 宽度不符 / 对射对不上。兜底：过不了间隙检查的件不抓，流到带尾进复检箱。演示规则写明最小件间净距，并故意放一组贴死的件演示"识别 → 跳过 / 复检"。

## 带尾翻板（✅ 选项 C）

- 装在带尾下方，件从带尾落下时由 MG996R 翻板打向不同出口，只作用于刚离开带面的件，**不误伤**。
- 两级串联：第 1 级 **复检 vs NG**，第 2 级 **返修 vs 报废**；先做第 1 级（P1），第 2 级 P2。
- 分流规则做成 UI 可配的"类别 + 分级 → 出口"映射表；去不同出口的两件同时到带尾 → 一律复检。
- PL 在件到达带尾那一刻打出 IO —— 对应赛题"NG 不良品输出 IO 控制""不良品实时分拣触发"。
- 做不出来就退回：机械臂 OK / NG 全夹，带尾放被动复检箱。

## 跟踪表

每件一个 ID，状态 `New → Tracking → Decided →（抓取 Picking | 带尾翻板 / 复检）→ Done`（实现命名见下）；冷却按"离开工位的带位置距离"而非定时器。槽满的件直接走到带尾进复检，不排队堆积。

**实现**：`ps/scheduler/tracker`（状态 New → Tracking → Decided → Picking → Done）+ `picker`（停带 / 夹取 / 翻板）+ `ps/app/belt_ctl`（停带计划 → PL 步进位置模式命令：Run = 目标设在远处、StopAt = 运动中改写目标（PL 重算减速点，停在那一步）、Hold = 机械臂在带面上不动；停住后绝不倒车去追身后的目标）。
- 跟踪丢失只在**整件**都应在视野内时计数（50mm 齿条在视野出口不再被误判为丢失），已判定的件不再计丢失。

**硬件在环测试**（`ps/tests/test_belt_hil.cpp`，板上 PL v5，不接电机）：模拟零件骑在"真实步进计数"上走，模拟相机（含边缘半截件）→ 跟踪表 → 调度 → `BeltDriver` → PL 步进。12 件（8 良品 4 NG，间距 70mm，抓取线在视野下游 80mm，模拟机械臂 0.3s 下探 + 0.7s 放料）：

| 带速 | 结果 |
|---|---|
| 50 mm/s | 8 件全抓、4 件到带尾；**停带误差最大 0.04mm**（1~2 步）；无来不及停、无机械臂下探时动带；22.7 件/分 |
| 100 mm/s | 同上，39.3 件/分 |
| 150 mm/s | 同上，48.9 件/分 |

## 节拍口径

机械臂取放最慢（数百 ms 量级），推理不是约束；只有 OK 件停带。报告分"纯检测节拍"与"含分拣节拍"两个数。
