> 接线见 [硬件与接线](硬件与接线.md)；实测数字见 [测试与验证](测试与验证.md)。

## 机械臂（6 轴）

德晟 DS-SY15A 串口总线舵机，菊花链，**PL 直驱总线（经 BSS138）**；PS 算 IK 与路径点，PL 管 SYNC WRITE 帧时序与遥测。

| 轴 | 作用 | 说明 |
|---|---|---|
| #1 | 底座偏航 | 横向覆盖 + 决定放哪个料盒 |
| #2 | 大臂俯仰 | 受力最大，电流监测重点 |
| #3 | 小臂俯仰 | |
| #4 | 腕俯仰 | 补偿 #2/#3，保持夹爪垂直向下 |
| #5 | 腕旋转 | 对准视觉给出的物料角度 θ |
| #6 | 夹爪 | 电流 + 位置回读判定是否夹住 |

- 协议：德晟 v4.01，115200 半双工，帧头 `FF FF`；**SYNC WRITE(0x83)** 与 REG WRITE + ACTION 均可广播同步；可回读位置(0x38) / 电流(0x2E) / 温度(0x3F)。
- **关节软限位**（`des_app.json` 的 `arm.joints`）：1~5 号 ±145°（300° 舵机），夹爪 ±88°（180° 舵机）。标定零位后用界面「机械臂」页实测机械极限再收紧；料盒 / 回零姿态越限会被 `plan_pick` 拒绝。
- 抓取确认（P1）：闭合时电流上升且停在该类宽度附近 = 夹住；全闭 + 低电流 = 抓空。
- 安装：侧装优先（与带面等高或更高），正上方倒挂备选；够不着的区域用挡板限定摆放区。
- **#5 腕旋零位约定**：#5 在 2048（中位）时，**两指沿径向闭合**（夹爪竖直朝下、从上往下看，一指靠近底座、一指远离）= 配置 `grip_axis_at_zero_deg = 0`；装成两指左右（切向）闭合则改成 90。重装夹爪后在界面「机械臂」页重新「设为初始姿态」。

**可达范围**（按实测夹爪，抓取点 = 指尖、抓取高 3 / 安全高 60 都要解得出，关节 ±145°，单位 = 离底座轴水平半径 mm）：

| 底座板相对带面 | 竖直 | 倾 20° | 倾 30° | 倾 40° |
|---|---|---|---|---|
| 低 60 | 22~116 | 65~169 | 87~193 | 115~215 |
| 低 30 | 40~140 | 90~190 | 109~211 | 125~230 |
| 齐平 | 51~155 | 94~202 | 108~221 | 117~238 |
| **高 30** | **42~163** | **91~206** | 110~219 | 125~229 |
| 高 60 | 51~155 | 94~195 | 107~207 | 114~214 |
| 高 90 | 40~140 | 74~178 | 81~187 | 96~190 |

零件走皮带中线 ±30mm → 底座轴离中线 d 时要够 d−30 ~ d+30（再加抓取线前后 ±20）。**推荐底座板比带面高 0~30mm、底座轴离中线 150~170mm**（底座伸到带边上方）：竖直覆盖到 ~160，外侧由倾 20° 补；底座只能放在侧框外（d ≈ 220）时只能靠倾 40°（最远 ~238）。`des_app.json` 现填 `base_xy` y = −170。

**倾斜下探（已实现）**：竖直够不着时，圆形零件允许夹爪朝外倾斜（`arm.max_tilt_deg` 40、`tilt_step_deg` 5，取最小能到的倾角；下探仍竖直走）。倾斜时两指必须沿**切向**闭合（垂直于底座→零件连线），所以 Picker 对圆形件先试切向（`picker.tangential_first`，由 max_tilt_deg > 0 打开），`arm_ik` 对非切向的倾斜请求直接拒绝。`test_scheduler` 含 12 项倾斜下探检查（见 [测试与验证](测试与验证.md)）。

**夹爪实测**：#4 转轴 → 指尖应合拢点约 **106mm**（`l_tool` 27；两指全合时实际先碰在橡胶套下端约 86mm，抓 10mm 厚齿轮时下面的指尖会先顶到带面 → 指尖缠胶布加粗，让末端先合上）；指尖中心偏离 #5 转轴 **9mm**（`tool_offset_mm`，运动学已按 #5 转角补偿，否则抓取点随 #5 转动画半径 9mm 的圆）；#6 舵机最低点离指尖竖直约 70 / 横向约 40mm → 竖直夹取碰不到；**倾斜下探时让舵机在外侧**（`servo_side_deg` ±90，符号零位标定时确认）。

- **夹爪始终朝下（10-22，用户提醒）**：夹爪长 190mm，从「夹爪朝上 / 水平」的姿态直接转去抓取，关节空间插值会让夹爪经过水平、朝前横扫过皮带（可能碰对面灯条）。规则：初始姿态（ready）、料盒姿态、抓取各点都必须夹爪朝下（q2+q3+q4 ≤ −40°，倾斜下探最多 40°）；夹爪俯仰角是关节角的线性组合，两端都朝下时插值全程朝下。`plan_pick` 对当前姿态 / 初始姿态 / 料盒姿态不朝下的直接拒绝（「reset the arm to the ready pose first」/「teach it again」）；真动（--go）时每次抓取前先读舵机实际位置再规划；界面「复位」时夹爪方向与初始姿态差 >60° 拒绝，提示先手动摆。`test_scheduler` 256 项。
- **6 号舵机别朝底座**（10-21 零位标定时实测：小臂平伸、夹爪朝下、离底座轴约 83mm 时，6 号舵机朝底座一侧会撞到底座转台）：竖直夹取时若舵机朝向底座超过 60° 且抓取点离底座轴 < `arm.servo_in_min_r_mm`（默认 120），`arm_ik` 改用 q5 ± 180°（同一条合拢线、舵机换到另一侧），5 号关节转不到就报「servo would face the base」，Picker 换另一个合拢方向。`test_scheduler` 249 项含 24 项近底座检查。示教料盒 / 初始姿态时同样注意。
- **零位与计数比例（10-22 已标，扭矩关手摆 + 水平仪）**：#1~#5 零位 2012 / 3085 / 1977 / 1986 / 1985，计数 / 度 +12.47 / −12.14 / −12.33 / −12.13 / −12.6（规格书约 13.0、各舵机差约 2%；原配置 13.65 错）；q1 = 0 时手臂垂直指向皮带（`base_yaw_deg` −90，机械臂在台面 +y 侧）；#5 = 1985 时两指切向合拢、6 号舵机朝底座（`grip_axis_at_zero_deg` 90、`servo_side_deg` 90）。夹爪开口与计数**不成正比**（连杆）：`grip_table` = 全合 2919 / 32mm 2318 / 全开 61mm 1195 分段线性。数据与校验见 [log/2026-10-22](log/2026-10-22-机械臂零位标定.md)。
- PWM 双驱动：六舵机信号脚同一电气节点，做 PWM 必须改星型布线 → 降为 P2 对比实验。

### 上电调试步骤（`des_tool arm`）

1. **上电前**：逐个量舵机 V+~GND 电阻；降压模块设 **6.8V、限流约 5A**，舵机链只从 #1 链头进电。电平转换与管脚见 [硬件与接线](硬件与接线.md)（CEP PIN19，经 BSS138）。
2. `des_tool arm scan`：6 个舵机都应回应（打印位置 / 电流 / 温度 / 状态位）；全无回应 → 查电源、BSS138 接线、ID 1~6。
3. **示教**：`des_tool arm torque-off` 后手摆到回零 / 各料盒位置，每次 `des_tool arm teach` 把打印的 `[q1..q5]` 填进 `des_app.json` 的 `arm.home_deg` / `arm.bins_deg`，再 `torque-on`。各关节零位（`zero_count`）与方向（`counts_per_deg` 正负）按 `arm read` 打印角度 = 实际几何角度校。
4. **运动**：先空跑看舵机码（默认只打印），无误再加 `--go`：`des_tool arm home --go`（单步 1.5s，故意慢）→ `arm goto <x> <y> --go` → `arm pick <x> <y> [角度] [料盒] --go`。
5. 夹取确认：闭合后读 #6 位置，比闭合命令差 1.5mm 以上 = 夹住了，完全闭合 = 空抓（阈值 ⚠ 上实物再调）。
6. **手眼标定**（`des_tool calib-arm`，⬜ 待实物；须在相机标定 + 关节零位校好后做）：交互式逐点——放标记物让相机定位，再手掰夹爪尖碰标记中心读关节角（正运动学）；≥3 点最小二乘求 `table = base + R(yaw)·arm`（与 `table_to_arm` 同约定），`--marker-h` 给标记物厚度时顺带求带面高度 `belt_z`；结果写 `calib.json` 的 `arm` 段（`load_config` 合并、`calib-cam` 重跑保留）。测试项见 [测试与验证](测试与验证.md)。

## 传送带跟踪抓取（conveyor tracking）

```
X_now = X_拍摄 + (POS_now − POS_拍摄) · k        Y 不变        θ 由视觉给出
```

- POS 来自 PL 步进脉冲计数（轻载开环不丢步）；编码器后接同一位置接口（先用来验证打滑）。
- **帧起始锁存**（`enc_frame_latch`）：PL 在 MIPI 帧起始那一拍锁存带位置并绑定帧号，消除 PS 推理延迟的 ±1~2mm 基准抖动。
- 停带时坐标自动冻结，加减速、反转也自动正确。

### 工位布局（沿带方向，✅ 已采纳）

上料 → 相机视野（检测 + 多帧融合）→ 视野外短跟踪段 → **对射到位线**（抓取线上游 40~60mm）→ **抓取工位**（机械臂侧装，不进相机视野）→ 导流挡板（抓取线下游）→ 带尾复检箱。视野下游边到抓取线合计 60~80mm。

- **谁触发停带**：跟踪表 + 带位置（"下一个要夹的 OK 件的 X 到达抓取线"），**不是光电**。
- **对射**：到位确认 + X 校正（实测前沿 vs 预测前沿，差值即报告里的"跟踪误差"）+ 异常报警（有边沿无预测 = 视觉漏检；有预测无边沿 = 件丢失）。漏检件补建记录（类别未知）→ 带尾复检。
- 夹爪下探不得切到光束；光束离带面 ≤5mm。
- ⚠ 现有 M12 传感器是**电感式接近开关**（Aotochs LJ12A3-4-Z/BX：检测距离 4mm、NPN 常开、6~36V）——只感应 4mm 内的**金属**，看不见 POM 零件，不能当到位传感器；可留作皮带打滑检测（从动辊端面装螺钉，每转一个脉冲，P2）。到位确认要另买对射型光电开关（P1）。

### 带速自适应（`sched/picker` 的 `SpeedAdaptConfig` / `adapt_speed`）

机械臂接到任务时按规划的各段动作时间算出「回到初始姿态」的时刻；之后若下一个良品离抓取线 d、机械臂还要 t 秒才空闲，带速改为 max(`min_mm_s`, d / t)（不超过设定带速），让零件差不多在臂空出来时到线——少一次「急刹 → 等待 → 再起步」。定点停在抓取线仍由调度器的停带命令保证；没有待抓件或臂空闲时回到设定带速；变化小于 5% 不改。配置 `belt.adapt`（默认开、下限 15mm/s）。

### 传送带什么时候停

| 情形 | 动作 |
|---|---|
| 下一个 OK 目标（已过间隙检查）到抓取线 | 减速停 → 下探 → 夹 → **抬起即恢复走带** |
| 目标到了、臂还没回来 | 停等 |
| 异常 | 反转回退复检（P2）或放行进复检箱 |
| 安全 / 故障 | 急停；失步 / 打滑 / 卡带；舵机过流 / 过温 / 总线超时；对射长时间被挡；跟踪表溢出 |
| 其他 | 料盒满；UI 暂停；CAN 模拟 PLC 联锁暂停 |
| **不停** | NG / 复检件（导流挡板在线分流）；机械臂放料、回位期间 |

**拦截式不停带夹取（P1，已实现、默认关 `picker.flying`，⬜ 停带抓取跑通后实物调）**：零件在**竖直可达区**时，夹爪转成**两指横跨皮带开合**（闭合方向 ⟂ 走带方向），提前下探到抓取线、指尖离带面 3~5mm、张口最大（60mm，32mm 齿轮横向容差 ±14mm）——零件随皮带**从两指之间穿入**，按带位置在零件中心到达前 v ×（命令延迟 + 合到接触时间）发闭合 → 抬起，皮带不停。超出竖直区的件仍「停带 + 倾斜 + 切向夹取」（在底座正前方切向 = 沿走带方向，前指会挡路，必须停带）。实现：`Picker`（`picker.flying`，`flying_ok`：圆形件、离底座轴 r0~r1、两指张到 max_open 横跨皮带不碰邻件、gap_mm 内无其他零件）在零件离抓取线 need（= 带速 × ready_s）~ need + window 时派活（`PickJob::flying` + `arrive_belt_mm`），皮带不停、Runner 不置 `arm_clear=false`；早了让它来，来不及 / 臂忙退回停带抓取；机械臂线程只允许竖直解，「close」帧带 `wait_belt`，`ArmExec` 发它之前等带位置 ≥ 到线 − 带速 × close_lead_s，超时 10s 或离开运行 / 暂停 → 张着抬起、该件复检。风险：y 预测误差（视差已校正）、合爪时刻（带速 50 时 ±50ms = ±2.5mm）、带面起伏擦指尖（指尖高 4~5mm）。

### 夹取碰到邻件

预防：间隙检查（夹爪张口按该类宽度设，两指占位矩形与邻件外扩区求交，θ 与 θ+90° 都试）+ 垂直下探 / 抬起。发现：抓空 / 宽度不符 / 对射对不上。兜底：过不了间隙检查的件不抓，流到带尾进复检箱。演示规则写明最小件间净距，并故意放一组贴死的件演示"识别 → 跳过 / 复检"。

## NG 分流（侧边导流挡板）

抓取线下游、皮带一侧装两个 MG996R 摆杆（长 230~250mm、45°、底边离带面 1~2mm；转轴在摆杆下游端、带边外侧；打开时转到带外）。合上时斜拦过零件摆放带，零件被皮带推着顺挡板滑进侧边料盒。**挡板 1 = 报废、挡板 2 = 返修、带尾 = 复检**（挡板不动作的件都进复检 = 失效安全：漏检、跟丢、挡板故障都不会混进报废或良品）。

- 时序：零件到拦截点前约 110mm 合上、过后约 190mm 打开；合上期间会扫到别的件则这件不拦、改走复检。
- PL `des_pwm` 两路照用（PIN18 / PIN20；信号名沿用原拨叉 / 翻板）。调度已按挡板位置触发：`sched/picker` 的 `FlapSequencer`（代码沿用 `flap` 命名）、`picker` 每件 NG / 复检件一个事件，带挡板序号或 −1 = 带尾；配置 `flaps.gates`（拦截点 `after_pick_mm`、`open_us` / `closed_us`）。
- 布局要求相机往上游挪约 20cm（挡板合上时伸向上游约 180mm，须在抓取线 + 40mm 之后）。布局 / 机械 / 采购 / 实施步骤见仓库外「侧边导流挡板方案」。
- 带尾两级翻板方案已否决（需要 15~20cm 落差，现场带面高度不够）。

## 背面检测：单板翻转 + 落料台（P2）

> **状态：闲置，不启用**（用户对方案仍不满意，主线与 P1 完成前不投入）。

相机只看得到零件朝上的一面；#5 轴垂直于零件表面，转腕不能翻面 → 另做翻转机构：水平转轴两侧各一块同高的板，左「翻转板」由舵机带动、右「落料台」固定（各约 65×70mm）。机械臂把正面判 OK 的件放到翻转板上 → 舵机翻约 120° 把件翻到落料台（背面朝上，约 0.5s）→ 机械臂顺着转轴方向夹起 → 放回皮带相机视野内 → 皮带倒退一小段送到镜头下 → 检测背面 → 按两面结果分拣；一次翻面约 2~3s。翻转舵机 **ID 设为 7**，串在现有总线上（PL 不用改），供电同机械臂。U 形翻面叉方案已否决。

⬜ 未解决：① 翻转机构装在哪（机械臂够得着、不挡皮带和相机）；② 机械臂能否够到相机视野下游边缘放件（`pick_after_fov_mm` 现为 80mm）；③ 皮带倒退时跟踪表要认出「同一件」；④ 背面缺陷样本。

## 分阶段

S1 单件 / 摆正 / 固定 Y / 停带夹取 → S2 随机 Y → S3 随机姿态 + 腕旋对 θ（以上 P0）→ S4 多件同时在带、跟踪队列逐个夹取 + 粘连跳过（P1）→ S5 不停带动态抓取（P2；拦截式已提前实现，见上）。

## 跟踪表

每件一个 ID，状态 `New → Tracking → Decided →（Picking 抓取 | 挡板 / 复检）→ Done`；冷却按"离开工位的带位置距离"而非定时器。槽满的件直接走到带尾进复检，不排队堆积。

- **实现**：`ps/src/sched/tracker`（New → Tracking → Decided → Picking → Done）+ `picker`（停带 / 夹取 / 挡板，代码 `flap`）+ `ps/src/app/belt_ctl`（停带计划 → PL 步进位置模式命令：Run = 目标设在远处、StopAt = 运动中改写目标（PL 重算减速点，停在那一步）、Hold = 机械臂在带面上不动；停住后绝不倒车去追身后的目标）。
- 跟踪丢失只在**整件**都应在视野内时计数，已判定的件不再计丢失。
- **硬件在环测试**（`ps/tests/test_belt_hil.cpp`，真 PL 步进、不接电机）：模拟零件骑在真实步进计数上走，模拟相机（含边缘半截件）→ 跟踪表 → 调度 → `BeltDriver` → PL 步进；3 档带速下良品全抓、NG 到带尾，停带误差见 [测试与验证](测试与验证.md)。

## 节拍口径

机械臂取放最慢（数百 ms 量级），推理不是约束；只有 OK 件停带。报告分"纯检测节拍"与"含分拣节拍"两个数。
