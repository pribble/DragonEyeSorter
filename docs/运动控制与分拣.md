# 运动控制与分拣

> 接线见 [硬件与接线](硬件与接线.md)；实测数字见 [测试与验证](测试与验证.md)。

## 机械臂（6 轴）

德晟 DS-SY15A 串口总线舵机，菊花链，**PL 直驱总线（经 BSS138）**；PS 算 IK 与路径点，PL 管 SYNC WRITE 帧时序与遥测。

| 轴 | 作用 | 说明 |
|---|---|---|
| #1 | 底座偏航 | 横向覆盖 + 决定放哪个料盒 |
| #2 | 大臂俯仰 | 受力最大，电流监测重点 |
| #3 | 小臂俯仰 | |
| #4 | 腕俯仰 | 补偿 #2/#3，保持夹爪垂直向下 |
| #5 | 腕旋转 | 对准视觉给出的物料角度 θ |
| #6 | 夹爪 | 电流 + 位置回读判定是否夹住 |

- 协议：德晟 v4.01，115200 半双工，帧头 `FF FF`；**SYNC WRITE(0x83)** 与 REG WRITE + ACTION 均可广播同步；可回读位置(0x38) / 电流(0x2E) / 温度(0x3F)。
- **关节软限位**（`des_app.json` 的 `arm.joints`）：1~5 号 ±145°（300° 舵机），夹爪 ±88°（180° 舵机）。标定零位后用界面「机械臂」页实测机械极限再收紧；料盒 / 回零姿态越限会被 `plan_pick` 拒绝。
- 抓取确认（P1）：闭合时电流上升且停在该类宽度附近 = 夹住；全闭 + 低电流 = 抓空。
- 安装：侧装优先（与带面等高或更高），正上方倒挂备选；够不着的区域用挡板限定摆放区。
- **竖直夹取够得着的范围（按 `arm_ik` 算）**：#4 保持夹爪竖直时，最后一段（腕 79.05mm + 夹爪）竖直下垂，水平方向只有大臂 + 小臂（各 82.85mm）在出力 → 离底座轴**最远约 150~160mm**（产品页「工作半径 ~300mm」是整条臂水平伸直的数）。要求抓取高度 6mm 和安全高度 60mm 都解得出：

  | 夹爪长 l_tool（#4 轴下方到指尖夹持点再减 79.05） | 底座板比带面低 60 | 齐平 | 高 30 | 高 60 |
  |---|---|---|---|---|
  | 30mm | 13~112 | 50~153 | 45~162 | 50~157 |
  | 50mm（现配置） | 10~85 | 42~144 | 50~157 | 45~162 |
  | 70mm | — | 15~130 | 47~149 | 49~160 |

  （单位 mm，离底座轴的水平半径，关节限位 ±145°。）→ 只用竖直夹取时：底座板宜比带面高 30~60mm、底座轴离皮带中线约 110mm（带宽 300 时要架在带边上方）。零件全为齿轮后改用倾斜下探，底座放在带边旁、与带面大致齐平即可（具体位置按底座直径与边框尺寸定）。`des_app.json` 现填的 `base_xy` y = −170（离中线 170mm）够不着中线。**倾斜下探（已实现）**：竖直够不着时，圆形零件允许夹爪朝外倾斜（`arm.max_tilt_deg` 40、`tilt_step_deg` 5，取最小能到的倾角；下探仍竖直走）。倾斜时两指必须沿**切向**闭合（垂直于底座→零件连线，倾斜不会让它倾），所以 Picker 对圆形件先试切向（`picker.tangential_first`，由 max_tilt_deg > 0 打开），`arm_ik` 对非切向的倾斜请求直接拒绝。底座板与带面齐平时可达半径：竖直 42~144、倾 20° 90~192、30° 114~217、40° 133~240mm（l_tool 50 估算，抓取高 6 / 安全高 60 都要解得出）。`test_scheduler` 新增 12 项（200mm 处竖直不可达、倾 30° IK/FK 往返 <0.01mm、径向轴被拒、120mm 仍竖直、Picker 先给切向轴）。待量：`l_tool`、带面离桌面高度、底座占地尺寸。
- **#5 腕旋零位约定**：#5 在 2048（中位）时，**两指沿径向闭合**（夹爪竖直朝下、从上往下看，一指靠近底座、一指远离）= 配置 `grip_axis_at_zero_deg = 0`；装成两指左右（切向）闭合则改成 90。重装夹爪后在界面「机械臂」页重新「设为初始姿态」。
- PWM 双驱动：六舵机信号脚同一电气节点，做 PWM 必须改星型布线 → 降为 P2 对比实验。

### 上电调试步骤（`des_tool arm`）

✅ 6 个舵机已联通：通信与小幅动作正常（4.9V 临时供电）；负载、精度与电流 / 温度读数待 6.8V 正常供电后验证（[log/2026-10-17-舵机总线首次联通](log/2026-10-17-舵机总线首次联通.md)）。

1. **上电前**：逐个量舵机 V+~GND 电阻；降压模块设 **6.8V、限流约 5A**，舵机链只从 #1 链头进电（#6 夹爪只有固定接口）。电平转换与管脚见 [硬件与接线](硬件与接线.md)（CEP PIN19，经 BSS138）。
2. `des_tool arm scan`：6 个舵机都应回应（打印位置 / 电流 / 温度 / 状态位）；全无回应 → 查电源、BSS138 接线、ID 1~6。
3. **示教**：`des_tool arm torque-off` 后手摆到回零 / 各料盒位置，每次 `des_tool arm teach` 把打印的 `[q1..q5]` 填进 `des_app.json` 的 `arm.home_deg` / `arm.bins_deg`，再 `torque-on`。各关节零位（`zero_count`）与方向（`counts_per_deg` 正负）按 `arm read` 打印角度 = 实际几何角度校。
4. **运动**：先空跑看舵机码（默认只打印），无误再加 `--go`：`des_tool arm home --go`（单步 1.5s，故意慢）→ `arm goto <x> <y> --go` → `arm pick <x> <y> [角度] [料盒] --go`。
5. 夹取确认：闭合后读 #6 位置，比闭合命令差 1.5mm 以上 = 夹住了，完全闭合 = 空抓（阈值 ⚠ 上实物再调）。
6. **手眼标定**（`des_tool calib-arm`，⬜ 待实物；须在相机标定 + 关节零位校好后做）：交互式逐点：放标记物让相机定位，再手掰夹爪尖碰标记中心读关节角（正运动学）；≥3 点最小二乘求 `table = base + R(yaw)·arm`（与 `table_to_arm` 同约定），`--marker-h` 给标记物厚度时顺带求带面高度 `belt_z`；结果写 calib.json 的 `arm` 段（load_config 合并、calib-cam 重跑保留）。`test_scheduler` 全量 178 项（host 与板上实测），其中手眼标定 9 项：±0.4mm 误差下底座 <1mm、朝向 <0.3°、带面 <0.3mm；放错一点残差明显变大；点太少 / 太挤拒绝。

## 传送带跟踪抓取（conveyor tracking）

```
X_now = X_拍摄 + (POS_now − POS_拍摄) · k        Y 不变        θ 由视觉给出
```

- POS 来自编码器（P1）；✅ 已定：主线先用 PL 步进脉冲计数（轻载开环不丢步），编码器后接同一位置接口。
- **帧起始锁存**（`enc_frame_latch`）：PL 在 MIPI 帧起始那一拍锁存带位置并绑定帧号，消除 PS 推理延迟的 ±1~2mm 基准抖动。
- 停带时坐标自动冻结，加减速、反转也自动正确。

### 工位布局（沿带方向，✅ 已采纳）

上料 → 相机视野（检测 + 多帧融合）→ 视野外短跟踪段 → **对射到位线**（抓取线上游 40~60mm）→ **抓取工位**（机械臂侧装，不进相机视野）→ 带尾翻板。视野下游边到抓取线合计 60~80mm。

- **谁触发停带**：跟踪表 + 带位置（"下一个要夹的 OK 件的 X 到达抓取线"），**不是光电**。
- **对射**：到位确认 + X 校正（实测前沿 vs 预测前沿，差值即报告里的"跟踪误差"）+ 异常报警（有边沿无预测 = 视觉漏检；有预测无边沿 = 件丢失）。漏检件补建记录（类别未知）→ 翻板送复检。
- 夹爪下探不得切到光束；光束离带面 ≤5mm。
- ⚠ 现有那只 M12 传感器是**电感式接近开关**（Aotochs LJ12A3-4-Z/BX：M12、检测距离 4mm、NPN 常开、6~36V、棕 + / 黑信号 / 蓝 −）——只感应 4mm 内的**金属**，看不见 POM 零件，不能当到位传感器。可留作皮带打滑检测（从动辊端面装一颗螺钉，每转一个脉冲，对比步进计数；P2）。到位确认要另买对射型光电开关（P1，主线闭环后再买）。

### 传送带什么时候停

| 情形 | 动作 |
|---|---|
| 下一个 OK 目标（已过间隙检查）到抓取线 | 减速停 → 下探 → 夹 → **抬起即恢复走带** |
| 目标到了、臂还没回来 | 停等 |
| 异常 | 反转回退复检（P2）或放行进复检箱 |
| 安全 / 故障 | 急停；失步 / 打滑 / 卡带；舵机过流 / 过温 / 总线超时；对射长时间被挡；跟踪表溢出 |
| 其他 | 料盒满；UI 暂停；CAN 模拟 PLC 联锁暂停 |
| **不停** | NG / 复检件（翻板在线分流）；机械臂放料、回位期间 |

### 夹取碰到邻件

预防：间隙检查（夹爪张口按该类宽度设，两指占位矩形与邻件外扩区求交，θ 与 θ+90° 都试）+ 垂直下探 / 抬起。发现：抓空 / 宽度不符 / 对射对不上。兜底：过不了间隙检查的件不抓，流到带尾进复检箱。演示规则写明最小件间净距，并故意放一组贴死的件演示"识别 → 跳过 / 复检"。

## 带尾翻板（✅ 选项 C）

- 装在带尾下方，件从带尾落下时由 MG996R 翻板打向不同出口，只作用于刚离开带面的件，**不误伤**。
- 两级串联：第 1 级 **复检 vs NG**，第 2 级 **返修 vs 报废**；先做第 1 级（P1），第 2 级 P2。
- 分流规则做成 UI 可配的"类别 + 分级 → 出口"映射表；去不同出口的两件同时到带尾 → 一律复检。
- PL 在件到达带尾那一刻打出 IO —— 对应赛题"NG 不良品输出 IO 控制""不良品实时分拣触发"。
- 降级方案：机械臂 OK / NG 全夹，带尾放被动复检箱。

## 背面检测：单板翻转 + 落料台（P2）

> **状态：闲置，不启用**（用户对方案仍不满意，主线与 P1 完成前不投入；以下为保留的设计）。

相机只看得到零件朝上的一面。夹爪 #5 的轴垂直于零件表面，转腕不能翻面 → 另做一个翻转机构，把正面判 OK 的件翻到背面朝上再检一次。

**机构**：水平转轴两侧各一块同高的板——左侧「翻板」由舵机带动，右侧「落料台」固定。两块板各约 65×70mm（齿条 50mm、齿轮 Ø32 都放得下），铝板 / 亚克力，翻板用螺丝固定在舵盘上，转轴与台面同高。

- **放件**：机械臂从上方把零件放到翻板上（上方敞开）。
- **翻转**：舵机把翻板往上翻（约 0.5s），零件滑向转轴并靠住；翻板过竖直后零件顺势翻倒在落料台上，背面朝上。翻板转到约 120° 即可，不必 180°（否则会压到落料台上的零件），随后回 0°。
- **取件**：落料台上方完全敞开；零件靠着转轴边，夹爪两指**顺着转轴方向**夹零件两侧（#5 腕旋对准）。落料台两侧的挡边离零件要留出手指宽度；远端可加挡块定位。
- **舵机**：总线舵机 **ID 设为 7**（厂家调试软件改 ID），串在现有舵机总线上 → PL 不用改，PS 多一条 SYNC / WRITE；负载只有几克，型号随意（同款最省事）。供电同机械臂舵机。
- **流程**：机械臂把正面判 OK 的件放到翻板上 → 翻转 → 机械臂从落料台夹起（背面朝上）→ 放回皮带**相机视野内** → 皮带倒退一小段送到镜头下 → 检测背面 → 正常向前、按两面结果分拣。一次翻面约 2~3s（含机械臂往返）。
- **演示**：视频里拍「翻面 → 复检」一镜（3D 示意动画只在设计讨论时画过，未入库）。

⬜ 未解决：① 翻转机构装在哪（机械臂够得着、不挡皮带和相机）；② 机械臂能不能够到相机视野下游边缘放件（`pick_after_fov_mm` 现为 80mm）；③ 皮带倒退时跟踪表要认出「同一件」（倒退期间暂停新件建轨、按件号锁定，或只在空线时做）；④ 背面缺陷样本（缺陷只做在底面的件，按 `物料与缺陷样本.md`（仓库外）的轻 / 重各做几件）。

## 跟踪表

每件一个 ID，状态 `New → Tracking → Decided →（抓取 Picking | 带尾翻板 / 复检）→ Done`（实现命名见下）；冷却按"离开工位的带位置距离"而非定时器。槽满的件直接走到带尾进复检，不排队堆积。

**实现**：`ps/src/sched/tracker`（状态 New → Tracking → Decided → Picking → Done）+ `picker`（停带 / 夹取 / 翻板）+ `ps/src/app/belt_ctl`（停带计划 → PL 步进位置模式命令：Run = 目标设在远处、StopAt = 运动中改写目标（PL 重算减速点，停在那一步）、Hold = 机械臂在带面上不动；停住后绝不倒车去追身后的目标）。

- 跟踪丢失只在**整件**都应在视野内时计数（50mm 齿条在视野出口不再被误判为丢失），已判定的件不再计丢失。
- **硬件在环测试**（`ps/tests/test_belt_hil.cpp`，真 PL 步进、不接电机）：模拟零件骑在"真实步进计数"上走，模拟相机（含边缘半截件）→ 跟踪表 → 调度 → `BeltDriver` → PL 步进。50 / 100 / 150 mm/s 下 8 件良品全抓、4 件 NG 到带尾，停带误差 ≤0.04mm，无来不及停、无机械臂下探时动带；对应节拍见 [测试与验证](测试与验证.md)。

## 节拍口径

机械臂取放最慢（数百 ms 量级），推理不是约束；只有 OK 件停带。报告分"纯检测节拍"与"含分拣节拍"两个数。
