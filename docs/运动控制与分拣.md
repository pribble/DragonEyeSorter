## 机械臂（6 轴）

德晟 DS-SY15A 串口总线舵机，菊花链，**PL 直驱总线（经 BSS138）**；PS 算 IK 与路径点，PL 管 SYNC WRITE 帧时序与遥测。

| 轴 | 作用 | 说明 |
|---|---|---|
| #1 | 底座偏航 | 横向覆盖 + 决定放哪个料盒 |
| #2 | 大臂俯仰 | 受力最大，电流监测重点 |
| #3 | 小臂俯仰 | |
| #4 | 腕俯仰 | 补偿 #2/#3，保持夹爪垂直向下 |
| #5 | 腕旋转 | 对准视觉给出的物料角度 θ |
| #6 | 夹爪 | 位置回读判定是否夹住（这批舵机不提供电流） |

- 协议：德晟 v4.01，115200 半双工，帧头 `FF FF`；**SYNC WRITE(0x83)** 与 REG WRITE + ACTION 均可广播同步；可回读位置(0x38)。电流(0x2E) / 温度(0x3F) 这批舵机不提供（0x2E 随供电电压、0x3F 恒 255），只看应答状态位（过载 / 过热 / 电压）。
- **关节软限位**（`des_app.json` 的 `arm.joints`）：1~5 号 −145°~+145°（#2 下限 −70；300° 舵机），夹爪 ±88°（180° 舵机）。标定零位后用界面「机械臂」页实测机械极限再收紧；料盒 / 回零姿态越限会被 `plan_pick` 拒绝。
- 抓取确认（挤压差判据与 0.8mm 门限）：见「上电调试步骤」第 5 步。
- 安装：侧装优先（与带面等高或更高），正上方倒挂备选；够不着的区域用挡板限定摆放区。
- **#5 腕旋零位约定**：#5 = 2048（中位）时两指沿径向闭合（夹爪竖直朝下，一指靠近底座、一指远离）= `grip_axis_at_zero_deg = 0`；装成两指左右（切向）闭合则改成 90（**实装 = 90**，见「零位与计数比例」）。重装夹爪后在界面「机械臂」页重新「设为初始姿态」。

**可达范围**（按实测夹爪，抓取点 = 指尖、抓取高 3 / 安全高 60 都要解得出，关节 ±145°，单位 = 离底座轴水平半径 mm）：

| 底座板相对带面 | 竖直 | 倾 20° | 倾 30° | 倾 40° |
|---|---|---|---|---|
| 低 60 | 22~116 | 65~169 | 87~193 | 115~215 |
| 低 30 | 40~140 | 90~190 | 109~211 | 125~230 |
| 齐平 | 51~155 | 94~202 | 108~221 | 117~238 |
| **高 30** | **42~163** | **91~206** | 110~219 | 125~229 |
| 高 60 | 51~155 | 94~195 | 107~207 | 114~214 |
| 高 90 | 40~140 | 74~178 | 81~187 | 96~190 |

零件走皮带中线 ±30mm → 底座轴离中线 d 时要够 d−30 ~ d+30（再加抓取线前后 ±20）。**推荐底座板比带面高 0~30mm、底座轴离中线 150~170mm**：竖直覆盖到 ~160，外侧由倾 20° 补；底座只能放在侧框外（d ≈ 220）时只能靠倾 40°（最远 ~238）。**实装**：底板比带面高 53mm、底座轴离中线约 132~142mm；手眼标定给出底座在台面 (437.8, 142.4)、belt_z −54.1，写在板上 calib.json。上表按工具段 27mm 计算；工具段 111mm 时竖直最远约 158mm。

**倾斜下探（已实现）**：竖直够不着时，圆形零件允许夹爪朝外倾斜（`arm.max_tilt_deg` 40、`tilt_step_deg` 5，取最小能到的倾角；下探仍竖直走）。倾斜时两指必须沿**切向**闭合，Picker 对圆形件先试切向（`picker.tangential_first`，由 max_tilt_deg > 0 打开），`arm_ik` 拒绝非切向的倾斜请求。⚠ **这台臂上用不上**：倾斜需 6 号舵机在上侧 = #5 转到 ±180°，超出 ±145° 行程 → 实际只有竖直夹取。

**圆形件保持初始姿态的腕部朝向**（`picker.keep_wrist` 默认 true）：圆形件合拢方向任意 → 第一个候选方向 = 初始姿态 #5 不动时的合拢线（`arm_wrist_axis`，只随 #1 转角变，抓取线上约 93°），两侧被挡才每 15° 换一个；倾斜可行的臂上切向作备选（`PickJob::alt_axis`）。同一条合拢线有两个 #5 解，`arm_ik` 的 `q5_pref_deg`（`plan_pick` 传 `home_deg[4]`）取离初始姿态 #5 近的；#5 行程与「近底座舵机不朝底座」规则仍优先。界面重新「设为初始姿态」后下一周期生效；`des_tool arm pick / goto / ik` 不给 axis（或写 `keep`）= 同样保持腕部。

**夹爪几何**：#4 转轴（小臂末端下沿）→ 指尖末端 190mm，`l_tool` = 190 − 79.05 ≈ **111**（10-22 手眼标定，见 [log/2026-10-22](log/2026-10-22-机械臂零位标定.md)）；指尖缠胶布加粗，让末端先合上；指尖中心偏离 #5 转轴 **9mm**（`tool_offset_mm`，运动学已按 #5 转角补偿，否则抓取点随 #5 画 9mm 圆）；#6 舵机最低点离指尖竖直约 70 / 横向约 40mm → 竖直夹取碰不到；**倾斜下探时让舵机在外侧**（`servo_side_deg` ±90，符号零位标定时确认）。

- **夹爪始终朝下**：从朝上 / 水平姿态直接转去抓取，关节空间插值会让夹爪横扫过皮带。规则：初始姿态、料盒姿态、抓取各点都必须夹爪朝下（q2+q3+q4 ≤ −40°，倾斜下探最多 40°）。`plan_pick` 拒绝不朝下的当前 / 初始 / 料盒姿态；真动（--go）每次抓取前先读舵机实际位置再规划；界面「复位」时夹爪方向与初始姿态差 >60° 拒绝。
- **料盒低于行程高度时先到盒上方**：料盒姿态低于 `z_safe`（皮带面上方 30mm）时，`plan_pick` 自动加「over bin」= 同姿态抬到 `z_safe`（`arm_raise` 重解，保持示教肘部方向）→ 竖直放下 → 松开 → 「rise」回上方 → 回初始姿态；抬不到 `z_safe` 的料盒直接拒绝、要重教。放料全程夹着的齿轮高于带面；转过去时低于底板 / 纸箱顶（见「实装」），纸箱下游侧要离开这段弧。料盒示教：夹爪尖在盒口上方 1~2cm、对准盒中心、夹爪朝下，盒底垫泡棉防弹跳。见 [log/2026-10-26](log/2026-10-26-料盒示教与放料过渡.md)。
- **低处出发先竖直抬起**：夹爪低于 `z_safe` 时（停在料盒姿态、抓取中断），界面「复位」、`des_tool arm home / goto` 和下一次抓取都先「rise first」= 同姿态竖直抬到 z_safe，再走后面的关节插值；目标低于 z_safe 的手动移动从正上方「over target」进入；夹爪俯仰变化 >60° 拒绝（`plan_move`）。手动移动每步 ≥1.5s（界面复位 ≥2s）。
- **底座大角度转动在外圈转**（`wide_turn`）：黑色底板从底座轴伸向皮带约 7cm、下游约 8~10cm、顶面比 `z_safe` 高约 2cm，斜穿的关节插值会剐蹭它下游的角 → 底座转角 >15° 且两端离轴半径差 >5mm 时在较大半径上转：抓完先「out」沿径向外伸到料盒半径再转「over bin」，放完「rise」后「back」同半径转回初始姿态方向再径向收回；界面复位 / `des_tool` 移动与中断后恢复同理，不加转腕。
- **夹爪转角 / 开口的避让**：抓取高度（带面 +3）时 6 号舵机底在带面 +73，高于底板与纸箱顶，腕怎么转都从上方过，只可能碰底座转台（上条规则管）。离物体最近的是**初始姿态（姿势 B）的内侧手指** → 回初始姿态一律用示教开口（`arm_home.json` 的夹爪计数，`des_tool arm home` 不全开），`goto` 不改开口；界面微调（jog）不做检查，靠人看。
- **6 号舵机别朝底座**（平伸时舵机朝底座会撞转台）：竖直夹取时若舵机朝底座超过 60° 且抓取点离底座轴 < `arm.servo_in_min_r_mm`（默认 120），`arm_ik` 改用 q5 ± 180°（同一条合拢线、舵机换到另一侧），5 号关节转不到就报「servo would face the base」，Picker 换另一个合拢方向。示教料盒 / 初始姿态时同样注意。
- **零位与计数比例（10-22 已标）**：#1~#5 零位 2012 / 3085 / 1977 / 1986 / 1985，计数 / 度 +12.47 / −12.14 / −12.33 / −12.13 / −12.6（规格书约 13.0、各舵机差约 2%）；q1 = 0 时手臂垂直指向皮带（`base_yaw_deg` −90，机械臂在台面 +y 侧）；#5 = 1985 时两指切向合拢、6 号舵机朝底座（`grip_axis_at_zero_deg` 90、`servo_side_deg` 90）。夹爪开口与计数**不成正比**（连杆）：`grip_table` = 全合 2919 / 32mm 2318 / 全开 61mm 1195 分段线性。数据与校验见 [log/2026-10-22](log/2026-10-22-机械臂零位标定.md)。
- PWM 双驱动：六舵机信号脚同一电气节点，做 PWM 必须改星型布线 → 降为 P2 对比实验。

### 上电调试步骤（`des_tool arm`）

1. **上电前**：逐个量舵机 V+~GND 电阻；降压模块设 **6.8V、限流约 5A**，舵机链只从 #1 链头进电。电平转换与管脚见 [硬件与接线](硬件与接线.md)（CEP PIN19，经 BSS138）。
2. `des_tool arm scan`：6 个舵机都应回应（打印位置 / 状态位）；全无回应 → 查电源、BSS138 接线、ID 1~6。
3. **示教**：`des_tool arm torque-off` 后手摆到回零 / 各料盒位置，每次 `des_tool arm teach` 把打印的 `[q1..q5]` 填进 `des_app.json` 的 `arm.home_deg` / `arm.bins_deg`，再 `torque-on`。各关节零位（`zero_count`）与方向（`counts_per_deg` 正负）按 `arm read` 打印角度 = 实际几何角度校。
4. **运动**：先空跑看舵机码（默认只打印），无误再加 `--go`：`des_tool arm home --go`（单步 1.5s）→ `arm goto <x> <y> --go` → `arm pick <x> <y> [角度] [料盒] --go`。
5. 夹取确认：闭合后读 #6 位置，比闭合命令差 **0.8mm** 以上 = 夹住了，完全闭合 = 空抓（10-26 实测定标，见 [log/2026-10-26](log/2026-10-26-料盒示教与放料过渡.md)）。
6. **手眼标定**（`des_tool calib-arm`，✅ 10-22 已标定，见上文「实装」与 [log/2026-10-22](log/2026-10-22-机械臂零位标定.md)；换臂位 / 相机后重做）：交互式逐点——放标记物让相机定位，再手掰夹爪尖碰标记中心读关节角（正运动学）；≥3 点最小二乘求 `table = base + R(yaw)·arm`（与 `table_to_arm` 同约定），`--marker-h` 给标记物厚度时顺带求带面高度 `belt_z`；结果写 `calib.json` 的 `arm` 段（`calib-cam` 重跑保留）。

## 传送带跟踪抓取（conveyor tracking）

```
X_now = X_拍摄 + (POS_now − POS_拍摄) · k        Y 不变        θ 由视觉给出
```

- POS 来自 PL 步进脉冲计数（轻载开环不丢步）；编码器后接同一位置接口。
- **32 位 POS 与 PS 侧累计**：PL 的 POS / 帧锁存寄存器是 32 位步数（2^31 步 ≈ 44 km，50 mm/s 连续走带约 10 天回绕）。PS 侧（`BeltDriver::belt_mm` 与 live 的帧锁存链）用回绕安全的**无符号**差分累计成 int64，跟踪 / 抓取 / 显示统一用累计值；PL 目标寄存器仍是 32 位绝对步数，`StopAt` 按当前 POS 换算成相对目标写入。累计链锚定 **PL 计数器零**（整机重启 POS 归零对齐，仅重启 des_app 时避免 POS₀×mm/step 错位）。
- **帧起始锁存**（`enc_frame_latch`）：PL 在 MIPI 帧起始那一拍锁存带位置并绑定帧号，消除 PS 推理延迟的 ±1~2mm 基准抖动。
- 停带时坐标自动冻结，加减速、反转也自动正确。

### 工位布局（沿带方向）

上料 → 相机视野（检测 + 多帧融合）→ 视野外短跟踪段 → **对射到位线**（抓取线上游 40~60mm）→ **抓取工位**（机械臂侧装，不进相机视野）→ 导流挡板（抓取线下游）→ 带尾复检箱。视野下游边到抓取线合计 60~80mm。

- **谁触发停带**：跟踪表 + 带位置（"下一个要夹的 OK 件的 X 到达抓取线"），**不是光电**。
- **对射**：到位确认 + X 校正（实测前沿 vs 预测前沿，差值即报告里的"跟踪误差"）+ 异常计数（有边沿无预测 = 视觉漏检；有预测无边沿 = 件丢失 / 光束没对准）。漏检件当前不补建 Track、只计事件，不会被抓取也不会被挡板拦，物理上落到带尾复检箱（⚠ 零件记录补齐待定）。实物过件结果见 [测试与验证](测试与验证.md)。
- 夹爪下探不得切到光束；光束离带面 ≤5mm。
- ⚠ 现有 M12 传感器是**电感式接近开关**（Aotochs LJ12A3-4-Z/BX：检测距离 4mm、NPN 常开、6~36V）——只感应 4mm 内的**金属**，看不见 POM 零件，不能当到位传感器；可留作打滑检测（从动辊端面每转一脉冲，P2）。到位确认要另买对射型光电开关（P1）。

### 带速自适应（`sched/picker` 的 `SpeedAdaptConfig` / `adapt_speed`）

臂按规划动作时间算出回到初始姿态的时刻；若下一个良品离抓取线 d、还要 t 秒才空闲，带速改为 max(`min_mm_s`, d / t)（不超过设定带速）。定点停在抓取线仍由调度器的停带命令保证；没有待抓件或臂空闲时回到设定带速；变化小于 5% 不改。配置 `belt.adapt`（默认开、下限 15mm/s）。

### 传送带什么时候停

| 情形 | 动作 |
|---|---|
| 下一个 OK 目标（已过间隙检查）到抓取线 | 减速停 → 下探 → 夹 → **抬起即恢复走带** |
| 目标到了、臂还没回来 | 停等 |
| 异常 | 反转回退复检（P2）或放行进复检箱 |
| 安全 / 故障 | 急停；失步 / 打滑 / 卡带；舵机过流 / 过温 / 总线超时；对射长时间被挡；跟踪表溢出 |
| 其他 | 料盒满；UI 暂停；CAN 模拟 PLC 联锁暂停 |
| **不停** | NG / 复检件（导流挡板在线分流）；机械臂放料、回位期间 |

**拦截式不停带夹取（P1，已实现、默认关 `picker.flying`，⬜ 停带抓取跑通后实物调）**：零件在**竖直可达区**时，夹爪两指横跨皮带开合，提前下探到抓取线、指尖离带面 3~5mm、张口最大（60mm，32mm 齿轮横向容差 ±14mm），零件随皮带从两指间穿入，按带位置在中心到达前发闭合 → 抬起，皮带不停；超出竖直区的件仍停带夹取。`Picker`（`flying_ok`：圆形件、离底座轴 r0~r1、横跨皮带不碰邻件、gap_mm 内无邻件）在零件离抓取线 need ~ need + window 时派活（`PickJob::flying` + `arrive_belt_mm`），来不及 / 臂忙退回停带抓取；「close」帧带 `wait_belt`，`ArmExec` 发它之前等带位置 ≥ 到线 − 带速 × `close_lead_s`，超时 / 离开运行 → 张着抬起、该件复检。**默认关的原因**见 [log/2026-10-26](log/2026-10-26-料盒示教与放料过渡.md)；合拢方向 `flying.axis_deg` 90 = 横跨皮带，与初始姿态一致。

### 夹取碰到邻件

预防：间隙检查（夹爪张口按该类宽度设，两指占位矩形与邻件外扩区求交，θ 与 θ+90° 都试）+ 垂直下探 / 抬起。发现：抓空 / 宽度不符 / 对射对不上。兜底：过不了间隙检查的件不抓，流到带尾进复检箱。演示按最小件间净距放件，并故意放一组贴死的件演示"识别 → 跳过 / 复检"。

## NG 分流（侧边导流挡板）

两块 MG996R 平摆挡板，转轴都在机械臂对侧带边（布局见仓库外「侧边导流挡板方案」§2c）：挡板 1（报废）转轴正对机械臂底座（x≈438），**在抓取线上游就拦**；挡板 2（返修）在计米轮支架前（x≈613）。去向：报废 → 挡板 1、返修 → 挡板 2、复检 → 带尾（失效安全：漏判、跟丢、挡板坏都进不了报废盒）。合上时摆杆斜朝上游伸进皮带，零件被皮带推着沿摆杆滑到转轴处、落进带边料盒。

**11-01 改为单挡板**：用户只保留带尾侧那块（原挡板 2 的位置），信号线已挪到 PIN18（PWM 通道 0）。报废和返修两类不良都由它拨进同一个料盒，复检照旧走带尾。

- 配置：这块挡板的 `outlet` 写成列表 `["scrap", "rework"]`，表示一块挡板接多个去向。记录、CAN、界面里仍按各类自己的去向写报废或返修。
- 没写进列表的去向，这块挡板不拨，照旧走带尾复检（失效安全）。
- PWM 通道按 `gates` 的顺序分配：第 1 块 = 通道 0 = PIN18，第 2 块 = 通道 1 = PIN20。
- **11-01 已标定并启用**（`flaps.enabled` true）：开 1500 / 合 1100µs。
  - 几何用相机量：挡板停在合位时截一张 HDMI 界面，取摆杆朝上游那一面的边。这条边离画面中心近，对应板子贴着带面的那条线。按 3/4 缩放、上下各裁 20 行换回原图像素，再用 `calib.json` 的 `px_to_table` 换成台面坐标，拟合直线。
  - 结果：与带边夹角 42.3°（用户尺量 42.6°），末端约 (322, +36)，过对侧带边处 x≈526，与尺量对得上。
  - 摆杆面不过舵机转轴，偏了约 6mm（摆杆用舵盘上的对角螺丝孔固定）。配置的转轴取在摆杆面的延长线上：`pivot_xy` [557, −178]、`len_mm` 321、`closed_deg` 42.3、`open_deg` 0。
  - 启动日志：中线零件在 x≈338 碰到摆杆，扫过 x 259..400，最晚在 x 236 前判定（判定线 195）。扫过区离机械臂抓取点（x≈438）约 4cm，停在抓取点的良品不受影响。
  - 能可靠挡住的横向范围：y ≤ 约 +27（末端留 10mm 余量）。更靠机械臂侧的不良件改走复检。

几何（`sched/gate.hpp`，配置 `des_app.json` 的 `flaps.gates`：转轴 `pivot_xy`、摆杆长 `len_mm`、合上 / 打开角 `closed_deg` / `open_deg`，角度从上游方向朝皮带中线量）：程序按零件横向位置和大小算碰件点 x、摆杆扫过区（扇形）与滑出皮带所需带行程（无摩擦斜面估算，`hold_mm` 可按实测覆盖）；启动日志 `[run] gate` 行打印中线零件的这些数。

调度（`sched/picker`，每件 NG / 复检一次判断）：

- **够不着**：零件横向位置超出合上摆杆的伸出范围 → 改走复检（`beyond gate reach`）。
- **来不及**：挡板要在零件进入扫过区之前合好（开合渐变 + 错开 + 一个周期 + 一个 PWM 周期，按设定带速换算成带行程）；判定时已经来不及 → 复检（`gate too late`）。判定线 `tracker.decide_x` 据此定为 195（中线零件 50mm/s 下最晚约 x 208）。判定线下游（画面左侧）新出现的物体不建跟踪、不画轮廓（`tracker.spawn_before_decide`，默认开）：上游冒出来的多为手 / 挡板摆杆，不能当零件计数或让挡板误判；已在跟踪的零件照常显示。服务重启后停在判定线下游的零件不再被跟踪（演示要放回上游）。
- **冲突**：在挡板必须开始合的那一刻做最终检查：从开始合到「最早能打开」（零件沿摆杆滑过一半）再加一次开合，任何别的零件进扫过区都算冲突 → 这件改走复检（`gate conflict`）。**去抓取线的良品也算**（挡板 1 在抓取线上游，良品会路过）；停在抓取线上游的良品对下游的挡板不算；同一挡板、合上时段重叠的两件共用一次合上。
- **合上后**：后面又来了件，挡板提前打开，赶在它进扫过区之前开完，但不早于「最早能打开」。
- **执行**（`FlapSequencer`）：开 / 合脉宽按 smoothstep 在 `move_ms`（300ms）内渐变；两块挡板起步错开 `stagger_ms`（120ms）；程序一启动就到打开位并保持（上电前把摆杆拨到打开位附近）；产线停着时已合上的挡板按带行程保持，带不动就一直合着。
- **记录**：分给挡板的不良品，CSV / CAN PART / 计数等挡板定下来（合上或改走复检）再出，与实际去向一致。
- 挡板 2 的扫过区紧挨抓取线（中线上约 x 431 起），零件停在抓取线被夹时挡板 2 不动作（摆杆尖离夹爪手指只有几毫米），紧跟着的返修件改走复检。
- 合上时挡板 1 的摆杆尖伸进画面最下游（约 x 305~373），摆杆和支架须黑色哑光，免得被当成零件。

PL `des_pwm` 两路：PIN18 = 挡板 1（`FLAP1_PWM`）、PIN20 = 挡板 2（`FLAP2_PWM`）。装好后：量转轴位置 / 摆杆长 / 角度填配置 → `desreg pwm` 实测开 / 合脉宽 → 点动皮带核对碰件点 → 看零件实际滑出距离填 `hold_mm` → `flaps.enabled` 打开。

## 分阶段

S1 单件 / 摆正 / 固定 Y / 停带夹取 → S2 随机 Y → S3 随机姿态 + 腕旋对 θ（以上 P0）→ S4 多件同时在带、跟踪队列逐个夹取 + 粘连跳过（P1）→ S5 不停带动态抓取（P2；拦截式已提前实现，见上）。

## 跟踪表

每件一个 ID，状态 `New → Tracking → Decided →（Picking 抓取 | 挡板 / 复检）→ Done`；冷却按"离开工位的带位置距离"而非定时器。槽满的件直接走到带尾进复检，不排队堆积。

- **实现**：`ps/src/sched/tracker` + `picker`（停带 / 夹取 / 挡板，代码 `flap`）+ `ps/src/app/belt_ctl`（停带计划 → PL 步进位置模式命令：Run = 目标设在远处、StopAt = 运动中改写目标（PL 重算减速点，停在那一步）、Hold = 机械臂在带面上不动；停住后绝不倒车去追身后的目标）。
- 跟踪丢失只在**整件**都应在视野内时计数，已判定的件不再计丢失。
- **硬件在环测试**（`ps/tests/test_belt_hil.cpp`，真 PL 步进、不接电机）：模拟零件骑在真实步进计数上走，模拟相机（含边缘半截件）→ 跟踪表 → 调度 → `BeltDriver` → PL 步进；3 档带速下良品全抓、NG 到带尾，停带误差见 [测试与验证](测试与验证.md)。

## 对射光电（IR1）：跟踪误差与漏检（`ps/src/sched/beam`）

激光对射横跨皮带（接线见 [到货联调清单](到货联调清单.md) 3.8）。PL `des_io` 在每次「挡光」边沿（20µs 去抖）锁存步进位置与编码器计数，与相机帧起始同一 75MHz 时钟（赛题硬性①「多通道传感器同步采集」的证据）。

- **标定**：`des_tool.sh calib-beam -n 3 --od <卡尺外径>`：一个齿轮放在视野里、光束上游；皮带带它前进过光束再退回原处，静止测中心 → 「中心在边沿时刻的位置 + R」= 光束 x，写 calib.json `beam.x_mm`；运行时与之的差即动态跟踪误差。
- **运行**（`des_app.json` 的 `"beam"` 段，默认 `enabled: false`，开对射时置 true）：跟踪表按带坐标存件（s = x − B），挡光时该件前沿预测 = s + B<sub>边沿</sub> + R（R = 实测外径 / 2）。`BeamMonitor` 把边沿配给前沿离光束最近（±`match_mm` 12）的等待件：**matched**；同一件还挡着光束时的抖动边沿 = **repeat**；走过 `expire_mm`（120）没人认领 = **no_track**（漏检）；等待件前沿已过光束 `miss_mm`（25）还没边沿 = **missed**；PL 只锁最后一个边沿，两次读之间多于 1 个 = **lost**。no_track / missed / lost 目前只写 beam CSV 与 stdout，不触发界面 / 三色灯报警。
- **记录**：零件 CSV 末尾两列 `beam`（matched / missed / na / waiting）、`beam_err_mm`；全部事件另写 `beam_<会话>.csv`；`part_stats.py` 出「对射光电：跟踪误差」表；退出时打印汇总；画面画 `beam` 线（挡光变红）。
- **位置约束**：记录在判定线写出 → 光束要在 `decide_x − 20` 上游（→ 光束 x ≤ 175），并避开挡板扫过区；推荐视野上游半段 x ≈ 100~170。装在视野上游（上料端）也支持，此时 `expire_mm` ≥ (视野起点 − 光束 x) + 60。
