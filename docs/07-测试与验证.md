# 07 · 测试与验证

> 验证清单、测试框架与未决事项。实测记录见 `log/`。

## 测试原则

- **定量指标表是赛题必交项**，完整的目标值 / 测法 / 状态表随验证推进建立，最终版进作品报告；本文维护验证清单与未决事项。
- **诚实性**：指令分辨率与实测精度分开报告；帧率口径分开（采集/显示链路 vs 按物料触发的推理）。所有数字以实测为准，未实测的条目标 ⚠。
- 每项验证先定**判定标准**和**失败的后果**，再动手。

## 量化测试报告框架（赛题必交）

报告需覆盖以下类别，具体指标值随实测建立：

- **控制同步精度**：多轴同步误差、指令响应延迟、重复定位精度、传送带定位误差、电子齿轮主从同步
- **采集链路**：帧率稳定性、预处理延迟、端到端显示延迟
- **AI 推理**：单次推理耗时、端到端触发延迟、分类准确率、尺寸测量误差（量块标定）
- **总线稳定性**：CAN / RS485 / 舵机总线的误码、超时、丢帧统计
- **工程可靠性**：连续运行、失步检测触发率（人为注入）
