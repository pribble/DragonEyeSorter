# 07 · 测试与验证

> 测试原则、量化报告框架、验证清单与未决事项。实测记录见 `log/`。

## 测试原则

- **定量测试报告是硬性项⑥**：数据在写代码时就埋点（见 [06-软件与UI](06-软件与UI.md)「测试埋点」），不能最后补。逻辑分析仪是测同步误差的主力工具。
- **诚实性**：指令分辨率与实测精度分开报告（舵机回差 / 虚位各 ≤1°，定位精度只能报实测量级）；帧率口径分开（采集 / 显示链路 vs 按物料触发的推理）。未实测的条目标 ⚠。
- 每项验证先定**判定标准**和**失败后果**，再动手。

**还缺（按优先级）**：
1. 实物：舵机 SYNC 同步误差（逻辑分析仪抓多舵机动作起点）、机械臂重复定位、传送带位移 vs 读数、跟踪误差 —— 等舵机 / 驱动器 / 皮带接好；
2. 实物分类准确率（NPU 上，独立零件编号的验证集）、测量误差（卡尺真值对比，`des_app measure -n` 重复性）；
3. 端到端：拍摄 → NPU 结果可用的延迟（时间戳已在跟踪表 / 存储里，可直接算）；
4. CAN 实物收发（USB-CAN ZQWL-UCAN-101E + PC「PLC」程序）、长时间误码统计；舵机总线长时间应答丢失率（PL 错误计数器）；
5. 2h 连续运行（存储记录直接出统计）。
