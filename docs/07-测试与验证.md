# 07 · 测试与验证

> 测试原则、量化报告框架、验证清单与未决事项。实测记录见 `log/`。

## 测试原则

- **定量测试报告是硬性项⑥**：数据在写代码时就埋点（见 [06-软件与UI](06-软件与UI.md)「测试埋点」），不能最后补。逻辑分析仪是测同步误差的主力工具。
- **诚实性**：指令分辨率与实测精度分开报告（舵机回差 / 虚位各 ≤1°，定位精度只能报实测量级）；帧率口径分开（采集 / 显示链路 vs 按物料触发的推理）。未实测的条目标 ⚠。
- 每项验证先定**判定标准**和**失败后果**，再动手。

## 量化报告框架

| 类别 | 指标 | 目标 | 测法 |
|---|---|---|---|
| 控制同步精度 | 总线 SYNC WRITE 多舵机同步误差 | < 100 µs | 逻辑分析仪抓帧尾 + 动作起点 |
| | 指令响应延迟 | < 10 ms | PL 时间戳计数器 |
| | 机械臂重复定位精度 | 实测值（非指令分辨率） | 30 次重复定位 |
| | 传送带定位误差 | < 1 mm | 位置读数 vs 实测位移 |
| | 跟踪误差 | — | 对射前沿 vs 预测前沿 |
| 采集延迟 | 采集帧率 / 预处理延迟 / 端到端显示延迟 | — | 帧计数 + 时间戳 |
| AI 推理 | NPU 单次推理 | < 50 ms | demo 分阶段计时 |
| | 端到端（触发 → 类别可用） | < 100 ms | 时间戳 |
| | 分类准确率 | ≥ 92% | 独立测试集 |
| | 尺寸测量误差 | < 0.3 mm | 标准量块标定 |
| 总线稳定性 | CAN 误码 / 舵机总线丢帧 / RS485 超时 | 0 / <0.01% / <0.1% | 统计计数 |
| 工程可靠性 | 连续运行 | 2h 无故障 | 自动化脚本 + 日志 |
| | 漏检率 | — | 对射与跟踪表逐件对账 |
