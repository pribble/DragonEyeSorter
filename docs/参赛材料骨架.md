## 5 范围取舍与风险

**已定取舍**（现行 vs 原设想）

| 现行 | 原设想 |
|---|---|
| 视觉定位放 PS（OpenCV 阈值 + 轮廓） | PL 8 个图像模块为 P0 |
| 标注用自动框、按类别分文件夹 | 每类人工标注 |
| 带位置用 PL 步进脉冲计数，编码器降 P1 | 编码器必需 |
| 取消 STM32 过渡，PL 直驱舵机总线 | PL → I2C → STM32 |
| CAN 走 PS SocketCAN，RS485 降 P1 | CAN 用 PL IP；CAN + RS485 都 P0 |
| 只做一个 HDMI 界面，Web UI 降 P2 | Qt + Web 双 UI |
| 沿用厂家内核 / rootfs / 设备树，`/dev/mem` 访问 | 完整 Buildroot 重编 |
| PS 算 IK 与路径点，PL 管 SYNC WRITE 与遥测；`traj_interp` 降 P2 | `traj_interp` 为 P1 |
