## 6. 范围取舍与风险

**已定取舍**（相对最初设想砍掉 / 降级）：

| 取舍（现行） | 原设想 |
|---|---|
| 视觉定位放 PS（OpenCV 阈值 + 轮廓 → `minAreaRect`），PL 只做逐像素预处理 | PL 8 个图像模块为 P0 |
| 标注用自动框、按类别分文件夹 | 每类人工标注 |
| 带位置用 PL 步进脉冲计数，编码器降 P1（接进同一接口） | 编码器必需 |
| 取消 STM32 过渡，PL 直驱舵机总线 | PL → I2C → STM32 |
| CAN 走 PS SocketCAN，RS485 降 P1 | CAN 用 PL IP；CAN + RS485 都是 P0 |
| 只做一个 HDMI 界面，Web UI 降 P2 | Qt + Web 双 UI |
| 沿用厂家内核 / 根文件系统 / 设备树，只换比特流；`/dev/mem` 访问寄存器 | 完整 Buildroot 重编 |
| PS 算 IK 与路径点，PL 管 SYNC WRITE 时序与遥测；`traj_interp` 降 P2 | `traj_interp` 为 P1 |
