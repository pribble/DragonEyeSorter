# 系统概述

> 顶层视图：定位、架构与设计原则；实测数据见 [测试与验证](测试与验证.md) 与 [log/](log/README.md)。

## 定位

基于安路飞龙 F3P SoC 的**塑胶传动件注塑后在线质检分拣系统**，检测对象是多规格 / 多颜色的 POM 齿轮；覆盖 2026 嵌入式竞赛安路赛道选题四的六项硬性要求（清单见「优先级分级」P0）。

应用领域：**流水线工业视觉检测**（领域 3）为主，融合**多轴运动与机电伺服控制**（领域 1：机械手 + 传送机构）；赛题允许"任选其一或融合多场景"。

硬件平台型号、CEP 引脚、电平与供电树见 [硬件与接线](硬件与接线.md)。

## 系统一句话

传送带走带 → 相机发现物料、NPU 判类别、视觉给出 (x, y, θ) → 按带位置跟踪每件 → OK 件到抓取线停带，6 轴机械臂夹起（够不着时倾斜下探）、按规格 / 颜色入料盒 → NG 件不停带，抓取线下游的两个侧边导流挡板按位置拦进报废 / 返修盒，存疑件到带尾复检箱 → PC 经 CAN 当"产线 PLC"下发启停 / 调速 → HDMI 界面显示画面、计数、曲线与参数。

```

                   │   二值；ROI 面积 · 外接框 · 质心）→ 帧写 DDR → HDMI │
```

## 设计原则

1. **A35 只做调度、界面、存储、网络与推理**，像素搬运与时序关键的运动控制下沉 PL。
2. **帧率口径分开**：采集 / 显示实时性由 PL 保证；推理按物料触发，不逐帧跑。
3. **位置按编码器 / 步进计数算，不按"速度 × 时间"算**：X = X_拍摄 + (ENC_now − ENC_拍摄)·k；停带、变速、反转时坐标自动正确。
4. **质检逻辑自洽**：OK 盒只有确认的 OK，NG 箱只有确认的 NG；判不准 / 冲突 / 漏检进复检。
5. **物料无关的前景定位**：背景差分 / 阈值 + 轮廓，不绑定单一物料几何。
6. **指令分辨率与实测精度分开报告**。

## 已锁定的关键决策

| 项 | 决定 |
|---|---|
| 物料 | 多规格、浅色多色的 POM 齿轮（齿条已取消）：NPU 判缺陷 {良品, 缺料, 飞边, 黑点}（良品含全部规格颜色），规格（齿数 / 外径 / 孔径）由测量判，颜色由色调判；尺寸超差 / 混料也由测量判 |
| 分拣 | 多件随机摆放 + 传送带跟踪抓取；机械臂**只夹 OK**；NG 不停带，侧边导流挡板分流（挡板 1 报废、挡板 2 返修；挡板不动作的件走带尾 = 复检，失效安全） |
| 机械臂 | DS-SY15A 总线舵机，6 轴全用（#1~#4 + #5 腕旋 + #6 夹爪），**PL 直驱总线（经 BSS138）**；PWM 双驱动降 P2 |
| 急停 | 常闭串在主电源上同时切步进 + 全部舵机；常开报 PL 锁存，需 UI 手动复位 |
| 显示 | HDMI 1080p；必须是真界面（曲线 + 参数配置），不能只放视频流 |
| 语音 + LLM | P2，不挤占 P0/P1，必须有离线命令词表降级 |

## 优先级分级

状态：✅ 已完成 · 🟡 部分完成 / 待实物 · ⬜ 未做。
