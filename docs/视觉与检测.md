# 视觉与检测

> 检测对象、类别表、数据集与模型上板路线；实测数字见 [测试与验证](测试与验证.md)，明细见 `log/`。

## 检测对象（✅ 定版）

**多规格、多颜色的 POM 齿轮**（纯塑胶注塑件）：宽度在夹爪张口内、有 ≥8mm 夹持高度、平放稳定，有标准几何尺寸便于测量。齿条已取消，全部按齿轮测（`des_app.json` gear_ratio 0；沿革见 [log/2026-10-18](log/2026-10-18-取消齿条与倾斜下探.md)）。

## 缺陷制造（冷加工，可复现）

| 缺陷 | 做法 |
|---|---|
| 缺料 | 锉齿顶 / 剪整齿 |
| 飞边 | 同色 AB 补土卡进齿槽或孔里；轻 = 1 处（孔里填不到一半也算 1 处），重 = ≥2 处或孔里填过一半 |
| 黑点 | 油漆笔点（不刷透明指甲油，良品也不刷，两边表面一致；采集前检查有没有蹭掉） |

缺陷要在相机分辨率下看得见：视野约 373mm 宽 / 1920px ≈ 0.19mm/px，需要时降低相机高度收到约 200mm（≈0.1mm/px）。

## 数据集

- 每类 ≥300 张、≥30 个零件（5 类 ≥1500 张；7 类 ≥2100 张）；覆盖不同位置、朝向、进入方向、亮度扰动。train/val = 9:1。
- **独立测试集按实物样本划分**：每类 2~3 个从未参与训练的实物样本。
- 必须在**最终光学条件**下采（两侧条形光、最终相机高度），否则重采；光源人工手动（不接 PL）→ 全程档位固定并记录。
- **对射激光**：零件经过光束时侧面会被照出小红点，训练 / 测试图都不收带红点的（`train/drop_laser.py`）；最后开着激光实测，有影响时先让投票跳过带红点的帧；把红点图加回训练集必须每类都有，否则红点会被当成判断依据。
- **7 类训练要点（过程见 [log/2026-10-29](log/2026-10-29-7类模型训练与上板.md)）**：① 不做灰度增强（训练图随机 30% 转灰度会让 UINT8 量化掉分；整体不靠颜色）；② 训满 60 轮、取最后一轮权重（不提前停、不按测试集挑选）；③ 良品要含全部规格（缺规格会被误判，孔 8 已挪进训练集）。
- 采集：`des_tool collect`（`ps/src/app/collector`）每次只放一类，PS 用轮廓自动生成框（标注 = 按类别分文件夹）；物料贴死时自动框出错就丢弃该帧。

## 视觉定位与角度

- **阈值（按白电平）**：`locate.rel_thresh` 0.65 = 像素亮于「该位置白纸亮度（flat.json）× 0.65」才算零件（下限 `rel_floor` 25）。零件顶面约为白纸的 0.97~1.02，皮带与接缝反光远低于此；无 flat.json 时退回 Otsu。改用相对阈值的经过见 [log/2026-10-24-PS与工具链优化](log/2026-10-24-PS与工具链优化.md)。
- 夹爪随机姿态抓取需要角度 θ：降采样灰度图阈值 + 轮廓 → `minAreaRect` 得 x, y, θ, 宽, 高，近方形物料取窄边方向夹；另一路径是二值 blob 二阶矩 `θ = ½·atan2(2μ11, μ20−μ02)`。
- 两件贴死时连通域会连成一个 blob → 判"粘连"不抓、流到带尾复检。
- 主线在 PS（`ps/src/app/locate`，1/4 降采样）；PL `des_vision` 只做显示与粗测。定位耗时见 [测试与验证](测试与验证.md)。

## 相机标定（像素 → 台面毫米）

`des_tool calib-cam`（`ps/src/measure/calib`）：一张平放在皮带上的棋盘格 → **皮带平面单应矩阵**，写进 `calib.json`，`load_config` 读完 `des_app.json` 后自动合并。

**台面坐标系**：x 沿皮带前进方向；y 是从上往下看 x 逆时针转 90°（右手系，z 朝上，机械臂 IK 依赖这一点，不能镜像）。**原点**：x = 0 在视野上游边缘（画面中线处），y = 0 在画面中线。抓取线、带尾位置都用尺子从视野上游边缘量。

**操作**：
0. **标定板用 A4 打印的棋盘格**（现用打印件 10×7 格、格边 25mm、内角点 9×6，换板时同步改 `--board` / `--square`）。打印选「实际大小 / 100%」，贴在硬平板上（KT 板 / 亚克力，不起翘、不反光）。
1. 标定板**平放在皮带上，一条边贴着侧挡边**（板的一条轴 = 皮带方向）；整块板都在画面里，最好占画面一半以上。
2. **卡尺量一格的边长**（打印件会缩放，以实测为准）。
3. `/root/des/des_tool.sh calib-cam --board <列>x<行> --square <mm> --travel right --dump /root/des/calib.png`
   - `--board` 是**内角点**数（黑白格交点）：10×7 个格子 → `9x6`；
   - `--travel` 是皮带在画面里往哪边走（right / left / down / up）。
4. 看输出的残差（rms / max）和 `calib.png`：红色 x 箭头应指向皮带前进方向，网格每格 50mm。

**限制**：单应只描述**皮带平面**。零件顶面比带面高（齿轮约 10mm）→ 有视差，见「视差」。视差校正 / 镜头畸变校正属测量功能（P1）。

**检测速度与超时**：经典角点 → 半分辨率 sector → 全分辨率穷举（`--exhaustive`）三级检测。⚠ `--board` 填错时经典检测器会搜好几分钟，故检测放子进程，默认 20s（`--exhaustive` 120s），超时杀掉并提示检查内角点数。

### 传送带标定（mm / 步 + 方向，`des_tool calib-belt`）

相机标定之后做。一个零件放画面上游边缘附近（整件在画面里）→ `/root/des/des_tool.sh calib-belt`：
1. 短走约 8mm（按配置里的 mm/步）→ 粗比例 + 方向；
2. 长走到画面约 75% 处 → 用整段位移 / 总步数算 mm/步（位置取 7 帧静止中位数）；
3. 退回起点 → **往返误差**（打滑 / 回差）、横向漂移（mm / 100mm，> 2 说明相机 x 轴没沿皮带或跑偏）、等效辊径。

结果写进 `calib.json` 的 `belt` 段（`load_config` 合并，覆盖 `des_app.json`；重跑 `calib-cam` 时保留）。选项：`--belt <mm/s>`（默认 20）、`--steps <长走步数>`、`--out`。两段比例差 > 25% 或零件没动会报错不写。当前 mm/步与往返误差见 [测试与验证](测试与验证.md)。

### 计米轮编码器标定（mm / 计数 + 方向，`des_tool calib-enc`）

计米轮（E6B2-CWZ6C 1000 线，PL `des_io` 4 倍频 → 名义 200mm 周长 / 4000 = 0.05mm / 计数）压在带面上，量的是**皮带本身**，不经过主动辊。`calib-belt` 之后做，**空皮带**：`/root/des/des_tool.sh calib-enc -n 3` —— 每轮下游走 300mm（`--steps` 可改）再退回，全程每 10ms 采一次（时间、步进位置、编码器计数）。输出：mm / 计数与方向、轮周长、往返误差、加减速滞后、匀速段带速、Z 脉冲数、非法 A/B 跳变数（> 0 = 干扰或太快 → 加 4.7k 上拉）→ `calib.json` 的 `encoder` 段（合并到 `belt.enc_mm_per_count / enc_dir`）。编码器不计数时（没接 / 没压到带面）报错不写。跟踪抓取仍用步进位置（帧起始锁存 `CAP_POS`）；编码器先用于验证打滑，界面显示见 [软件与UI](软件与UI.md)。

### 平场（零件裁切图亮度归一，`des_tool calib-flat`）

4.2mm 广角镜头的渐晕加两侧条形光不均，视野边缘明显偏暗（实测见 [测试与验证](测试与验证.md)），同一零件在不同位置裁出来亮度不同，NPU 会当成差异。`calib-flat`：空白 A4 横放在上料端、盖住视野上游边，皮带每次带它走 40mm（`--steps` 可改），每站 4 帧平均，直到纸前沿到达视野下游边再多一站，然后退回；像素在「自己最暗 ~ 最亮」之间超 60% 且离纸边 25px 以上才算纸面，求平均 → 平滑 → 48×27 白电平网格 → `des_app.json` 同目录的 `flat.json`（`flat_file`，相机重标不覆盖）。`crop_part` 把裁切图乘 ref / white（白电平按 8×8 节点取值插值，增益限 1/3~3）——NPU 输入、NG 存图、训练集都走它，训练与推理一致；几何测量和定位用原始帧。**换相机位置、灯光、曝光后重做**，并重采训练图。

## 几何测量（P1，`ps/src/measure/measure`）

管「尺寸超差 / 规格混料」两类 NPU 不判的 NG，也给缺齿 / 缺料 / 飞边一个与 NPU 无关的第二意见。每件只在**一帧**里测（见「视差」）。

**流程**：ROI 二值化（Otsu 只用来找轮廓）→ 外轮廓 + 最大内孔 → 沿每个轮廓点的法线找灰度穿过 **50% 电平**（皮带、零件两类灰度中位数的中点）的亚像素位置 → 单应映射到台面 mm → 视差校正 → 拟合。

| 输出 | 方法 |
|---|---|
| 外径（齿顶圆）、根径、孔径、偏心（孔心 − 齿顶圆心）、**规格齿数**、缺料齿 / 缺齿 / 飞边齿槽数、r(θ) 曲线（720 点，UI 画图用） | r(θ) 过半高的段 = 齿；**规格齿数由齿距算**（30 齿缺 2 个和 28 齿都只看到 28 个齿，但 28 齿的齿距是均匀的 12.86°）：先取相邻齿间隔的中位数，再取中位数 ±25% 以内间隔的**平均**（缺齿处的双倍间隔会把中位数推高半格，齿相位网格同样用平均齿距）；齿顶圆只用法线接近径向的点拟合（模糊磨圆齿顶角会混入） |

**飞边三种样子都要判**：① 齿槽底被填高（槽底比中位槽底高 > `flash_mm`）；② 填到半高以上、两齿连成一段（宽度 = (n−1) 个齿距 + 1 个齿宽 → 多出的齿数 = 飞边）；③ 齿槽中间立着一小块（看着像多一个齿）→ 按**齿相位**判：偏离齿距网格 ¼ 齿距以上的段是槽里的料，且峰值 ≥ 中线 + ¼（齿顶 − 中线）才算（刚过中线的单点可能是毛刺或噪声）。

**标准件标定**（报告值 = `measure.size_gain` × 拟合值 + `od_offset_mm` / `bore_offset_mm`，齿判定用原始拟合）：用 20 / 28 / 30 齿（孔 6 / 孔 8）四件在画面正中拟合增益与偏置（单偏置随规格漂移；多规格拟合后换规格不用再分别定偏置，过程见 [log/2026-10-28](log/2026-10-28-多规格尺寸标定.md)）。偏置值与实测重复性见 [测试与验证](测试与验证.md)（孔径同样读小：亮顶面往孔里扩）。**位置**：尺寸只在画面中心附近可靠（外径横向偏离会偏小、孔径远离中心会偏大）→ `bore_near_arc`：离开中心只用靠光轴一侧的孔口圆弧（横向 ±42mm 内可靠），⚠ 沿带小偏离时偏小，默认关。**换曝光 / 灯光 / 相机后重做**（`des_tool.sh measure -n 20`，标准件放画面正中）。

**视差**（`camera_h_mm` 填实测相机高度后启用；当前配置 4.2mm 镜头、H 295mm；下面用 8mm 镜头 / H≈360mm 作推导示例）：
- **侧壁暗**（只有顶面亮，`walls_visible` false，**现行生产配置**，灯为高位朝下）：整件按 1/k 缩回，没有拖影限制；判齿形由 `judge_max_dist_mm`（40）限定离光轴的距离，**横向 ±40mm 内齿形与尺寸都可信**（实测扫描见 [log/2026-10-24-缺齿样品初测](log/2026-10-24-缺齿样品初测.md)）。
- **侧壁亮**（`walls_visible` true，旧灯位）：亮区 = 底面（×1）到顶面（×k）所有截面的并集；远离光轴一侧的边是顶面边（缩回 1/k），朝向光轴一侧是底面边（不动），沿光轴方向的边是竖棱投影，直接丢掉。此时有**拖影限制**：每条边沿「离开光轴」方向拖长 smear = (k−1)·|中心 − 光轴|，顺齿排方向会填平齿槽；smear > `max_smear_mm`（0.6mm）时**外径 / 孔径照常给（已校正），齿的判定不做**（`teeth_judged = false`）。现 H=295、厚 10.05 → 系数 0.035/mm，对应零件中心离光轴 ≤17mm；导向条收在中线 ±10mm 时拖影 ≤0.36。
- 跟踪里每件**选离光轴最近的那一帧测**；横向偏移靠摆放或导向条收口。还超的 → 复检（`measure.rule.unjudged_recheck`，默认开，尺寸判废打开后生效：NPU 判 OK 但齿形不判的件不抓、也不按外径 / 齿数判报废）。拖影超限时测到的缺齿 / 缺料不能用（远侧齿槽被侧壁填平，报乱数；实测见上述 log）。
- **导向条**（相机上游 V 形收口）：零件中心要同时落在三个范围——判齿形 / 尺寸（离光轴 ≤40mm）、NPU 训练数据覆盖（采集时中线 ±40mm 内）、机械臂抓取线竖直可达（台面 y −10~+60，+y = 机械臂侧）→ 交集 y −10~+40，留余量取 **y 0~+30（出口中线在光轴往机械臂侧约 15mm）**。出口宽 = 齿轮外径 32 + 摆动 → **50~60mm**（中心在出口中线 ±9~14mm）。收口两边与前进方向夹角 ≤30°（再陡零件打转不走），入口按放料范围定（160mm → 25° 时收口段约 110mm），收口后再有 30~50mm 平行段；条底离带面 0.5~1mm、不压皮带，高度 ≥ 齿轮厚一半，接触面可贴 PTFE 胶带；最好整条在视野外，伸进画面的部分贴黑色哑光胶带（浅色条会被当成零件）。装好后看记录里的 y 分布微调。
- ⚠「光轴」默认取画面中心映射到台面（`axis_from_image`），只在相机垂直向下时成立；视差真正的中心是**相机正下方那一点**。相机倾斜时两者分开 → 先把相机调平（≤2°），否则用 `axis_table` 填正下方点。
- 视差同样影响**位置**：`load_config` 把「绕正下方点按 1/k 缩放」并进单应得 `px_to_part`（`measure_config.hpp` `part_homography`；侧壁暗 k = H/(H−h)，侧壁亮时斑点中心在顶面与底面中间，k = (2H−h)/(2(H−h))）——定位、跟踪、PL ROI、画面叠加、零件裁切全部用它，几何测量照旧用带面单应（它逐个边缘点自己校正）。只有 `measure.camera_h_mm` 填了实测值才生效。

**合成图测试**：`ps/tests/test_measure.cpp` / `test_calib.cpp` 全过，误差数字见 [测试与验证](测试与验证.md)。⚠ 合成图精度 ≠ 实测精度（实拍另有畸变、倒角 / 毛刺、光照不均）；实测精度用卡尺量过的良品件标（样本登记表在仓库外），报告里分开写。

**卷帘快门**：整帧读出约 16ms，期间皮带走了 b1−b0（PL 锁存的帧首 / 帧尾带位置）；每个边缘点按所在行退回到帧中间那一刻（`belt_mm_per_row`，与定位的行时间补偿同一口径）。

**接入 `des_app run`（✅）**：`app/track_measure`（`TrackMeasurer`）在核 1 工作线程、跟踪表更新之后运行：
- 每帧最多测 `per_frame`（默认 1）件，**没测过的优先**，之后只有「离光轴距离 < 0.75 × 上次 − 1mm」才重测；
- 只测整个外框（+3mm）都在画面里的件；ROI 直接从相机缓冲转灰度，测完若该缓冲已被 DMA 复用就丢弃结果；
- 结果存进跟踪表 `Track::meas`（`PartMeasure`），画面标签 `OD32.02 z30`，有缺陷跟 `miss2` / `short1` / `flash1`（z = 按齿距算的规格齿数，30 齿缺 2 仍是 z30；齿未判时显示 `OD31.67 off-axis`、不显示齿数）；CAN 每件结果的 `size_mm` = 测量值（0 = 没测到）；
- **判定**（`tracker` 的 `SizeRule`，`des_app.json` 的 `measure.rule`，默认开；界面「尺寸判废」开关与公差在板上 `ui_params.json`，优先于配置）：只复核「按类别要抓取」的件（不把 NPU 的 NG 改成 OK）——规格齿数不符 / 外径超差（公差 = 配方卡尺均值 ±0.2）/ 孔径超差 / 偏心 > 0.3 → 导流挡板 `scrap`；NPU 判 OK 但测到缺齿 / 缺料 / 飞边（且齿已判）→ 复检；NPU 判 OK 但齿未判（离光轴过远）→ 复检（`unjudged_recheck`）；但模型置信度 ≥ `measure.rule.unjudged_pick_conf`（现 0.8，11-01 用户「模型能判定出正确类型就夹」）时按模型照样夹，这类件不再核对齿形 / 尺寸 / 规格，原因列写 `off-axis: model only`。测量另给出缺陷程度与尺寸 / 规格（配方名义值见 `scripts/deploy/out/recipes.json`）。
- 耗时见 [测试与验证](测试与验证.md)（自动测试在 `ps/tests/`，构建时运行）。

**已实测 / 待实测（⚠）**：标定与交叉验证、7 类准确率、量化上板全链路见 [测试与验证](测试与验证.md)；开激光整线的轻飞边合计检出率、实物跑线 Cpk 待实测。

## 模型与量化路线

官方两个 ONNX 已逆向：量化格式为 **QDQ / UINT8 / per-tensor**，`fire_detect` 的 producer 是 ORT `quantize_static` 的签名，结构是标准 ultralytics YOLOv8n（Detect 前截断）。详见 [log/2026-09-20](log/2026-09-20-NPU与硬件实测.md)。

**✅ 已定：PS 定位 + 每件 ROI 裁切 → NPU 分类（YOLOv8n-cls @ 224，激活换 ReLU）。**
- 原因：**4.2mm** 镜头（H72° V56°）+ IMX415 全幅 2×2 合并读出（`WINMODE=0`、`HADD/VADD=1`），1080p 保留全视场（标定 0.1945mm/像素、视场约 373×214mm）；整帧缩到 416 后 1mm 缺陷只剩约 1 像素，按零件裁 56mm→224px 约 4 像素。
- 做法：`roi_crop`（零件中心、转正到零件轴向）→ NPU 分类（现 7 类）→ 每件分类 3~6 次，概率软投票（`Tracker::vote`），置信度 = 胜出类的平均概率。定位、多件跟踪仍是 OpenCV（已在 60fps 主循环里）。
- 标注：不用画框（采集即按类别分文件夹，见「数据集」）。
- 工具链：`train/`（合成数据冒烟 → 训练 → 导出去 Softmax → ORT 量化 → 板上 `test_npu` 核对 + 测耗时）。
- 板上实测：单次推理耗时、加载时间与准确率见 [测试与验证](测试与验证.md)。量化后必须 `infer_shapes`，否则板上 ArmNN 解析器段错误。

**备选路线（未采用）**：整帧检测 YOLOv8n @ 416×416——1mm 缺陷只剩约 1 像素，精度不够，故用分类路线。导出 / 量化流程与分类路线相同（QDQ/UINT8/per-tensor，校准集 100~300 张）；采集时 `des_tool collect --full N` 可同时存整帧 + 自动框。

帧率不够的退路：走 `yolo_face` 极简路线（416、13 层 Conv、纯 ReLU、双头 anchor 版）；最保守兜底：照 `fire_detect` 原结构训，只改输出通道数。
