## CEP 排针（J12，2.54mm 2×13）

- FEP 被 VID005 占用，运动控制 IO 只能走 CEP：26 针 = PIN1 电源 + PIN2 地 + **24 根信号**（12 对差分）。
- 信号 = 底板网名 `B13_` → DR1 **BANK11** → **固定 3.3V LVCMOS，不可调**。
- **PIN1 `VCC_CEP1` = 3.3V**（经磁珠取自 3.3V 主轨；5V 路为空焊位，**无跳线**），只给逻辑用，合计 <100mA；传感器 / 继电器 / 编码器一律外部供电。

## IO 分配

| PIN | 信号 | 方向 | 电平处理 | 接到 |
|---|---|---|---|---|
| 3 | `STEP_PUL` | 出 | **3.3V 直驱，高有效**（共阴） | 驱动器 PUL+（PUL− 接地） |
| 4 | `STEP_DIR` | 出 | 3.3V 直驱 | 驱动器 DIR+（DIR− 接地） |
| 5 | `STEP_ENA` | 出 | 3.3V 直驱，**高 = 脱机** | 驱动器 ENA+（ENA− 接地） |
| 6~8 | `ENC_A/B/Z` | 入 | 4.7k 上拉 3.3V | 编码器（NPN OC，P1） |
| 9 | `IR1` | 入 | 上拉 3.3V | 对射光电接收端（抓取线上游） |
| 12 | `LIMIT1` | 入 | 内部上拉 + 去抖 | 翻板回位限位（可选） |
| 15 | `ESTOP_IN` | 入 | 内部上拉，**低 = 急停** | 急停常开触点，另一端接地 |
| 17 | `LAMP_EN` | 出 | 直驱 | MOSFET 模块 → 光源（P2 可做曝光同步频闪） |
| 18 | `FORK_PWM` | 出 | 直驱（舵机门限 2.0V） | 翻板舵机（第 1 级；沿用原拨叉信号名，寄存器侧为 `FLAP_*`） |
| 19 | `SERVO_BUS` | 双向 | **BSS138 双向电平转换** | 机械臂舵机链 |
| 10、11、13、14、16、20~26 | — | — | — | 空闲 12 根（翻板第 2 级需占 1 根，待分配） |

CEP 只有 PIN2 一根地 → 在转接板上做一小段地线母排分出。

## 电平结论

- **舵机总线空闲电平实测 3.7V**，超过 3.3V IO 绝对最大值 → **必须经 BSS138 双向电平转换**，禁止直连；不可用 TXS0108E 类自动方向芯片（强上拉总线上会误判锁死），不可用纯电阻分压（发送方向余量不足）。BSS138 高压侧默认接 5V（⚠ 待实测确认）。
- 舵机六路信号脚通断档实测**并联** → 确认是总线舵机。

## 步进驱动器（✅ 实测）

> **2026-10-10 接法改为共阴、FPGA 3.3V 直驱，取消 74HCT245**（免焊）：PUL+/DIR+/ENA+ 接 CEP，PUL−/DIR−/ENA− 接地；顶层 `STEP_COMMON_CATHODE=1` 反转极性。
> 驱动电流约 6~8mA（偏低但常见可用），⚠ 待 `step_test` / 实物点动确认；丢步则加「74AHCT125 电平转换模块」并改回共阳（参数置 0）。以下为驱动器本体实测：

- 输入**共阳极**：PUL / DIR / ENA 三个 `+` 端内部不导通，需外部都接 +5V；PL 侧三路全部低有效。
- 拨码：`1=OFF 2=OFF 3=ON 4=OFF 5=ON 6=ON` → 16 细分（3200 脉冲 / 圈），2.5A / 峰值 2.7A。
- 电机接线：`B−` 绿、`B+` 黑、`A−` 红、`A+` 蓝。
- 点动测试工程见 [pl/test/step_test](../pl/test/step_test/)（测试时为共阴极 / 高有效，最终改回共阳）。

## 供电树

```
插排（220V 总闸）
├─ FPGA 板原配适配器 12V
├─ 12V 适配器 ─→ MOSFET 模块（栅极 = LAMP_EN）─→ 光源
└─ 24V 主电源 LRS-350-24（FG 必须接地）
   ├─ +V1 ─ 急停【常闭】─→ 受控 24V 母排（急停一拍全断）
   │                        ├─ 步进驱动器 VCC
   │                        └─ 数控降压（XY6020L）→ 7.2V · 恒流限流 → 7.2V 母排 + 1000µF
   │                                                  ├─ 舵机链入口 A（底座 #1）
   │                                                  ├─ 舵机链入口 B（臂中段 #3/#4）
   │                                                  └─ 翻板舵机
   ├─ +V2 ──→ 常电 24V 母排（急停不断）
   │           ├─ 5V 降压 → 5V 母排（74HCT245、驱动器 PUL+/DIR+/ENA+、BSS138 HV）
   │           ├─ 编码器 V+
   │           └─ 对射光电 V+
   └─ −V ──→ 24V GND 母排 → 所有 24V / 5V 负载的地；**单点**接 CEP PIN2
   XY6020L OUT− ──→ 7.2V GND 母排 → 舵机链、翻板地（与 24V GND 母排不外接）
```

- **分段供电**：菊花链电流逐级累加，6 舵机峰值 >10A，单个连接器针约 3A → 链上两处进电（底座 #1、臂中段）。
- **单点共地**：PL 地只在 24V GND 母排一点相连。**XY6020L 的 OUT− 与 IN− 不可外部短接**（会旁路低边采样电阻，限流失效）。
- 线规：主干（电源 → 急停 → 母排 → 降压）16AWG；母排 → 驱动器 / 舵机入口 20AWG；信号与小电流支路 22AWG / 杜邦线。
- 多股软线进螺钉端子必须压管型端子；一个端子只压一根线；电源线两端贴线标；电解电容注意极性。

### 舵机供电实测

原链路（12V/5A/60W 适配器 → 扩展板内部降压）舵机 V+ 实测 6.87V，在规格内；带不动的原因是 60W 不够（4 轴堵转约 75W），不是舵机坏。

## 急停逻辑（✅ 一起切）

| 部分 | 行为 |
|---|---|
| 常闭触点 | 串在主电源 +V1 → 受控 24V 母排：按下**同时断步进和全部舵机**（含翻板） |
| 常电 24V | **不断**：5V 逻辑、编码器、光电保持 → PL 仍能读急停，电平转换器不断电，引脚不浮空 |
| 常开触点 | → `ESTOP_IN`（低有效）→ PL 把全部输出置安全态并**锁存** |
| 复位 | 拔起急停 → UI 点"复位" → PL 解锁，**不自动重启** |
| 降压模块 | 设为"上电不自动输出" |

## 操作规范

- ⚠ 新电源首次接入机械臂前，**必须逐个测舵机 V+~GND 电阻并检查旷量**，排除短路。
- 改接线先查本文件；电平不确定先量再接。
- PL 侧操作禁忌（运行 Linux 时禁止 JTAG 下载 SRAM 等）见 [09-开发环境与构建](09-开发环境与构建.md)。
