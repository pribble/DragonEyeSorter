# 05 · 硬件与接线

> 接口资源、电平与供电结论、IO 分配与操作规范。实测数据见 `log/`；引脚与原理图细节以板卡手册和原理图为准。

## 接口资源约束

- FEP 高速口被 VID005 视觉子卡占用，运动控制 IO 只能走底板 CEP 排针（26 针 = 电源地 + 24 根信号，12 对差分）。
- 板载已有、不占 CEP：CAN、RS485、HDMI、千兆网 ×2、USB、WiFi/4G、音频、按键、LED。

## 电平结论（已查原理图，待万用表复核）

- CEP bank 电压**固定 3.3V LVCMOS，不可调**（BANK11 与 PS 端 BANK200 相连，核心板定死）。
- `VCC_CEP1`（1 脚）= 3.3V 主轨经磁珠的滤波支路，无跳线可选（5V 路为空焊位）。**只能给逻辑供电**（电平转换、上拉、基准），合计电流控制在 100mA 以内；传感器 / 继电器 / 编码器一律从外部电源取电。
- 舵机总线空闲电平实测高于 3.3V IO 的绝对最大值，**禁止直连**，必须加 BSS138 双向电平转换（无方向性结构）。不要用 TXS0108E 等自动方向芯片——带强上拉的总线上会误判锁死。
- 备用降级路径：PL → I2C → 现有 STM32 扩展板 → 舵机总线（零电平风险，但拿不到遥测，健康诊断线断）。

## 供电原则

- 舵机轨由独立电源供电，多轴同时启动的浪涌功率必须按堵转电流核算，不得依赖原小功率适配器。
- 电源切换 / 新电源首次接通前，必须先完成逐个舵机的电阻与旷量检查。
- 扩展板舵机座 V+ 是其内部降压输出；外接电源灌同一 V+ 会与之对顶。正确做法：延长线断开 V+，信号线接扩展板，GND 共地。

## IO 分配（CEP 24 根信号，草案）

| # | 信号 | 方向 | 电平处理 | 去向 |
|---|---|---|---|---|
| 1~3 | `STEP_PUL/DIR/ENA` | O | 电平移位到 5V | 步进驱动器 |
| 4~6 | `ENC_A/B/Z` | I | OC 上拉 3.3V | 增量编码器 |
| 7~9 | `IR1/IR2/IR3` | I | OC 上拉 + 光耦 | 工位光电传感器 |
| 10~12 | `LIMIT1~3` | I | 上拉 + 去抖 | 端点 / 拨叉复位限位 |
| 13 | `ESTOP_IN` | I | 上拉 | 急停按钮 |
| 14 | `PUMP_EN` | O | 光耦继电器 | 气泵 |
| 15 | `LAMP_EN` | O | 直驱 | 三色灯 / 蜂鸣器 |
| 16 | `FORK_PWM` | O | 直驱 | 拨叉 PWM 舵机 |
| 17 | `SERVO_BUS` | I/O | **BSS138 双向转换** | 机械臂总线舵机 |
| 18~21 | `SERVO_PWM1~4` | O | 直驱 | 机械臂 PWM 模式 |
| 22~24 | `SPARE1~3` | — | — | 预留 |

> 差分对的具体引脚号、约束重排以硬件手册引脚表为准；写约束时按噪声考虑重排。

## 操作禁忌

- **Linux 运行期间禁止用 BitWriter 往 SRAM 下载 bit**：Linux 所需的 MIPI/VDMA/HDMI/NPU IP 全在 PL，JTAG 会直接覆盖它们。SRAM 下载易失，断电重启恢复。
- `mipicam.ko` 为动态模块，不跨重启，重启后必须重新 insmod（或改 built-in / 开机脚本）。
- 厂商脚本 `run_mipicam_fb_fire_recognition.sh` 缺 `-s` 参数属已知 bug，手动补参绕过。
