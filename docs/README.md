# 文档索引

## 文档如何演进

- 设计文档记录**当前共识与设计意图**：做什么、为什么、怎么验证；结论以**手册、原理图、实测结果**为准。
- ⚠ = 待实测回填，✅ = 已确认；“草案，待确认” = 未拍板。

## 修订规则

| 变更类型 | 去处 |
|---|---|
| 设计意图 / 方案调整 | 直接改对应设计文档 |
| 实测 / 验证结果 | 新增 `log/YYYY-MM-DD-主题.md`，相关设计文档同步定性结论 |
| 结论被推翻 | 设计文档改写，log 留痕不删 |
