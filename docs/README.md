# 文档索引

## 文档如何演进

- 设计文档记录**当前的工作共识与设计意图**：做什么、为什么这样做、打算怎么验证；随验证推进与新的实测证据持续修订。
- 一切结论以**手册、原理图与实测结果**为准。实测数据进入 `log/` 按日期存档，设计文档吸收其结论并保持同步。
- 设计文档回答"打算做成什么样"，`log/` 记录"实际测到了什么"；log 数据与设计假设不符时，修订设计文档。

## 修订规则

| 变更类型 | 去处 |
|---|---|
| 设计意图 / 方案调整 | 直接改对应设计文档 |
| 实测 / 验证结果 | 新增 `log/YYYY-MM-DD-主题.md`，并在相关设计文档同步定性结论 |
| 结论被推翻 | 设计文档改写，log 保留旧记录留痕，不删 |
