# 文档索引

## 文档如何演进

- 设计文档记录**当前的工作共识与设计意图**：做什么、为什么、怎么验证；随实测证据持续修订。
- 一切结论以**手册、原理图与实测结果**为准。实测数据进入 `log/` 按日期存档，设计文档吸收其结论并保持同步。
- 标 ⚠ 的是待实测回填项，✅ 是已确认；标"草案，待确认"的是尚未拍板的建议。

## 修订规则

| 变更类型 | 去处 |
|---|---|
| 设计意图 / 方案调整 | 直接改对应设计文档 |
| 实测 / 验证结果 | 新增 `log/YYYY-MM-DD-主题.md`，并在相关设计文档同步定性结论 |
| 结论被推翻 | 设计文档改写，log 保留旧记录留痕，不删 |
