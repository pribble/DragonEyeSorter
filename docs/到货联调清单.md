# 到货联调清单（按顺序做，每步有命令和判定标准）

> 操作单：只写命令、做法与判定；数字引用 [测试与验证](测试与验证.md)（唯一源），现场记录进 `docs/log/`。板端命令在 SSH 里执行：`ssh $BOARD_HOST`；**`des_app` / `des_tool` 运行期间 `desreg` 只用 `r` 只读**（舵机总线 / 步进只能有一个主人）。
> PS 四层见 [ps/README](../ps/README.md)：产品用 `des_app.sh`（`run` / `live`），运维用 `des_tool.sh`。引脚见 [硬件与接线](硬件与接线.md)，机械臂见 [运动控制与分拣](运动控制与分拣.md)「上电调试步骤」，标定见 [视觉与检测](视觉与检测.md)。

## 1. 电源与安全（接任何执行器之前）

| 步 | 做法 | 判定 |
|---|---|---|
| 1.1 | 万用表逐个量舵机 V+~GND 电阻（C4）；顺手检查每个舵机输出轴旷量 | 无短路（几 kΩ 以上，记录数值）；旷量明显异常先换舵机 |
| 1.2 | XY6020L 设 **6.8V**、限流约 5A、上电不输出；有过压保护（OVP）就设约 7.2V、有按键锁就锁上（旋钮被碰到会改电压，夹爪舵机上限 6.0V 已在超用）。输入取**受控 24V**（急停常闭之后），输出 → 6.8V 母排，OUT− 不接 24V 地；舵机链和挡板舵机的电源线从 5V 模块上拆下改接 6.8V 母排，5V 模块只留 BSS138 高压侧和编码器 | 空载（不接舵机）万用表量 OUT 6.8V；接舵机后开输出，静止电流约 0.1~0.5A、机械臂不自己动 |
| 1.2b | **10-25 换用 300W 20A 恒压恒流降压模块（无屏，XY6020L 屏坏）+ 片式保险丝**。① 只接输入（受控 24V，急停常闭之后；与 TB6600 同一 WAGO），输出什么都不接，上电量 OUT：这类模块出厂常偏高（可能 >10V），拧 CV 电位器（多圈，通常顺时针升高）调到 **6.80V**。② 限流：断电 → **先把 CC 电位器往减小方向拧 15~20 圈到底** → 万用表 10A 档表笔直接接 OUT+ / OUT− → 上电 → 慢慢加到约 **6A** → 断电拆表（不调也行：CC 拧到最大、靠舵机堵转 3s 自保护，但万用表短接测试前必须先拧到最小）。③ 保险丝座串在 OUT+ 与 6.8V 母排之间，先放 **7.5A**；OUT− 只进 6.8V 地母排（同 XY6020L：不与 24V 地外接，模块多为低边采样）。④ 舵机链（原厂线 V+ / GND）和两个挡板 MG996R 的电源从 5V 临时模块挪到 6.8V 母排；5V 模块只留 BSS138 高压侧和编码器 | ① 空载 6.80V；② 短路电流约 6A；③ 保险丝后母排 6.80V；④ 接舵机上电后机械臂不自己动；`desreg ping 1`~`6` 全应答；`des_tool.sh arm scan` 电流 / 温度读数变正常（4.9V 时是无效值 ~3150mA / 255℃）；`/root/bin/test_servo_gap 2` 复测静默窗口。正常动作时保险丝熔断 → 换 10A（不再大，20AWG 线）。⚠ 测急停前让机械臂停在低姿态或用手托住：急停切舵机电源后机械臂会软掉落下 |
| 1.3 | 急停常开触点 → CEP PIN15（另一端接地）；`desreg step vel 800` 让步进空转，按下急停，`desreg step status` | 立即停、`HALTED` 置位；按住时再发 `step vel` 不动；松开后新的运动命令才动（同时清 HALTED） |
| 1.4 | 急停常闭触点串主电源 | 按下时步进驱动器、舵机电源都断 |

## 3. 传送带（TB6600 + 57 步进）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| 3.1 | 拨码 `1=OFF 2=OFF 3=ON 4=OFF 5=ON 6=ON`（16 细分，2.5A）；电机 `B−绿 B+黑 A−红 A+蓝`；PUL+/DIR+/ENA+ → CEP PIN3/4/5，PUL−/DIR−/ENA− 接地（共阴） | — |
| 3.2 | `desreg step vel 1600` → 看皮带 → `desreg step stop` | 平稳走、不抖；**零件在画面里从右往左走**（方向反了改 `belt.dir` 或交换 DIR，`des_tool.sh calib-belt` 也会自动判方向） |
| 3.3 | `desreg step move 3200` | 主动辊正好转一圈 |
| 3.4 | `desreg steplat 100` | 记录「命令 → 第一个步进脉冲」（进测试报告） |
| 3.5 | **计米轮编码器（E6B2-CWZ6C）接线与预检**（10-20 已按此接好：棕 → 5V 母排、蓝 → PL 地；输出带上拉 → A/B/Z 经 BSS138 HV2/3/4 → LV2/3/4 → CEP PIN6/7/8，HV 5V / LV 3.3V、GND 共地，屏蔽线只在板子这头接 PL 地；不接 24V）。重接前先单独测：信号线悬空，蓝–黑 ≈0V、棕–黑极慢转轮在 0 / 5V 间跳 | 读到 ≈5V = 内部带上拉，必须走 BSS138（本批实测转动时约 1.5V）；`desreg io watch 20` 手转一圈：A/B 跳、计数 ≈ ±4000（1000 线 ×4）、Z +1、err 0；err 涨或乱跳 → PIN6/7/8 各加 4.7kΩ 到 PIN1 |
| 3.6 | 计米轮压在有支撑的带面（辊子上方 / 托板上）、摆臂拖行；**空皮带** `des_tool.sh calib-enc -n 3`（往返 300mm × 3 次，约 40s） | 3 次 mm/计数一致（sd < 0.2%）；轮周长与名义 200mm 差 < 3%；往返误差 < 0.5mm；写进 calib.json 的 `encoder` 段。之后界面「带速 xx 实测 xx」、曲线页绿线 = 编码器实测 |
| 3.7 | **皮带跑偏**（10-23：带尾往计米轮那侧偏、带边鼓起）：先排除计米轮——把计米轮抬离皮带，界面「正转」点动 2~3 圈看还偏不偏；计米轮引起的就把它摆正（轮轴与辊子平行）、压力调到「刚好不打滑」、离带边 ≥2cm，并查带尾侧框上的角码 / 螺丝头有没有蹭带边。还偏再调带尾（从动）辊两侧张紧螺丝：**往哪边偏就紧哪边**（或松另一边），每次 1/4 圈，点动 2~3 圈再看；两边别拧太紧（步进带不动）。停着才动手。调完重跑 3.6 | 皮带居中、带边平；calib-enc 复标后 mm/计数变化记录在案 |
| 3.8 | **激光对射光电（M18 直角，NPN）**（PL `des_io` IR1 从 v11 起就有：CEP PIN9 / V6、内部上拉、20µs 去抖，挡光边沿锁存时间戳 / 步进位置 / 编码器）。**位置**：皮带两侧带边外各一个，L 支架竖边用 M5 T 型螺母拧进侧框侧槽、探头竖直穿在水平边上，两颗螺母调到光束离带面 **3~5mm**，出光窗对准对面；沿带放在**挡板 1 摆杆够不着的上游段**（离挡板 1 转轴 ≥25cm，即视野上游半段或上料端；对侧 x≈208~668 被两块挡板扫过，再往下游是计米轮支架）。**先测再接**：只接电源（发射端、接收端都是棕 → 常电 24V、蓝 → 24V 地），接收端黑线悬空，万用表量黑–蓝，挡光 / 不挡各量一次 | 黑–蓝两种状态都约 0V（纯集电极开路）或有一态约 24V（内部上拉）——**后者必须串 1N5819 / BAT85**：负极（色环端）朝传感器黑线、正极接 PIN9；纯 OC 也建议串（防接错）。接好后 `desreg io watch 10`：手挡一下 IR1 `blocked` / 松开 `clear`，edges 每挡一次 +1；极性反了 → `desreg w 0x538 1`（CFG b0） |
| 3.9 | **标定光束位置**：光束要在判定线上游 20mm 以上（现 decide_x 195 → x ≤ 175，推荐视野上游半段）。停服务 → 一个已知外径的齿轮放在视野里、光束上游、中线附近 → `des_tool.sh calib-beam -n 3 --od <卡尺外径>`（皮带带它过光束再退回，3 轮）→ `des_app.json` 改 `"beam": {"enabled": true}` → 起服务 | 3 轮 x 的 sd < 0.5mm，写进 calib.json `beam`；起服务日志有 `beam: x …`；画面上出现 `beam` 线、挡光变红；走带后零件 CSV 末两列 `beam` = matched、`beam_err_mm` 有值，同目录多一个 `beam_<会话>.csv`；`part_stats.py` 出「对射光电：跟踪误差」表 |

## 7. CAN（USB-CAN ZQWL-UCAN-101E）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|

| 7.2 | 板上 `/root/des/can_up.sh can0 normal` | `ip -details link show can0` 为 UP、ERROR-ACTIVE；打印「classic mode refused … FD mode」属正常（驱动只支持 FD 模式，经典帧照常收发） |
| 7.2b | 先不开 des_app，板上 `cansend can0 123#DEADBEEF`；分析仪发一帧，板上 `candump can0` | 分析仪收到 0x123；板子 candump 收到分析仪的帧；分析仪上无错误帧 |

## 7b. RS485（Modbus-RTU 4 路继电器 + 三色灯 + USB-RS485）

> 板载 RS485（SP3485EN，PL 管脚 TX L17 / RX N16 / DE N15）**v15 比特流没引出**，板上联调要等 v16（PL `rs485`，分支 `v16-rs485`）。R1、R2 只用 PC + USB-RS485（`pc/rs485/rs485_tool.py`，要 pyserial），不依赖板子，先做。

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| R1 | 继电器模块接**常电 24V**（不经急停）；USB-RS485 插 PC，A → 模块 A、B → 模块 B（旧网线一对绞线）；`cd pc/rs485` → `python rs485_tool.py ports` 找 COM 口 → `python rs485_tool.py scan --port COMn`（自动试地址 1~16、常见波特率 / 校验）→ 记下地址和波特率；不是 1 / 9600 8N1 的话按说明书改成它，或改 des_app.json `rs485` | scan 报 `address 1 answers`；`python rs485_tool.py coils --port COMn` 读回 0000；不通先对调 A / B（无损），再查 24V |
| R2 | 三色灯：先认公共线——公共线接 24V 地、24V+ 碰红线，亮 = **共负**；不亮就公共线接 24V+、红线碰地，亮 = **共正**。共负接法：公共线 → 24V 地，24V+ → 4 个继电器 COM，各继电器 NO → 绿 / 黄 / 红 / 蜂鸣（继电器 1~4 = 程序里 0~3）；共正反过来（公共线 → 24V+，COM → 24V 地）。然后 `python rs485_tool.py lamp --port COMn red`、`… lamp green yellow`、`… demo`（按 des_app 的灯语轮一遍） | 点哪个亮哪个；顺序不对就改接线，或改 `rs485.lamp_coils`（绿、黄、红、蜂鸣各接几号继电器，同一顺序传给 `--lamp-coils`） |
| R3 | （v16 比特流上板后，`desreg` 读 VERSION 16）板子 J11 **第 5 位 = 485_A、第 6 位 = 485_B**（CAN 占 2 / 3 + 一个 GND，互不冲突；板上 R121 已有 120Ω），模块端有 120Ω 跳线就接上；USB-RS485 并在同一对线上 `python rs485_tool.py sniff --port COMn` 旁听。停服务后：`desreg 485`（状态 / 配置 / 计数，只读）→ `desreg 485 cfg 9600 N 100`（波特率、校验 N/E/O、应答超时 ms）→ `desreg 485 tx 01 01 00 00 00 04`（读 4 个继电器；PDU 十六进制、不含 CRC，打印应答字节 + 时延）→ `desreg 485 tx 01 05 00 00 FF 00` / `… 01 05 00 00 00 00`（继电器 1 开 / 关）；`desreg 485 bc 00 05 …` 广播不等应答；`desreg 485 listen 10` 旁听 10s（PC 当主站时板子收到的帧）；`desreg 485 clr` 清计数 | 读到 4 个继电器状态、开关命令灯照办；sniff 显示请求 / 应答 CRC ok、应答间隔几 ms；`desreg 485` 的帧错误计数不涨 |
| R3b | 测试报告「总线稳定性」：`desreg 485 soak 1000 01 01 00 00 00 04`（连发 1000 次读线圈） | 成功率 100%、应答时延 min / avg / max 记进 [测试与验证](测试与验证.md)；与 CAN 2h 浸泡同一轮再跑一次 |
| R4 | `des_app.json` 改 `"rs485": {"enabled": true, …}` → 重启服务：日志有 `[run] RS485 9600 8N1, relay module at address 1`；界面状态栏 `485 ok`；启动 / 暂停 / 急停 / 复位各做一次；PC：`python mb_client.py lamp red buzzer`（以太网 → RS485）、`python mb_client.py lamp auto`、`python zqwl.py send 105#010401`（CAN → RS485：接管、红灯、序号 1）、`… send 105#000001`（还原）；`python mb_client.py status` 看 RS485 一行 | 绿 运行 / 黄 暂停 / 红 + 蜂鸣 2s 急停 / 空闲绿闪；接管命令 ACK OK、灯照办；RS485 成功次数一直涨、失败 0；报告「总线稳定性」用 mb_client status 的成功 / 失败 / 应答时间 + 2h 浸泡 |

**RS485 一直乱码 / 发不出去（`desreg 485` 帧错误、listen 计数一直涨、发送报 `bus never quiet`）**：
- **总线没偏置**：板上 R121（120Ω）跨在 A / B 上，SP3485 没有「终端后空闲」的失效保护 → 什么都不接、或对端没有偏置电阻时空闲差分 ≈ 0V，接收输出乱跳，PL 一直收到乱码、等不到 3.5 字符静默，请求发不出去。USB-RS485 和多数继电器模块自带偏置，接上一般就好；仍乱就在 A 端加 680Ω~1kΩ 上拉到 3.3V / 5V、B 端同值下拉到地（只在一处加），或去掉一端的 120Ω（2m 线、9600 波特率不需要两端终端）。
- **A / B 接反**：空闲差分为负、总线一直读低，现象同上 → 对调两根线（无损）。
