# 到货联调清单（按顺序做，每步有命令和判定标准）

> 硬件到一样接一样；每步做完在「结果」记一笔（数据同时进 `docs/测试与验证.md` / 测试报告）。
> 板上命令都在 SSH 里执行：`ssh $BOARD_HOST`。**`des_app` 运行期间 `desreg` 只用 `r` 只读**（舵机总线 / 步进只有一个主人）。
> 引脚见 [硬件与接线](硬件与接线.md)，机械臂见 [运动控制与分拣](运动控制与分拣.md)「上电调试步骤」，标定见 [视觉与检测](视觉与检测.md)。

## 0. 开机自检（每次上电）

| 步 | 命令 | 判定 |
|---|---|---|
| 0.1 | `desreg` | `DES_ID 0x44455301`，VERSION ≥ 5（v6 起有 PL 视觉、v7 起有翻板 PWM） |
| 0.2 | `/root/des/des_app.sh probe -n 5` | 约 60fps、无跳帧 |

## 1. 电源与安全（接任何执行器之前）

| 步 | 做法 | 判定 |
|---|---|---|
| 1.1 | 万用表逐个量舵机 V+~GND 电阻（C4） | 无短路（几 kΩ 以上，⚠ 记录数值） |
| 1.2 | XY6020L 设 **6.8V**、限流约 5A、上电不输出 | 空载电压 6.8V |
| 1.3 | 急停常开触点 → CEP PIN15（另一端接地）；`desreg step vel 800` 让步进空转，按下急停，`desreg step status` | 立即停、`HALTED` 置位；按住时再发 `step vel` 不动；松开后新的运动命令才动（同时清 HALTED） |
| 1.4 | 急停常闭触点串主电源 | 按下时步进驱动器、舵机电源都断 |

## 2. 舵机总线（BSS138 + 机械臂）

| 步 | 命令 | 判定 |
|---|---|---|
| 2.0 | 舵机供电线（10-16 定：剪原厂扩展板→1 号舵机那根线的扩展板端）：剪前用原厂板上电量出 V+ / 信号 / GND 各是哪根；V+、GND 进 XY6020L 输出端子（6.8V、限流 5A），信号经 WAGO 接杜邦线到 BSS138 HV 通道；BSS138 GND 接 PL 地（CEP PIN2），**不接舵机地**（系统接线 §4 ①） | 线端万用表：V+–GND 电阻非短路（记录） |
| 2.0a | 剪完后没记哪根是哪根：把剪下来的那个插头（带一截线）插回原厂扩展板，看插座旁丝印（G/V/S 一类）对上颜色——插头上的线和剩下那段颜色一致；或用通断档：PH2.0 三针**中间针 = V+**（规格书 1 信号 / 2 Vcc / 3 GND） | 三根线各自确定，贴线标 |
| 2.1 | BSS138：低压侧 3.3V（CEP PIN1）、高压侧 5V，信号 CEP PIN19 ↔ 舵机信号线；GND 接 PL 地（低压侧插哪三针见 [figures/fig_servo_lv_wiring.png](figures/fig_servo_lv_wiring.png)：PIN1 → LV、PIN19 → LV1、低压侧 GND → PIN2 那个 WAGO） | 空闲时 PIN19 = 3.3V、舵机侧 ≈ 5V（或 3.7V） |
| 2.2 | `desreg ping 1` … `desreg ping 6` | 每个都有应答（`reply after … us`），状态字节 0。✅ 10-17（4.9V 临时供电）6 个全应答，0.61~0.87ms，见 [log/2026-10-17-舵机总线首次联通](log/2026-10-17-舵机总线首次联通.md) |
| 2.3 | `des_app.sh arm scan` | 6 个都报位置 / 电流 / 温度 |
| 2.4 | `desreg sync 2048 1000 1 2 3 4 5 6`（**先确认臂周围无障碍、各关节在中位附近**） | 6 个同时动；**不动 → 先查 SYNC 校验（文档 0x8B vs 公式 0xBA）**。✅ 10-17 单舵机同步写已验证，公式 0xBA 对；6 个同时动等 6.8V |
| 2.5 | `desreg cmdlat 200` | 记录「命令 → 总线第一位」min / avg / max（测试报告） |
| 2.6 | 示教 / 零位 / 方向 / 料盒姿态：按 [运动控制与分拣](运动控制与分拣.md)「上电调试步骤」3~5 | `arm read` 角度 = 实际几何角度；`arm pick … --go` 能夹起零件 |
| 2.7 | 30 次重复定位（同一目标点，记夹爪尖位置） | 记录重复定位精度（测试报告，⚠ 指令分辨率与实测分开报） |

## 3. 传送带（TB6600 + 57 步进）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| 3.1 | 拨码 `1=OFF 2=OFF 3=ON 4=OFF 5=ON 6=ON`（16 细分，2.5A）；电机 `B−绿 B+黑 A−红 A+蓝`；PUL+/DIR+/ENA+ → CEP PIN3/4/5，PUL−/DIR−/ENA− 接地（共阴） | — |
| 3.2 | `desreg step vel 1600` → 看皮带 → `desreg step stop` | 平稳走、不抖；**零件在画面里从右往左走**（方向反了改 `belt.dir` 或交换 DIR，calib-belt 也会自动判方向） |
| 3.3 | `desreg step move 3200` | 主动辊正好转一圈 |
| 3.4 | `desreg steplat 100` | 记录「命令 → 第一个步进脉冲」（测试报告） |

## 4. 相机、光源、标定

| 步 | 命令 | 判定 |
|---|---|---|
| 4.1 | 支架装好，测相机镜头到带面高度 H（填 `measure.camera_h_mm`）；两侧条形光（**手动**开关 / 调光，不接 PL）调到合适档位并**记下档位** | — |
| 4.2 | 对焦：`des_app.sh live`（HDMI 看）或 `des_app.sh locate --dump /root/des/locate.png` | 齿边清晰；零件与皮带对比明显，无大片反光 |
| 4.3 | 曝光：`--exp <µs>` 试几档（运动模糊 = 带速 × 曝光，50mm/s × 2ms = 0.1mm） | 选能看清缺陷的最短曝光，写进配置 |
| 4.4 | `des_app.sh calib-cam --board <列>x<行> --square <卡尺量的格边长> --travel left --dump /root/des/calib.png` | rms < 0.1mm；`calib.png` 红色 x 箭头指向皮带前进方向 |
| 4.5 | 一个零件放视野上游 → `des_app.sh calib-belt` | 两段比例一致，打印 mm/步（10-16 尺量 0.0207：主动轴 4 圈皮带约 265mm）、往返误差、横向漂移 < 2mm/100mm |
| 4.6 | 机械臂 ↔ 台面（手眼标定）：关节零位 / 方向先按 docs/运动控制与分拣.md 第 3 步校好 → `/root/des/des_app.sh calib-arm -n 4 --marker-h <标记物厚度>`，按提示：放标记物（小零件或 10~20mm 圆片）到视野里机械臂够得着的地方、手臂移开 → 回车（相机定位）→ 手掰夹爪尖碰标记中心 → 回车（读关节角）；4~6 个点尽量分散 | 残差 rms < 1.5mm、max < 3mm；写进 calib.json 的 `arm` 段（base_xy / base_yaw / belt_z）；之后 `arm goto` 到标记处空跑核对 |

## 5. 测量精度

| 步 | 命令 | 判定 |
|---|---|---|
| 5.1 | 卡尺量 10 个齿轮外径 / 孔径、10 根齿条长度，填进 `齿轮齿条采购清单.xlsx`（仓库外）样本登记表 | — |
| 5.2 | 单件静止：`des_app.sh measure -n 30 --dump /root/des/m.png` | 重复性 σ（报告）；与卡尺差 < 0.3mm（赛题中级） |
| 5.3 | 走带：同一件反复过线 5~10 次 → `part_stats.py --same-part --true-size <卡尺值> parts_*.csv` | 平均误差、最大误差 |
| 5.4 | 侧壁亮不亮（看 `m.png`）→ `measure.walls_visible`；零件厚度 → `gear_h_mm / rack_h_mm`；公差定了 → `measure.rule.enabled = true` | — |

## 7. CAN（USB-CAN ZQWL-UCAN-101E）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| 7.1 | 适配器 H/L ↔ 板子 CAN 端子 H/L，两端各 120Ω，GND 共地；**先确认 CAN 引到了板载端子（风险 R7）** | — |
| 7.2 | 板上 `/root/des/can_up.sh can0 normal` | `ip -details link show can0` 为 UP、ERROR-ACTIVE |
| 7.3 | PC：装驱动，卖家 `ControlCAN.dll` 放到 `pc/plc_sim/`，`python plc_gui.py --backend zqwl --dev-type <手册值>` | 连上后板子 STATUS 10Hz 滚动；点启动 → 板子 ACK |
| 7.4 | 2h：板上 `SOAK_CAN=normal /root/des/soak.sh 7200`，PC 端 GUI 开着 | STATUS 无丢失、ACK 往返统计（报告「总线稳定性」） |

## 8. 数据、训练、NPU

| 步 | 命令 | 判定 |
|---|---|---|
| 8.1 | 每类一次：`des_app.sh collect --cls gear_ok --belt 30`（8 类各 ≥300 张、≥30 件；验证集用另外编号的零件，会话名带 `val_`） | `/root/des/data/collect/` 下按零件分目录 |
| 8.2 | 拷回 PC → WSL：`prepare_dataset.py` → `train_cls.py`（GPU）→ `export_npu.py` → `eval_onnx.py`（命令见 train/README） | PC uint8 准确率 |
| 8.3 | 上板：`test_npu <json> <refs>`；`NPU_EVAL_DIR=<val> test_npu …` | NPU 与 PC 一致；准确率 ≥ 92%（赛题高级） |
| 8.4 | `des_app.json` 加 `"npu": {"enabled": true, "model": "part_cls.json"}` | live 画面每件出类别 |

## 9. 整机

| 步 | 命令 | 判定 |
|---|---|---|
| 9.1 | `des_app.sh run --can can0`（不加 `--go`，机械臂空跑） | 跟踪 / 停带 / 翻板 / CAN 都对 |
| 9.2 | `des_app.sh run --can can0 --go` | 良品被夹进对应料盒，不良进对应出口 |
| 9.3 | 投放已知数量和类别的零件 → `part_stats.py --fed N file=label …` | 漏检率、准确率、节拍 |
| 9.4 | 2h：`SOAK_CAN=normal soak.sh 7200` 期间持续上料 | 无故障（报告「工程可靠性」） |
| 9.5 | 开机自启（**改 /etc，先征得用户同意**）：`ln -s /root/des/des_service.sh /etc/init.d/S90des`；`autostart.conf` 里 ARGS="--go" | 断电重启后不用 SSH：上电显示画面，PLC 按启动即运行；`kill -9` des_app 2s 后自动恢复 |
| 9.6 | 拍视频：按 [演示视频脚本](演示视频脚本.md) | — |
