| 步 | 做法 | 判定 |
|---|---|---|
| 1.1 | 万用表逐个量舵机 V+~GND 电阻（C4）；顺手检查每个舵机输出轴旷量 | 无短路（几 kΩ 以上，记录数值）；旷量明显异常先换舵机 |
| 1.2b | **舵机供电 = 300W 20A 恒压恒流降压模块（无屏）+ 片式保险丝**，输入取**受控 24V**（急停常闭之后，与 TB6600 同 WAGO）。① 调压：空载上电量 OUT（出厂常偏高 >10V），拧 CV 电位器（顺时针通常升压）到 **6.80V**。② 限流：断电 → **CC 电位器往减小拧 15~20 圈到底** → 万用表 10A 档短接 OUT+/OUT− → 上电 → 加到约 **6A** → 断电拆表（不调也行：CC 拧到最大靠堵转自保护；短接前必须先拧到最小）。③ 保险丝座串 OUT+ 与 6.8V 母排间（7.5A，熔断换 10A 上限，20AWG）；OUT− 只进 6.8V 地母排，不与 24V 地外接（低边采样）。④ 舵机链（原厂线）与两个挡板 MG996R 挂 6.8V 母排；5V 只留 BSS138 高压侧和编码器 | 空载 / 保险丝后 6.80V；短路约 6A；上电后机械臂不自己动；`des_tool.sh arm scan` 状态位全 0（0x2E / 0x3F 非电流 / 温度，见 [运动控制与分拣](运动控制与分拣.md)）；`/root/bin/test_servo_gap 2` 复测静默窗口。⚠ 测急停前让机械臂停在低姿态或托住：急停切舵机电源后会软掉 |
| 1.3 | 急停常开触点 → CEP PIN15（另一端接地）；`desreg step vel 800` 空转，按急停，`desreg step status` | 立即停、`HALTED` 置位；按住时再发 `step vel` 不动；松开后新命令才动（同时清 HALTED） |

## 7b. RS485（Modbus-RTU 4 路继电器 + 三色灯 + USB-RS485）

> 板载 RS485（SP3485EN，TX L17 / RX N16 / DE N15）由 v16 引出（**板上已是 v16**）；`rs485.enabled` 已 = true，des_app 为逐路 FC 05 版。R1、R2 只用 PC + USB-RS485（`rs485_tool.py` 需 pyserial）。

**端子对应**：USB-RS485 = 艾莫迅 USB 转 RS485/422（GND · R+ · R− · T+ · T−）→ **只用 T+ = A、T− = B**，R+ / R− 不接，GND 先不接（不稳再接模块 GND）。继电器模块 = bestep 4 入 4 出板：左上 **A+ / B−** = RS485；右上 **VCC / GND** = 电源（DC7~24V，常电 24V / 24V 地）；中间 IN1~IN4 / GND = 光耦输入（备用）；每继电器 3 端子 = NO / COM / NC（**按板上丝印**，不吸合时 COM–NC 通）；P3 跳线保持出厂（RS485）。三色灯 5 芯：红 / 黄 / 绿 = 三色，灰 / 紫 一公共一蜂鸣（以商品说明或点测为准）。

**bestep 板四个怪癖**（10-26 实测，工具与 des_app 已适配）：① 出厂地址 **255**（1~16 之外），旧 scan 找不到，查询 = 广播 FC 03 寄存器 0；② 改地址**只认广播 FC 10**，FC 06 不理 → 已改**地址 1**（断电保持）；③ FC 01 读线圈**只在数量 = 8 时应答** → `rs485.coils` 填 8；④ FC 0F 多路写**只接受全 0** → 用**逐路 FC 05**（应答 = 原样回显），只写与现状不同的路。

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| R1 | 继电器模块接**常电 24V**（不经急停）；USB-RS485 插 PC，A → 模块 A、B → 模块 B（旧网线绞线对）；`cd pc/rs485` → `python rs485_tool.py ports` 找 COM 口 → `… scan --port COMn`（各波特率 / 校验先发广播查询，再试 1~16、255）→ 记下地址波特率；地址不是 1 → `… setaddr --port COMn 1`（广播，总线上只挂它）；波特率不是 9600 8N1 就改 des_app.json `rs485` | ✅ 10-26 已通（地址 1、9600 8N1）。不通看文末排障 |
| R2 | 先认公共线：公共线接 24V 地、24V+ 碰红线亮 = **共负**；不亮则公共线接 24V+、红线碰地亮 = **共正**。共负：公共线 → 24V 地，24V+ → 4 继电器 COM，各 NO → 绿 / 黄 / 红 / 蜂鸣（继电器 1~4 = 程序 0~3）；共正反之。然后 `python rs485_tool.py lamp --port COMn red`、`… lamp green yellow`（自动读回，不符报 MISMATCH）、`… demo`（灯语轮一遍；蜂鸣默认跳过，`--buzzer` 才响） | ✅ 10-26：读回一致、`demo` 0 错误；继电器 1 / 2 / 3 = 绿 / 黄 / 红（`lamp_coils` 0,1,2,3 不用改，蜂鸣器 = 继电器 4）。不对就改接线或 `rs485.lamp_coils`（同序传 `--lamp-coils`） |
| R3 | J11 **第 5 位 = 485_A、第 6 位 = 485_B**（CAN 占 2/3 + 一个 GND）。**J11 空着的 GND 不接继电器任何线**：模块 GND 已随 24V 地母排与 PL 地单点共地（[硬件与接线](硬件与接线.md)），再拉即成第二条地回路；灯与继电器电源线更不能接。CRC / 帧错误上涨先查 A/B 与终端电阻（模块端 120Ω 跳线接上）；`… sniff --port COMn` 旁听。停服务后：`desreg 485`（只读）→ `… cfg 9600 N 100` → `… tx 01 01 00 00 00 08`（读继电器；PDU 不含 CRC）→ `… tx 01 05 00 00 FF 00` / `… tx 01 05 00 00 00 00`（继电器 1 = 绿开 / 关；别开 `… 00 03 …`，蜂鸣器）；`… bc 00 05 …` 广播不等应答；`… listen 10` 旁听；`… clr` 清计数 | 8 位状态（低 4 位有效）、开关灯照办；sniff CRC ok；帧错误不涨。✅ 10-27 结果见 [测试与验证](测试与验证.md) |
| R3b | 「总线稳定性」：`desreg 485 soak 1000 01 01 00 00 00 08`（连发 1000 次读线圈） | 成功率、应答时延记进 [测试与验证](测试与验证.md)。✅ 10-27 全过；⬜ 与 CAN 2h 浸泡同轮复测 |
| R4 | 部署 10-26 后的 des_app → `des_app.json` 改 `"rs485": {"enabled": true, …}` → 重启服务（日志应有 `[run] RS485 9600 8N1, relay module at address 1`、状态栏 `485 ok`）；启停 / 急停 / 复位各一次；PC：`cd pc/modbus` → `python mb_client.py lamp red buzzer`、`… lamp auto`、`python zqwl.py send 105#010401`（CAN 接管、红灯、序号 1）、`… send 105#000001`（还原）；`mb_client.py status` 看 RS485 行 | 绿 运行 / 黄 暂停 / 红 + 蜂鸣 1s 急停（`buzzer_s` 1）/ 空闲不亮（10-28 起默认，`rs485.idle` 可改）；接管 ACK OK、灯照办、成功涨失败 0；「总线稳定性」用 mb_client status + 2h 浸泡。✅ 10-27：enabled true 已改（备份 data/des_app.json.before_rs485on）；驱灯结果见 [测试与验证](测试与验证.md)。⬜ 启停 / 急停 / 复位各看一次灯；⬜ CAN → RS485（`zqwl.py send 105#…`） |

**RS485 一直乱码 / 发不出去（`desreg 485` 帧错误、listen 计数一直涨、发送报 `bus never quiet`）**：
- **总线没偏置**：R121（120Ω）跨在 A / B 上，SP3485 无失效保护偏置 → 空闲差分 ≈ 0V 时接收乱跳、发不出请求。USB-RS485 和多数继电器模块自带偏置，接上即好；仍乱就在 A 端加 680Ω~1kΩ 上拉 3.3V/5V、B 端同值下拉地（只在一处），或去掉一端 120Ω（2m 线、9600 波特无需两端终端）。
- **A / B 接反**：空闲差分为负、总线读低，现象同上 → 对调两线（无损）。
