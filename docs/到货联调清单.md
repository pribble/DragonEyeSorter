# 到货联调清单（按顺序做，每步有命令和判定标准）

> 本清单是**操作单**：只写命令、做法与判定；数字与出处一律引用 [测试与验证](测试与验证.md)（实测数字唯一源），逐次现场记录进 `docs/log/`。
> 板上命令都在 SSH 里执行：`ssh $BOARD_HOST`。**`des_app` / `des_tool` 运行期间 `desreg` 只用 `r` 只读**（舵机总线 / 步进只能有一个主人）。
> PS 产物分四层（见 [ps/README](../ps/README.md)）：产品运行时用 `des_app.sh`（`run` / `live`），运维模式用 `des_tool.sh`（`probe` / `locate` / `track` / `display` / `collect` / `measure` / `calib-*` / `arm` / `ik`）。
> 引脚见 [硬件与接线](硬件与接线.md)，机械臂见 [运动控制与分拣](运动控制与分拣.md)「上电调试步骤」，标定见 [视觉与检测](视觉与检测.md)。

## 0. 开机自检（每次上电）

| 步 | 命令 | 判定 |
|---|---|---|
| 0.1 | `desreg` | `DES_ID 0x44455301`，**VERSION ≥ 9**（v9 才有步进目标改写检查；des_vision / des_pwm 项见 `pl_check.sh`） |
| 0.2 | `/root/des/des_tool.sh probe -n 5` | 约 60fps、无跳帧 |

## 1. 电源与安全（接任何执行器之前）

| 步 | 做法 | 判定 |
|---|---|---|
| 1.1 | 万用表逐个量舵机 V+~GND 电阻（C4） | 无短路（几 kΩ 以上，记录数值） |
| 1.2 | XY6020L 设 **6.8V**、限流约 5A、上电不输出 | 空载电压 6.8V |
| 1.3 | 急停常开触点 → CEP PIN15（另一端接地）；`desreg step vel 800` 让步进空转，按下急停，`desreg step status` | 立即停、`HALTED` 置位；按住时再发 `step vel` 不动；松开后新的运动命令才动（同时清 HALTED） |
| 1.4 | 急停常闭触点串主电源 | 按下时步进驱动器、舵机电源都断 |

## 2. 舵机总线（BSS138 + 机械臂）

| 步 | 命令 | 判定 |
|---|---|---|
| 2.0 | 舵机供电线：剪原厂扩展板 → 1 号舵机那根线的扩展板端。剪前用原厂板上电量出 V+ / 信号 / GND 各是哪根；V+、GND 进 XY6020L 输出端子（6.8V、限流 5A），信号经 WAGO 接杜邦线到 BSS138 HV 通道；BSS138 GND 接 PL 地（CEP PIN2），**不接舵机地**（接线见 [硬件与接线](硬件与接线.md)） | 线端万用表：V+–GND 电阻非短路（记录） |
| 2.0a | 剪完记不清线序时：把剪下来的插头（带一截线）插回原厂扩展板，看插座旁丝印（G/V/S 一类）对上颜色；或用通断档：PH2.0 三针**中间针 = V+**（规格书 1 信号 / 2 Vcc / 3 GND） | 三根线各自确定，贴线标 |
| 2.1 | BSS138：低压侧 3.3V（CEP PIN1）、高压侧 5V，信号 CEP PIN19 ↔ 舵机信号线；GND 接 PL 地（低压侧插哪三针见 [figures/fig_servo_lv_wiring.png](figures/fig_servo_lv_wiring.png)：PIN1 → LV、PIN19 → LV1、低压侧 GND → PIN2 那个 WAGO） | 空闲时 PIN19 = 3.3V、舵机侧 ≈ 5V（或 3.7V） |
| 2.2 | `desreg ping 1` … `desreg ping 6` | 每个都有应答（`reply after … us`），状态字节 0（实测值见 [log/2026-10-17-舵机总线首次联通](log/2026-10-17-舵机总线首次联通.md)） |
| 2.3 | `des_tool.sh arm scan` | 6 个都报位置 / 电流 / 温度 |
| 2.4 | `desreg sync 2048 1000 1 2 3 4 5 6`（**先确认臂周围无障碍、各关节在中位附近**） | 6 个同时动；不动先查 SYNC 校验（按公式算的 `0xBA` 正确，协议文档例子印的 `0x8B` 有误）；单舵机同步写已验证，6 个同时动等 6.8V 供电 |
| 2.5 | `desreg cmdlat 200` | 记录「命令 → 总线第一位」min / avg / max（进测试报告） |
| 2.6 | 示教 / 零位 / 方向 / 料盒姿态：按 [运动控制与分拣](运动控制与分拣.md)「上电调试步骤」3~5 | `des_tool.sh arm read` 角度 = 实际几何角度；`des_tool.sh arm pick … --go` 能夹起零件 |
| 2.7 | 30 次重复定位（同一目标点，记夹爪尖位置） | 记录重复定位精度（⚠ 指令分辨率与实测分开报） |

## 3. 传送带（TB6600 + 57 步进）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| 3.1 | 拨码 `1=OFF 2=OFF 3=ON 4=OFF 5=ON 6=ON`（16 细分，2.5A）；电机 `B−绿 B+黑 A−红 A+蓝`；PUL+/DIR+/ENA+ → CEP PIN3/4/5，PUL−/DIR−/ENA− 接地（共阴） | — |
| 3.2 | `desreg step vel 1600` → 看皮带 → `desreg step stop` | 平稳走、不抖；**零件在画面里从右往左走**（方向反了改 `belt.dir` 或交换 DIR，`des_tool.sh calib-belt` 也会自动判方向） |
| 3.3 | `desreg step move 3200` | 主动辊正好转一圈 |
| 3.4 | `desreg steplat 100` | 记录「命令 → 第一个步进脉冲」（进测试报告） |
| 3.5 | **计米轮编码器（E6B2-CWZ6C，NPN 开集电极）先单独测**：只接棕 → 5V 母排、蓝 → PL 地，三根信号线悬空；万用表 ① 蓝–黑：一直 ≈0V（读到 ≈5V 或转动时 0/5V 跳 = 内部带上拉，**不能直连 FPGA**）；② 棕–黑：极慢转轮子，在 ≈0 / ≈5V 之间跳；白、橙同样测 | 三路都是「对地不出电压、对 5V 能拉低」= 真开集电极，可直连；① 出现电压 = 输出带上拉 → 3.6 走 BSS138（10-20 本批实测：① 转动时约 1.5V → 走 BSS138） |
| 3.6 | 断 24V 总电源 → 黑 A / 白 B / 橙 Z 各接一路 BSS138 高压侧（HV = 5V，LV = 3.3V，GND 共地；舵机总线那块模块还空三路），三路低压侧 → CEP PIN6 / 7 / 8；屏蔽线 → PL 地（只在板子这头接）；**不接 24V** → 上电，`desreg io watch 20` 手转轮子一圈（真开集电极的编码器可以不经 BSS138 直连） | A/B 跟着跳；计数变化 ≈ ±4000（1000 线 ×4）、Z +1、err 0；err 涨或计数乱跳 → PIN6/7/8 各加 4.7kΩ 到 PIN1 |
| 3.7 | 计米轮压在有支撑的带面（辊子上方 / 托板上）、摆臂拖行；**空皮带** `des_tool.sh calib-enc -n 3`（往返 300mm × 3 次，约 40s） | 3 次 mm/计数 一致（sd < 0.2%）；轮周长与名义 200mm 差 < 3%；往返误差 < 0.5mm；匀速段实测带速波动小；写进 calib.json 的 `encoder` 段。之后界面「带速 xx 实测 xx」、曲线页绿线 = 编码器实测 |

## 4. 相机、光源、标定

| 步 | 命令 | 判定 |
|---|---|---|
| 4.1 | 支架装好，测相机镜头到带面高度 H（填 `measure.camera_h_mm`）；两侧条形光（**手动**开关 / 调光，不接 PL）调到合适档位并**记下档位** | — |
| 4.2 | 对焦：`des_app.sh live`（HDMI 看）或 `des_tool.sh locate --dump /root/des/locate.png` | 齿边清晰；零件与皮带对比明显，无大片反光 |
| 4.3 | 曝光：`--exp <µs>` 试几档（运动模糊 = 带速 × 曝光，50mm/s × 2ms = 0.1mm） | 选能看清缺陷的最短曝光，写进配置 |
| 4.4 | `des_tool.sh calib-cam --board <列>x<行> --square <卡尺量的格边长> --travel left --dump /root/des/calib.png` | rms < 0.1mm；`calib.png` 红色 x 箭头指向皮带前进方向 |
| 4.5 | **一块平的白纸片**（约 3×3cm，视野里只放它）放视野上游 → `des_tool.sh calib-belt`。不要用零件：零件顶面高出带面 h，按带面标定看它的位移会放大 H/(H−h)（11mm 齿轮实测 0.02125 vs 白纸片 0.02073，偏大 2.5%） | 两段比例一致；打印 mm/步（尺量参考值与来源见 [测试与验证](测试与验证.md)）、往返误差、横向漂移 < 2mm/100mm |
| 4.6 | 机械臂 ↔ 台面（手眼标定）：关节零位 / 方向先按 [运动控制与分拣](运动控制与分拣.md) 第 3 步校好 → `des_tool.sh calib-arm -n 4 --marker-h <标记物厚度>`，按提示：放标记物（小零件或 10~20mm 圆片）到视野里机械臂够得着的地方、手臂移开 → 回车（相机定位）→ 手掰夹爪尖碰标记中心 → 回车（读关节角）；4~6 个点尽量分散 | 残差 rms < 1.5mm、max < 3mm；写进 calib.json 的 `arm` 段（base_xy / base_yaw / belt_z）；之后 `arm goto` 到标记处空跑核对 |

## 6. 侧边导流挡板（板端 v9 起）

| 步 | 命令 | 判定 |
|---|---|---|
| 6.1 | 挡板 1（报废）信号 → CEP PIN18、挡板 2（返修）→ PIN20；电源取 6.8V 母排（临时可接 5V 模块空载试），GND 与电源同负极 | — |
| 6.2 | `desreg pwm 0 1000`、`desreg pwm 0 1900`、`desreg pwm 1 …` 试出两个位置 | 打开 = 摆杆转到带外，合上 = 45° 斜拦过零件摆放带、底边离带面 1~2mm；脉宽填进 `flaps.gates[i].open_us / closed_us` |
| 6.3 | 放一个零件在中线，挡板合上，`desreg step move` 点动皮带到零件刚碰到摆杆 → 读带位置换算拦截点 | 拦截点 − 抓取线 = `flaps.gates[i].after_pick_mm`（默认 70 / 170） |
| 6.4 | `flaps.enabled = true`；`des_app.sh run` 带速 30mm/s，不放件空跑 | 挡板不动（没有 NG 件） |
| 6.5 | 报废 / 返修 / 复检件各 10 件单独过，再混合过（件距 ≥30cm） | 分流正确率（报告「NG 输出 IO / 不良品实时分拣」）；挡板不动作的件都落进带尾复检箱 |

## 7. CAN（USB-CAN ZQWL-UCAN-101E）

| 步 | 做法 / 命令 | 判定 |
|---|---|---|
| 7.0 | **前提：比特流 ≥ v12**（`desreg` 显示 VERSION 12）。v11 及以前没把 PS CAN0 引到 F20 / F19（接收脚接 0），接了也不通（10-19 查出，见 [PL设计](PL设计.md)） | `desreg` VERSION ≥ 12 |
| 7.1 | 适配器（或 CAN 分析仪）**H → J11 第 3 位（CANH）、L → 第 2 位（CANL）、GND → 第 1 或第 4 位**（J11 位序见 [硬件与接线](硬件与接线.md)）；板上已有 120Ω（R120），适配器内部没有（10-19 量 H–L 约 31.6kΩ），适配器端再接入 120Ω（ZQWL 端子板上标「RS」的端子按说明书短接，或在 H–L 间并一个 120Ω），总线两端各一个；分析仪设 **经典 CAN、500kbit/s、正常模式** | 断电时量 H–L 间电阻：只有板子一端约 120Ω，两端都接约 60Ω |
| 7.2 | 板上 `/root/des/can_up.sh can0 normal` | `ip -details link show can0` 为 UP、ERROR-ACTIVE；会打印「classic mode refused … FD mode」属正常（驱动只支持 FD 模式，经典帧照常收发） |
| 7.2b | 先不开 des_app，板上 `cansend can0 123#DEADBEEF`；分析仪发一帧，板上 `candump can0` | 分析仪收到 0x123；板子 candump 收到分析仪的帧；分析仪上无错误帧 |
| 7.3 | PC：适配器插 USB（免驱动，设备管理器里是「USB 串行设备 (COMn)」，VID 3562），关掉厂家调试软件；`cd pc/plc_sim` → `python zqwl.py`（读型号，只读）→ `python zqwl.py listen`（板上 7.2b 再发一帧）→ `python zqwl.py send 123#11223344`（板上 candump 看） | zqwl.py 打印 UCAN-101E；listen 收到板子的 0x123；send 后心跳仍「正常」、错误计数 0 |
| 7.3b | 板上起 des_app（自启服务即可）；PC `python plc_gui.py --backend zqwl`（见 [pc/plc_sim/README](../pc/plc_sim/README.md)） | STATUS 10Hz 滚动；点启动 → 板子 ACK；「总线统计」里适配器一栏「正常」 |
| 7.4 | 2h CAN 稳定性与 §9.4 是同一轮测试（命令见 §9.4），PC 端 GUI 开着 | STATUS 无丢失、ACK 往返统计进报告「总线稳定性」 |

## 9. 整机

| 步 | 命令 | 判定 |
