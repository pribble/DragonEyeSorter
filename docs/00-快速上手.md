# 00 · 快速上手指南

> 从零到运行的线性步骤清单。详细说明见其他文档。

## 前置条件

### 必需硬件
- 安路飞龙 F3P 开发板（米联客 F3P-NPU 版）
- SD 卡（≥8GB，推荐 32GB）+ 读卡器
- 网线（直连电脑）或 USB-TTL 串口（调试）
- PC（Windows 10/11，建议 16GB+ RAM，多核 CPU）

### 可选硬件
- 相机模块（IMX219，2-lane MIPI）
- HDMI 显示器
- 6 轴总线舵机机械臂（传动比 6:1，TTL 总线）
- 步进电机 + 驱动器（传送带控制）
- CAN 收发器（与 PLC 通信）

## 一、环境安装

### 1. 安装 TD 6.2.1（必需，用于 PL 综合布线）

1. 下载：安路官网 → FPGA 开发套件 → TD 6.2.1 Release（Build 175876）
2. 安装：解压后运行安装程序，路径**不能有中文和空格**
3. 许可证：`Anlogic.lic` 放到 `<TD安装目录>\license\Anlogic.lic`
4. 验证：打开 TD，Help → About 确认版本

⚠ **注意**：
- TD 6.2.1 与 2026.1 使用相同 UpgradeCode，**不能共存**
- 如机器上已安装 2026.1，需先卸载
- 打开本仓库 PL 工程只用 6.2.1（其他版本会触发格式升级）

### 2. 安装 FD 2026.1 SP1（必需，用于交叉编译和 BOOT.bin 打包）

1. 下载：安路官网 → 嵌入式开发套件 → FD 2026.1 SP1
2. 安装：包含 aarch64 Linux 交叉编译器（Linaro GCC 7.4，glibc 2.25）
3. 记录路径：后续配置 `.env` 时需要填写 FD 安装目录

### 3. 配置 WSL（必需，用于 SD 镜像制作）

```powershell
# Windows PowerShell（管理员）
wsl --install -d Ubuntu-22.04
# 重启后进入 WSL，设置用户名密码
```

```bash
# WSL 终端
sudo apt-get update
sudo apt-get install -y lz4 u-boot-tools mtools dosfstools parted device-tree-compiler
```

### 4. 安装 Python 训练环境（可选，仅需训练模型时）

```bash
# WSL 终端
python3 -m venv ~/des-train
source ~/des-train/bin/activate
cd <仓库根>/train                      # 换成你的仓库在 WSL 里的挂载路径

# GPU 版（推荐，需 NVIDIA GPU + CUDA 12.1）
pip install -r requirements-gpu.txt

# CPU 版（调试或无 GPU）
pip install -r requirements.txt
```

## 二、配置环境变量

### 1. 复制配置模板

```powershell
cd <仓库根目录>
copy .env.example .env
```

### 2. 编辑 .env 文件

逐项填成本机的实际路径（每个变量指向什么、怎么获取，见 [docs/13-环境配置指南.md](13-环境配置指南.md)）：

| 变量 | 填什么 |
|---|---|
| `FD_ROOT` | FD 安装目录（含 `toolchain/gcc/aarch64_linux/`） |
| `TD_ROOT` | TD 6.2.1 安装目录（含 `license/`、`bin/`） |
| `NPU_DEMO` | 厂家 NPU demo 解压目录（含 `boot/`、`soc_sdk/`） |
| `SDK_LIBS` | 该 demo 里的 `face_detection/libs`（编 PS 应用用） |
| `FREETYPE_INC` | FreeType 头文件目录（HDMI 界面中文显示用） |
| `BOARD_LIBS` | 板上库文件的本地拷贝目录（`libfreetype.so.6` 等） |
| `BOARD_IP` / `BOARD_USER` / `SSH_KEY` | 板子地址、登录用户、私钥路径（部署用；`SSH_KEY` 可写 `$HOME/...`） |
| `DES_TRAIN_VENV` | WSL 里的训练虚拟环境路径（可选） |

路径只写在你本机的 `.env` 里（不入库），文档与脚本一律用变量名引用。

### 3. 生成 Make 配置文件

```powershell
# Windows PowerShell
bash scripts/generate_env_make.sh
```

### 4. 验证环境

```powershell
.\scripts\test_env.ps1
```

检查输出，确保关键路径存在。

## 三、获取依赖文件

### 1. NPU Demo 完整包（必需）

**用途**：提供 SDK 库（OpenCV, ArmNN）用于编译 PS 应用，以及 boot/ 目录文件用于制作 SD 镜像。

**获取方式**：
1. 访问米联客论坛：https://uisrc.com/t-5868.html
2. 下载 NPU demo 压缩包（具体文件名见论坛帖子）
3. 解压后获取以下目录：
   - `demo/boot/` - 包含 `uInitrd.lz4`, `system.dtb`, `uImage.lz4`（SD 镜像制作需要）
   - `demo/sdk/face_detection/libs/` - 包含 `armnn_lib/` 和 `ffmpeg_opencv4.7.0_aarch64/`（PS 编译需要）

**配置**：在 `.env` 中设置 `SDK_LIBS` 指向 `face_detection/libs/` 目录

**⚠ 重要**：在 Windows 上解压会丢失 `.so` 软链接，需运行修复脚本：
```bash
sh scripts/sdk_fix_sonames.sh <SDK_LIBS路径> <FD_ROOT>/toolchain/gcc/aarch64_linux/bin/aarch64-linux-gnu-readelf
```

### 2. FreeType 头文件（必需，用于 PS 应用）

**选项 A：从板上拷贝（推荐，需先完成板卡初始配置）**
```bash
scp -r root@192.168.137.100:/usr/include/freetype2 "$FREETYPE_INC"
```

**选项 B：从官网下载**
```bash
wget https://download.savannah.gnu.org/releases/freetype/freetype-2.10.1.tar.gz
tar -xzf freetype-2.10.1.tar.gz
# .env 中设置 FREETYPE_INC 指向 freetype-2.10.1/include
```

### 3. 板上库文件（必需，用于 PS 应用）

需先完成板卡初始配置（见第四章），然后（`$BOARD_LIBS` 就是你在 `.env` 里填的那个目录）：

```bash
mkdir -p "$BOARD_LIBS"
scp root@192.168.137.100:/usr/lib/libfreetype.so.6 "$BOARD_LIBS/"
scp root@192.168.137.100:/opt/armnn_lib/lib/libfmt.so "$BOARD_LIBS/"
scp root@192.168.137.100:/usr/lib/libpng16.so.16 "$BOARD_LIBS/"
scp root@192.168.137.100:/usr/lib/libz.so.1 "$BOARD_LIBS/"
```

## 四、板卡初始配置

详细步骤见 [docs/14-板卡初始配置.md](14-板卡初始配置.md)，以下是摘要：

### 1. 硬件连接

- 插入 SD 卡（厂家预装系统）
- 拨码开关：ON-OFF-OFF（从 SD 启动）
- 网线连接：板子 PS 网口 ↔ 电脑有线网口
- 可选：USB-TTL 串口（115200 8N1，用于调试）

### 2. 网络配置

**Windows 侧**：
- 控制面板 → 网络连接 → 以太网适配器属性 → IPv4
- 设置静态 IP：`192.168.137.1`，子网掩码 `255.255.255.0`

**板子侧**（首次需通过串口或默认 DHCP 登录）：
```bash
# 通过串口登录，或查看路由器分配的临时 IP
ssh root@<临时IP>  # 默认密码见板卡手册

# 配置固定 IP（永久生效）
cat >> /etc/dhcpcd.conf << 'EOF'

interface eth0
static ip_address=192.168.137.100/24
static routers=192.168.137.1
EOF

reboot
```

### 3. SSH 密钥配置

```powershell
# Windows PowerShell
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_anlu
ssh-copy-id -i ~/.ssh/id_ed25519_anlu.pub root@192.168.137.100

# 后续免密登录
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
```

### 4. 板上目录初始化

```bash
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
mkdir -p /root/des /root/bin
# 验证环境
ls /opt/armnn_lib/lib/libarmnn.so  # 应存在
uname -a  # 应显示 6.1.111-rt42
```

## 五、编译 PL（FPGA 逻辑）

### 1. 打开工程

```
TD 6.2.1 → Open Project → pl/soc_base/soc_prj.al
```

### 2. 修改源码（可选）

- 新模块放 `pl/soc_base/src/`
- 在 `system_top.v` 中例化
- 管脚约束加到 `src/constraint/io.adc`（CEP 接口 = BANK11，3.3V）

### 3. 综合、布局、布线

TD 界面：
1. Synthesis → Run（约 6 分钟）
2. Place → Run（约 10 分钟）
3. Route → Run（约 19.5 分钟）
4. Bitstream → Run（几秒）

生成比特流：`pl/soc_base/soc_prj_Runs/phy_1/soc_prj.bit`

**资源需求**：峰值内存约 5GB，建议 16GB RAM + 4 核以上 CPU

### 4. 打包 BOOT.bin

```powershell
cd scripts\bootbin
.\make_bootbin.ps1 -Bit ..\..\pl\soc_base\soc_prj_Runs\phy_1\soc_prj.bit
```

产物：`scripts/bootbin/BOOT.bin`

### 3. 编译内核模块（可选，仅改 mipicam 驱动时）

## 七、制作 SD 镜像（首次或更新系统）

### 1. 准备 boot 目录文件

从 NPU demo 的 `demo/boot/` 目录拷贝：
- `uInitrd.lz4`（根文件系统）
- `uImage.lz4`（内核）
- `system.dtb`（设备树）

放到本地某个工作目录，例如 `<工作目录>/npu_demo_boot/`

### 2. 生成镜像

```bash
# WSL 终端（需 root 权限）
wsl -u root -e bash scripts/sd_image/make_sd_image.sh
```

根据提示输入 boot 目录路径和 BOOT.bin 路径。

产物：`sd_persistent.img`（约 4GB）

### 3. 烧录到 SD 卡

**选项 A：Windows PowerShell（管理员）**
```powershell
Get-Disk  # 确认 SD 卡磁盘号
.\scripts\sd_image\flash_to_disk.ps1 -DiskNumber <N>
```

**选项 B：balenaEtcher / Rufus**

用 GUI 工具烧录 `sd_persistent.img` 到 SD 卡

## 八、部署与运行

### 1. 更新 BOOT.bin（只改 PL 逻辑时）

```bash
# 从 PC 拷贝到板子
scp -i ~/.ssh/id_ed25519_anlu scripts/bootbin/BOOT.bin root@192.168.137.100:/mnt/mmcblk0p1/

# 板子上操作
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
cd /mnt/mmcblk0p1
mv BOOT.bin BOOT.bin.backup  # 备份原版
mv ~/BOOT.bin BOOT.bin        # 或直接 scp 到目标位置
sync
reboot
```

### 2. 更新应用程序

```bash
scp -i ~/.ssh/id_ed25519_anlu ps/build/des_app root@192.168.137.100:/root/des/
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
chmod +x /root/des/des_app
```

### 3. 运行

```bash
ssh -i ~/.ssh/id_ed25519_anlu root@192.168.137.100
cd /root/des
./des_app --help          # 查看命令帮助
./des_app live            # 实时模式（相机预览 + HDMI 显示）
./des_app collect --cls gear_ok  # 数据采集模式
```

## 十、常见问题

### 编译问题

**Q: TD 报 "License expired"**

A: 许可证已过期或未正确放置。检查 `<TD安装目录>\license\Anlogic.lic`，确保有效期未过。

---

**Q: ps/build/des_app 编译报 "cannot find -lfreetype"**

A: 检查 `.env` 中 `BOARD_LIBS` 路径，确保包含 `libfreetype.so.6`。

---

**Q: 链接时报 "undefined reference to cv::..."**

A: 检查 `SDK_LIBS` 是否正确指向 `face_detection/libs/` 目录，并确认运行过 `scripts/sdk_fix_sonames.sh`。

### 板卡问题

**Q: SSH 连接超时**

A: 检查网络配置（PC 侧 192.168.137.1/24，板子 192.168.137.100/24），ping 192.168.137.100 是否通。

---

**Q: 板子上运行 des_app 报 "error while loading shared libraries: libfmt.so"**

A: 板上缺少运行库。检查 `/opt/armnn_lib/lib/libfmt.so` 是否存在，或重新制作 SD 镜像。

---

**Q: 换 BOOT.bin 后起不来，串口无输出**

A: 拨码开关可能设置错误（应为 ON-OFF-OFF 从 SD 启动），或比特流损坏。恢复备份的 BOOT.bin：

```bash
# 从串口或用 SD 卡读卡器操作
mv /mnt/mmcblk0p1/BOOT.bin.backup /mnt/mmcblk0p1/BOOT.bin
sync
reboot
```

### 训练问题

**Q: 训练时 CUDA out of memory**

A: 降低 batch size：`train_cls.py --batch 16`（默认 32）

---

**Q: 板上 NPU 推理段错误**

A: 量化模型缺少形状信息。确认 `export_npu.py` 运行成功，检查 JSON 文件是否包含 `input_shape` 字段。
