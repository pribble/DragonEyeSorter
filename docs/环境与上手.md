## 2. 配置 `.env`

本机路径统一由 `.env` 管理：

- [.env.example](../.env.example)（✅）：模板；`.env`（❌）：本机实际路径；`.env.make`（❌）：生成物，供 `ps/Makefile` include。
- [scripts/env/env_loader.ps1](../scripts/env/env_loader.ps1) / [.sh](../scripts/env/env_loader.sh)：加载进会话；[generate_env_make.sh](../scripts/env/generate_env_make.sh)：生成 `.env.make`；[test_env.ps1](../scripts/env/test_env.ps1)：检查关键路径。

**自动加载 `.env`**（免手动 source）：[make_bootbin.ps1](../scripts/boot/make_bootbin.ps1)、`ps/Makefile`（`-include ../.env.make`）。

### 怎么配

```powershell
cd <仓库根目录>
copy .env.example .env                  # 从模板复制
bash scripts/env/generate_env_make.sh       # 生成 .env.make
.\scripts\env\test_env.ps1                  # 自检关键路径
```

| 变量 | 指向什么 |
|---|---|
| `FD_ROOT` / `TD_ROOT` | FD / TD 安装目录（FD 含 `toolchain/gcc/aarch64_linux/`；TD 含 `license/`、`bin/`） |
| `ARMNN_LIB` / `OPENCV_LIB` | ArmNN / OpenCV 库目录（各含 `include/`、`lib/`，`libfmt.a` 在 ArmNN 里） |
| `FREETYPE_INC` / `BOARD_LIBS` | FreeType 头文件目录 / 板上库的本地拷贝（链接期用，不上板） |
| `NPU_DEMO`（可选） | NPU demo 解压目录（用途见 §1） |
| `BOARD_HOST` | `ssh` / `scp` 目标：`~/.ssh/config` 别名（推荐）或 `root@<板子IP>` |
| `BOARD_IP` | 板子原始 IP：`ping`、`ssh-keygen -R`、写 `~/.ssh/config`、板端 dhcpcd 用 |
| `SSH_KEY` | PC 端私钥路径；未配别名时配 `-i` |

第三方库**一个库一个变量、各自一个根**，与板上 `/opt` 同构（见 §3）。**§4 起的板端命令都按「变量已加载」来写**（加载见下）。

### 手动加载与覆盖

```powershell
. .\scripts\env\env_loader.ps1              # 加载后 $env:FD_ROOT 等可用
```
```bash
source scripts/env/env_loader.sh            # Bash / WSL
make -C ps CROSS=<工具链前缀> ARMNN_LIB=<armnn_lib 目录> OPENCV_LIB=<ffmpeg_opencv4.7.0_aarch64 目录>   # 命令行覆盖
```

**优先级**：命令行参数 > Shell 环境变量 > `.env` > 无默认值；都没给时报错并提示配法。路径格式：`FD_ROOT=<盘符>:/目录/FD`（正 / 反斜杠均可，勿含空格）、`DES_WORK_DIR=$HOME/des-work`。env_loader.sh 只展开 shell 已有的 `$NAME` / `${NAME}`（`$HOME` 靠它生效），`$()` 与未知名原样保留；env_loader.ps1 按 PowerShell 语义展开，勿写 PowerShell 语法（`$()` 会执行）。

### 常见问题

| 现象 | 处理 |
|---|---|
| `make -C ps` 报 `FD_ROOT 未设置` / `ARMNN_LIB 未设置或目录不存在` | 填好 `.env` 后 `bash scripts/env/generate_env_make.sh` 重生成 `.env.make` |
| 换一台电脑 | 照「怎么配」走一遍（`.env.make` 须重生） |

路径只写**不入库**的 `.env`，不改脚本 / Makefile（规则见 [文档索引](README.md) 写作约定）；新增配置项同步 `.env.example`。

## 3. 获取依赖文件

四个库**自行获取、不入库**，来源见 §1。

NPU demo 包提供前两个库（路径见 §1；`.env` 指到目录本身）。Windows 解压会丢 `.so` 软链接，先跑修复脚本：

```bash
sh scripts/env/sdk_fix_sonames.sh "$ARMNN_LIB"  "$FD_ROOT/toolchain/gcc/aarch64_linux/bin/aarch64-linux-gnu-readelf"
sh scripts/env/sdk_fix_sonames.sh "$OPENCV_LIB" "$FD_ROOT/toolchain/gcc/aarch64_linux/bin/aarch64-linux-gnu-readelf"
```

FreeType 头文件：从板上拷（先做完 §4）`scp -r $BOARD_HOST:/usr/include/freetype2 "$FREETYPE_INC"`；或源码包 freetype-2.10.1（`FREETYPE_INC` 指向其 `include/`）。

板上库文件 → `$BOARD_LIBS`，两套名字都要有（SONAME + 链接名，报错对照见 §6）：

```bash
mkdir -p "$BOARD_LIBS"
scp $BOARD_HOST:/usr/lib/{libfreetype.so.6,libpng16.so.16,libz.so.1} "$BOARD_LIBS/"
sh scripts/env/sdk_fix_sonames.sh "$BOARD_LIBS" \
    "$FD_ROOT/toolchain/gcc/aarch64_linux/bin/aarch64-linux-gnu-readelf.exe"   # 按 SONAME 补出链接名
```

`-lfmt` 用 `$ARMNN_LIB/lib/libfmt.a`（静态），不必从板上拷。

## 4. 板子一次性配置

### 启动与拨码

- **拨码开关**（SW1，3 位）：**ON-OFF-OFF** = 从 SD 卡启动（日常）；OFF-OFF-OFF = 从 eMMC 启动（出厂系统，救生艇，保持原样）。
- **SD 卡**：厂家预装卡或自制持久化镜像（见 [开发环境与构建](开发环境与构建.md)「SD 卡布局与烧卡」）。
- **PS 网口**（RJ45，靠 USB 那个）：接电脑有线网口或路由器；PL 网口不支持（当前工程无网卡逻辑）。
- **串口**（可选，调试 / 首次配置）：USB-TTL 3.3V 接 J10 —— 1 = GND、2 = 板子 RX、3 = 板子 TX；115200 8N1，无流控。
- **首次登录**：串口登录 Buildroot `root`（密码默认为空，或见板卡手册）。

### 板端网络

板子 `eth0` 由 dhcpcd 管理，固定 IP（= `BOARD_IP`）追加到 `/etc/dhcpcd.conf` 末尾：

```bash
cp /etc/dhcpcd.conf /etc/dhcpcd.conf.orig
cat >> /etc/dhcpcd.conf << 'EOF'

# DragonEyeSorter 固定 IP 配置
interface eth0
static ip_address=192.168.137.100/24
static routers=192.168.137.1
EOF
reboot      # 重启后板子固定为 192.168.137.100
```

PC 侧有线网卡设 `192.168.137.1`、掩码 `255.255.255.0`；Windows「Internet 连接共享」会自动改成它。

### 免密 SSH

没有密钥就 `ssh-keygen -t ed25519 -f "$SSH_KEY" -C "<标签>"`，已有别的密钥就把 `.env` 的 `SSH_KEY` 指向它；公钥追加到板端 `/root/.ssh/authorized_keys`：

```bash
ssh-copy-id -i "$SSH_KEY.pub" root@$BOARD_IP     # PowerShell 无此命令：用 Git Bash / WSL
# 手动追加：mkdir -p /root/.ssh && cat "$SSH_KEY.pub" >> /root/.ssh/authorized_keys
#          chmod 700 /root/.ssh && chmod 600 /root/.ssh/authorized_keys
```

**配别名（推荐）**：`~/.ssh/config` 收进 IP、用户、私钥，之后只写别名。`Host` 名必须与 `.env` 的 `BOARD_HOST` 一致；`HostName` / `IdentityFile` 同 `BOARD_IP` / `SSH_KEY`（以 `des` 为例）：

```
Host des
    HostName 192.168.137.100
    User root
    IdentityFile ~/.ssh/<密钥文件名>
    IdentitiesOnly yes
```

`IdentitiesOnly yes` 只用这把密钥；不配别名时补 `-i "$SSH_KEY"`；非交互会话加 `StrictHostKeyChecking accept-new`。

### 板上目录与时间

板端 `/root/des`、`/root/bin` 由部署器 / `scp` 建好，布局见 [板端布局](板端布局.md)。

**无 RTC**：每次开机从 1970-01-01 起算，需手动设置或对时（板端 `ls -l` 时间戳不可信）：`date -s "2026-10-15 14:30:00"` 或 `ntpdate pool.ntp.org`；PC 端：`$ts = Get-Date -Format "yyyy-MM-dd HH:mm:ss"; ssh $BOARD_HOST "date -s '$ts'"`。

### 启动脚本

开机自启**已装好**：`/etc/init.d/S90des` → `/root/des/des_service.sh` 软链接（BusyBox init 按 `S??` 顺序执行 `start`），源在 `scripts/deploy/out/des_service.sh`。

```bash
ls -l /etc/init.d/S90des            # -> /root/des/des_service.sh
/root/des/des_service.sh status     # 在不在跑 + 最近服务事件
```

监督进程：拉起 `des_app`，崩了 2 秒重启、退避到 30 秒，5 分钟内退出 5 次放弃；事件写 `/root/des/data/service.log`（超 1 MB 轮转 `.1`），PID 在 `des_service.pid`。板端路径全部取自同目录的 `des.env`（唯一有路径的文件，见 [scripts/deploy/out/des.env](../scripts/deploy/out/des.env)），整目录拷走也能部署；改它用 `deploy.ps1 -WithService`。

行为由 `/root/des/autostart.conf` 决定（首次运行自动生成，改完 `restart` 生效，当前值以板上文件为准）：

| 变量 | 作用 |
|---|---|
| `ENABLED` | `0` = 开机不启动（只改这个文件，不动 `/etc`） |
| `MODE` | `run`（生产）/ `live`（不带传送带、机械臂、CAN） |
| `CAN` | 有值时先跑 `can_up.sh <CAN> <CAN_MODE>` 再传 `--can <CAN>`；留空直接进 RUN |
| `CAN_MODE` | `normal` = 要有总线伙伴应答（PC 的 USB-CAN 当 PLC）；`loopback` = 无总线自测 |
| `ARGS` | 追加给 `des_app` 的参数，如 `--go`（机械臂真动）、`--belt 60` |

带 CAN 启动时 `des_app` 先停**空闲**等 START（PLC 或界面按钮）；机械臂只在 `ARGS` 带 `--go` 时才真动——自启默认不碰硬件。

人工跑 `des_app.sh` / `des_tool.sh` 或 `desreg` 写命令前先停服务（相机 / 总线 / 步进主人唯一），用完恢复（`pl_check.sh` / `soak.sh` 自动暂停恢复）；命令见 [开发环境与构建](开发环境与构建.md)「部署与运行」。

**板端限制**：BusyBox 没有 `timeout`、`pkill`，限时运行用后台 + `sleep` 实现。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 编 `des_app` 报 `cannot find -lfreetype` | `$BOARD_LIBS` 缺**链接名** `libfreetype.so`（`-l` 只认无版本号名）：`sh scripts/env/sdk_fix_sonames.sh "$BOARD_LIBS" <readelf>` 补 |
| 编 `des_app` 报 `undefined reference to png_*@PNG16_0` / `inflate*`，或 warning `libpng16.so.16, needed by .../libfreetype.so, not found` | `$BOARD_LIBS` 缺 **SONAME 名** `libpng16.so.16` / `libz.so.1`：同上补 |
| 链接报 `undefined reference to cv::...` | 检查 `OPENCV_LIB` 指向（见 §3），并跑过 `sdk_fix_sonames.sh` |
| 板上跑 `des_app` 报 `error while loading shared libraries: libfmt.so` | 板上 `/opt/armnn_lib/lib/libfmt.so` 缺失或库路径没设：从厂家镜像补齐（`des_app` rpath 已指到该目录） |
| 换 `BOOT.bin` 后起不来、串口无输出 | 拨码应为 ON-OFF-OFF（见 §4）。起不来无法 SSH：断电取 SD 卡插 PC，在 FAT 分区删 `BOOT.bin`、复制 `BOOT.bin.prev` 改回 `BOOT.bin`；或拨 eMMC（OFF-OFF-OFF）挂载 SD 的 p1（FAT32）同操作 |
| 厂家生成的 `proc_sys_reset_*.v` 显示「已修改」 | CRLF 差异会使 `rebase --autostash` 失败：`git update-index --assume-unchanged <文件>`，rebase 完再 `--no-assume-unchanged` |
| Git Bash heredoc / `printf` 吞反斜杠（Windows 路径、转义丢失） | 含反斜杠的脚本先写成文件再执行，不用内联 heredoc |
