## 镜头

### V1 全景（20s）

- **画面**：从带头慢推到带尾：上料 → 相机龙门 + 两侧条形光 → 抓取线与机械臂 → 带尾两级翻板 → HDMI 显示器 → PC。
- **字幕**：各部件名称（逐个出现）。
- **解说**：「这是一条塑胶齿轮和齿条的注塑后质检分拣线。核心是一块安路飞龙 F3P 开发板：PL 做硬实时控制和视觉预处理，PS 跑 Linux 做定位、测量和调度，NPU 做缺陷分类。」

### V2 PL 硬实时（45s）

- **操作**：逻辑分析仪接 SERVO_BUS（BSS138 低压侧）与 STEP_PUL；终端 `des_tool.sh arm goto ... --go` 走一个点；同时 `des_app.sh run` 让皮带启停一次。
- **画面**：左：逻辑分析仪一帧 SYNC WRITE + 应答；右：6 个舵机同时动。再切步进 PUL 的加速 / 匀速 / 减速波形。
- **字幕**：「SYNC WRITE 一帧 3.30ms（理论 3.30ms）」「命令 → 首个步进脉冲 10.6µs」
- **解说**：「舵机总线协议在 PL 里用硬件实现：帧头和校验由硬件补、应答由硬件解析并打时间戳，六个舵机用一帧广播同时起跑。传送带步进的梯形加减速也在 PL 里，命令下发到第一个脉冲约十微秒。」

### V2b PL 视觉（30s）

- **操作**：界面「参数」页 → 「PL 显示」按钮连点：原图 → 灰度 → 高斯 → 二值 → Sobel → 边缘 → 原图。
- **画面**：HDMI 全屏，右上角帧率保持 60。
- **字幕**：每个模式名；「PL 处理，60fps 不降」
- **解说**：「图像进 DDR 之前，PL 先做灰度、高斯滤波、二值化和 Sobel 边缘检测，并对每个零件的区域统计面积和外接框，作为硬件尺寸粗测。切换模式，帧率始终是六十。」

### V3 界面与存储（45s）

- **操作**：鼠标依次点 总览 → 曲线 → 参数（把带速 50 改到 70 再改回）→ 记录（点开一件 NG 的裁切图）；SSH 窗口 `ls /root/des/data/log/<日期>/`、`head -3 parts_*.csv`。
- **字幕**：「每件一行记录（43 列）+ 不良件图像，存 SD 卡」
- **解说**：「操作界面直接画在 HDMI 视频下方：总览看产量良率，曲线页是外径和长度趋势与过程能力 Cpk，参数改了立即生效，记录页能翻每一件的图像和测量值。每件判定都写进 SD 卡。」

### V4 PL↔PS 双向（15s，可并入 V3）

- **操作**：终端 `desreg lat`。
- **字幕**：「PS 读一次 PL 寄存器 188ns；PL 每帧锁存拍摄时刻的带位置」
- **解说**：「PS 和 PL 之间通过 AXI 寄存器双向交换：命令下行，帧号、带位置、舵机应答和视觉统计上行。」

### V5 NPU 分类（40s）

- **操作**：放 3~4 件不同类别的零件过视野。
- **画面**：HDMI 叠加：跟踪框 + 类别 + 置信度 + NPU 耗时。
- **字幕**：「YOLOv8n-cls，UINT8 量化，单次 7.8ms；每件 3~6 次投票」（准确率填实测）
- **解说**：「每个零件按自身方向裁成 224 的小图送 NPU 分类，一件在视野里会被分类三到六次，概率平均后再判定。实物验证集上准确率（……）。」

### V6 CAN 产线联动（40s）

- **操作**：PC 上 PLC 模拟器：启动 → 调速 80 → 暂停 → 恢复；画面右侧滚动 PART 帧。
- **画面**：分屏：PC 模拟器 + 皮带实物。
- **字幕**：「CAN 2.0A 500kbit/s；命令往返（实测 ms）」
- **解说**：「电脑扮演产线 PLC，通过 CAN 下发启停、调速和配方，板子十赫兹回报状态，每判定一件就发一帧结果。」

### V7 分拣闭环（60s，主镜头）

- **操作**：随机摆 6~8 件（含良品、缺陷件、混料件）连续上料。
- **画面**：多机位：俯拍皮带 + 机械臂近景 + 带尾翻板近景；HDMI 小窗。
- **字幕**：「良品：到抓取线停带 → 按姿态夹取 → 按品种入盒」「不良品：不停带，带尾两级翻板分到返修 / 报废 / 复检」
- **解说**：「零件随机摆放进入视野，跟踪表按带坐标追踪每一件。良品到抓取线时皮带由 PL 减速正好停准，机械臂按零件角度夹起、按品种放进料盒；不良品不停带，在带尾由两级翻板分流。来不及停准的件转复检，绝不倒车。」

### V7b 换型（30s）

- **操作**：停机 → PLC 模拟器配方改 2（28 齿）→ 启动；放 28 齿件和 30 齿件各一件。
- **字幕**：「配方 1：28 齿 = 规格混料 → 报废」「配方 2：28 齿 = 良品，30 齿 → 报废」
- **解说**：「换型只要切配方：同样两个零件，换到二十八齿配方后，去向随之对调。运行中不允许换配方。」

### V8 测量与卡尺（40s）

- **操作**：同一件齿轮过视野 5 次；手持卡尺量同一件外径。
- **字幕**：「重复性 σ（实测）mm；与卡尺偏差（实测）mm」
- **解说**：「测量用亚像素边缘，并补偿了视差和卷帘快门。同一件来回测五次，结果与卡尺对比。」

### V9 可靠性（30s）

- **操作**：运行中按急停：步进与舵机断电、界面变「急停」、PLC 模拟器收到报警帧；复位后启动。再插 2h 运行的延时摄影 + `soak.sh` 汇总。
- **字幕**：「急停：常闭切动力 + 常开报 PL；2h 连续运行 60.02fps」
- **解说**：「急停按下，动力电直接切断，PL 同时锁存急停、停止脉冲并上报。连续运行两小时，帧率和内存都保持稳定。」

### V10 数据（20s，片尾字幕）

- 测试报告总表：同步（SYNC 帧时长、命令延迟）/ 采集（帧率、拍摄锁存）/ AI（推理耗时、准确率）/ 总线（CAN 往返、丢帧）/ 分拣（节拍、漏检率、测量误差）。数字取 `part_stats.py` 当天输出与 [测试与验证](测试与验证.md)。
