# 04 · 运动控制与分拣

> 运动控制方案、分拣流程与物料跟踪机制。

## 机械臂关节定义

拆掉原 #5 腕旋转、#6 夹爪，末端换固定吸盘支架，保留 4 轴：

| 轴 | 作用 | 说明 |
|---|---|---|
| #1 | 底座偏航 | 决定放到哪个料盒 |
| #2 | 大臂俯仰 | 受力最大，电流监测重点 |
| #3 | 小臂俯仰 | |
| #4 | 腕俯仰 | 补偿 #2/#3，保持吸盘始终垂直向下 |

## 驱动方式：总线与 PWM 双路并存

总线和 PWM 两条路径**都布线**，运行时由寄存器选择哪套驱动生效。成本只是几根线加三态控制，换来"同一硬性项用两种方式实现并给出对比数据"。

- **总线模式**（主选）：单线半双工、带位置/电流/温度遥测，是"设备健康诊断"创新项的前提。
- **PWM 模式**（备选）：是否启用取决于 W1 舵机 PWM 模式实测结果。

## 分拣时序

```
t0  物料进入视野 → PL 前景 Blob 连续确认 n 帧 → 分配跟踪 ID，记下当时编码器位置
t1  PL 裁 ROI → 打包张量 → 中断通知 PS
t2  PS 取 ROI → NPU 推理 → 类别 + 置信度 + bbox → 写回跟踪队列
t3  PL 按编码器位置实时推算该物料当前位置（带速变化自动跟随）
t4a NG：到达拨叉位 → 电子齿轮按主轴位置触发 → 剔除到 NG 槽（不停带）
t4b OK：到达取料位 → 传送带精确停位 → 机械臂吸取 → 放到 A/B 区 → 复位 → 继续走带
t5  写数据库 + 存 NG 图 + 更新 UI + 计数
```

## 物料跟踪原则

- **防重复触发**：每个物料一个跟踪 ID，状态机 `NEW → INFERRED → SORTED → DONE`；冷却由"物料离开该工位的编码器距离"决定，而不是定时器。
- **机械臂忙时不堆积**：新任务写入队列槽；槽满则该物料直接走到带尾回收。队列深度待定（草案 8 槽）。
- **节拍瓶颈认识**：机械臂取放是数百 ms 量级的最慢环节，推理相对而言不是约束。因此 NG 不停带、OK 才停带，把停带次数降到最低。报告里节拍分"纯检测"与"含分拣"两个口径。

## 待验证事项

- 舵机 PWM 模式是否可用（决定 `servo_pwm_x4` 去留）。
- 机械臂工作半径能否覆盖所有料盒（W1 实测可达性）。
- 传送带辊径、每脉冲位移、编码器分辨率换算。
