# 测试与验证

> **本文件是全仓实测数字的唯一来源**：其它文档只引用，不重复写数；需要证据时给 `log/` 链接。
> 出数：板上每件记录（43 列 CSV，含 NPU `npu_ms` / `lat_ms`）→ `pc/report/part_stats.py`；长时间稳定性 → `scripts/deploy/out/soak.sh`（见 [pc/report/README](../pc/report/README.md)）。

## 测试原则

- **定量测试报告是硬性项⑥**：数据随代码埋点（见 [软件与UI](软件与UI.md)「测试埋点」），不能最后补；同步误差主用逻辑分析仪。
- **口径诚实**：指令分辨率与实测精度分开报（舵机回差 / 虚位各 ≤1°，定位精度只报实测量级）；帧率口径分开（采集 / 显示 vs 按物料触发的推理）；未实测标 ⚠。每项先定判定标准与失败后果。
- **条件随数字**：板端版本、负载、界面布局等条件与数字同格出现；同一指标只留最新值，旧值放括号，条件不同的各占一行。
- **改 RTL 修 bug 先写测试**：先写能抓到 bug 的用例（旧 RTL 失败、新 RTL 通过），并检查修复没吃掉相邻既有行为；断言要具体（时长、步数、标志位），不写 `≥` 这类弱断言。例见 [log/2026-10-15-审查队友提交](log/2026-10-15-审查队友提交.md)。

## 量化报告框架（硬性项⑥）

| 类别 | 指标 | 目标 | 测法 |
|---|---|---|---|
| 控制同步精度 | SYNC WRITE 多舵机同步误差 / 指令响应延迟 | < 100 µs / < 10 ms | 逻辑分析仪抓帧尾 + 动作起点；PL 时间戳计数器 |
| | 机械臂重复定位精度 / 传送带定位误差 / 跟踪误差 | 实测值 / < 1 mm / — | 30 次重复定位；位置读数 vs 实测位移；对射前沿 vs 预测前沿 |
| 采集延迟 | 采集帧率 / 预处理延迟 / 端到端显示延迟 | — | 帧计数 + 时间戳 |
| AI 推理 | NPU 单次推理 / 端到端（触发 → 类别可用） | < 50 ms / < 100 ms | `test_npu` 分阶段计时；`lat_ms` |
| | 分类准确率 / 尺寸测量误差 | ≥ 92% / < 0.3 mm | 独立测试集；卡尺 / 标准量块真值 |
| 总线稳定性 | CAN 误码 / 舵机总线丢帧 | 0 / <0.01% | 统计计数 |
| 工程可靠性 | 连续运行 / 漏检率 | 2h 无故障 / — | 自动化脚本 + 日志；对射与跟踪表逐件对账 |
