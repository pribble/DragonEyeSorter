# 测试与验证

> **本文件是全仓实测数字的唯一来源**：其它文档只引用，不重复写数；需要证据时给 `log/` 链接。
> 出数：板上每件记录（40 列 CSV，含 NPU `npu_ms` / `lat_ms`）→ `pc/report/part_stats.py`；长时间稳定性 → `scripts/deploy/out/soak.sh`（用法见 [pc/report/README](../pc/report/README.md)）。

## 测试原则

- **定量测试报告是硬性项⑥**：数据随代码埋点（见 [软件与UI](软件与UI.md)「测试埋点」），不能最后补；同步误差主用逻辑分析仪。
- **口径诚实**：指令分辨率与实测精度分开报（舵机回差 / 虚位各 ≤1°，定位精度只报实测量级）；帧率口径分开（采集 / 显示链路 vs 按物料触发的推理）；未实测标 ⚠。
- 每项验证先定**判定标准**与**失败后果**。
- **条件随数字**：板端版本、负载、界面布局等条件与数字同格出现；同一指标只留最新值，旧值放括号，条件不同的各占一行。

## 量化报告框架（硬性项⑥）

| 类别 | 指标 | 目标 | 测法 |
|---|---|---|---|
| 控制同步精度 | 总线 SYNC WRITE 多舵机同步误差 | < 100 µs | 逻辑分析仪抓帧尾 + 动作起点 |
| | 指令响应延迟 | < 10 ms | PL 时间戳计数器 |

| | 传送带定位误差 | < 1 mm | 位置读数 vs 实测位移 |
| | 跟踪误差 | — | 对射前沿 vs 预测前沿 |
| 采集延迟 | 采集帧率 / 预处理延迟 / 端到端显示延迟 | — | 帧计数 + 时间戳 |
| AI 推理 | NPU 单次推理 | < 50 ms | `test_npu` 分阶段计时 |
| | 端到端（触发 → 类别可用） | < 100 ms | 时间戳（`lat_ms`） |
| | 分类准确率 | ≥ 92% | 独立测试集 |
| | 尺寸测量误差 | < 0.3 mm | 卡尺 / 标准量块真值 |

## 还缺（按优先级）

1. **实物（舵机 / TB6600 / 皮带已接，舵机暂 4.9V 欠压）**：舵机 SYNC 同步误差（逻辑分析仪抓多舵机动作起点）、机械臂重复定位、传送带位移 vs 读数、跟踪误差 —— 按 [到货联调清单](到货联调清单.md) §2 / §3 / §5 / §9 做。
2. **实物精度**：分类准确率（NPU，独立编号验证集）、测量误差（卡尺真值，`des_tool.sh measure -n` 重复性）。
3. **端到端延迟**：拍摄 → NPU 结果可用（`lat_ms` 已在每件记录里，可直接统计）。
4. **长时间**：CAN 实物收发与误码（USB-CAN + PC「PLC」）、舵机总线长时间应答丢失率（PL 错误计数器）、接实物 2h（含持续上料）。
