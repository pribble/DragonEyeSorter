# 2026-10-17 舵机总线首次联通（PL v9 + BSS138 + 机械臂 6 舵机）

## 接线

- BSS138 低压侧：LV ← J12 PIN1（3.3V），LV1 ↔ PIN19（SERVO_BUS），GND → PL 地 WAGO（接线图已出库，见 [硬件与接线](../硬件与接线.md)）；实测 LV 3.3V、LV1 3.2V（空闲高）。
- 高压侧：HV ← 5V 降压模块 OUT+（固定 5V 款，实测 4.9V；空载略上飘），GND ← OUT−；HV1 ↔ 舵机信号线。
- 舵机供电：数控电源（XY6020L）面板排线断、屏不亮（IN 实测 23.9V，等新排线）→ **临时用同一 5V 模块（4.9V）供电**，只做通信与小幅动作。15kg 舵机额定 6.0~7.4V、夹爪（ID 6）4.8~6.0V，4.9V 偏低。

## 发现：15kg 舵机应答后有 10~15ms 不收命令

- 现象：对 ID 1~5 连续发 PING / READ，**严格「成、败、成、败」交替**（100 次 50 / 50），总线 RX 错误计数 0；ID 6（夹爪）100 次全成；两次命令隔 0.3s 则全成。
- 测量（`ps/tests/test_servo_gap.c`，PL 时间戳控制「上一条应答结束 → 下一帧开始」）：ID 2 在 0.2 / 0.5 / 1 / 2 / 5 / 10ms 间隔都交替，**15 / 20 / 30 / 50 / 100ms 全成**；被忽略的那一帧之后立刻再发又能成。
- 影响：读完舵机马上发运动命令会被丢（第一次试底座 / 腕旋没动，加 50ms 后正常）；`ArmExec::probe()` 连读 3 项丢一半。
- 处理（`ps/src/hw/des_hw.c` 的 `wait_quiet`）：每帧发出前等目标舵机自上次应答起静默满 **20ms**（同步写按 id 逐个算，广播按全部）；跨进程用 PL 记录的「最后应答时间 + 应答 id」。`des_servo_set_quiet_us(0)` 可关（测量程序用）。验证：连发 PING 20/20、连读 10/10，「读完立刻写」腕旋照常转动。
- ⚠ 是否与 4.9V 欠压有关未知：数控电源修好、6.8V 供电后用 `test_servo_gap 2` 复测。
