# 2026-10-29 报告重构：工程说明书 → 纯论文式（Word 生成链同步改造）

目的：作品报告从「工程说明书」体（封面 + 目录 + 页眉 + 10 章阿拉伯编号 + 项目符号罗列）重构为**纯论文式**（标题 + 摘要 + 关键词 + I~IX 节 + 参考文献 + 附录 A），排版与语言参照一篇中文 LaTeX 期刊论文。**内容与数字仍以 [技术文档](../../submission/技术文档.md) 为唯一源**，本次只换结构、版式与文档语言，不改任何实测口径；生成链仍是 Markdown → DOCX → Word 导 PDF → 插图高清化。

## 1 动机

初赛线上评审按论文体读报告：先看标题 / 摘要 / 关键词，再看分节编号与图表顺序号，最后看参考文献与附录，而不是按操作手册翻。旧报告是工程说明书体：封面、目录、页眉、10 章阿拉伯编号、大量「问题—做法—结果」三段式与项目符号，图表引用写成「图 2-1」「第 3.1 节」，与论文阅读习惯不符。重构目标是在不丢一个数字、不丢一张图表的前提下，把同一份 Markdown 内容源换成论文结构与版式。

## 2 结构变化（旧章号 → 新章号）

| 1 作品概述 | I. 引言（A 应用背景与检测对象 / B 赛题要求与设计目标 / C 主要工作与贡献） |
| 2 系统架构 | II. 系统总体设计（A~D） |

| 5 视觉与 AI | V. 视觉与缺陷分类（A~D） |
| 6 工业总线 | VI. 工业总线通信（A~C） |
| 7 机械与电气 | VII. 机械、电气与安全（A~D） |
| 8 测试报告 | VIII. 实验与结果（A~E） |
| 9 创新点 | 并入 I-C 主要工作与贡献（五条贡献各带关键数字） |
| 10 总结与展望 | IX. 结论与展望 |

- 摘要、关键词、参考文献、附录 A 是**不编号**一级标题；编号写在标题文字里（`## I. 引言`），脚本不自动编号。
- 图表统一阿拉伯顺序号：图 1~12（5 张现有线稿 + 7 张实物照片占位）、表 1~11；交叉引用统一为「如图 N 所示」「见表 N」「第 III-A 节」「第 V 节」，不再用「图 2-1」「第 3.1 节」。
- 新增 7 张实物照片占位图（图 1 / 2 / 7 / 8 / 10 / 11 / 12），占位图与 `placeholder_manifest.json` 一一对应；拍完后只换 PNG、把 `replaced` 置 true，正文与图注一字不动。
- 语言：第三人称「本文 / 本系统」，连贯段落取代项目符号，首次出现的术语给中文全称 + 英文缩写，数字与单位间加半角空格。

## 3 排版令牌与参照实测值

参照论文 PDF 用 PyMuPDF 实测：A4 595.28×841.89pt；左右边距 68.0pt（2.4cm）；正文 10.95pt（LaTeX 11pt）、行距 13.55pt；标题 17.28pt 粗；一级标题 14.4pt；二级 12pt；图注 10pt 粗；表体 9pt；页脚页码 11pt 居中。

本报告落版令牌（`submission/build/md2docx.py` 顶部，`out/_md2docx.json` 的 `tokens` 可核对）：标题 17.5pt 黑体居中；一级标题 14.5pt、二级 12pt 黑体左对齐；正文 11pt 宋体 / 西文 Times、首行缩进 440 twips（2 字符）、单倍行距、段前段后 0；图注 10pt 宋体加粗居中（图下）、表注 10pt 宋体加粗居中（表上）；三线表表体 9pt；插图宽 15.8cm（满版心）、整表 ≤15.6cm；页脚居中页码 11pt；**无页眉、单节、无封面 / 目录**；全篇只有黑色。

## 4 与参照论文的刻意差异（记在此备查）

1. **正文首行缩进 2 字符**：参照 LaTeX 译文未缩进是转换器行为，中文排版规范要缩进。
2. **一级标题用罗马数字、图表用阿拉伯顺序号**：参照论文表用罗马数字（表 I），中文报告易与章节号混淆，统一改阿拉伯（表 1）。
3. **关键词**：用「关键词」而非「索引术语」。
