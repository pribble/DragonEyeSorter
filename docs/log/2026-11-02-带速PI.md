# 2026-11-02 带速 PI（PS 侧，视频演示用，默认关）

## 1. 为什么做

用户希望在演示视频里出现“带速闭环”镜头。明确口径：这是 **PS 侧的带速 PI**（编码器反馈修巡航目标速度），**不是 PL 硬件 PID**；默认关闭，生产 `des_app.json` 不打开。不能把它写成“PL 高级控制算法硬件实现”。

## 2. 实现

- `ps/src/sched/speed_pid.{hpp,cpp}`：纯逻辑 PI，`period_ms` 100、输出限幅 `trim_mm_s`、死区、抗积分饱和；默认 `enabled=false`。
- `Runner`：只在 `RUN + BeltPlan::Run + 未停带` 时工作；启动斜坡（PL 速度 < 0.95×目标）期间冻结；`belt_.set_speed(base + trim)`。
- 实际带速用 **ENC_CNT 100ms 计数窗**（0.49mm/s 分辨率），不用 `ENC_SPEED` 的 10ms 量化（4.9mm/s）。
- 配置：`des_app.json` 的 `belt.pid`；生产默认 `{"enabled": false, ...}`。
- UI：面板状态行在启用时追加 `PI +x.x mm/s`；终端 1Hz `[pid] base ... actual ... trim ...`。
- 不改 PL、不改寄存器。

## 3. 实测

- 单测 `test_belt_pid`：**11 passed / 0 failed**（主机）。
- 板上（80mm/s 快档，空带）：
  - 稳定段 `base 80.0 / actual 80.0~82.7 / trim +0.00`；死区 5mm/s 覆盖编码器/带面波动，不再来回追。
  - 自然负载跌落 `actual 74.5 → trim +2.81`；`77.4 → -1.50`（积分回吐），随后回 0。
  - 服务态正常 60fps；默认 `pid` 关闭时无 `[pid]` 行、行为不变。
- 新 `des_app` 已上板（`c74ffa4e...`）；备份 `/root/des/des_app.before_pid`、`/root/des/des_app.json.before_pid`。

## 4. 演示用法（拍视频时）

```sh
/root/des/des_service.sh stop
cd /root/des
DES_CONFIG=/root/des/des_app_pid.json nohup ./des_app.sh run --go > /tmp/pid_run.log 2>&1 &
tail -f /tmp/pid_run.log          # 看 [pid] base/actual/trim
```

- `des_app_pid.json` = 板上配置副本 + `pid.enabled=true`（kp 0.5 / ki 0.05 / 死区 5 / 限幅 3）。
- 拍法：皮带 80mm/s 稳定后，手轻压皮带 1~2s → actual 掉、trim 升到 +3，松手后回 0；同时拍总览右上角「带速 / 实测」和状态行 `PI`。
- 拍完：`kill` 掉手动进程，`/root/des/des_service.sh start` 回生产（PI 默认关）。

## 5. 注意

- 视频字幕必须写 **「PS 侧带速 PI，编码器反馈，默认关」**；不要说“PL PID / 硬件 PID”。
- 编码器 100ms 窗口 + 5mm/s 死区是为了稳；更小的死区会追 10ms 量化噪声。
- 生产不要默认打开；带速变化会影响停带/抓取时序，需要重新整定。
