# 2026-11-02 图 4 工位布局朝向修正（上下反了）

## 1. 问题

用户看图 4（`submission/figures/fig_layout.py`，报告 p9）指出：机械臂与良品料盒画在皮带**上方**、导流挡板与两只料盒画在**下方**，与实物相反。

核查：图是**上下镜像**的，而且 +y 箭头也跟着指向上方，所以图本身自洽、看不出错，只有对照实物才发现。

## 2. 事实依据

- 10-21 用户纠正（`10_项目文档/侧边导流挡板方案.md` §2b）：「机械臂在俯视图 / 画面**下侧**，挡板 / 支架 / 计米轮在上侧；主动辊在右（上料端）」。
- 手眼标定（10-22）：底座 `base_xy` 的 y = **+142 mm**，+y 指向机械臂一侧。
- 俯视且上料在右时，要走料方向 +x 向左、+y 向下、+z 出纸面才构成右手系 → 机械臂必须画在图**下方**。图上原来是 +x 向左、+y 向上，等于从纸面**背面**看，所以整体上下反了。
- 沿革：10-31 的 `f0c6abe` 把 +y 箭头改成「指向机械臂一侧」，只把箭头指向上、没有把图翻转，于是「+y 向上 + 机械臂在上」被固化下来。

## 3. 修正

`fig_layout.py` 重排纵向位置，新增 `Y(mm) = CY − mm·K` 统一换算：

- 机械臂、良品料盒 → 图下方（`SIDE_Y0 = BY0 − 22 − ARM_H`）；挡板、报废 / 返修盒、龙门 → 图上方。
- 挡板转轴 (557, −178) → 图上方带边外；合位末端 (322, +36) → 伸进带面（`Y()` 换算，几何不变）。
- +y 箭头改为向下；带尾复检箱居中于带尾；两根条形光对称画在视野上、下沿（原来一里一外不对称）。
- 标签避让：「挡板（报废 + 返修）」移到转轴左侧避免压住料盒框；「碰件后摆开扫出」移到带面内；条形光说明移到左上角两行，避开料盒与龙门。
- 正文补朝向，防止再被翻回去：2.1 加「机械臂在图形下方」，图 4 图注加「机械臂与良品料盒在图下方（底座在 +y 侧），导流挡板、两只料盒与龙门在对侧」。
