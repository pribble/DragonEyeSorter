# 2026-10-09 · 底板工程与 BOOT.bin 零件入库

## 决定

- **soc_prj 底板工程入库** `pl/soc_base/`（原"工程本体不入库"作废）：385 文件，含 13 个安路加密 IP 文件（`*.enc.v`/`pragma protect`，NPU 软核、MIPI DPHY、HDMI 控制器等），仅随底板使用，禁止单独提取分发（AGENTS.md 第 7/9 条已改）。
- **BOOT.bin 固定零件入库** `scripts/bootbin/parts/`：`fsbl.elf`（1767704 B，MD5 a64a56c0…，源自 demo.zip soc_fsbl/build）+ `u-boot.elf`（992360 B，U-Boot 2021.01，从厂家 BOOT.bin 分区 2 偏移 0x40e4c0 / 长度 0xe2248 截取后 objcopy 包成 ELF，载入/入口 0x200000）。二者不随 PL/应用重编而变；`vendor.bit`、`u-boot.bin` 中间件不入库（.gitignore 白名单只放两个 .elf）。
- **TD 版本决定**：不装 6.2.1，用本机 2026.1 SP2（6.2.2）打开并接受格式升级；6.2.1 原版底板在 git 历史可回退；格式升级产生的本地 diff 不提交。

## 验证

- 仓库内零件重打包：`make_bootbin.ps1`（FD BootGen albg1 -arch dr1p104）输出 5179264 B，**MD5 = 41489E5701B8B91D625A4A7B22687874**，与 10-08 log 记录一致。
- 回退路径验证：删掉 parts/u-boot.elf 后重跑脚本，自动从厂家 demo 重取重打包，重生成的 u-boot.elf 与已入库版**逐字节一致**（cmp 通过），重打包 MD5 同上。
- 零件来源 demo.zip 内 BOOT.bin MD5 = d6b2d387…（与脚本内置校验值一致）。

## 影响

- 换机器/克隆仓库即可打包 BOOT.bin，不再依赖本地厂家资料路径（FD_ROOT 仍需指向本机 FD 安装）。
- 阶段 0 出口路径不变：TD 打开 pl/soc_base → 挂自研 AXI-Lite → 出 .bit → make_bootbin → 上板。
