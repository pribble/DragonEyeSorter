## 修复

| 类别 | 问题 | 修法 | 文件 |
|---|---|---|---|
| 死代码 | 文档→头文件方向恒真（`$docSet` 用文档自己构建） | 新建头文件地址集合比较；补「文→头」检出力 | `check_sources.ps1` |
| 盲区 | 行内代码/围栏代码块里的失效路径检不出（目录迁移防不住） | 新增 `inlinePaths` 规则：只查 `scripts/` 前缀、`Test-Path` 校验，例外带 reason | `check_docs.ps1` / `doc_check.json` |
| CSV | `csv_header()` 内带引号注释会污染列数（44→45 误报） | 只取 `return` 到分号之间的字符串字面量，剥注释；口径正则扩写（兼容「N 列，」等，5→6 处） | `check_sources.ps1` |
| 部署清单 | `out/` 只查已入库文件，新建未 `git add` 的部署件漏检 | 已入库 ∪ `git ls-files --others --exclude-standard` | `check_sources.ps1` |
| 类别表 | 全文正则会把普通表格误判成类别表 | 只解析表头含 label/类别 的表格块，标签反引号可选 | `check_sources.ps1` |
| 锚点 | 与 GitHub 语义不符（重复标题无 -1/-2、连续空格收成一个连字符） | 重复标题加 -1/-2 后缀；空格逐字符转 `-` | `check_docs.ps1` |
| 链接 | 引用式链接、图片嵌链接外层目标漏检；转义反例误报；4 空格缩进代码块误报 | 补引用式定义解析、嵌套图片外层、转义跳过、缩进代码块状态 | `check_docs.ps1` |
| 数字 | 「同段」实为同行；`catalog/` 因含 `log/` 子串而免检 | 按段落判断，来源必须是真链接（测试与验证 / log） | `check_docs.ps1` |
| 索引 | 只查 docs 根与 log，子目录文档可游离 | docs 递归索引 + 各顶层目录 README 必须挂链 | `check_docs.ps1` |
| 寄存器 | >0xFFF 的基址 / ID 常量被静默跳过 | `headerNonRegister` 例外（7 个常量带 reason）；未登记的才告警；头文件缺失时收敛为 1 条错 | `check_sources.ps1` / `source_check.json` |
| 配置纪律 | 例外缺 reason | `allowedExtraDocIds` / `missingAllowedGlobs` / `inlinePaths` 等一律对象 + reason，缺 reason 报 error | 两个 JSON |
| 自测 | 检查器无回归用例，改坏规则无人发现 | 新增 `selftest.ps1`：临时副本上注入 24 组坏样例，断言退出码与关键报错 | `selftest.ps1` |
| 文档表述 | `test_env` 被写成查「板端连接」（实际不查）；docs 四目录行误写 `sdk_fix_sonames.sh`；v16「10-25 重编」与台账不符；log 措辞自相矛盾；`.gitignore` / `verify_report.py` 引用旧编号；`.gitattributes` 悬空 `fakebin` | 逐处改正（按当前唯一源） | `scripts/README.md`、`docs/README.md`、`pl/soc_base/README.md`、`docs/log/2026-10-27-scripts目录拆分.md`、`.gitignore`、`.gitattributes`、`submission/build/verify_report.py` |
