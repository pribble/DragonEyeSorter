## 1. 相机与灯三轮调整

| 轮 | mm/px | 视野沿带 | 总倾斜 | 白纸亮度（最亮 / 上下两侧差） |
|---|---|---|---|---|
| ① 下午 | 0.1942 | 373mm | 1.0° | 171 / 上侧暗约 25%，左上角 78 |
| ② 镜头表面约 29cm | 0.1930 | 370mm | 1.8°（镜头偏上游 1.6°、偏挡板侧 1.0°） | 178 / 上侧暗约 24% |
| ③ 相机挪到两灯正中（定版） | **0.1945** | **373mm** | **0.7°** | 184 / 上下差约 6% |

- **倾斜的算法**：单张近正视棋盘格同时拟合焦距不收敛（f 估出 2064~2999px，对应 H 395~579mm，明显不对）→ 改为固定焦距 f ≈ 1530px（由镜头表面 29cm + 0.193mm/px 反推）再分解单应。f 取 1450 或 1530 时倾斜只差 0.1°。之前对话里报的「沿带 1.4° / 横向 0.6°」是自由拟合的结果、偏大，同法重算第①轮为 1.0°。
- **正下方点不改用计算值**：定版后正下方点离画面中心约 4mm，与「主点在画面中心」这一假设本身的误差同量级；测量的拖影校正每毫米约 0.008mm，4mm 只差约 0.03mm，且被标准件偏置吸收 → 继续用画面中心当光轴。
- 第③轮把相机挪到两根灯正中后，上下两侧亮度差从 24% 降到 6%，灯不再调。

## 2. 平场采集（数据，代码待做）

- 做法：白 A4（沿带 210mm、横向盖满视野）放上料端，`desreg step move` 每 40mm 停一次拍一张，共 7 张（f00~f06），再回到起点。**注意 `desreg step move N` 的 N 是绝对目标位置**（des_tool 里的 `belt_move` 才是相对步数），第一次按相对步数连发 6 次只走了一站。
- 合成：每张取纸面（往里收 25px 避开纸边）求平均 → 平滑 → 48×27 网格（板上 `data/flat_1021/flat_1021.json`，中心白电平 180.6）。
- **整幅白电平**：中心 100%；中线处左缘 44%、右缘 70%；四角最低 37%。按 cos⁴ 估算，4.2mm 广角镜头自身的渐晕就让边缘降到 50~60% → 灯光只能改善一部分；左（下游）比右暗约 37%，说明灯整体偏上游。灯不往下游挪（会挤占抓取线和机械臂空间）。
- 用网格校正后，三张纸面图 p5~p95 = 175~185（约 ±3%）。
- ⬜ 代码：`crop_part` 按网格乘增益（NPU 输入、存图、训练集共用），`des_tool calib-flat` 自动扫描写独立文件（calib-cam 重跑不覆盖）；正式采训练图前完成。

## 3. 计米轮往返误差

每轮正走 0.4250 计数 / 步、倒走 0.4219（差 0.73%），300mm 往返后编码器显示少回 2.1~2.2mm；同一时段相机看皮带往返只差 0.08mm → 误差在计米轮：倒转时轮子被推着走（安装是拖行方向），有效半径 / 打滑与正转不同。生产只正转，标定取正转值，不影响。下午 50mm 短测得到的 0.0504mm/计数是旧步距 + 20mm/s 下的粗值，作废。

## 4. 三齿轮视差扫描

- 三个 30 齿（卡尺外径 32、厚 10）横排（y ≈ +81 / −1 / −82），每站 2390 步 = 50.00mm，7 站有效；每站一帧，用 H 280 / 290 / 300 / 310（侧壁亮）与 300（侧壁暗）分别测量。脚本 `data/par_sweep2.sh`，结果 `data/par_1021_sweep.txt`。
- **位置**：三行齿轮在台面坐标走了 305.9~306.1mm，真实 300.0mm → k = 1.0196~1.0203。纸片步距与齿轮位置用同一单应，单应的比例误差相互抵消。按侧壁亮模型 k = (2H − h) / (2(H − h)) 反推 H ≈ 265，比尺量（光心约 295）低 30 → 解释为斑点质心的等效高度约 5.7mm（模型假设 h/2 = 5.0mm）。按 H = 295 做位置校正，残差 0.25%，视野边缘约 0.46mm，对抓取无影响。
- **外径随位置的离散**（离画面中心 60~120mm / 120~200mm 两带的 sd）：H 280 → 0.48 / 0.66；H 290 → 0.31 / 0.35；H 300 → 0.30 / 0.49；H 310 → 0.33 / 0.28；侧壁暗 H 300 → 远处外径 +1.5~3.3mm。→ 取 H = 295、`walls_visible` = true。
- 孔径离中心越远越大（中心约 5.6 → 远处 7.1~7.4，真值 6）→ 孔径与外径一样，只在画面中心附近可信（软件取离中心最近的一帧测）。

## 5. 失误：临时配置放错目录导致齿轮掉落

标准件测量时把临时配置（改 H / 偏置）放在 `data/` 下，`calib_file` 按配置所在目录解析 → 没读到 `calib.json`，坐标是未标定的占位值（日志有 `config: no calib.json`），据此让皮带倒走 96mm，把齿轮送出了上料端。改正：临时配置必须与 `des_app.json` 同目录（之前的扫描脚本就是这样做的），动皮带前先确认日志里有 `config: camera calibration from …calib.json`，并尽量只往下游走。
