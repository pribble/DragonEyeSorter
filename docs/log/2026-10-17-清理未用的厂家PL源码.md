# 2026-10-17 清理未例化的厂家 PL 源码（删 15 个文件 + 综合验证）

用户问「厂家这些模块我们都用得到吗」，确认 **A+B+C 全删**。

## 判定方法

- 从 `system_top` 出发做**引用链扫描**：解析 140 个明文 `.v/.sv/.vh` 的 `module` 定义与例化点，BFS 求可达集；`pragma protect`（加密）文件按「所属 IP 包装是否可达」判断。
- 候选逐个回查**真实例化点**，排除注释误命中 —— 如 `divider` 只在 `awb.v` / `awb_seq_div.v` 的注释里被提到（第一次扫描误判成「可达」）。
- 结论：`system_top` 只例化 `design_0`（块设计）、`uidbuf_write`、5 个自研 `des_*`、`design_top_wrapper`；实际视频链 = `mipi_rx` + `csi_unpacket` → `raw10_unpacket_4lane` + `image_correction` → `isp_top` → 帧写 → HDMI。

## 效率对比

| 对比 | 原件 | 替代品 | 结论 |
|---|---|---|---|
| AWB 除法器 | 厂家 `DR1_SEQ_DIV`：50 级流水线、**每时钟一个商**（两实例共占 u_awb 2341 LUT / 2402 加法链 / 6168 FF） | 自研 `awb_seq_div`：**每 49 时钟一个商**，几百 LUT | 吞吐低 49×，但 AWB 增益每帧才更新（49 拍 @75MHz ≈ 0.65µs，60Hz 可忽略）；slice 90.2% → 81.7%、布线 5h 不通 → 23 分钟通过，增益差 ≤1 步 |
| Sobel / 3×3 | `axis_sobel` + `matrix_3x3` + `shift_ram` + `ram0`（单算子、AXI-Stream、无统计无多模式） | `des_vision`：灰度 / 高斯 / Sobel / 二值 + ROI 统计 + 6 种显示模式一条链，993~1073 LUT + 2 ERAM + 13 DSP | 功能覆盖与接口贴合度更好；**同条件面积 / 时序对比没做 ⚠** |
| 翻板 PWM | 厂家 AXI PWM（3 实例，AXI 动态配参，输出当 lock） | `des_pwm`（58 LUT，2 通道、µs 写值、下周期生效、周期计数确认） | 自研贴合需求；删厂家那份要改块设计，收益只在编译时间与可读性 |

TD 只编译清单里的文件，**没被例化的模块综合时被裁掉、不占 LUT/ERAM**；此前「两套都编、只有替代品进网表」，删掉后才是「只编替代品」。
