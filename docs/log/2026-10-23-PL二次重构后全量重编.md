- 仿真：以 WSL Ubuntu 22.04 + Icarus Verilog 12.0 对当前树与重构前基线（`f197081`）各跑 8 项，日志逐字节比对。
- 上板：按[开发环境与构建](../开发环境与构建.md)「换 `BOOT.bin`」——`scp` 到 `/root/BOOT.bin.new`、板上校验 md5、p1 `cp BOOT.bin BOOT.bin.prev` → `mv` → `sync` → `reboot`；起来后跑 `/root/des/pl_check.sh`，另跑 `soak.sh 120` 与 VDMA 扫描输出抽查。
- 踩坑（文档已记，仍复现一次）：传给 TD 的 `.tcl` 路径**必须用正斜杠**——用 `C:\...` 时 Tcl 吃掉反斜杠，报 `couldn't read file "C:AnlogicTD...DefaultFlow.tcl"`。

## 备注（soak 后服务恢复的脚本竞态）

soak 结束时它自己的 `des_app` 尚未完全退净，`des_service.sh` 抢先拉起新实例，被 `des_app.sh` 的单实例保护（`pidof des_app`）连续拒绝，达到 5 次阈值后服务放弃；随后服务再次 `start` 恢复（日志 `00:05:07 start`），当前生产运行 60fps 正常。属测试脚本时序 / 既有保护逻辑，与 PL 无关；要彻底消除，`des_service.sh` 恢复前应等 soak 的 `des_app` 退净。
