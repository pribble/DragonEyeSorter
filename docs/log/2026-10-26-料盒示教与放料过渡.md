# 2026-10-26 料盒示教、放料过渡、舵机电流 / 温度

## 舵机电流 / 温度：这批舵机不提供

协议 v4.01 写 0x2E = 当前电流（mA）、0x3F = 当前温度（℃），界面一直读到 ~4300 / 255。6.8V、扭矩开、臂在料盒姿态实测：

| 舵机 | 0x2E | 0x3F |
|---|---|---|
| 1、2、4、5 号（15kg） | 4300~4334 | 255 |
| 3 号 | 1996（一次，复读 5 次 4306~4315） | 255 |
| 6 号夹爪（6kg） | 0 | 1 |

- 2 号肩（扛整条臂）和 5 号腕旋（几乎不受力）读数一样；5 号扭矩关掉 1s，0x2E 4330 不变 → 不是电流。读数随供电电压：4.9V ≈3150、6.8V ≈4310（约 635 / V）。
- 0x3F 恒 255（夹爪 1）→ 无温度数据。规格书（DS-SY15A）也没写电流检测 / 温度传感器；协议是厂家通用版，很多项标「？」。
- 有效的健康信息只有应答状态位：b5 过载（堵转保护）、b2 温度异常、b0 电压异常。
- 处理：界面机械臂页去掉电流 / 温度两列（用户定「直接去掉」），轮询不再读这两个地址（每轮少 12 次读、每次 20ms 静默）；夹取判断本来只看夹爪停的位置，去掉了没用的 0x2E 读；`des_tool arm scan` 打印原始值并注明。

## 料盒示教

用户扭矩开、界面微调到料盒（第一个，桌面上、底座下游 13.5cm、带边外 5cm），先在盒底上方 13.7cm，建议降到夹爪最低处高出盒口 1~2cm（程序放料不进盒，掉太高齿轮会弹）。`des_tool arm teach`：counts 3424 2976 2446 2746 853、q = [113.2, 9.0, −38.0, −62.7, 89.8]、夹爪竖直朝下（俯仰 −91.7°）、夹爪尖比带面低 57mm（台面 574.9, 200.3）。→ `des_app.json` `arm.bins_deg` 只留这一个、`bins` = ["gear_box"]（良品 gear_ok → gear_box；占位的第二个 rack_box 去掉，它按正解会落在底座后方、比纸箱顶低约 10cm）。

## 放料过渡（over bin / rise）

按标定参数（calib.json arm 段）逐点算「抬起 → 直接转到料盒」的关节插值：夹着的齿轮在离侧框约 2cm（台面 y≈172~176）时比带面低 47~53mm（抓取点 y −10~+60、两种合拢方向都一样），料盒 → 初始姿态同样低约 45mm → 会擦侧框。

改为：料盒姿态低于 `z_safe`（带面 +30）时，`plan_pick` 加「over bin」（料盒姿态抬到 z_safe：底座转角 / 腕旋 / 夹爪俯仰不变，`arm_raise` 平面两连杆重解）与「rise」（松开后回到 over bin）。新路径：皮带 / 侧框上方夹着的齿轮始终高于带面 27mm；over bin → 料盒竖直下降，水平漂移 ≤7.6mm。抬不到 z_safe 的料盒直接拒绝。`test_scheduler` 369 项（+11：步骤名、over bin 在料盒正上方 / 高度 / 转角腕旋不变、摆动段不低于行程高度 15mm 而旧直插低 30mm 以上、arm_raise 往返、料盒高于行程不加步、抬不到则拒绝）。
