# 2026-10-26 料盒示教、放料过渡、舵机电流 / 温度

## 舵机电流 / 温度：这批舵机不提供

协议 v4.01 写 0x2E = 当前电流（mA）、0x3F = 当前温度（℃），界面一直读到 ~4300 / 255。6.8V、扭矩开、臂在料盒姿态实测：

| 舵机 | 0x2E | 0x3F |
|---|---|---|
| 1、2、4、5 号（15kg） | 4300~4334 | 255 |
| 3 号 | 1996（一次，复读 5 次 4306~4315） | 255 |
| 6 号夹爪（6kg） | 0 | 1 |

- 2 号肩（扛整条臂）和 5 号腕旋（几乎不受力）读数一样；5 号扭矩关掉 1s，0x2E 4330 不变 → 不是电流。读数随供电电压：4.9V ≈3150、6.8V ≈4310（约 635 / V）。
- 0x3F 恒 255（夹爪 1）→ 无温度数据。规格书（DS-SY15A）也没写电流检测 / 温度传感器；协议是厂家通用版，很多项标「？」。
- 有效的健康信息只有应答状态位：b5 过载（堵转保护）、b2 温度异常、b0 电压异常。
- 处理：界面机械臂页去掉电流 / 温度两列（用户定「直接去掉」），轮询不再读这两个地址（每轮少 12 次读、每次 20ms 静默）；夹取判断本来只看夹爪停的位置，去掉了没用的 0x2E 读；`des_tool arm scan` 打印原始值并注明。

## 放料过渡（over bin / rise）

按标定参数（calib.json arm 段）逐点算「抬起 → 直接转到料盒」的关节插值：夹着的齿轮在离侧框约 2cm（台面 y≈172~176）时比带面低 47~53mm（抓取点 y −10~+60、两种合拢方向都一样），料盒 → 初始姿态同样低约 45mm → 会擦侧框。

改为：料盒姿态低于 `z_safe`（带面 +30）时，`plan_pick` 加「over bin」（料盒姿态抬到 z_safe：底座转角 / 腕旋 / 夹爪俯仰不变，`arm_raise` 平面两连杆重解）与「rise」（松开后回到 over bin）。新路径：皮带 / 侧框上方夹着的齿轮始终高于带面 27mm；over bin → 料盒竖直下降，水平漂移 ≤7.6mm。抬不到 z_safe 的料盒直接拒绝。`test_scheduler` 369 项（+11：步骤名、over bin 在料盒正上方 / 高度 / 转角腕旋不变、摆动段不低于行程高度 15mm 而旧直插低 30mm 以上、arm_raise 往返、料盒高于行程不加步、抬不到则拒绝）。

板上空跑 `des_tool arm pick 438 10`：above → descend → close → lift → over bin（3424 2794 2045 3322 854，968ms）→ to bin（= 示教读数 ±1）→ release → rise → home。部署：des_app `ee9fe4d7`、des_app.json `1626d4ee`、/root/bin/des_tool `640015c2`（变基到 d0e9972 后重编）、test_scheduler `c251d23d`（旧版 .prev），板上 test_scheduler 369 过，界面截图核对机械臂页。

## 照片核对障碍物 + 路径间隙（用户顶部 / 侧面照）

障碍物：黑色底板伸进皮带上方约 7~8cm（比带面高约 5cm）；纸箱下游侧面紧贴料盒姿态的夹爪；6 号舵机在料盒姿态时就在带尾辊端上方；黄色复检箱、皮带 / 侧框。按照片（A4 纸定比例 1.98 px/mm，按高度修正）建模、夹爪按手指 / 6 号舵机 / 本体三个盒子，逐点算「现在的路径（含 over bin）」和「再加特殊点（抬起后先径向外移到料盒半径、等半径转过去、竖直下降分 3 段、等半径转回再回初始）」的最小间隙（脚本 scratchpad clearance_sim.py，不入库）：

- 两种路径的最紧处一样，都在**示教姿态本身**：料盒姿态（夹爪内侧手指 ↔ 纸箱下游面、6 号舵机 ↔ 带边 / 辊端）和初始姿态（手指 ↔ 黑色底板边）；中间的转动、升降都不比这两个点更近 → 除 over bin / rise 外**不需要再加特殊点**，竖直下降的 ≤7.6mm 偏移也没有朝障碍物方向超过终点。
- 照片误差约 ±10mm，模型按示教姿态算出负间隙（实物能摆进去）→ 模型偏保守；只能说明余量很小（估计 0~10mm）。
- 建议：料盒点离纸箱面和带边再各让出约 2cm（重教到料盒中间）；用户用尺量三处间隙（料盒姿态：夹爪 ↔ 纸箱面、6 号舵机 ↔ 带尾辊；初始姿态：手指 ↔ 黑色底板边），<1cm 就重教；然后不夹件慢速演练一遍。

## 夹爪转角 / 开口的避让核对

- 腕旋（6 号舵机朝向）：IK 默认让 6 号舵机朝底座半边，离轴 <120mm 时换另一侧（防撞转台，10-21）。舵机最低点在指尖上方约 70mm → 抓取高度时舵机底在带面 +73，高于黑色底板 / 纸箱顶（+53~60）→ 转到任何角度都从上方过；转向料盒时更高；料盒处竖直下降时腕不转。
- 开口：抓取 / 放料用零件开口（外径 + 2×4mm），离障碍最近的是初始姿态（两指径向、内指朝黑色底板边，用户示教时 40mm 能放进去）。原来抓取回初始姿态用零件开口（大齿轮更大）、`des_tool arm home` 全开 61mm（内指多伸 ~10mm）→ 可能顶到底板边。→ 回初始姿态一律用示教开口（home_grip_count），goto 不改开口；test_scheduler 379。部署 des_app `b683f465`、des_tool `563d9355`，板上空跑 home / pick 的 home 帧夹爪都是 2008。
