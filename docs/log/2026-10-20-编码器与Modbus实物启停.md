# 2026-10-20 计米轮编码器准备 / Modbus 实物启停 / ZQWL USB-CAN 后端

## 1. ZQWL USB-CAN 串口后端（10-19 深夜，`d188aff`）

- 适配器 = USB CDC 虚拟串口（COM9，VID 0x3562 / PID 0x0103），Windows 自带 usbser，不用驱动 / DLL。按厂家协议 V1.05 写 `pc/plc_sim/zqwl.py`（配置 / 数据 / 心跳帧）。
- 实物：`UCAN-101E` / 固件 `V2.7`；500k 打开 CAN0，心跳 1Hz、总线正常；无其他节点时发一帧 → 被动错误（帧上了总线但没人应答）。
- ⚠ 单节点发帧后，心跳里文档标「CAN0 接收错误计数」的字节 = 135、「发送错误计数」= 0；按 CAN 规则没人应答时涨的应是发送错误计数 → 文档 D10 / D11 可能写反，双节点时核对。

## 3. Modbus-TCP 实物启停（皮带真走）

`pc/modbus/mb_run_test.py`（电脑经网线，v12，des_app run 自启）+ 板上每 0.2s 读步进位置：

- 带速 0 / 配方 99 / 空闲时恢复 → BAD_VALUE / BAD_VALUE / REJECTED ✓；带速 50 → 启动 OK，1s 后 RUN、皮带在动；运行中换配方 2 → REJECTED ✓。
- 运行中带速 50 → 30 → 80 → OK；板上报 50.0 / 30.0 / 80.0，**步进位置独立换算 50.5 / 30.0 / 79~81 mm/s**（采样窗 ~1.2s，抖动来自 ssh 读取时刻）。暂停（联锁）→ 恢复 → 停止 → PAUSED 2s 内皮带停 / RUN / IDLE 2s 内停 ✓。
- 写入 → 板上执行确认（SEQ 变化）**14~24ms**（含 10ms 轮询间隔）；全程皮带走约 970mm。PLC 在线标志在脚本停顿 4s 不发请求时掉线 = 设计如此（1s 无请求即判离线，真 PLC 持续轮询）。

## 4. 计米轮编码器：接线结论与标定工具

- 实物 E6B2-CWZ6C 1000 P/R，标签 5~24V；线色 棕 V+ / 蓝 0V / 黑 A / 白 B / 橙 Z / 屏蔽 GND。**棕 → 5V 母排（不接 24V）**、蓝 → PL 地、黑 / 白 / 橙 → CEP PIN6 / 7 / 8、屏蔽 → PL 地（只在板子这头）；理由与接法见 [硬件与接线](../硬件与接线.md)，接前按联调清单 3.5 用万用表确认输出级。
- 未接时 `desreg io`：A1 B1 Z1（内部上拉）、计数 0、err 0。
- **`des_tool calib-enc`**（`measure/calib.cpp`）：空皮带往返 300mm × `-n` 轮、每 10ms 采样 → mm/计数、方向、轮周长、往返误差、加减速滞后、匀速段带速 ± 标准差、Z 数、非法跳变数 → `calib.json` 的 `encoder` 段。`test_calib` +11 项，板上 63 项全过。
- 无编码器实跑：往返 300mm 后报「the encoder did not count (0 counts, ~6000 expected)」，不写文件 ✓。

## 4b. 编码器接上板（经 BSS138）

- 万用表：5V 供电、黑线对 0V 转动时约 1.5V → 输出被拉到 5V（不是纯开集电极）→ 不直连，经 BSS138 模块（HV2 / HV3 / HV4 ↔ LV2 / LV3 / LV4）接 CEP PIN6 / 7 / 8，屏蔽线暂未接。
- 接好后 `desreg io`：A1 B0；误触累计 −4544 计数、Z 1、err 0 → 清零 → 手滚一圈（皮带前进方向）：**−3944、Z 2、err 0**；两次 Z 位置（换算同一零点）861 与 −3139 相差 **4000 计数** = 1000 线 × 4，一圈不丢数；停点比记号少约 56 计数（≈5°）。**皮带前进方向计数减小**（calib-enc 会写 dir）。

## 4c. 曝光、重标定、三齿轮视差扫描（30 齿：卡尺外径 32、厚 10、孔 6）

- **曝光**：3000µs 时白齿轮顶面 86% 像素 = 255、外径被光晕撑大（中心件 32.67）；800µs 顶面约 190、皮带约 30、无频闪横纹 → `camera.exposure_us` 800；侧壁 800µs 下灰度约 80~100（顶面 ~165~190，阈值 ~110）。
- **相机重新标定**（10-18 后相机被碰过：旧标定下三件不校正外径上 32.9 / 中 33.6 / 下 35.6，上下不对称 = 单应失效）：rms 0.247mm、0.1813mm/px、视野 x 0~348、y 约 ±95；倾斜沿带 3.4°（旧 7.0°）、横向 0.6°（旧 3.4°）。旧文件备份 `data/par_1020/calib.json.before`。
- **扫描**：三件横跨皮带一列（y ≈ +71 / −5 / −75），每次走 2411 步（按旧步距 = 50mm），8 站，每站 1 帧 × 8 种模型（脚本 `/root/par_sweep.sh`，原图 `data/par_1020/sweep/`）。不校正外径（H=0）随离画面中心距离 d 增大：d≈5 → 32.58、≈50 → 32.8~33.0、≈75 → 33.2、≈100 → 34.4~35.2、≈150 → 37.6（侧壁 / 扫掠进轮廓，斜率 0.02~0.03/mm）。校正后画面中列（x≈178）三件：侧壁亮/H280 = 31.36 / 31.42 / 30.89，侧壁暗/H280 = 31.97 / 31.42 / 32.02 → **尺寸只在画面中心附近可信**；中心件与卡尺的差受边缘模糊 + 阈值影响 → 要「标准件」偏置标定。
- **位置**：每 50mm（旧步距）齿轮在台面坐标走 51.0~52.1mm、均 51.5（+3%）。若步距仍对，3% ≈ 只看顶面视差放大（H280：1.036）而非侧壁亮模型（1.018）；但 0.02074 是旧标定下纸片测的 → ⬜ 新标定下重跑 `calib-belt` 把两者分开，再定 `walls_visible`（定位用）与 H。
- **新标定下重跑 calib-belt**（50mm 白纸方片）：**0.020997mm/步**（旧 0.02074，+1.2%；有效辊径 21.39mm），往返误差 +0.92mm（224mm 往返，换向回差），横向漂移 +0.43mm/100mm（相机 x 轴与皮带基本平行）。
- **由此定视差模型**：每站真实带移 2411 × 0.020997 = 50.62mm，中列齿轮质心走 51.54mm → 质心放大 **1.018**；侧壁亮模型 (2H−h)/(2(H−h)) = 1.018 → **H ≈ 285mm**（只顶面模型要 H ≈ 560，不可能）→ **`walls_visible` = true 正确，H 用尺量 280 即可**（该法对步距误差敏感，±0.2% 步距 ≈ ±30mm H）。
- **标准件偏置**：做记号的 30 齿，卡尺三向 31.98 / 31.95 / 31.96（均 31.963）；放画面正中（166, −4）测 20 次：外径 31.555（σ 0.0042、极差 0.015）、齿根 27.451（理论 27.5）、孔 6.074、偏心 0.366 → 只有齿尖偏小 → 新增 `measure.od_offset_mm` / `bore_offset_mm`（test_measure +1，板上 66 过），`od_offset_mm` = 0.41 → 复测 10 次 31.961（σ 0.008）。
