## 1. ZQWL USB-CAN 串口后端（10-19 深夜，`d188aff`）

- 适配器 = USB CDC 虚拟串口（COM9，VID 0x3562 PID 0x0103 = 1 通道 CAN），Windows 自带 usbser，不用驱动 / DLL。按厂家《ZQWL-USBCANFD 二次开发通讯协议 V1.05》写 `pc/plc_sim/zqwl.py`（配置帧 `49 3B … 45 2E`、数据帧 `5A … A5`、心跳 `5A FF … A5`）。
- 实物：读出 `UCAN-101E` / 固件 `V2.7`；500k 打开 CAN0，心跳 1Hz、总线正常；无其他节点时发一帧 → 被动错误（帧被适配器接受并发上总线，没人应答）。
- ⚠ 单节点发帧后，心跳里文档标「CAN0 接收错误计数」的字节 = 135、「发送错误计数」= 0；按 CAN 规则没人应答时涨的应是发送错误计数 → 文档 D10 / D11 可能写反，双节点时核对。重新打开通道清零。
- `plc_gui.py --backend zqwl` 直接用它，「总线统计」末行显示适配器心跳。

## 4. 计米轮编码器到货：接线结论 + 标定工具

- 实物 E6B2-CWZ6C 1000 P/R，标签 5~24V；棕 V+、蓝 0V、黑 A、白 B、橙 Z、屏蔽 GND。
- 接线：**棕 → 5V 母排（不接 24V）**、蓝 → PL 地、黑 → CEP PIN6、白 → PIN7、橙 → PIN8、屏蔽 → PL 地（只在板子这头）。理由：NPN 开集电极本应与电源电压无关，但若是内部带上拉的仿品，输出就是电源电压，24V 会直接烧 3.3V 管脚 → 接信号前先用万用表确认（[到货联调清单](../到货联调清单.md) 3.5）。
- 板上未接时 `desreg io`：A1 B1 Z1（内部上拉）、计数 0、err 0。
- **`des_tool calib-enc`**（`ps/src/app/tool_main.cpp`，计算在 `measure/calib.cpp` `enc_from_samples`）：空皮带往返 300mm × `-n` 轮，每 10ms 采样 → mm/计数、方向、轮周长、往返误差、加减速滞后、匀速段实测带速 ± 标准差、Z 数、非法跳变数 → `calib.json` 的 `encoder` 段（`calib-cam` 重跑时保留）。`test_calib` +11 项（合成：0.0505mm/计数、方向反、0.3mm 加速滞后、0.1mm 蠕动；不计数必须报错；文件合并），板上 63 项全过。
- 无编码器实跑：皮带往返 300mm 后报「the encoder did not count (0 counts, ~6000 expected)」，不写文件 ✓。

## 4b. 编码器接上板子（经 BSS138）

- 万用表：5V 供电、黑线对 0V 转动时约 1.5V → 输出被拉到 5V（不是纯开集电极）→ 不直连，黑 / 白 / 橙 → 舵机总线那块 BSS138 模块的 HV2 / HV3 / HV4，LV2 / LV3 / LV4 → CEP PIN6 / 7 / 8（模块电源已有：HV 5V、LV 3.3V）；屏蔽线暂未接。
- `desreg io`：接好后 A1 B0（B 被编码器拉低 → 通路通）；误触累计 −4544 计数、Z 1 次、err 0 → 清零 → 手滚一圈（皮带前进方向）：**−3944、Z 2、err 0**。两次 Z 脉冲的位置（换算到同一零点）861 与 −3139 **正好相差 4000 计数** = 1000 线 × 4，一圈不丢数；手滚停点比记号少约 56 计数（≈5°）。**皮带前进方向计数减小**（calib-enc 会写 dir）。

## 4c. 曝光、重新标定、三齿轮视差扫描（30 齿：卡尺外径 32、厚 10、孔 6）

- **曝光**：3000µs 时白齿轮顶面 86% 像素 = 255、外径被光晕撑大（中心件 32.67）；800µs 顶面约 190、皮带约 30、无频闪横纹 → `camera.exposure_us` 800。侧壁在 800µs 下灰度约 80~100（顶面 ~165~190，阈值 ~110）。
- **相机重新标定**（10-18 后相机被碰过：旧标定下三件不校正外径上 32.9 / 中 33.6 / 下 35.6，上下不对称 = 单应失效）：rms 0.247mm、0.1813mm/px、视野 x 0~348、y 约 ±95；倾斜 沿带 3.4°（旧 7.0°）、横向 0.6°（旧 3.4°）。旧文件备份 `data/par_1020/calib.json.before`。
- **扫描**：三件排成横跨皮带的一列（y ≈ +71 / −5 / −75），每次走 2411 步（按 0.02074mm/步 = 50mm），8 站，每站 1 帧 × 8 种模型（`/root/par_sweep.sh`，原图 `data/par_1020/sweep/`）。不校正外径（H=0）随离画面中心距离 d 增大：d≈5 → 32.58、≈50 → 32.8~33.0、≈75 → 33.2、≈100 → 34.4~35.2、≈150 → 37.6（侧壁 / 扫掠进了轮廓，增长斜率 0.02~0.03/mm，介于「只顶面」与「全扫掠」之间）；离中心远的件齿数判成 28~34（按设计不判齿）。各模型校正后在画面中列（x≈178）三件：侧壁亮/H280 = 31.36 / 31.42 / 30.89，侧壁暗/H280 = 31.97 / 31.42 / 32.02 → **尺寸只在画面中心附近可信**；中心件绝对值（校正 31.4、不校正 32.6 vs 卡尺 32.0）受边缘模糊 + 阈值影响 → 要「标准件」偏置标定。
- **位置**：每 50mm（按旧步距）齿轮在台面坐标里走 51.0~52.1mm，均 51.5（+3%）。若步距仍对，3% ≈ 只看顶面的视差放大（H280：1.036），而不是侧壁亮模型（1.018）；但 0.02074mm/步是旧相机标定下用纸片测的 → ⬜ 新标定下重跑 `calib-belt`（白纸片）把两者分开，再定 `walls_visible`（定位用）与 H。
- **新标定下重跑 calib-belt**（50mm 白纸方片）：**0.020997mm/步**（旧 0.02074，+1.2%；有效辊径 21.39mm），往返误差 +0.92mm（224mm 往返，换向回差），横向漂移 +0.43mm/100mm（相机 x 轴与皮带基本平行）。纸片 locate 尺寸 51.7 × 50.7（1/4 降采样定位的粗尺寸，不作比例核对）。
- **由此定视差模型**：每站真实带移 2411 × 0.020997 = 50.62mm，中列齿轮质心走 51.54mm → 质心放大 **1.018**。侧壁亮模型 (2H−h)/(2(H−h)) = 1.018 → **H ≈ 285mm**（只顶面模型要 H ≈ 560，不可能）→ **`walls_visible` = true 正确，H 用尺量 280 即可**（该法对步距误差敏感，±0.2% 步距 ≈ ±30mm H）。
