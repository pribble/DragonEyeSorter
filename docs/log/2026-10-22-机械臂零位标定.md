# 2026-10-22 机械臂零位与计数比例标定（扭矩关、手摆）

> 6.8V 未到，舵机由 5V 模块（4.9V）供电：总线通信正常、不出力。扭矩关，用户手摆姿势、垫书支撑，`des_tool.sh arm read` 读计数；后几个姿势用手机水平仪对准水平 / 竖直。机械臂临时放在纸箱上（未定位）。

## 结论（已写 `ps/src/des_app.json` 的 `arm.joints` 并部署）

| 关节 | 零位（计数） | 计数 / 度 | 依据 |
|---|---|---|---|
| #1 底座 | 2012（小臂垂直指向皮带 = q1 0） | **+12.47** | 平行带边指向上游 890（俯视顺时针 90°，计数减） |
| #2 大臂 | 3085（水平 = q2 0） | **−12.14** | 竖直 1992（水平仪对准两端） |
| #3 小臂 | 1977（伸直，三次 1966 / 1980 / 1986 平均） | **−12.33** | 大臂竖直、小臂水平（水平仪）3097 |
| #4 手腕 | 1986（伸直，三次 1976 / 1987 / 1995 平均） | **−12.13** | 夹爪竖直朝下（水平仪）3078 |
| #5 腕旋 | 1985（两指切向合拢、6 号舵机朝底座 = q5 0） | **−12.6** | 俯视逆时针 90° 到 851 = 径向合拢、舵机指向上游 |

- **计数比例不是 13.65**：原配置按 4096 / 300° 写。规格书是「计数 96~4000 = 300° ± 10°」（约 13.0），实测各舵机 12.1~12.6（相差约 2%，属个体差异）。按 13.65 算会差 8~10%，抓取点偏几毫米。
- **#5 / 夹爪方向**：`grip_axis_at_zero_deg` 90、`servo_side_deg` 90（原值即 90，符号确认）。用户口述「顺时针」与照片、「舵机在右手边（= 上游）」矛盾，按后两者定为逆时针。
- **底座方向**：机械臂在画面下侧 = 台面 +y（`px_to_table` 的 y 随图像行号增大）→ q1 = 0（指向皮带）= 台面 −y → `base_yaw_deg` −90；`base_xy` = [453, 150]（抓取线 = 视野下游边 373 + 80；离中线 150）、`belt_z` −30（平台比带面高 30）是安装前估计，⬜ 装好后 `calib-arm` 手眼标定覆盖。旧配置 `base_xy` y = −170 / yaw 90 是「右侧 = −y」的假设，作废。
- **#2 软限位**：计数 96 端约 −75°，min 改 −70；其余 ±145 都在舵机行程内（#1 −154~+159、#3 −164~+153、#4 −166~+156、#5 −160~+150）。
- 校验：部署后同一姿势读回 q1..q5 = −90.0 / 90.9 / −90.8 / −90.2 / 90.1（夹爪朝下 a3 = −90.1），正运动学指尖 = 底座往上游 81mm + 手指偏置 9mm，一致。

## 夹爪（#6）

扭矩关手掰：全合（指尖贴合）**2919**、夹住 32mm 齿轮 **2318**（松手略回弹）、全开 **1195**（卡尺量指尖 61mm）。连杆非线性很大：按开合两点画直线，2318 只相当于 21mm；按直线去「夹 32mm 齿轮」会把夹爪停在实际约 38mm，碰不到齿轮。→ 新增 `arm.grip_table`（[[2919, 0], [2318, 32], [1195, 61]]，分段线性；`grip_count` / `grip_mm` / `grip_counts_per_mm`），夹住判定用当地斜率（30mm 附近 18.8 计数 / mm）；`grip_max_open` 61。`test_scheduler` 253 项过（+4）。部署后夹着齿轮读回 32.0mm。⬜ 6.8V 后实测夹持电流与「堵转 3s 保护」：`grip_squeeze` 2mm ≈ 38 计数，若搬运途中保护松爪就减小。

## 安装高度

用户量：黑色底板底面 → 2 号（肩）水平转轴中心 **106mm**（厂家标 107.5）→ `base_h` 106。目标肩轴比带面高约 138mm（可达范围表「底座板比带面高 30」那行）→ **平台顶面（黑板底面）离桌面 144mm**（带面 112 + 32，±10 都行），`belt_z` −32。按此算竖直夹取最远 163mm（抓取高 3 / 安全高 60 都一样）；底座轴离中线 **140~145mm**（带边往里 5~10mm）时，零件在中线 ±10mm、抓取线前后 ±20mm 所需半径 130~156，留 7~12mm 余量；零件偏到 ±40mm 要倾斜下探（最远约 186）。黑板伸到皮带上方的部分离带面 32mm，10mm 厚齿轮能过。

## 夹爪长度（手眼标定第 1 点发现）

第 1 点：齿轮 (250, 1.6) 送 100mm 到 (350, 1.6)，用户指尖贴齿轮顶面（照片确认），读数 q −32.2 / 30.7 / −32.4 / −85.9。按旧工具长（#4 轴 → 指尖 106mm，l_tool 27）正运动学指尖高出 83mm，水平只差 1cm。用户按照片确认 **#4 转轴 = 小臂末端下沿**（不是竖支架上的螺丝），复量到指尖末端约 **190mm** → `l_tool` 111（与角度反推 189 一致）；同一姿势读回指尖在带面上 9.1mm（齿轮顶面 10.05）。10-20 的 106mm 是从夹爪座量起的。

工具变长后安全高度处够不远：`z_safe` 60 时竖直最远 138mm → 改 **40**（齿轮顶面上 30mm 走行），最远 150mm（抓取高度 162）；平台再高 30mm 两者都会更好。该点作废，标定重跑。

## 发现

- 姿势 B（夹爪离底座轴约 83mm）时 6 号舵机朝底座一侧会撞转台 → `arm_ik` 加「近底座舵机不朝底座」（`a832beb`，见 [运动控制与分拣](../运动控制与分拣.md)）。
- 机械臂侧灯条最近点离中线约 21cm（带边外 6cm）、左端在抓取线上游约 8cm、高于带面 45~85mm → 手臂伸向皮带时碰不到；料盒放下游 / 外侧。
