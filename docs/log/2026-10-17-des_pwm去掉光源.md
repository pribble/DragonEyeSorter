# 2026-10-17 des_pwm 去掉光源输出（光源改人工手动，PL v10，未上板）

光源只能人工手动开关 / 调光，不接 PL → `des_pwm` 由「2 路翻板 PWM + 光源开关」改为纯 2 路 PWM，删 `CTRL` b8、`lamp` 端口、管脚 `LAMP_EN`（PIN17 Y7）与 MOSFET 支路；光源本身保留，改由人手设定。

## 改动

| 层 | 文件 | 改动 |
|---|---|---|
| PL RTL | `pl/soc_base/src/des/des_pwm.v`、`src/system_top.v`、`src/constraint/io.adc` | 删 `lamp` 端口与 `lamp_r`；`CTRL` 只取 `[NCH-1:0]`（b8 无含义）、读回不返 b8；`system_top` 删 `LAMP_EN` 端口与连接、`VERSION` 9 → **10**；`io.adc` 删 PIN17 = Y7 约束 |
| PS | `ps/src/hw/des_hw.h` / `des_hw.c`、`des_regs.h`、`runner.cpp`、`ps/tools/desreg.c` | `des_pwm_enable(h, ch_mask)` 去 `lamp` 参数；`DES_PWM_CTRL` 注释改 `[1:0]`；runner 两处调用改单参数（both flaps + light → both flaps）；`desreg` 删 `lamp on\|off`，`pwm` 不读 / 写 b8 |
| 脚本 | `scripts/deploy/out/pl_check.sh` | PWM 段去掉 `lamp on/off`；使能读回掩码 `0x103` → `0x3` |
| 文档 / 插图 | `docs/PL设计.md`、`docs/硬件与接线.md`、`docs/到货联调清单.md`、`docs/技术文档.md`、`docs/系统概述.md`、两个 README、`docs/figures/make_*.py` | 去光源字样与 `CTRL` 表 b8；硬件与接线删 PIN17 行（空闲 11 → **12 根**）、新增「光源（手动）」节、供电树改「12V 适配器 → 光源（手动）」；联调清单删 6.4；插图重跑 `fig_architecture` / `fig_pl_regs` / `fig_system_wiring` |

## 验证

- 全部 PL 仿真（WSL iverilog，`bash pl/sim/run_sim.sh <t>`）：`des_axi` / `servo_bus` / `stepper` / `pwm` / `vision` / `vision2` / `awb` **7 项全过**（`pwm` 11 passed / 0 failed、`vision` 与 `vision2` 各 790 / 0、`awb` 5 / 0）。
- PS 交叉编译（FD 2026.1 SP1，`-Wall -Wextra`）：`make -C ps build/desreg`、`build/des_app` 0 错误 0 警告（自研代码；厂家 `src/vision/*.cpp` 既有 warning 未变）。
- `tb_des_pwm.v` 新增断言：向 `CTRL` 写 `0x103`（旧「两通道 + 灯」写法）后读回必须 `0x0003`——证明 b8 已被忽略、老写法不会静默改变行为，也防止以后加回该位而不改测试；检查项仍 11。

## 未做 / 注意（⚠）

- **未重编比特流、未上板**：板上仍是 v9（`des_pwm` 还带 lamp 位）；`VERSION = 10` 只在仓库源码，等下次重编 → 打 `BOOT.bin` → 换卡生效，之后跑 `pl_check.sh`。
- `desreg lamp` 已删，在 v9 板上暂时没法用它点灯；`desreg pwm` 不受影响（v9 的 b8 默认 0，`pl_check.sh` 也不再查）。
- 只删 **PL 控制的光源输出**（寄存器位 + 管脚 + MOSFET 支路），**光源本身保留**、改人工手动开关 / 调光（「档位一次定好」，见 [硬件与接线](../硬件与接线.md)「光源（手动）」）。以后要做曝光同步频闪，需重新占管脚、加回寄存器位并升 `VERSION`。
