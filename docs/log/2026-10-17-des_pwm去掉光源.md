# 2026-10-17 des_pwm 去掉光源输出（光源改人工手动，PL v10，未上板）

## 背景

光源是有的，但**只能人工手动开关 / 调光**，不接 PL。因此把 PL 侧的光源控制整条去掉——`des_pwm` 原来是「2 路翻板 PWM + 光源开关」，现删掉 `CTRL` b8、`lamp` 端口、管脚 `LAMP_EN`（PIN17 Y7）与 MOSFET 支路；光源本身保留，改由人手设定。

`tb_des_pwm.v` 这次**新增一项**断言：向 `CTRL` 写 `0x103`（旧脚本里「两通道 + 灯」的写法）后读回必须是 `0x0003` —— 既证明 b8 已被忽略、老写法不会静默改变行为，也防止以后有人把这一位加回来而不改测试。检查项总数仍是 11。

## 未做 / 注意（⚠）

- **未重编比特流、未上板**：板上现在跑的仍是 v9，其 `des_pwm` 还带 lamp 位（`CTRL` b8）。`VERSION = 10` 只存在于仓库源码；等下次重编 → 打 `BOOT.bin` → 换卡才生效，之后按流程跑 `pl_check.sh`。
- 因为 `desreg lamp` 已删，在 v9 板上暂时没法用它点灯；翻板 `desreg pwm` 不受影响（v9 的 b8 默认 0，`pl_check.sh` 也不再查它）。
- 本次只删**PL 控制的光源输出**（寄存器位 + 管脚 + MOSFET 支路）。**光源本身保留**，改为人工手动开关 / 调光：`docs/硬件与接线.md` 新增「光源（手动）」一节（含"档位一次定好"），供电树保留 12V 适配器支路、去掉 MOSFET 栅极；`docs/到货联调清单.md` §4.1、`docs/视觉与检测.md` 数据集一节、`docs/技术文档.md` 硬件表都注明"手动档位全程不变"；`docs/参赛材料骨架.md` R8「短曝光 + 高亮光源」的缓解措施随之成立（手动把灯调到够亮）。
- 若以后要做曝光同步频闪（卷帘快门那条风险的进一步缓解），要重新占一个管脚、加回寄存器位并升 `VERSION`——见 `docs/硬件与接线.md`「光源（手动）」。
- PIN17 / Y7 已释放为普通 IO，`docs/硬件与接线.md` 的 IO 表已把它计入空闲。
