# 2026-10-18 取消齿条、改多规格齿轮；倾斜下探

## 决定（用户确认）

- **取消齿条，改多规格 / 浅色多色 POM 齿轮**：齿条难锯、又厚又宽，只能沿一个方向夹（倾斜下探对它基本无用）；齿轮圆对称、任意角度可夹。实物数据集尚未开采，换物料代价最小；齿条测量代码闲置不删。
- 判定分工：NPU 只学缺陷 4 类（良品类覆盖全部规格颜色）；规格靠测量（齿数 / 外径 / 孔径）；颜色靠色调。缺陷样本只做在白色 30 齿主力款上。
- 加买建议（采购内容在仓库外）：明显更小 / 更大一档齿数各一种 + 一种浅色；避开黑 / 深蓝 / 深绿 / 透明（皮带黑色哑光，灰度差太小）。

## 倾斜下探（`c995c4f`）

竖直夹取离底座轴最远约 150mm。允许夹爪朝外倾斜后，两指必须沿切向闭合（倾斜绕切向轴转，切向仍水平；径向会一高一低）：

- `arm_ik(..., tilt)`：腕轴 = 抓取点 − L·(sin t 径向, −cos t)，q4 = −90° + t − (q2 + q3)；非切向闭合（偏差 >10°）直接拒绝。
- `plan_pick`：先竖直，够不着且轴为切向时按 `tilt_step_deg`（5°）加到 `max_tilt_deg`（40°），取最小可达倾角；下探仍竖直。
- Picker：`tangential_first`（由 max_tilt_deg > 0 打开）→ 圆形件 12 个候选角从切向开始，邻件间隙检查照旧。
- 可达半径（底座板与带面齐平，l_tool 50 估算）：竖直 42~144，20° 90~192，30° 114~217，40° 133~240mm。
- `test_scheduler` +12 项 → 178 项，host（WSL g++）与板上 aarch64 全过；已部署。
