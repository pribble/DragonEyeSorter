# 2026-11-02 技术文档改楷体版式（标题四号 / 正文小四）

> 作者给定格式规格：标题楷体四号加粗 2 倍行距、正文楷体小四 1.5 倍行距、英文全部 Times New Roman、图片居中图注五号。本轮把 [submission/build/md2docx.py](../../submission/build/md2docx.py) 版式令牌整体换掉，`verify_report.py` 验收口径同步，重出 docx / PDF 并全项复检。内容源 [技术文档.md](../../submission/技术文档.md) 一字未动。

## 规格 → 落版口径（与作者确认过三处）

| 元素 | 规格 | 落版 |
|---|---|---|
| 章节标题（## / ### / ####） | 楷体四号加粗 2 倍行距 | 楷体 14pt 加粗、line 480 auto；段前段后维持 14/8、12/6、10/5；**一 / 二 / 三级同号**，层级靠编号与段距 |
| 作品名（# 唯一大标题） | 规格未提 | **维持黑体 17.5pt 居中**（作者选「仅章节标题」） |
| 元信息行 | 规格未提 | 维持 10pt 单倍；标签黑体、值改楷体 |
| 正文 | 楷体小四 1.5 倍 | 楷体 12pt、line 360 auto、首行缩进 2 字符 = 480 twips、两端对齐 |
| 英文 / 数字 | 全部 Times New Roman | 西文 ascii/hAnsi 本就是 Times，不变 |
| 行内代码 | 作者确认保留等宽 | Consolas 11pt（正文升小四后同步 +1pt，表格内仍降 9pt） |
| 图注 / 表注 | 五号 | 楷体加粗 10.5pt 居中，位置不变（图下 / 表上） |
| 表格 | 规格未提，作者选楷体 | 表头楷体加粗 9pt、表体楷体 9pt（维持 9pt 防宽表撑爆），三线表线条不变 |
| `**强调**` | 规格未提 | 中文黑体 → **楷体加粗**（与「加粗」口径一致；西文仍 Times Bold） |
| 参考文献列表 | 规格未提，按正文 | 12pt、1.5 倍、悬挂 1.5 字符 = 360 twips |
| 页脚 / 页眉 / 颜色 / 图宽 | 规格未提 | 全部维持（页脚 Times 11pt；页眉官方 logo；纯黑；图 15.8cm 居中） |

## 生成链改动

- `md2docx.py`：设计令牌区换 `FONT_CN = 楷体`、字号（正文 12 / 标题 14 / 图注 10.5 / 代码 11 / 列表 12）与行距（`BODY_LINE = 1.5`、`HEAD_LINE = 2.0`，倍数仍一律 lineRule=auto，不引入固定行距）；章节标题整段加粗（含标题内行内代码 / 强调片段）；`add_runs` 加 `cn` 覆盖参数——作品名走黑体默认、章节标题显式传楷体。
- **新踩的坑**：python-docx 默认模板带着 `word/stylesWithEffects.xml`（Word 2010 用的旧式样式副本），里面 docDefaults 是 Word 默认 `after=200 / line=276`——`setup_doc_defaults` 只改 styles.xml 够不到它；旧行距检查只扫 `<240` 所以从未暴露，本轮「倍数只允许 240/360/480」检查把它扫了出来。新增 `sync_effects_part()` 保存后原地重写该部件（line 276 → 240）。
- 自检同步：样式字体（H1/H2/H3 → 楷体加粗）、正文 480 twips / 360、标题 2 倍、图注 10.5、表格楷体 9pt、规格外倍数行距扫描；统计 JSON 增加 `font_cn / h3_pt / list_pt / code_pt / body_line / head_line`。
- `verify_report.py`：版式令牌与 PDF 侧同步（正文 12pt 楷体、标题层级 14pt 楷体加粗 + 行距 480、强调楷体加粗、图注 10.5、列表 12/360、倍数白名单 240/360/480）；PDF 字体族 `fam()` 增加 KaiTi/楷体 映射，「四族齐全」变为楷体 / 黑体 / Times / Consolas；三线表加中文字体（楷体）断言。表格断言只对含中文的 run 查 eastAsia——加粗纯数字 run（如 `**1783**` 小计行）经强调路径写入 eastAsia=Times，数字渲染走 ascii=Times，本就不受中文规格约束。

## 实测结果

- `build.ps1` 全链通过：**31 页 / docx 3.03MB / PDF 6.78MB（7,106,674 字节）**，段落 173、表 12、图 14、H1 6 / H2 14。页数 23 → 31（正文 11pt 单倍 → 12pt 1.5 倍，行密度降 ~40%）。
- `verify_report.py`：**65 项 63 PASS + 2 SKIP / 0 FAIL**；SKIP 与上轮相同（`--final` 占位门禁 6 张待照片、check_numbers.py 已归档）。
- PDF 字体：KaiTi、SimHei、TimesNewRomanPS(MT/-BoldMT)、Consolas、SegoeUISymbol（⚠ / 数学符号回退）五族全嵌入；中文全部命中楷体 / 黑体。
- 逐页留白最低 59.6%（p5，表 2 整表不可分割让位；p4/p10 底部留白为满版心块前的结构性留白，口径与上轮一致）。
- 人工看图（110dpi 渲染 p1/2/4/8/10/31）：标题块、章节标题加粗宽行距、正文楷体、三线表、图注居中、参考文献悬挂缩进均符合规格；visual-judge 子代理本轮供应商不可用，改为按渲染页逐页人工核对。
