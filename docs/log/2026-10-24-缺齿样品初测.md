# 2026-10-24 缺齿样品初测（缺一整个齿 / 缺半个齿）

用户做了两个 30 齿样品，并排放在视野上游侧：画面上侧（挡板侧）一个、下侧（机械臂侧）一个。板上 `des_tool.sh measure -n 5 --dump`，原图 / 标注图在板上 `/root/des/data/defect_1024/`（raw.png、report.png、report2.png）。

| 样品 | 台面位置 (x, y) | 离正下方点 | 视差拖影 | 程序结论（max_smear 0.8） |
|---|---|---|---|---|
| 缺一整个齿 | (161.6, +25.4) | ≈35mm | 1.22mm | 齿数 **29**（5/5 帧），齿形「不判」 |
| 缺半个齿 | (161.7, −31.3) | ≈39mm | 1.40mm | 齿数 30，齿形「不判」 |

- 两件都在画面中心上游约 24mm、横向 25~31mm → 拖影超过 `max_smear_mm` 0.8 → 缺料 / 缺齿 / 飞边按设计不判（只在离正下方点 ≲23mm 内判齿）。
- **缺一整个齿**：齿数按齿距数，离中心远也稳定数出 29（规格 30）→ 不靠齿形判断也能抓到。
- **缺半个齿**：原图极坐标展开（离线脚本，阈值取亮暗中值）：30 个齿里有 1 个齿尖比其余矮约 **0.7mm**（3.5px，齿高约 1.9mm），其余齿尖高度一致 → 当前灯光下**轮廓里看得见**，超过 `short_tooth_mm` 0.4 的判定门槛。
- 临时把 `max_smear_mm` 放到 2.0 在原位置再测（`/root/des/tmp_smear.json`）：缺齿 3~8、飞边 6~8，全是误报 → 离中心远时齿谷被侧壁拖影填平，0.8 的门槛是对的、不能放宽。生产时零件在离中心最近的那一帧测，横向靠导向条收在中线 ±10mm 内（拖影 ≤0.35mm）。
- ✅ **缺半个齿放到画面正中**（用户摆放，测得位置 (173.5, −3.8)，拖影 0.49 < 0.8 → 判齿）：`measure -n 10`，第 1 帧和第 10 帧都是 **齿数 30、缺料 1、缺齿 0、飞边 0**（10 帧齿数全为 30）；离线极坐标核对：只有一个齿尖矮 **0.74mm**（门槛 0.4），其余 29 个齿尖高度一致 → 程序报的就是这个齿。外径 31.72（σ 0.019）、孔 6.26：零件在中心上游约 12mm，且未登记卡尺值，不作尺寸结论。原图 / 标注图板上 `data/defect_1024/half_raw.png`、`half_report.png`。
- ✅ **缺一整个齿放到画面正中**（(170.5, +3.6)，拖影 0.57）：`measure -n 10`，第 1 / 10 帧 **规格齿数 30、缺齿 1、缺料 0、飞边 0**（10 帧齿数全为 30）；离线核对：29 个齿、一处齿间隔 24°（正常 12°）。规格齿数按齿距算，所以缺一个齿时仍报 30 + 缺齿 1；离中心远、齿形不判时数出来是 29——两种情况都会被当成不良。外径 31.63（σ 0.005），无卡尺值。
- **外径偏小**：缺半齿那件用户卡尺 **31.97**，正中附近（x 173.5）测得 31.72 → **−0.25**。先怀疑是零件在画面中心上游约 14mm（标准件偏置在 (190.9, 9.7) 定）→ 用缺整齿那件验证：皮带往下游走 956 步（读当前 pos −127318 → 目标 −128274，零件 x 170.5 → 190.3），同一件外径 **31.631 → 31.643（只差 +0.01）**、齿根 27.06 → 27.15、孔 6.35 → 5.89（孔径只在中心可信，已知），齿形结论不变（30 齿、缺齿 1）→ **沿带 20mm 以内的位置不是外径偏小的原因**（10-21 那次 35mm 时 −0.51，说明影响在 20~35mm 之间才明显）。⬜ 下一步：标准件（卡尺均 31.96）放 x≈190 复测——读回 31.96 说明系统没变、是这两件样品本身轮廓与卡尺读数不同（如锉 / 割时碰到齿尖、毛刺）；也偏小则说明 10-21 之后灯光 / 相机有变化，要重定偏置。
- **原因找到：用户动过光源**。缺整齿件卡尺 **31.98**，画面正中测 31.643 → −0.34（缺半齿件 −0.25）。同一件在画面正中的灰度：顶面 p50 179 / p95 185（10-21 定偏置时 173 / 184，基本没变），**皮带背景 p50 43（10-21 为 28）** → 背景变亮 → 零件 / 背景分割阈值上移约 7 级 → 模糊的窄齿尖更早掉到阈值以下 → 外径读小（齿根、孔是宽轮廓，影响小）。外径偏置 0.53 是 10-21 灯光下定的，灯一动就失效（视觉与检测「标准件偏置」早有「换灯光要重做」）。⬜ 灯光定死（贴胶带标位置）后：标准件 + 1 / 2 号 + 两件缺齿样品排在中线上、间隔 5cm，皮带每次往下游走 50mm 把下一件送到正中，各测 20 帧 → 重定 `od_offset_mm` / `bore_offset_mm`；再用白纸 `calib-flat` 重采平场。NPU 实物训练图也要在定死的灯光下采。
