# 2026-10-17 背面检测方案（翻面叉 → 单板翻转 + 落料台）

## 背景

相机只看得到零件朝上的一面，判完正面要检测背面，必须有翻面手段。VID005 子卡只有一路 MIPI 输入。

## 否决的方案

- **夹爪旋转（#5）翻面**：从上方夹取时零件正面朝着夹爪，#5 的轴垂直于零件表面，转多少度都只是在平面里打转；要翻面得绕水平轴转 180°，而从上往下夹的夹爪转过去后零件在上方、正面朝下，放不回皮带。
- **上视（底面）相机**：第二个相机要走 USB + 单独采集 / 标定，用户否决。

## 初版：U 形翻面叉（提交 `3dc8f30`）

机械臂旁固定一个「翻面叉」：两块平行板 + 叉底垫块组成 U 形叉，开口朝外，叉底装在一个**水平轴**的舵机舵盘上。

- 板间距 = 零件厚度 + 2~4mm（零件被两板和叉底兜住，不夹紧）；深度 > 最长零件（齿条 50mm → 约 60mm）；宽度够齿轮 Ø32。铝板 / 亚克力 + 垫块用螺丝固定在舵盘上。
- 转向：开口先朝上（转动全程重力把零件压在某一块板或叉底上，开口从不朝下）；转完 180° 开口朝侧面，零件背面朝上躺在另一块板上。约 0.5s。
- 舵机：**再加一个总线舵机，ID 设为 7**（厂家调试软件改 ID），串在现有舵机总线上 → PL 不用改，PS 多一条 SYNC / WRITE；负载只有几克，型号随意（同款最省事）。供电同机械臂舵机。
- 流程：机械臂把正面判 OK 的件放进叉口 → 叉子转 180° → 机械臂从叉口夹出（背面朝上）→ 放回皮带**相机视野内** → 皮带倒退一小段送到镜头下 → 检测背面 → 正常向前、按两面结果分拣。一次翻面约 2~3s（含机械臂往返）。
- 演示动画：对话中的 3D 交互图（U 形叉版，可转视角）。

## 改版：单板翻转 + 落料台（提交 `cb398df`）

用户指出 U 形叉的问题：翻完零件靠在叉底、上方还盖着一块板，**夹爪从上往下伸不进去**；放件时上板同样挡着。

改为：转轴（水平）两侧各一块同高的板，左边「翻板」由舵机带动，右边「落料台」固定。

- 尺寸：翻板、落料台各约 65×70mm（齿条 50mm、齿轮 Ø32 都放得下）；铝板 / 亚克力，翻板用螺丝固定在舵盘上，转轴与台面同高。
- 放件：机械臂从上方把零件放到翻板上（敞开）。
- 翻转：舵机把翻板往上翻（约 0.5s），零件滑向转轴并靠住；翻板过了竖直后零件顺势翻倒在落料台上，背面朝上。翻板转到约 120° 即可，不必 180°（否则会压到落料台上的零件），随后回 0°。
- 取件：落料台上方完全敞开；零件靠着转轴边，夹爪两指**顺着转轴方向**夹零件两侧（#5 腕旋对准）。落料台两侧的挡边离零件要留出手指宽度；远端可加挡块定位。
- 舵机：仍用 ID 7 总线舵机（同前）。
- 演示动画：对话中的 3D 交互图（改进版，可转视角）。

## 保留的结论

- 翻转舵机 ID 7 串在现有舵机总线上 → PL 不改，PS 多一条 SYNC / WRITE；供电同机械臂舵机。
- 一次翻面约 2~3s（含机械臂往返）；视频里拍「翻面 → 复检」一镜。
- 流程闭环：正面判 OK → 翻面（背面朝上）→ 放回相机视野内 → 皮带倒退到镜头下 → 检测背面 → 正常向前、按两面结果分拣。

## 未决（⬜）

1. 翻转机构装在哪（机械臂够得着、不挡皮带和相机）；
2. 机械臂能不能够到相机视野下游边缘放件（`pick_after_fov_mm` 现为 80mm）；
3. 皮带倒退时跟踪表要认出「同一件」（倒退期间暂停新件建轨、按件号锁定，或只在空线时做）；
4. 背面缺陷样本（缺陷只做在底面的件，按 `物料与缺陷样本.md`（仓库外）的轻 / 重各做几件）。
