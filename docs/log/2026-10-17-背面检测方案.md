# 2026-10-17 背面检测方案（U 形翻面叉 → 单板翻转 + 落料台）

相机只看得到零件朝上的一面；VID005 子卡只有一路 MIPI 输入，判完正面必须翻面检背面。

## 否决项

- **夹爪旋转（#5）翻面**：从上方夹取时 #5 轴垂直于零件表面，转多少度都只是在平面里打转；绕水平轴转 180° 后零件在上方、正面朝下，放不回皮带。
- **上视（底面）相机**：第二个相机要走 USB + 单独采集 / 标定，用户否决。

## 初版：U 形翻面叉（`3dc8f30`，已弃）

机械臂旁固定 U 形叉（两块平行板 + 叉底垫块），叉底装在水平轴舵机上：板间距 = 零件厚度 + 2~4mm（兜住、不夹紧），深约 60mm、宽够齿轮 Ø32。开口先朝上，转 180° 后开口朝侧、零件背面朝上躺在另一块板上，约 0.5s；翻面舵机 ID 7 串现有总线。

**弃用原因**：翻完零件靠在叉底、上方盖着一块板，**夹爪从上往下伸不进去**；放件时上板同样挡着。

## 改版：单板翻转 + 落料台（`cb398df`，采用）

转轴（水平）两侧各一块同高板：左「翻板」由舵机带动、右「落料台」固定；翻板 / 落料台各约 65×70mm（最长零件 50mm、齿轮 Ø32 都放得下），铝板 / 亚克力，转轴与台面同高。

- 放件：机械臂从上方放到翻板（敞开）→ 翻板上翻约 0.5s，零件滑向转轴并靠住；过竖直后零件翻倒在落料台、背面朝上。翻板到约 120° 即回 0°（180° 会压到落料台上的零件）。
- 取件：落料台上方敞开，夹爪两指**顺着转轴方向**夹零件两侧（#5 腕旋对准）；两侧挡边留出手指宽度，远端可加挡块定位。
- 舵机：仍用 ID 7（同前）。

## 保留的结论

- 翻转舵机 ID 7 串现有舵机总线 → PL 不改，PS 多一条 SYNC / WRITE；供电同机械臂舵机。
- 一次翻面约 2~3s（含机械臂往返）；视频里拍「翻面 → 复检」一镜。
- 流程闭环：正面判 OK → 翻面（背面朝上）→ 放回相机视野内 → 皮带倒退到镜头下 → 检测背面 → 正常向前、按两面结果分拣。

## 未决（⬜）

1. 翻转机构装在哪（机械臂够得着、不挡皮带和相机）；
2. 机械臂能不能够到相机视野下游边缘放件（`pick_after_fov_mm` 现为 80mm）；
3. 皮带倒退时跟踪表要认出「同一件」（倒退期间暂停新件建轨、按件号锁定，或只在空线时做）；
4. 背面缺陷样本（缺陷只做在底面的件，按仓库外 `物料与缺陷样本.md` 的轻 / 重各做几件）。
