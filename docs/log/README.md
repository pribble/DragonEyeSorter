# log 说明

按日期归档的**实测与验证记录**。每份记录是当日的数据快照，仅代表当时配置下的结果；设计文档吸收其定性结论，数字汇总进 [测试与验证](../测试与验证.md)，原始数据在此留痕备查。

**归属**：决策沿革、被推翻的方案、历史数据只写在本目录；设计文档、README 与地图只写当前结论（见 [文档索引](../README.md)「写作约定」）。

命名：`YYYY-MM-DD-主题.md`（文件名日期 = 实际做事的日期）。

原始日志文件（putty 抓取、demo 输出等）体积大且可能含板卡序列号等信息，默认不入库，存放于各成员工作机；如需入库先脱敏。

**豁免**：log 是**当时**的快照，允许出现当时那台机器的主机路径（工具装在哪个盘、原始日志在哪、许可文件在哪）——那是证据，改写反而失真。**设计文档、README 与脚本注释里不得出现主机路径**（见 [AGENTS.md](../../AGENTS.md) 硬性约定第 9 条）。
