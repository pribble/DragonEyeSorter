# log 说明

按日期归档的**实测与验证记录**：每份是当日快照，仅代表当时配置；设计文档吸收定性结论，数字汇总进 [测试与验证](../测试与验证.md)，原始数据在此留痕。决策沿革、被推翻的方案、历史数据只写本目录，正文只写当前结论（见 [文档索引](../README.md)）。

- 命名 `YYYY-MM-DD-主题.md`（日期 = 实际做事日期）；原始日志（putty 抓取、demo 输出）体积大、可能含板卡序列号，默认不入库、入库先脱敏。
- **豁免**：log 是当时的快照，允许出现当时那台机器的主机路径（工具、原始日志、许可文件在哪）——那是证据；**设计文档、README 与脚本注释里不得出现主机路径**（规则见 [文档索引](../README.md) 写作约定「不写主机路径」）。
