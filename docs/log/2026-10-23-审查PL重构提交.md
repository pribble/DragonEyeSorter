## 留档（没改、记一笔）

- **cmdlat 两轮不可互证**：TD 版平均 6.23µs、打包版 20.19µs，均无 min/avg/max 与时段（历史 25.5~27.6µs）。`STATUS` 112 / 64 / 96 可解释（b4~6 = A/B/Z 滤波电平，随编码器位置），但两篇 log 未注明。下次 `pl_check` 建议留原始 min/avg/max。
- **参数化静默失效**（默认配置安全）：`des_io` 的 `spd_div` 20bit（`SPEED_MS>13` 失效）、去抖 `WDB` 固定（`EST_DEB_US>1747` / `IN_DEB_US>27` 失效）、`des_pwm` 的 `div` 7bit（`CLK_HZ>128MHz` 失效）；`des_vision` ROI/BBOX 位域改随 WIDTH/HEIGHT（`$clog2`），默认 1920×1080 仍 11bit、与旧逐位相同，但改 1280×720 会静默变 [9:0]/[25:16]。建议 `WDB` 用 `$clog2(N)` + elaboration 断言、`des_vision` 位域固定 11bit。
- **覆盖缺口**：`des_vision` TB 固定 WIDTH=32/HEIGHT=12，真实 11bit ROI/BBOX 位域无断言；`des_common` 无独立 TB；`tb_servo_bus` 未覆盖非法 LEN / 垃圾 FF / 忙时二次 GO / `RX_COUNT` 上限（本次差分覆盖但不入库）；首帧发布无断言。
- **口径**：TD log 表“起止时刻”与“耗时”是两套口径（8m55 vs 8m10s 等，后者为 TD RUN-1001 内部时长）；“slice reg 39,441” 实为 #reg 总数（#slice reg 39,437）；`FRAME_PERIOD` 1,249,612 / 1,249,613 / 现读 `0x13114B` 属 ±1~2 tick 抖动。
- **提交粒度**：本提交含“RTL 重构 + v13 全量重编上板 + BOOT 复核”三件事，消息未提 v13；合并后 `pl/des-refactor-v13` 分支可删或留作追溯。
