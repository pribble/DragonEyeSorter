# 2026-11-03 皮带张紧与台面坐标平移

## 1. 起因与做法

- 11-02 起皮带运行时有高频异响，带速同步卡顿，带速 PI 演示不了（服务 11-02 04:35 起停着排查，见 [2026-11-02 带速 PI](2026-11-02-带速PI.md) §6）。用户判断：电机带轮与主动辊之间的同步带轻微老化、伸长。
- 电机模块装在近侧型材槽里，紧贴相机龙门近侧立柱的底座。张紧要把电机模块往带尾推，龙门必须先让开。
- 定的做法：龙门整体往带尾平移，只松两个立柱底座，相机、灯条、横杆的夹子都不动，相机跟着龙门一起走；位移用光束标定实测，软件里把不随相机动的东西（机械臂、挡板、光束、带尾）的台面 x 平移同样的量。
- 没选的两种：
  - 把相机推回原位：相机夹块夹在圆杆上，一松就会绕杆转，转 0.5° 在皮带上就偏约 2.6mm；而且灯相对相机变了，要重做平场、复核尺寸偏置。
  - 整体挪传送机：挡板、对射、计米轮都装在机架上，会跟着一起动，照样要改参数；还要靠两次手量的位移正好抵消。
- 台面坐标由相机定义（`calib.json` 的 `px_to_table`：画面上游边 x = 0，沿走带方向 x 增大）。相机和灯一起动，相机与灯的相对关系不变，所以单应、平场、尺寸偏置、NPU 输入都不受影响；只有相对相机挪了位的东西要改坐标。

## 2. 实测

用户：两个立柱底座往带尾挪约 3.5mm，同步带已张紧。

**光束标定**（停服务；30 齿标准件，`--od 31.95`；零件原先在光束下游 x 161.5，先倒走 5736 步放回上游）：

```
start: part at x 42.92 y -2.79 mm, size in the image 32.01 mm, caliper OD 31.95 used -> R 15.98 mm
each round: 14788 steps (+309 mm) at 20 mm/s and back
[1] ... back at x 43.34 (start 42.92, +0.42); centre at the edge 118.51 -> beam x 134.48 mm
[2] ... back at x 43.18 (start 42.92, +0.25); centre at the edge 117.91 -> beam x 133.88 mm
[3] ... back at x 43.48 (start 42.92, +0.56); centre at the edge 117.98 -> beam x 133.96 mm
== beam: x 134.11 mm (sd 0.33 over 3 rounds), part y -2.8
```

- 光束 x 由 139.69（10-29，sd 0.05，零件 y +11.6）变为 **134.11** → 相机相对机架实际平移 **5.58mm**，取 5.6。
- 比底座位移 3.5mm 多约 2mm。推断是底座重新拧紧时龙门后仰约 0.4°（相机高 295mm × tan 0.4° ≈ 2mm）。光束偏斜的贡献很小：10-30 那次 10 件过光束，跟踪误差 sd 只有 0.29mm，说明光束基本垂直于走带方向。
- 每轮退回的偏差 +0.25 ~ +0.56mm（10-29 为 +0.16 ~ +0.43）→ 同步带没有跳齿。
- 倒走 5736 步：编码器 −2440 计数 = 120.1mm，与步数 × 0.020921 = 120.0mm 一致。同一段相机读数差 123.7mm，是因为第一次读数时零件还在摆（外形读 30mm，正常 33mm），作废。
- 3 轮往返（共约 1854mm）后，编码器比起点多计 248（12.2mm）：计米轮倒转时多计约 1.3%（10-21 标定时 0.73%）。生产只正转，不影响跟踪；⚠ 若正转「计数 / 步」也偏离 0.4250，要重跑 `calib-enc`。
