# 2026-10-29 板端 /root 清理

用户要求：连上板子，把 `/root` 收拾干净、删掉无用 / 过期文件。范围只到 `/root`（p1 启动分区与系统件未动），自启服务全程未停、未 `reboot`。

## 1. 判断依据

板子无 RTC，`date` = 1970-01-01：同一 boot 内文件的 mtime 只表示「距本次上电多久」，**不能按 mtime 判新旧**。本次按 [log](README.md) 里的实验日期、现行配置引用与文档结论逐项判断；删除前对当前运行进程的 fd/maps、板端脚本与配置做了引用扫描（`rev1027`、`test_old`、`data/*` 等 0 命中）。

清理前：根分区 707.3 MB / 3.6 GB（20%），`/root` 565,344 KB。
