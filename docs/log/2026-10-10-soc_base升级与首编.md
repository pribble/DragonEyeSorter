## 结论

- **TD 2026.1 SP2（6.2.2.200067）成功打开并编译 6.2.1 底板工程**，无格式阻断：综合前自动重分析 117 个源文件；`soc_prj.al` 升级 diff 仅 3 行（Path / TD_Version / UCode），已 checkout 还原，不提交。

## 流程要点（踩坑）

1. 批处理入口是 `td_commands_prompt.exe <script.tcl>`（SWUG105 §2.2），`run.exe` 不是命令行入口。
2. **single_run 模式必须显式 `import_device dr1_90.db -package DR1M90GEG400 -speed 2`** —— open_project 恢复的 settings.cfg 里 device_name 为空会让 run 卡死不启动。
3. **TD 无 license 会静默停在 optimize_rtl**（RUN-8008 才暴露）；当时把有效期至 2026-10-10 的许可复制到 `TD\license\Anlogic.lic`。
4. **single_run 不会自动读 io.adc**：第一轮 bitgen 被 `BIT-8123 unconstrained io(s)` 拦截（24 个端口随机分配）；脚本补 `read_adc ./src/constraint/io.adc` 后通过。多 run 模式（launch_runs）无此问题。
5. **bitgen 必须带 `-bit <路径>`**：不带参数时内部完成（「3022694 bits」）但不落盘 `.bit`。
