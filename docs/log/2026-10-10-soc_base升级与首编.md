## 流程要点（踩坑记录）

1. 批处理入口是 `td_commands_prompt.exe <script.tcl>`（SWUG105 §2.2），
   `run.exe`/`bw.exe` 不是命令行入口（bw 是 BitWriter GUI）。
2. **single_run 模式必须显式 `import_device dr1_90.db -package DR1M90GEG400 -speed 2`**
   ——open_project 恢复的 settings.cfg 里 device_name 为空会让 run 卡死不启动。
3. **TD 无 license 会静默停在 optimize_rtl**：RUN-8008 错误后才暴露。
   已把 FD 的节点锁定许可（FEATURE TD，**有效期至 2026-10-10**）复制到
   `TD\license\Anlogic.lic`。⚠ 许可明天到期，续期前编译全被卡。
4. **single_run 流程不会自动读 io.adc**：第一轮 bitgen 被
   `BIT-8123 unconstrained io(s)` 拦截（24 个端口随机分配）。脚本补
   `read_adc ./src/constraint/io.adc` 后通过。多 run 模式（launch_runs）无此问题，
   约束集随工程走。
5. **bitgen 必须带 `-bit <路径>`**：不带参数时 bitgen 内部完成（"3022694 bits"）
   但不落盘 .bit 文件。第三轮 `bitgen -bit ./soc_prj_TD622.bit` 成功。
