## 五、板上 `/root/des` 比 `scripts/deploy/out/` 多的是什么

`out/` 是 9 项（8 个清单件 + `MD5SUMS.txt`），板上 `/root/des` 是 14 项 + `data/`。差集：

| 板上多的 | 是什么 | 仓库里有吗 |
|---|---|---|
| `pl_check.sh` / `soak.sh` / `display_check.sh` | 测试 / 回归脚本 | **有**（`ps/board/` 那三份，与板上逐字节一致），只是不在 `out/` |
| `autostart.conf` | 自启行为（ENABLED / MODE / CAN / CAN_MODE / ARGS） | 否。`des_service.sh` 首次运行写缺省 |
| `ui_params.json` | 界面参数（11 键） | 否。`Hmi::save_params()` 只在改参数 / 换配方时写 |
| `data/`（`service.log`、`des_service.pid`、`log/`） | 运行数据（CSV 2 份、`img/` 空） | 否 |
| （反向）`out/MD5SUMS.txt` | 部署器台账 | **有**（10-16 拍板后 `out/` 文本件入库） |

**判据更正**：`out/` 是**部署暂存目录**，「板上比 `out/` 多」不等于「仓库里没有」——判断「仓库里有没有」要看 `manifest.tsv` + `ps/board/` + `ps/src/` + `models/`。

### `ui_params.json` 与仓库配置的口径差

| 键 | 板上 | 仓库 | 影响 |
|---|---|---|---|
| `belt_speed` | 150.0 | `belt.run_speed` = 50 | 界面值覆盖配置，板上实际按 150 mm/s 走带 |
| `images` | 0（`none`） | `storage.images` = `"ng"` | 板上**不存** NG / 复检裁切图（0/1/2 编码见 `ps/src/ui/hmi.hpp`） |

**未拍板**：哪个值该成为仓库默认（改 `ps/src/des_app.json` 才算数，`ui_params.json` 只是操作员状态）。倾向 `images` 回 `"ng"`——赛题硬性项②与演示视频脚本都要看 NG 裁切图；`belt_speed` 150 / 50 哪个是生产值待用户定。

## 六、规则修正：`out/` 入库（用户 10-16 拍板）

**规则**：不入库的是**能由源码编出来的二进制**；文本类的部署件要入库 —— `scripts/deploy/out/` 里平铺的脚本与配置就是发到板子上的那一份。这条推翻了原来「`out/` 整目录忽略」的做法。

本次改动：

- `.gitignore` §4：`scripts/deploy/out/` → `scripts/deploy/out/des_app`（只挡编出来的二进制）；§5 加 `part_cls.json`（训练导出物，与 `*.onnx` 同等）。
- `AGENTS.md` 硬性约定第 7 条补「不入库的是能由源码编出来的二进制；文本类部署件要入库」。
- `scripts/deploy/deploy.sh`：usage、`stage=` 注释、`stage_payload()` 台账头三处措辞；台账头 `# 生成：<时间>` → `# 清单指纹：manifest.tsv 的 MD5 = …`。
- `scripts/deploy/README.md`、`docs/板端布局.md`、`scripts/deploy/out/` 的 8 个文本件 `git add`（`des_app` 仍被忽略）。

实测：`git status --ignored -- scripts/deploy/out` 里只有 `!! scripts/deploy/out/des_app` 一项；`git check-ignore -v` 命中 `.gitignore:62`。

同轮拍板的三个细节：

1. **`MD5SUMS.txt` 不写生成时间**，改成「清单指纹」（`manifest.tsv` 的 MD5）。实测连跑两次 `--stage` 台账逐字节相同（`64459435…`）—— 清单一动它才动，刷新不再产生假 diff。
2. **`part_cls.json` 与 `*.onnx` 同等**：都是训练导出物。
3. **删掉 selftest 的两处活文档引用**（`scripts/deploy/selftest/` 已由用户删除；log 里的历史记录保留不改）。

行尾由 `.gitattributes` 统一（`.sh` / `.env` = LF，`.json` 工作区 CRLF），`out/` 副本与 `ps/board/`、`ps/src/` 的源在 git 中是同一种存储形态，不会因行尾反复产生 diff。
