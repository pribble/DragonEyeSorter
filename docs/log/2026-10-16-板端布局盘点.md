## 五、板上 `/root/des` 比 `scripts/deploy/out/` 多的是什么

`out/` 是 9 项（8 个清单件 + `MD5SUMS.txt`，生成于 18:00:57），板上 `/root/des` 是 14 项 + `data/`。两个方向的差集：

| 板上多的 | 是什么 | 仓库里有吗 |
|---|---|---|
| `pl_check.sh` / `soak.sh` / `display_check.sh` | 测试 / 回归脚本 | **有**——`ps/board/` 那三份，与板上逐字节一致（见第一节表），只是不在 `out/` |
| `autostart.conf` | 自启行为（ENABLED / MODE / CAN / CAN_MODE / ARGS） | 否。`des_service.sh` 首次运行写缺省（`cat > "$CONF"`，`ps/board/des_service.sh` 第 26 行） |
| `ui_params.json` | 界面参数（11 键） | 否。`Hmi::save_params()` 只在**改参数 / 换配方**时写（`ps/src/ui/hmi.cpp` 第 147、238 行），不是首启生成 |
| `data/`（`service.log`、`des_service.pid`、`log/`） | 运行数据（CSV 2 份、`img/` 空） | 否 |
| （反向）`out/MD5SUMS.txt` | 部署器台账（左列哈希、右列板端路径） | **有**（10-16 拍板后，见第七节）：`out/` 的文本件入库，这份台账在内 |

**判据更正**：`out/` 是**部署暂存目录**，"板上比 `out/` 多"不等于"仓库里没有"——判断"仓库里有没有"要看 `manifest.tsv` + `ps/board/` + `ps/src/` + `models/`。另外 `out/` 本身也要入库（文本件），被 `.gitignore` 挡住的只有编出来的二进制（见第七节）。

### `ui_params.json` 与仓库配置的口径差（附带发现）

板上那份 11 键里有 2 项与 `ps/src/des_app.json` 不同：

| 键 | 板上 | 仓库 `des_app.json` | 影响 |
|---|---|---|---|
| `belt_speed` | 150.0 | `belt.run_speed` = 50 | 界面值覆盖配置，板上实际按 150 mm/s 走带 |
| `images` | 0（`none`） | `storage.images` = `"ng"` | 板上**不存** NG / 复检裁切图（0/1/2 编码见 `ps/src/ui/hmi.hpp` 第 32 行） |

其余 9 项与仓库一致：`gear_od` 32 / `gear_od_tol` 0.15 / `rack_len` 50 / `rack_len_tol` 0.5 / `min_conf` 0.5 / `recipe` 1 / `size_rule` false 都对得上 `measure.rule`（`config.cpp` 第 171–196 行把 `measure.rule` 映到 `tracker.size`）；`pl_mode` 0 / `pl_thr` 128 是 des_vision 显示设置，仓库没有对应键，等于代码缺省。

**未拍板**：哪个值该成为仓库默认（改 `ps/src/des_app.json` 才算数，`ui_params.json` 只是操作员状态）。倾向 `images` 回 `"ng"`——赛题硬性项②与演示视频脚本都要看 NG 裁切图；`belt_speed` 150 / 50 哪个是生产值待用户定。
