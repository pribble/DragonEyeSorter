# 2026-10-28 多规格尺寸标定（20 / 28 / 30 齿）与 20 齿飞边误报

用户卡尺（各 5 件均值）：20 齿外径 21.87 / 孔 5.80，28 齿 29.90 / 5.79，30 齿孔 8 31.95 / 7.70；三种厚度都是 10.11（30 齿 10.05，`gear_h_mm` 不用分规格）。配方外径 / 孔径已改卡尺均值（`74dd9f7`）。

做法：三件沿皮带中线一前一后放，20 齿在画面正中；每件 `des_tool.sh measure -n 20`，再用皮带把下一件送到同一位置。皮带只往下游走：`desreg step move` 先读当前 pos 再加步数，先走 200 步确认方向（三件 x 都增加约 4mm），vmax 2400 步/s、acc 4800。原图与结果在板上 `/root/des/data/spec_1028/`（raw0~2.png、m0~m3.txt、regress/）。

## 2. 误差随尺寸变 → 增益 + 偏置

去掉偏置后的原始外径比卡尺小 0.63 / 0.85 / 0.98（20 / 28 / 30 齿孔 8），10-24 标准件（30 齿 31.93）小 0.96：都是外径的 2.9~3.1%，不是常数。四件最小二乘（卡尺 = a × 原始 + c）：**a = 1.0347、c = −0.12**，残差 ≤0.045。

孔径用同一增益时，两个 30 齿本体（标准件、孔 8）的偏置都约 0.095，20 / 28 齿分别 −0.01 / +0.34（卡尺内量爪量 6mm 小孔本身误差大）→ 取四件平均 0.13。

增益 1.0347 几乎正好是顶面视差缩放（H 295 / h 10.05：顶面边缘往光轴缩 1/1.0353）的倒数，即测出的轮廓尺度接近带面、不像顶面。原因未查明（候选：标定纸垫高、齿尖与边缘阈值）。带面尺度本身没有 3% 的错：皮带尺量 0.0207mm/步，相机标 0.020921（+1%）。位置 / 抓取用 `px_to_part`，不受影响（10-26 真抓 2/2）。

→ 新配置 `measure.size_gain`（默认 1 = 原行为）：外径 / 根径 / 孔径 / 偏心 = 增益 × 拟合值（外径、孔径再加各自偏置）。现值 `size_gain` 1.0347、`od_offset_mm` −0.12、`bore_offset_mm` 0.13。

## 3. 20 齿「飞边 1」

`DES_MEASURE_DEBUG=1` 打出的齿段：`[278-296 10.64] [298-298 9.67] [315-334 10.62]`。第 8 个齿下降沿后面多了 1 个 0.5° 槽宽的段，峰值只比中线 9.595 高 0.075mm，不在齿距网格上，于是按「槽里立着一块」计成飞边。真飞边样品是补土片伸出齿槽、接近齿顶，这个是齿面上的毛刺或噪声。

→ `filter_phase`：离网格的段，峰值 ≥ 中线 + ¼（齿顶 − 中线）才计飞边，更低的丢掉不计；在网格上的短齿不受影响。`test_measure` 加两例：槽中低矮小块（中线 +0.1mm）不算、伸出齿顶的鳍算 1 处（75 过，板上）。
