## 3. 颜色能力的事实边界

代码确实实现了，不是占位：

- `ps/src/measure/roi_crop.cpp` `part_color()`：裁切图中心圆盘（0.42 倍边长）内、按 V 的 Otsu 阈值取亮区，对色调做**饱和度加权圆均值**（避免红 / 蓝跨 0° 出错）。
- `classify_color()`：按配置的饱和度区间 + 色调区间分类，支持跨 0°（`hue_lo > hue_hi`）。
- `des_app.json` 的 `measure.colors` 配了白 / 黄 / 橙 / 蓝 / 红五类；每件算一次（A35 上约 0.5 ms），`hue / sat / color` 写进逐件 CSV，界面显示颜色名。
- 单测：`ps/tests/test_measure.cpp` 用合成裁切图（224×224、含孔、深色皮带）测白 / 黄 / 蓝 / 红四类，全部命中。

没验证的部分：现有样件全为白色（没买彩色齿轮），**真实成像下的颜色分类准确率没有任何实测**。所以报告只写「已实现 + 结果随记录保存」，标 ⚠，不写准确率、不进视频；`齿轮样品制作方案.md` 里「颜色分拣暂不演示」的结论不变。
