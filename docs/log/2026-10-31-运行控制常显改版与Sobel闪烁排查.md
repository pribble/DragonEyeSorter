## 改动 1：皮带计划文案（`ps/src/app/live.cpp` `plan_cn`）

- Run「一直走」→「连续运行（无待抓件）」；StopAt「停到抓取线」不变；Hold「停住（机械臂在带上）」→「停带（机械臂作业中）」。未运行仍「—」。

## 问题 3：Sobel 闪烁——排查实验单（⚠ 未执行）

- **11-01**：板上回退 v16 后，用户目视各 PL 模式（含 Sobel）都正常，10-31 之前那次「Sobel 持续闪」没有复现；第六轮候选上则连原图也黑屏闪烁（见 [第六轮候选上板复核](2026-10-31-PL第六轮候选上板复核.md)「11-01」）。实验单保留，复现时照做。

已有事实：
- PL 切换逻辑 TB 验证为帧原子（`tb_des_vision.v` 790 项断言含跨模式切换；`des_vision.v` 模式在 SOF 生效、CDC 有握手、无复位路径）；切模式只写 `DES_VIS_CTRL/THR/APPLY` 三个寄存器，碰不到扫描 VDMA。**静态停在 Sobel 上没有时变逻辑** → 持续闪烁只能来自内容：Sobel 画面大面积黑底、像素翻转密度高。
- [2026-10-16 HDMI 周期性黑屏](2026-10-16-HDMI周期性黑屏.md) 未解：单缓冲、不写任何 VDMA 寄存器也黑；剩余怀疑 = 线材 / 显示器 FreeSync / EMI / TMDS 串行器时序余量（v16 setup WNS 仅 +0.007ns，`pl/README.md`）。其待办（换线、关 FreeSync、换显示器、关光源）一直没做。
- 用户已确认：Sobel 上持续闪、原图不闪。缺的数据：灰度 / 高斯 / 二值 / 边缘闪不闪。

实验矩阵（上板，每段 3 min，记录每段黑屏次数）：

| 段 | 设置 | 判读 |
|---|---|---|
| A1~A6 | 界面切 6 个模式各停 3 min | 只有 Sobel / 边缘（高翻转密度）闪 → 指向串行器时序或显示器对高频内容的处理；二值也闪（同为高对比）而灰度 / 高斯不闪 → 内容相关概率大增；全模式都闪 → 基线黑屏，与模式无关 |
| B | **关光源控制器**（或盖镜头盖），停在原图 | 近黑原图也闪 → 显示器暗场表现（动态对比 / 背光自适应）或低亮度内容相关，与 Sobel 模式无关 |
| C | 闪烁瞬间看 **vtg_lock 灯**（led[1]） | 灯稳 → 同步没丢，内容 / 显示器侧；灯闪 → PL 串行器时序路径，再考虑重跑实现提余量（对照历版余量选基线） |
| D | 换短 HDMI 2.0 线 / 关显示器 FreeSync / 换显示器或采集卡；记录闪烁瞬间 TB6600 / 舵机是否在动作 | 10-16 遗留待办，逐项排除 |

- 处理模式期间定位 / NPU 看到的是处理后的图（`des_vision` 在 DDR 写入之前加工），误检会增多、帧率可能掉（10-16 已见 40 fps 时段与误检吻合）——这是显示模式的已知副作用，**帧率掉不是黑屏**，记录时分开记。
- 结论写回本文件并同步 [软件与UI](../软件与UI.md) / [PL设计](../PL设计.md)；若指向串行器时序，另开重编对照（历版余量：v9 +0.120 / v12 +0.041ns）。

## 问题 4：PL 显示是否得分点——结论：保留

- 评分细则无「显示画面」条目（[选题指南摘录](../ref/安路赛道选题指南_2026_摘录.md) §2.2 拓展项六条均不含显示）；得分的是**功能**：领域 3 简单级「硬件灰度滤波」、中级「PL 硬件边缘检测、尺寸粗测量」（摘录 65~66 行），`des_vision` 的 6 个显示模式正是这两条的实画面证据，演示视频 V2b 有 20s 专门镜头。
- ROI 投影尺寸粗测与显示在同一模块（记录页「PL 粗测 等效Ø / 框」），删模块会把「尺寸粗测量」条目一起删掉。
- 资源代价 ~968 LUT / 2 ERAM / 13 DSP（`docs/PL设计.md`）；整片 ERAM 93.21%（261/280，剩 19），腾 2 块塞不下任何新模块。日后若 ERAM 紧张，已有 LANES=2 减半方案（2026-10-28 第五轮精简评估过、暂不做），不删模块。
