# 2026-10-13 TD / FD 本机可用性实测

## 结论

- **TD 6.2.1（Build 6.2.175.876）可用**：命令行全流程（综合 → 布局布线 → bitgen）与图形界面均实测通过，能出比特流。
- **FD 2026.1 SP1 可用**：BootGen、交叉编译器、`make_bootbin.ps1` 打包、GUI 与许可证校验均通过。

## 许可证（本次最关键的发现）

1. TD 只认 `<TD 安装目录>\license\Anlogic.lic`，本机该目录**原本是空的** → 任何综合都会在 `optimize_rtl` 停住。
2. 资料 `软件&驱动\license\TD\Anlogic.lic`（`FEATURE TD`，到期 **2027-03-31**，`HOST_ID = ANY`）**同时能通过 FD 自带的校验器**。
3. 资料 `软件&驱动\license\FD\license.lic`（`FEATURE FD`，到期 2026-12-31）**被 FD 2026.1 SP1 的校验器拒绝**：`allv1.exe <该文件>` → `Invalid License! #3`。校验器是 FD 插件自带的 `allv/allv1.exe`；无参时在自身同目录找 `Anlogic_FD.lic`，可作排障线索。
4. FD 安装目录原来那份其实是 **TD 许可**，到期 2026-10-10 → `allv1.exe` 报 `License expired!`，即 FD 是「刚过期 3 天」，不是从没配好。

**已落地的改动（都在安装目录、均留了备份）**

| 文件 | 内容 | 备份 |
|---|---|---|
| `...\TD_6.2.1_Release_6.2.175.876\license\Anlogic.lic` | 资料 TD 许可，MD5 `E58DA2546330DAD0837EDDB9FDBD8322` | 原目录为空 |
| `...\FD_2026.1_SP1\license\Anlogic.lic`、`license.lic` | 同一把资料 TD 许可 | 原文件存为 `Anlogic.lic.bak-20261013-191607` |

## 注意：DSH 沙箱下 FD 的许可证校验会「假失败」

沙箱内启动 FD 会弹 `License Validation failed!`（同时报 `Microsoft Defender Exclusion Check` 失败），正常权限启动即通过。原因是 FD 用**管道**调用 `allv1.exe` 并写 `<FD>\logs\`，被沙箱拒绝——**不是 FD 的问题**。
