## 许可证（本次最关键的发现）

1. TD 只认 `<TD 安装目录>\license\Anlogic.lic`，本机该目录**原本是空的** → 任何综合都会在 `optimize_rtl` 停住。
2. 资料 `软件&驱动\license\TD\Anlogic.lic`（`FEATURE TD`，到期 **2027-03-31**，`HOST_ID = ANY`）**同时能通过 FD 自带的校验器**。
3. 资料 `软件&驱动\license\FD\license.lic`（`FEATURE FD`，到期 2026-12-31）**被 FD 2026.1 SP1 的校验器拒绝**：`allv1.exe <该文件>` → `Invalid License! #3`。（校验器是 FD 插件里自带的 `allv/allv1.exe`；无参时它在自身同目录找 `Anlogic_FD.lic`，可作排障线索。）
4. FD 安装目录原来那份其实是 **TD 许可**，到期 **2026-10-10** → 实测 `allv1.exe` 报 `License expired!`，即 FD 是"刚过期 3 天"，不是从没配好。

## 注意：DSH 沙箱下 FD 的许可证校验会"假失败"

在工作区沙箱内启动 FD 时出现 `License Validation failed!` 弹窗，同时报 `Microsoft Defender Exclusion Check` 失败；改用正常权限启动即 `License validation success!`。
原因是 FD 用**管道**调用自带 `allv1.exe` 并写 `<FD>\logs\`，这两件事被沙箱拒绝。**这不是 FD 的问题**，记录以免下次误判。
