# 2026-10-16 传送带首次上电（TB6600 + 57 步进，PL v9）

## 接线（用户照片核对）

- 电源 LRS-350-24：端子 1（+V）红、5（−V）黑 → 驱动器 VCC / GND；交流 L 棕 / N 蓝 / PE 黄绿，护盖盖着。急停未装（按钮未买），测试时以电源开关代替。
- 驱动器 High Voltage（左→右）：VCC 红、GND 黑、A+ 蓝、A− 红、B+ 黑、B− 绿 —— 与定版接法一致。
- Signal（左→右）：PUL+ 红 → J12 PIN3，PUL− 黑，DIR+ 橙 → PIN4，DIR− 黑，ENA+ 黄 → PIN5，ENA− 黑；三根「−」进 WAGO，再一根线到 PIN2（GND）。共阴、板子 3.3V 直驱。接线图 [figures/fig_step_wiring.png](../figures/fig_step_wiring.png)。

## 测试（停掉自启服务后用 `desreg`）

| 项 | 命令 | 结果 |
|---|---|---|
| 状态 | `desreg step status` | VERSION 9，`status 0x14`（使能、在位） |
| 慢速走带 | `step vel 1600`（加速度 20000 步/s²）3s → `step stop` | 4848 步；用户目视**平稳**；**方向反了**（皮带上表面背离带尾）→ `des_app.json` 的 `belt.dir` 改 **−1**（前进 = POS 递减），不改线 |
| 一圈 | `step move <当前−3200> 1600` | POS 4848 → 1648 正好 3200 步、`AT_TARGET`；⚠ 主动辊是否正好一圈待用户目视 |
| 命令 → 首脉冲 | `desreg steplat 100` | **min 10.61 / avg 10.63 / max 10.77µs**（接上真驱动器，与无负载时一致；其中 10µs 是换向建立时间） |

驱动电流（PL 3.3V 直驱光耦，约 6~8mA）够用：低速平稳、无丢步迹象（只凭目视；精确的往返误差等 `calib-belt`）。
