## Modbus-TCP 从站（网口对接 PLC）

- 板子是从站（端口 502，`des_app.json` 的 `plc.modbus_port`），PLC / 组态软件是客户端；电脑主动连板子，不动电脑防火墙。
- `ps/src/hw/modbus_tcp.{hpp,cpp}`：自写服务端，一个 poll 线程、最多 4 个客户端、MBAP 分帧（半帧、粘包都处理），FC 03 / 04 / 06 / 16，异常码 01 / 02 / 03，协议号不为 0 直接断开。写入只排队，`Runner::cycle` 每帧取出，按与 CAN、界面按钮同一套规则执行（`command` / `set_speed` / `select_recipe`），结果写回 HR3、HR4 序号加 1。寄存器表 `ps/src/hw/modbus_map.h`（文档：软件与UI「Modbus-TCP」）；「PLC 在线」= CAN 心跳或 Modbus 请求在 1s 内。PC 端 `pc/modbus/mb_client.py`（只用标准库）。
- **测试**：`ps/tests/test_modbus.cpp` WSL g++ 与板上 aarch64 各 **29 项全过**（读写、FC06 / FC16、异常码、越界写不排队、半帧 / 粘包、多客户端、请求计数、断开等）；板内回环读 24 个寄存器 0.22ms / 次。电脑经网线对板上 `des_app run`（空闲态）：status = 空闲、已标定、配方 1、映射版本 0x0100；time OK（板子无 RTC，记录时间改用 PC 时钟偏移）；recipe 2 / 99 = OK / 数值不对；speed 45.5 / 0 = OK / 数值不对；空闲时 cmd pause / resume = 状态不允许；cmd stop / reset = OK / OK；「PLC 在线」位在有 Modbus 请求后置位；bench 500 次读 24 个输入寄存器**平均往返 1.04ms**。
- 测完把配方改回 1、带速改回 50mm/s。**没在实物上发「启动」**（当时用户在皮带上装支架，皮带会动）；启动逻辑与 CAN 共用，CAN 侧已实测。
