## 10-18 皮带标定、曝光与打光

- **calib-belt**（用画面右侧齿轮）：0.021249 mm/步，dir −1，174mm 往返误差 +0.39mm，横向漂移 −0.40mm/100mm，写进 calib.json。⚠ 偏大：齿轮顶面高出带面约 11mm，位移放大 k = H/(H−h)；对比平铺标定纸的 0.0203 → k ≈ 1.047 → H ≈ 245~270mm（h 11~12），与镜头高 28cm / 单应 267mm 相符，坐实 2×2 合并（驱动打印 ReadoutMode H/V 2/2-line binning）。→ calib-belt 必须用**平的**目标（白纸片，联调清单 4.5 已改）；belt 段待重测覆盖。
- **曝光**：默认 SHR0 = 8 → 曝光 ≈ 16.6ms（整帧），50mm/s 拖影 0.8mm、白件过曝。扫曝光（两齿轮静置，原始灰度）：1 / 2 / 3 / 4 / 8ms → 零件中位 73 / 98 / 116 / 132 / 181（p95 85 / 114 / 133 / 151 / 207）、皮带中位 7 / 14 / 23 / 28 / 41（p95 14 / 27 / 33 / 39 / 56）、饱和 0。外径几乎不随曝光变（左齿轮 32.59~32.62）→ 偏大不是发光外扩、主要是视差。→ 新增 `camera.exposure_us` / `gain_db10`（des_app 与 des_tool 共用，`--exp` / `--gain` 优先），定 **3000**，已部署（日志 `camera open: … exposure 3000 us`），定位 5.7ms/帧；光源调亮到零件顶面 180~220。
