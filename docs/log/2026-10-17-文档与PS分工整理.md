## PS 产物分层

| 层 | 产物 | 职责 | 部署 |
|---|---|---|---|
| 产品运行时 | `des_app` | 只含 `run` / `live`：界面、定位、跟踪、调度、机械臂、CAN、存储 | 进 [manifest.tsv](../../scripts/deploy/manifest.tsv)，开机自启 |
| 人工运维 | `des_tool`（新） | `probe` / `locate` / `track` / `display` / `collect` / `measure` / `calib-cam` / `calib-belt` / `calib-arm` / `arm` / `ik` | 手动 `scp`，不进清单 |
| 自动测试 | `test_*` | 断言 + 退出码；`test_servo_gap` 无断言，归底层测量 | 手动 `scp` |
| 底层调试 | `desreg` / `canplc` | 寄存器 / 总线裸操作、PLC 陪测 | 手动 `scp` |

实现：

- `ps/src/app/main.cpp` 改为产品入口；新增 `tool_main.cpp`（11 个运维模式，子命令 token 不变）与 `cli_common.{hpp,cpp}`（共享参数解析与取帧辅助）；两个入口支持 `--version`。
- `ps/Makefile`：共用源码编一次到 `build/obj/*.o`（`-MMD -MP`），`des_app` / `des_tool` 分别链接各自入口；`des_tool` 额外链 `calib.cpp` / `measure_tool.cpp`，产品二进制不含标定与人工测量报告代码。`make all` 产物 9 个，`test_npu` / `test_servo_gap` 仍显式点名。
- 板端脚本：新增 `scripts/deploy/out/des_tool.sh`（加载相机驱动、取 `des.env`、单实例保护）；`pl_check.sh` / `display_check.sh` 改调 `des_tool.sh`；`des_app.sh` 的单实例检查同时覆盖 `des_tool`；`des_app.sh` / `des_service.sh` / `soak.sh` 的产品行为不变。
- 部署：`des_tool` 与 `test_*` 同为手动件，manifest 登记仍 11 条；`deploy.sh` 的手动件刷新列表加入 `des_tool.sh`；`out/MD5SUMS.txt` 重刷。
