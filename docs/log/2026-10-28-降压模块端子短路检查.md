# 2026-10-28 6.8V 降压模块端子被六角扳手短接后的检查

## 事件

- 用户：六角扳手不小心碰到 6.8V 降压模块的两个螺钉端子，短时间打出较大的电火花；之后机械臂仍有电（没断路）。这块是 300W 恒压恒流模块，输入取受控 24V，恒流限流还没调，见 [到货联调清单](../到货联调清单.md) 1.2b。碰到的是输入（24V）一对、输出（6.8V）一对还是各一个，待用户看烧痕确认。
- 板上时间线（板上 uptime 换算成电脑时间）：
  - 02:38 另一会话停了 des_app，去做相机测量。
  - 02:45 板上 USB WiFi 模块掉线，随即重连。这多半是火花的干扰：FPGA 板单独供电、单点共地，本身没重启（uptime 2 h 21 min）。
  - 之后 dmesg 没有其它异常。

## 检查

服务停着时做，全部只读，皮带和步进都没动。

| 项 | 结果 | 判断 |
|---|---|---|
| `des_tool.sh arm scan` ×2 | 6 / 6 应答，状态位全 0x00（无过载 / 过温 / 电压异常） | 正常 |
| 0x2E（随供电电压，约 635 / V） | 1~5 号 4304~4337（10-26 在 6.8V 下为 4300~4334）；夹爪 0（不提供） | 输出电压没变，仍 ≈6.8V、差 <0.05V，调压电位器没被碰动 |
| `DES_SB_RETRIES=0 desreg sstress 100`（步进驱动器已释放） | 600 / 600 成功、0 重试；PL 计数 timeouts / rx errors 不涨 | 总线、BSS138、舵机通信口正常 |
| 扭矩 0x28 | 6 个全 1 | 正在保持 |
| 位置 0x38 | 2017 / 2154 / 2906 / 3092 / 866 / 2012；初始姿态为 2012 / 2152 / 2906 / 3096 / 864 / 2008，差 ≤5 计数（<0.4°） | 停在初始姿态，没有掉下来 |
| 目标位置 0x2A | 6 个全 0 | 见下 |

0x2A 在上电后没写过时读 0（10-26），这次 6 个全 0：**最后一次下发姿态之后，6 个舵机一起断过电、复位过**。要是这期间没按急停、没关电源，就是这次短路让 6.8V 掉了电。6 个都正常回来了。

顺带看到：复位后扭矩读 1、位置没变 → 这批舵机重新上电后像是会自己开扭矩、停在原位（不乱动、也不软掉）。⚠ 这只观察到一次。前提是这段时间没人发过扭矩命令：服务 02:38 起一直停着，另一会话只做相机测量。

## 结论

**没发现损伤**：供电电压、状态位、通信都与之前相同。

远程看不到的可能后果：

- 端子：螺钉和端子座被电弧烧蚀。小黑点无害；熔化、焦味、电容鼓包就不行。端子的夹紧力也可能变松。
- 模块：功率管受了一次过流冲击。之后要是发热明显变大、有啸叫，或者带载时舵机复位、机械臂发软 → 换模块。

## 建议 / 规矩

1. 断电后看一眼端子，复紧螺钉。
2. 端子包绝缘：电工胶布、热缩管或小塑料盒都行。
3. 恒流限流调到约 6A（联调清单 1.2b：先拔保险丝，CC 电位器先拧到最小）。以后输出再被短接，就只流约 6A。输入侧（24V）短接，限流管不到，只能靠绝缘和断电。
4. 在电源和模块附近用金属工具前，先关 24V 总电源：急停只断受控 24V，常电 24V 的端子仍带电。关电前先把机械臂放低或托住，断电后它会软掉。
5. 判断「舵机有没有断过电」：`desreg sread <id> 0x2A 2` 读 0，就是上次下发后复位过。只在 des_app 停着时读。
