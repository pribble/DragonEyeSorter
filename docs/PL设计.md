## 基线

在官方 NPU demo 工程 `soc_prj`（MIPI RX + ISP + VDMA + HDMI + NPU 软核，已过 P&R）上叠加自研模块；顶层 `src/system_top.v`，PS 与 AXI 互联在块设计 `design_0`。

v15（已被 v16 取代）= 第三轮重构源码（`9e01d8f`，自研 + 厂家明文 RTL + `pl/sim` 框架）全量重编 + 上板（`BOOT.bin` `b0aef232…`，比特流 `e14fbb65…`；56m25s、0 error）；`pl_check.sh` 回归通过、2min soak 0 error；寄存器 `VERSION` 仍 12（接口未变）。自研各域 0 违例，NPU 软核域内 −0.093ns / 42 端点仍属厂家加密 IP；TMDS 视觉待复核 ⚠。2026-10-24 又对**厂家明文 RTL（非 des）**与**自研 `des/` + 顶层 + `pl/sim` 框架**各做一轮零行为重构（当时未重编比特流，源码由 v15 全量重编转正），明细见 [log/2026-10-24-PL厂家RTL重构](log/2026-10-24-PL厂家RTL重构.md) · [log/2026-10-24-PL第三轮重构](log/2026-10-24-PL第三轮重构.md) · [log/2026-10-24-PL第三轮重编上板v15](log/2026-10-24-PL第三轮重编上板v15.md)。逐版改动与上板记录见 [pl/soc_base/README](../pl/soc_base/README.md) 与 [log/](log/README.md)。

**板端当前 v16（10-25 上板：BOOT `71f41a20` / 比特流 `f0f63c91`；`pl_check.sh` 0 失败）**：新增 `des_485`（RS485 Modbus-RTU，窗口 `0x6xx`，J11 第 5 / 6 位）与帧起始锁存的编码器计数（`CAP_ENC0/1`），`VERSION` 16；对原有全部输出的整顶层等价回归逐拍一致。回退点 tag `v15-board-20261024`。见下面「RS485 `des_485`」。

**CAN 管脚（最新版已引到）**：底板 CAN 收发器接 PL 管脚 F20（TX）/ F19（RX），LVCMOS33、RX 上拉；RS485 接 L17（TX）/ N16（RX）/ N15（DE，1 = 发送；与 /RE 并联，原理图 p14）（硬件手册 p21），v16 起由 PL `des_485` 驱动。官方 demo 块设计没开 PS CAN（`CAN0_Available=0`，收发脚未约束）→ 最新版把 PS 硬核 `can0_tx_out` / `can0_rx_in` 经块设计引到 `system_top`，再到 F20 / F19。单节点验证：无人应答时发送错误计数按 CAN 规则累加、进 ERROR-PASSIVE 不进 BUS-OFF → 收发回路已通（明细见 log）；10-23 J11 接 PC USB-CAN 双节点实测通过（240/240，见 [测试与验证](测试与验证.md)）。注意：① ipms_canfd 驱动的错误帧把 ACK 位置码 0x19 写进 data[2]，candump 会显示成 bit-error，别被误导；② 驱动只支持 FD 模式，`ip link … fd off` 直接 EINVAL，收发经典帧不受影响（`can_up.sh` 照用）；③ 底板 B2B 管脚表（20250526）把 CAN / HDMI 管脚写反，以硬件手册 + 实测为准。

### 实现约束

- 寄存器读多路选择须为组合逻辑：`fvdma_ctrl` 桥按 1 拍取数，打 1 拍则 `0x3xx` 读回全是 THR。
- `clk_mipi` 在 `timing.sdc` 里约束到 `U_io_clk_div_1.clkdivout`（8.0ns，像素时钟 111.1MHz）；厂家原 SDC 写硬 MIPI PHY 引脚名，对本设计（LVDS IO）不生效。
- 跨时钟域用「翻转 + 两级同步」（像素域 ↔ 75MHz 已在 `set_clock_groups -exclusive`），不直接跨域采样。

## 寄存器通道（已实现）

不改块设计：借用 GP0 上 `fvdma_ctrl`（`mipicam`）的 64KB 窗口 `0x8030_0000~0x8030_FFFF`，把地址线从 4 位加宽到 16 位，**偏移 `0x1000~0x1FFF` 引出到 PL 顶层的寄存器总线**（`des_clk` 75MHz / `des_wr` 单周期写脉冲 / `des_waddr` / `des_wdata` / `des_raddr` / `des_rdata`）。`0x0000~0x0FFF` 仍是厂家寄存器，`mipicam` 驱动照常使用；厂家寄存器写入已排除我们的地址段。改动见 [pl/soc_base](../pl/soc_base/)，仿真 [pl/sim/tb_des_axi.v](../pl/sim/tb_des_axi.v)。

**`PL_BASE` = `0x8030_1000`**，`des_regs` 寄存器（在 `system_top.v` 里）：

| 偏移 | R/W | 名称 | 说明 |
|---|---|---|---|
| 0x000 | R | `DES_ID` | 固定 `0x44455301`（"DES" + 版本 01） |
| 0x004 | R | `DES_VERSION` | v15 板上 12；v16 = 16（编码见下） |
| 0x008 | R/W | `SCRATCH` | 读写测试 |
| 0x00C | R | `FREE_CNT` | 75MHz 自由计数器（硬件时间戳 / 延迟测量） |
| 0x010 | R/W | `LED_CTRL` | b0 = 接管 LED1，b1 = LED1 亮灭 |
| 0x014 | R | `FRAME_CNT` | ISP 输出帧起始计数（只看 tuser 上升沿） |
| 0x018 | R | `FRAME_TS` | 最近一次帧起始时的 `FREE_CNT` |
| 0x01C | R | `FRAME_PERIOD` | 最近两次帧起始的间隔（75MHz 计数；60fps ≈ 1,250,000） |
| 0x020 | R | `CAP_SEQ` | 已完成的 DMA 取帧次数 |
| 0x024 | R | `CAP_FCNT` | 写模块开始写这一帧时的 `FRAME_CNT` |
| 0x028 / 0x02C | R | `CAP_T0` / `CAP_T1` | 开始写 / 完成中断时的 `FREE_CNT` |
| 0x030 / 0x034 | R | `CAP_POS0` / `CAP_POS1` | 开始写 / 完成中断时的带位置（步进 `POS`） |
| 0x038 / 0x03C | R | `CAP_ENC0` / `CAP_ENC1` | 同一时钟沿的计米轮编码器计数（v16）：图像、步进、编码器三路同刻锁存 |
| 其余 | R | — | 读回 `0xDEADBEEF` |

`DES_VERSION` 编码：12 = v12~v15（v13~v15 是重构 / 重编，寄存器接口未变）；16 = v16（`CAP_ENC0/1` + `des_485`）；v8~v10 未改寄存器接口（v10 只去光源输出、未单独上板），PS 只需判断 5 / 6 / 7 / 11 / 16（拍摄锁存 / `des_vision` / `des_pwm` / `des_io` / `des_485` 与 `CAP_ENC`）。

**拍摄锁存**：厂家帧写模块 `uidbuf_write` 开始写一帧、完成中断 `f2p_irq` 上升沿各翻转一次，经两级同步进 75MHz 域；开始时锁暂存、完成时整组更新 `CAP_*`，PS 在 `WaitFinish` 返回后有整帧时间读。PS 用 `CAP_POS0/1` 按件所在图像行插值，得该行读出时刻的带位置（卷帘快门）。

### 舵机总线主机 `servo_bus`（`PL_BASE + 0x100`）

[pl/soc_base/src/des/servo_bus.v](../pl/soc_base/src/des/servo_bus.v)：115200 8N1 单线半双工，**开漏发送**（只拉低，高电平靠 BSS138 模块上拉），发送期间关闭接收，每次传输后强制留 1 字节时间（约 87µs）的总线换向间隔。PS 只填帧主体，`FF FF` 帧头和校验和由硬件补。

| 偏移 | R/W | 说明 |
|---|---|---|
| 0x100 | W | `CTRL`：b0 发送（自清零）/ b1 等应答 / b2 清状态和计数 / b[14:8] 帧主体字节数（≤64） |
| 0x104 | R | `STATUS`：b0 忙 / b1 完成 / b2 超时 / b3 接收错（校验、长度、帧错）/ b4 应答正确 / b[14:8] 收到字节数 / b[23:16] 舵机状态字节 |
| 0x108 | R/W | 应答超时，单位 µs（默认 3000，从发送结束起算） |
| 0x10C / 0x110 / 0x114 | R | 时间戳（75MHz 计数）：首个起始位 / 最后停止位结束 / 应答收完 |
| 0x118 / 0x11C / 0x120 | R | 计数：超时次数 / 接收错误次数 / 已发帧数 |
| 0x140~0x17F | W/R | 发送缓冲 64 字节：帧主体 `[ID, LEN, INSTR, 参数…]`，字节 i 在第 i/4 个字的 `[8*(i%4)+:8]` |
| 0x180~0x19F | R | 接收缓冲 32 字节：应答去掉 `FF F5` 后的 `[ID, LEN, STATUS, 参数…, CHK]` |

- 仿真 [pl/sim/tb_servo_bus.v](../pl/sim/tb_servo_bus.v)（`run_sim.sh servo_bus`）用协议文档原例当标准答案，全过；SYNC WRITE 帧线上时长与理论一致（数字见 [测试与验证](测试与验证.md)）。
- ⚠ 协议文档 2.3.6 的 SYNC WRITE 例子校验值印的是 `0x8B`，按文档公式算应为 `0xBA`（其余 5 个例子相符）。硬件按公式算；真舵机同步写无反应时先查这里，实测 `0xBA` 正确。

### 步进控制 `stepper_ctrl`（`PL_BASE + 0x200`）

[pl/soc_base/src/des/stepper_ctrl.v](../pl/soc_base/src/des/stepper_ctrl.v)：

- **模式**：速度模式（传送带连续走、改速度自动平滑过渡）+ 位置模式（梯形加减速，停在精确步数）。
- **速度表示**：每时钟前进的步数，Q0.32 定点；`inc = v[步/s] × 2^32 / 75e6`，单位换算由 PS 做；升降速节拍 10kHz。
- **输出极性**：按 TB6600 共阳接法（PUL 低有效、脉冲 5µs；换向后等 10µs 再发脉冲；ENA 使能时输出高）；顶层 `STEP_COMMON_CATHODE=1` 反相为共阴直驱（PUL 高有效，ENA 高 = 脱机），见 [硬件与接线](硬件与接线.md)。
- **运动中改写 `TARGET`**：传送带「停在某步」的做法（减速点自动重算）；目标落在运动方向身后（写得太晚）时减速停在目标之后（`AT_TARGET` = 0），不卡在 moving；改写成恰好等于当前位置则就地停（`AT_TARGET` = 1）。
- **停止**：`estop` 输入或写 HALT 立即停脉冲（不减速），置 HALTED。**速度上限**按每秒 5 万步用（5µs 脉冲需 10µs 周期）。

### PL 视觉 `des_vision`（`PL_BASE + 0x300`）

[pl/soc_base/src/des/des_vision.v](../pl/soc_base/src/des/des_vision.v)：插在 ISP 输出（128 位 AXI-Stream，每拍 4 个 BGRA 像素，MIPI 字节时钟）与写帧 DMA 之间，不反压。对应赛题领域 3：简单级「单路 1080P 图像 PL 采集；**硬件灰度滤波**」、中级「**PL 硬件边缘检测、尺寸粗测量**」。

- 灰度 BT.601（77R+150G+29B）>>8；一块 ERAM 存两行（480×64 位）组成 3×3 窗口；高斯 [1 2 1;2 4 2;1 2 1]/16、Sobel |Gx|+|Gy|，加法树拆 3 级流水。
- **显示模式**（下一帧生效，HDMI 60fps 直接看到）：0 原图（1 拍直通）/ 1 灰度 / 2 高斯 / 3 二值（高斯 ≥ 阈值）/ 4 Sobel（饱和到 255）/ 5 边缘（Sobel ≥ 阈值）；处理模式 6 拍延迟、alpha=0。3×3 结果落在中心左一像素、上一行（不加整行延迟，写帧时序不变）。
- **ROI 统计**（每帧起始发布）：二值图在 ROI（或全帧）内的面积、外接框、Σx / Σy（质心）、边缘像素数、每帧像素时钟数。PS 每帧把 ROI 设到离光轴最近的零件 → 每件「PL 粗测」（面积等效直径、外接框 mm）进记录，与 PS 亚像素测量并排。
- 仿真 [pl/sim/tb_des_vision.v](../pl/sim/tb_des_vision.v)（`run_sim.sh vision`，32×12 帧、随机空拍）：6 种模式逐像素对模型、统计量、ROI、设置下一帧生效等，790 项全过。
- **参数 `LANES`**（布线后备）：4 = 每个像素（默认）；2 = 每拍只处理第 0、2 个像素，滤波 / 统计逻辑约减半，处理图 960 宽，统计按处理的像素计（PS `des_vis_read` 按 `ACTIVE[27:24]` 把面积 / 边缘数 ×4/LANES）。
- 资源（综合）：约 1k LUT + 2 ERAM + 13 DSP。

### 现场输入 `des_io`（`PL_BASE + 0x500`）

[pl/soc_base/src/des/des_io.v](../pl/soc_base/src/des/des_io.v)（从未接入的 `io_sync.v` 已删除、无例化）：

- **急停**（PIN15）：按下保持 1ms 才算（去抖），**锁存**；锁存信号接步进 `estop`（不发脉冲、拒绝启动）。清除只能由 PS 写 `CTRL.b0`，按钮仍按着时清除无效；PS 在任何状态都能读到（`Runner` 进急停态；复位报警时清锁存）。常闭触点硬件断电不变。

- **编码器**（PIN6~8，E6B2-CWZ6C 类，经 BSS138 接入）：两级同步 + 8 拍（约 107ns）滤波，4 倍频（A 超前 B 计正，方向由 PS 配置换算），A/B 同时跳变计为错误，Z 相下降沿锁存计数，10ms 窗口测速。管脚开内部上拉。

- 板上：急停 / 对射状态可读；编码器已接上，手滚一圈计数与 Z 相符（约 4000 计数 / 圈）、err 0，皮带前进时计数减小。⬜ 急停实按 → 锁存 + 界面「急停」、旋开后「复位报警」才清；对射 / 限位实物待接。

### RS485 `des_485`（`PL_BASE + 0x600`，v16）

[pl/soc_base/src/des/des_485.v](../pl/soc_base/src/des/des_485.v)。板载 SP3485EN（J11 第 5 位 485_A、第 6 位 485_B，板上 R121 120Ω 终端）。PS 只写 PDU（地址、功能码、数据，不含 CRC），其余全在 PL：

- 发前等总线静默 t3.5（`T35_US`，PS 按波特率设：3.5 × 11 bit，>19200 时固定 1750µs）；DE 提前 1 bit 拉高，PDU 后补 CRC16（初值 0xFFFF、反射多项式 0xA001、低字节在前），最后一个停止位结束即放 DE。
- 要应答时从发完起计 `TIMEOUT_US` 等第一个起始位；收到的帧以 t3.5 静默判结束，CRC 对全部字节（含 CRC）求余为 0 才算对；8 位数据、校验位 无 / 偶 / 奇、1 停止位；校验位或停止位错、超过 64 字节都单独标出。
- 空闲时总线上出现的帧（PC 当主站）存为监听帧，PS 读后应答清标志；`CTRL` 的 go / 长度和 `TX_BUF` 在传输进行中写入被忽略（不会像 `servo_bus` 那样改到正在发的帧）；`CTRL` b4 中止：A/B 接反或终端无偏置时总线可能一直不静默，PS 驱动超期后中止并报错。
- 仿真 [pl/sim/tb_des_485.v](../pl/sim/tb_des_485.v)（`run_sim.sh rs485`）60 项：行为级从站逐位核对线上字节、CRC 金标准（01 05 00 00 FF 00 → 8C 3A；01 03 00 00 00 0A → C5 CD）、校验位、DE 提前 1 bit / 停止位结束释放，以及应答正确、CRC 错、短帧、校验位错、超时（误差 <1%）、溢出、广播、监听帧、t3.5 间隔、忙时写保护、总线卡低中止。
