# 02 · 视觉与检测

> 检测对象、数据集方向与模型上板路线。相关实测见 `log/`。

## 检测对象与选材准则

选材四条准则：

1. 每类物料必须有足够大的平整面（吸盘吸得住）；
2. 在赛题举例范围内（电子元件 / 塑胶零部件 / 包装流水线）；
3. 缺陷可人工制造、可复现、可批量；
4. 几何规则、尺寸测量有意义。

当前选定：A 电子模块板、B 塑胶注塑件两类打底；C 铝片为扩展项，用于证明强反光金属也可处理。

## 缺陷制造（可复现）

- 模块板：拆元件（缺件）、烙铁点锡连桥（连锡）、刀片划阻焊（划伤）
- 塑胶件：热刀切缺角（缺料）、留毛刺（飞边）、油性笔点/粉尘（脏污）

## 数据集方向

- 每类足量样本，覆盖不同位置、朝向、进入方向、亮度扰动；train/val 按常规比例切分。
- 具体数量目标待 W1 数据采集试验后确定，由数据支撑决策。

## 模型与量化路线

官方两个 ONNX 模型已完成逆向分析，确认其量化格式为 QDQ / UINT8 / per-tensor，与 ONNX Runtime `quantize_static` 的输出特征一致（详细拆解见 `log/`）。

主路线：

```
ultralytics 训 YOLOv8n（8 类）
  → 导出 ONNX，输出截断到 Detect 前的卷积头
  → ORT quantize_static（QDQ，激活/权重 UInt8，per-tensor，校准集）
  → 配套 JSON 换成我们的类别表
  → 用官方 yolo demo 加载上板
```

备选路线（按退化顺序，视实测性能决定）：

1. 降低输入分辨率训练（不追求一上来就用大分辨率）；
2. 改走官方 `yolo_face` 极简结构路线（层数少、算子简单，算力需求低一个量级）;
3. 最保守兜底：照搬 `fire_detect` 网络结构，只改输出通道数换权重。

## 待验证事项

- NPU 量化工具链能否完整走通"自训 → 量化 → 上板"（头号风险，见 [08-排期与风险](08-排期与风险.md)）。
- YOLOv8 的 SiLU 与 Split 算子在 NPU backend 上的实际落点。
- 输入分辨率的最终选择，等推理耗时实测数据。
