# 01 · 系统概述

> 系统的顶层视图：定位、架构与设计原则。实测数据见 `log/`。

## 定位

基于安路飞龙 F3P SoC 的**塑胶传动件注塑后在线质检分拣系统**。检测对象是 POM 齿轮与齿条，覆盖 2026 嵌入式竞赛安路赛道选题四的硬性要求：PL 工业级硬实时功能、PS Linux + 人机界面、PL-PS 双向交互、NPU 缺陷分类、工业总线驱动外设、量化测试报告。

应用领域：**流水线工业视觉检测**（领域 3）为主，融合**多轴运动与机电伺服控制**（领域 1：机械手 + 传送机构）。赛题允许"任选其一或融合多场景"。

## 系统一句话

传送带连续走带 → 相机发现物料、NPU 判类别、视觉给出 (x, y, θ) → 按带位置跟踪每一件 → OK 件到抓取线停带，6 轴机械臂腕旋对准后夹起，按品种放入齿轮盒 / 齿条盒 → NG 和存疑件不停带走到带尾，由翻板分流到 NG 箱 / 复检箱 → PC 经 CAN 当"产线 PLC"下发启停与调速 → HDMI 界面显示画面、计数、曲线与参数。

## 设计原则

1. **A35 只做调度、界面、存储、网络与推理调度**，像素搬运与时序关键的运动控制下沉 PL。
2. **帧率口径分开**：采集 / 显示链路的实时性由 PL 保证；推理按物料触发，不逐帧跑。
3. **位置按编码器（或步进计数）算，不按"速度 × 时间"算**：X = X_拍摄 + (ENC_now − ENC_拍摄)·k。停带、变速、反转时坐标自动正确。
4. **质检逻辑自洽**：OK 盒只有确认的 OK，NG 箱只有确认的 NG，判不准 / 冲突 / 漏检一律进复检。
5. **物料无关的前景定位**：背景差分 / 阈值 + 轮廓，不做绑定单一物料几何的步骤。
6. **指令分辨率与实测精度分开报告**。

## 已锁定的关键决策

| 项 | 决定 |
|---|---|
| 物料 | POM 齿轮 + 齿条，2 品种 × {OK, 缺料, 飞边, 黑点} = 8 类；尺寸超差 / 规格混料由测量判 |
| 分拣 | 多件随机摆放 + 传送带跟踪抓取；机械臂**只夹 OK**；NG 不停带走带尾翻板（两级：复检 vs NG，返修 vs 报废） |
| 机械臂 | DS-SY15A 总线舵机，6 轴全用（#1~#4 + #5 腕旋 + #6 夹爪），**PL 直驱总线（经 BSS138）**；PWM 双驱动降 P2 |
| 急停 | 常闭串在主电源上同时切步进 + 全部舵机；常开报 PL 锁存，需 UI 手动复位 |
| 显示 | HDMI 1080p；必须是真界面（曲线 + 参数配置），不能只放视频流 |
| 语音 + LLM | P2，不挤占 P0/P1，必须有离线命令词表降级 |

## 优先级分级

- **P0（硬性项，砍了不及格）**：① PL 硬实时（**工业总线时序解析 + 多通道同步采集**做实）；② PS Linux + HDMI 界面 + 本地存储；③ PL-PS AXI 双向交互；④ NPU 缺陷分类；⑤ ≥1 路工业总线实际驱动外设；⑥ 完整量化测试报告。
- **P1（加分，按顺序做，做到哪算哪）**：带尾翻板第 1 级 → 多件同时上带 + 粘连跳过 → 编码器 + 失步检测 → PL Sobel / 二值 + 投影尺寸粗测 → 帧起始锁存带位置 → RS485 外设（双总线）→ 2h 连续运行 → 夹爪电流判抓取。
- **P2（P1 全做完才碰）**：回退复检、速度自适应、翻板第 2 级、PL CCL / ROI 缩放 / 张量打包、亚像素、缺陷分级、Web UI、4 轴插补、PWM 双驱动对比、语音 + LLM、4G。

> 主线范围的精简建议（视觉定位先放 PS、带位置先用步进计数、CAN 走 SocketCAN、只做一个 HDMI 界面等）为**草案，待确认**，见 [08-排期与风险](08-排期与风险.md)。
