# 01 · 系统概述

> 系统的顶层视图：定位、架构与设计原则。实测数据见 `log/`。

## 定位

基于安路飞龙 F3P SoC 的智能产线视觉检测分拣系统，覆盖 2026 嵌入式竞赛安路赛道选题四的硬性要求：PL 工业级硬实时功能、PS Linux + 人机界面、PL-PS 双向交互、NPU 缺陷分类、工业总线驱动外设、量化测试报告。

应用领域：以**流水线工业视觉检测**为主，叠加**多轴运动与机电伺服控制**。

## 设计原则

1. **A35 只做调度、界面、存储、网络**，像素级运算一律下沉 PL，NPU 只吃 ROI 小图。
2. **帧率口径分开**：采集 / 预处理 / 显示链路的实时性由 PL 保证；推理按物料触发，不逐帧跑。两者不得混为一谈。
3. **物料无关的前景定位**：背景差分 + 连通域，不做绑定单一物料几何特征（如"圆形裁剪"）的步骤。
4. **双分拣机构**：拨叉在线剔除 NG（随编码器电子齿轮同步，不停带）；机械臂停带精放良品到分类料盒。把停带次数降到最低。
5. **指令分辨率与实测精度分开报告**，不混写。

## 优先级分级

- **P0（硬性项，砍了不及格）**：PL 硬实时三项（多轴伺服 + 工业总线时序解析 + 多通道同步采集）、PS Linux + HDMI 界面 + 本地存储、PL-PS AXI 双向交互、NPU 缺陷分类、≥1 路工业总线实际驱动外设、完整量化测试报告。
- **P1（中级创新，目标全做）**：双总线并行、PL 硬件图像算子与尺寸粗测、多类别检测、本地存储 + 千兆上传、Web UI、长时间连续运行、双重保护、电子齿轮、多轴硬件插补。
- **P2（高级创新，从后往前砍）**：亚像素测量、缺陷分级、速度自适应、PLC 联动、设备健康诊断（第二个 AI 任务）、第三类物料、语音 + LLM、4G 远程、双屏输出。
