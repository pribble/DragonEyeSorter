## 3 分镜 V1~V10

机位：**A** 主三脚架 · **B** 横臂俯拍 · **C** 机械臂近景 · **D** 屏幕 / 仪器 · **E** 微距 · **S** 采集卡录屏。对应：V1 A（横移）、V2 D+C（分屏）、V2b / V3 / V4 / V10 S、V5 B+S、V6 A+录屏、V7 A+B+C（不手持）、V7b B、V8 B+E、V9 C+S（排最后）。

### V1 全景（20s / 正式版 8s）

- **画面**：从带头慢推到带尾：上料 → 相机龙门 + 两侧条形光 → 抓取线与机械臂 → 侧边导流挡板 → 带尾复检箱 → HDMI 显示器 → PC。
- **字幕**：各部件名称（逐个出现）。
- **解说**：「这是一条塑胶齿轮的注塑后质检分拣线，齿轮有多种规格和颜色。核心是一块安路飞龙 F3P 开发板：PL 做硬实时控制和视觉预处理，PS 跑 Linux 做定位、测量和调度，NPU 做缺陷分类。」

### V2 PL 硬实时（45s）

- **操作**：逻辑分析仪接 SERVO_BUS（BSS138 低压侧）与 STEP_PUL；终端 `des_tool.sh arm goto ... --go` 走一个点；同时 `des_app.sh run` 让皮带启停一次。
- **画面**：左：逻辑分析仪一帧 SYNC WRITE + 应答；右：6 个舵机同时动。再切步进 PUL 的加速 / 匀速 / 减速波形。
- **字幕**：「SYNC WRITE 一帧 3.30ms（理论 3.30ms）」「命令 → 首个步进脉冲 10.6µs」
- **解说**：「舵机总线协议在 PL 里用硬件实现：帧头和校验由硬件补、应答由硬件解析并打时间戳，六个舵机用一帧广播同时起跑。传送带步进的梯形加减速也在 PL 里，命令下发到第一个脉冲约十微秒。」

### V2b PL 视觉（30s / 正式版 20s）

- **操作**：界面「参数」页 → 「PL 显示」按钮连点：原图 → 灰度 → 高斯 → 二值 → Sobel → 边缘 → 原图。
- **画面**：HDMI 全屏，右上角帧率保持 60。
- **字幕**：每个模式名；「PL 处理，60fps 不降」
- **解说**：「图像进 DDR 之前，PL 先做灰度、高斯滤波、二值化和 Sobel 边缘检测，并对每个零件的区域统计面积和外接框，作为硬件尺寸粗测。切换模式，帧率始终是六十。」

### V3 界面与存储（45s / 正式版 25s）

- **操作**：鼠标依次点 总览 → 曲线 → 参数（把带速 50 改到 70 再改回）→ 记录（点开一件 NG 的裁切图）；SSH 窗口 `ls /root/des/data/log/<日期>/`、`head -3 parts_*.csv`。
- **字幕**：「每件一行记录（45 列）+ 不良件图像，存 SD 卡」
- **解说**：「操作界面直接画在 HDMI 视频下方：总览看产量良率，曲线页是外径和孔径趋势与过程能力 Cpk，还有命令带速和编码器实测带速两条线，参数改了立即生效，记录页能翻每一件的图像和测量值。每件判定都写进 SD 卡。」

### V4 PL↔PS 双向（15s，并入 V3）

- **操作**：终端 `desreg lat`。
- **字幕**：「PS 读一次 PL 寄存器 188ns；PL 每帧锁存拍摄时刻的带位置」
- **解说**：「PS 和 PL 之间通过 AXI 寄存器双向交换：命令下行，帧号、带位置、舵机应答和视觉统计上行。」

### V5 NPU 分类（40s / 正式版 28s）

- **操作**：放 3~4 件不同类别的零件过视野（正式版 2 件 + 叠加特写）。
- **画面**：HDMI 叠加：跟踪框 + 类别 + 置信度 + NPU 耗时。
- **字幕**：「YOLOv8n-cls，UINT8 量化，单次约 7.9ms；每件 3~6 次投票」（准确率填实测）
- **解说**：「每个零件按自身方向裁成 224 的小图送 NPU 分类，一件在视野里会被分类三到六次，概率平均后再判定。实物验证集上准确率（……）。」

### V6 CAN 产线联动（40s / 正式版 25s）

- **操作**：PC 上 PLC 模拟器：启动 → 调速 80 → 暂停 → 恢复；右侧滚动 PART 帧（正式版只演启动 / 调速 / 暂停）。
- **字幕**：「CAN 2.0A 500kbit/s；命令往返（实测 ms）」
- **解说**：「电脑扮演产线 PLC，通过 CAN 下发启停、调速和配方，板子十赫兹回报状态，每判定一件就发一帧结果。」
- **补拍（10s）**：同一台电脑改用网口 `python pc/modbus/mb_client.py cmd start / speed 30 / cmd stop`，皮带跟着动；字幕「同一套命令也开放为 Modbus-TCP 从站，西门子 / 三菱 PLC 和组态软件可直接接入」。

### V7 分拣闭环（60s / 正式版 55s，主镜头）

- **操作**：随机摆 6~8 件（含良品、缺陷件、混料件）连续上料。
- **画面**：多机位：俯拍皮带 + 机械臂近景 + 导流挡板近景；HDMI 小窗。
- **字幕**：「良品：到抓取线停带 → 夹取 → 按规格 / 颜色入盒」「不良品：不停带，侧边导流挡板拦进报废 / 返修盒，存疑件进带尾复检箱」
- **解说**：「零件随机摆放进入视野，跟踪表按带坐标追踪每一件。良品到抓取线时皮带由 PL 减速正好停准，机械臂按零件角度夹起、按规格和颜色放进料盒；不良品不停带，由皮带边的导流挡板拦进对应料盒，判不准的走到带尾复检。来不及停准的件转复检，绝不倒车。」
- **速度自适应（切 HDMI 曲线页 10s）**：连续两件良品间距较近时，臂还在放料，带速曲线（白 = 命令、绿 = 编码器实测）自动降下、臂空出后回升；字幕「机械臂忙时自动降速，少一次急停急起；绿线为计米轮编码器独立实测」。
- **（若已做）拦截式不停带夹取**：竖直可达区的件，夹爪横跨皮带提前下探，零件穿入两指之间时合爪，皮带不停；字幕「近区不停带拦截夹取，远区停带倾斜夹取」。

### V7b 换型（30s，并入 V7）

- **操作**：停机 → PLC 模拟器配方改 2（28 齿）→ 启动；放 28 齿件和 30 齿件各一件。
- **字幕**：「配方 1：28 齿 = 规格混料 → 报废」「配方 2：28 齿 = 良品，30 齿 → 报废」
- **解说**：「换型只要切配方：同样两个零件，换到二十八齿配方后，去向随之对调。运行中不允许换配方。」

### V8 测量与卡尺（40s，并入 V5 / V3）

- **操作**：同一件齿轮过视野 5 次；手持卡尺量同一件外径（用没参与定偏置的齿轮）。
- **字幕**：「重复性 σ 0.004mm（静止 20 次，实测）；与卡尺偏差（实测）mm」
- **解说**：「测量用亚像素边缘，并补偿了视差和卷帘快门。同一件来回测五次，结果与卡尺对比。」

### V9 可靠性（30s，并入 V7 尾）

- **操作**：运行中按急停：步进与舵机断电、界面变「急停」、PLC 模拟器收到报警帧；复位后启动。再插 2h 运行的延时摄影 + `soak.sh` 汇总。
- **字幕**：「急停：常闭切动力 + 常开报 PL；2h 连续运行 60.02fps」
- **解说**：「急停按下，动力电直接切断，PL 同时锁存急停、停止脉冲并上报。连续运行两小时，帧率和内存都保持稳定。」

### V10 数据（20s / 正式版 8s 片尾）

- 测试报告总表：同步（SYNC 帧时长、命令延迟）/ 采集（帧率、拍摄锁存）/ AI（推理耗时、准确率）/ 总线（CAN 往返、丢帧）/ 分拣（节拍、漏检率、测量误差）。数字取 `part_stats.py` 当天输出与 [测试与验证](../docs/测试与验证.md)。

## 6 录屏 / 收音 / 剪辑要点

**录屏（采集卡 + OBS）**：板子 HDMI → 采集卡（环出接显示器）→ 笔记本 USB 3.0；OBS 用「**视频采集设备**」源，1080p 不缩放、60fps，NVENC（无独显 x264）、CQP 20，48kHz、不开监听，录 MKV 后重封装 MP4，录前「丢帧 0.0%」并试录 30s。板子侧单主人规则：拍摄负责人一人操作，`ssh $BOARD_HOST` → `des_service.sh stop` → `des_app.sh run --can can0 --go` → 拍完 `des_service.sh start`；当天另一条线不上板、不跑长测试、不换 `BOOT.bin`；每段前 `cat /root/des/autostart.conf` 核对 `ARGS`。无采集卡：`ssh $BOARD_HOST 'echo snap > /tmp/des_ui'`（存 `/tmp/des_snap_N.png`）后 `scp` 取回；翻页 `ssh $BOARD_HOST 'echo click <X> <Y> > /tmp/des_ui'`（见 [软件与UI](../docs/软件与UI.md)「脚本输入」）；动作镜头用连续 snap 定格或手机拍屏（亮度 70%、夹角 5~10°）。

**收音与剪辑**：领夹麦 > 录音笔 > 手机（飞行模式），麦夹领口下 15~20cm，峰值 -6~-12dB；**先剪画面、后配音**，语速 4~5 字/秒，逐镜头 1~2 句照 §3 解说词；起录先拍手一次，多机位按拍手帧对齐。剪映新建 1080p 同帧率，按 §2 粗剪卡 **169s**；字幕照 §3 字幕列粘贴（微软雅黑、正文 40~56、白字黑描边、距下边缘 ≥100px）；夹取 / 合挡板 / 舵机动作 0.5x 慢放、等待段 2~4 倍速，不整体变速；BGM 用可商用免费素材并在片尾注明。导出 H.264 **10~12Mbps** + AAC 48kHz MP4，跑 `ffprobe -v error -show_entries format=duration,size,bit_rate -show_entries stream=codec_name,width,height,r_frame_rate -of default=nw=1 <成片.mp4>`：期望 `h264`、1920×1080、`60/1`（或 `30/1`）、≤180s、≤300MB。

### 6.2 OBS 关键设置

采集卡 HDMI IN，OUT 环出接显示器；USB 3.0 口直连笔记本（不经无源 HUB，需要外接供电的卡要接电，否则周期性掉帧）。OBS：画布 / 输出 1920×1080 不缩放；60fps（相机只能 30 就全片 30）；源用「**视频采集设备**」（PC 演示用「窗口采集」，不用「显示器采集」）；**色彩格式 NV12、色彩空间 Rec.709、范围「部分（Limited）」**——相机也设同一档；编码器 NVENC（无独显用 x264），CQP 18~23（推荐 20）或 CBR；音频 48kHz、不开监听；**录制格式 MKV**，录完「重封装录像」成 MP4；输出到笔记本 SSD 单独目录，不写系统盘 / 存储卡。录制前状态栏「丢帧 0.0%」，试录 30s 回放确认。

### 6.3 对时与开拍口令

- **每段起录先拍手一次**（手入画 + 声音尖峰），单机位后期按拍手帧对齐；多机位都拍到同一次拍手，暗环境用手机闪光灯闪一下代替。
- **录屏与实物对齐**：起录后对屏幕做一次可见动作（切一次页）并同时喊口令，用「画面动作帧 + 声音尖峰」对齐。
- 拍前确认 PC 端 PLC 模拟器已连、界面左下显示「已对时」；拍完的 CSV 可与视频时间对账。
- **口令**：「OBS 已录制」→ 场记报「三、二、一」→ 第 3 秒执行动作；停录前静止 2s 再停，给剪辑留余量。

### 6.6 常见问题（拍 / 录 / 剪）

| 现象 | 处理 |
|---|---|
| 横向明暗条带（频闪） | 快门改 1/100；补光灯换直流供电、不用 PWM 调光；关顶灯 |
| 摩尔纹 | 改用采集卡录屏；必须拍屏时亮度 70%、夹角 5~10°、缩短曝光 |
| 反光过曝 | 关顶灯、光 45° 侧打、加 CPL、转零件角度、降一档曝光 |
| 果冻 / 画面歪晃 | 三脚架固定；相机支架与皮带架分开，不让机器振动传上来 |
| 对焦呼吸 | 手动对焦锁死、胶带固定对焦环；拍摄中不变焦 |
| 录音底噪 / 电流声 | 关空调风机；麦克风线不与电源线并行；降增益、后期轻降噪 ≤30% |
| 素材打不开 | OBS 录 MKV 后重封装；每段录完回放；卡满换卡不删；当天双备份 |
| 导出过大 / 超时长 | 码率降到 10~12Mbps；先删 V4 / V9，再压 V1 / V10；**不加速解说** |
| 字幕错别字 | 手打或识别后逐字校对；建术语表；另找一人复读 |
