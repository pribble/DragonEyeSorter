> 赛题条目与镜头的对应见 [参赛材料骨架](../docs/参赛材料骨架.md) §1；**本文是分镜 / 解说 / 字幕 / 时长 / 拍摄 / 交付的唯一源**。

### 5.2 B1 主闭环（V01 V04 V07~V15 V27）

1. A / B / C / S 四路开录，P 同时录 PLC 模拟器窗口（「逐件结果」逐行出现，V19 用）；对着镜头拍一次手（多机位按拍手声对齐）。
2. PLC 模拟器点「启动」（或 HDMI 右栏「启动」）：三色灯绿；空带时右栏「皮带计划」显示快档 80。
3. 按下表顺序放件，件距 ≥30 cm：前一件走过下游 30 cm 的胶带再放下一件（开头空带走快档 80，前两件放得快一点）。

| 序 | 零件 | 横向位置 | 预期去向 | 镜头 |
|---|---|---|---|---|
| ① | 良品 30 齿 | 中线偏机械臂侧 1 cm | 减速停准抓取线 → 夹取 → 蓝色良品料盒；机械臂作业时带速自动降 | V08 V12 |
| ② | 缺料重 | 中线 | 不停带，挡板慢摆 → 报废盒 | V09 |
| ③ | 飞边重 | 中线 | 挡板快摆 → 返修盒 | V10 |
| ④ | 脏污重 | 中线 | 不停带，挡板慢摆 → 报废盒 | V13 |
| ⑤ | 28 齿无缺陷 | 中线 | 测量判规格不符 → 挡板 → 报废盒 | V11 |

4. 横向位置的依据：机械臂可达 y −10~+68 mm（+y 为机械臂侧），y ≥ 40 走转腕夹取；挡板能可靠拦到 y 约 +27 mm。所以良品放 y 0~+30，不良品放 y 0~+15，演示件都不超过 +40。
5. 最后一件落盒后再录 5 s 再停。每条后看 HDMI 记录页最近 5 行，去向和上表一致才算可用；V11 要用的那条，28 齿件的类别应是「良品」、去向「报废」。把料盒里的零件取回。

## 7 剪辑与导出

### 7.1 录屏（采集卡 + OBS）

板子 HDMI → 采集卡（环出接显示器）→ 笔记本 USB 3.0 直连（不经无源 HUB）。OBS：画布 / 输出 1920×1080 不缩放、60 fps；源用「视频采集设备」（PC 画面用「窗口采集」）；色彩格式 NV12、色彩空间 Rec.709、范围「部分」；编码器 NVENC（无独显用 x264），CQP 20；音频 48 kHz、不开监听；录 MKV，录完「重封装录像」成 MP4；输出到 SSD 单独目录。录前状态栏「丢帧 0.0%」，试录 30 s 回放。

### 7.2 收音与配音

- 配音推荐真人：按 §2 的 8 段各录一个文件，照 §3 解说列念，语速约 5 字/秒；段前段后各留 1 s 静音，念错停 1 s 重念整句。
- 设备：领夹麦 > 录音笔 > 手机（飞行模式，离嘴 20~30 cm）；安静房间，关空调风机；峰值 −6~−12 dB。
- 先剪画面、后铺配音；起录先拍手一次，多机位按拍手帧对齐。

### 7.3 变速规范

| 素材 | 倍速 | 说明 |
|---|---|---|
| 皮带输送、零件走过视野、上料 | ×2 | 只加速等待段 |
| 机械臂转向料盒、回初始姿态 | ×2 | 夹取本身保持原速 |
| 换型后等零件走到机械臂 | ×3 | — |
| 界面翻页、PLC 模拟器 / 运维站操作 | ×1.5 | 鼠标移动段 |
| 终端敲命令 | ×3 | 最好提前粘好命令，只录回车后的输出 |
| 计时窗口录像 | 延时 | 角标写「延时」 |
| 夹爪合拢、返修件快摆 0.6 s、零件落盒、6 轴起步 | 0.5× | 需 60 fps 素材 |
| PL 六种显示、帧率画面、报警瞬间、报废慢摆 2.75 s | 原速 | 画面本身是证据，不改速 |

- 角标统一放右上角：白字、半透明黑底、36 号左右。
- 加速段静音或只留很低的环境声；解说任何时候都不变速；不整片统一加速；同一镜头内变速用曲线变速平滑过渡。

### 7.4 剪辑步骤

1. 素材先统一成 1920×1080、60 fps 恒定帧率（手机素材多为可变帧率，直接剪会音画漂移）。
2. 按 §3 时间码排画面，卡到 171 s 左右；段内硬切，段与段之间 0.3~0.5 s 交叉淡化；片头片尾淡入淡出。
3. 配音降噪、响度统一到约 −16 LUFS，按段对齐到画面；BGM 用可商用免费音乐，压在解说下约 −20 dB，解说时自动压低。
4. 解说字幕按配音逐句对齐，文字照 §3 解说列（不靠语音识别）；技术标注照 §3 屏上标注；规范见 §7.5。
5. 作品名：0:00–0:02 右下角标，片尾 3 s 再出一次；片尾小字注明 BGM 与字体来源。
6. 导出：MP4，H.264 10 Mbps，AAC 48 kHz；核对时长 ≤180 s、大小 ≤300 MB、编码 h264（`ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height -of default=nw=1 <成片.mp4>`，没有 ffprobe 用 `ffmpeg -i <成片.mp4>` 看）。
7. 文件名 `基于FPGA的工业智能检测系统_演示视频_3min.mp4`（命名见 [提交材料清单](提交材料清单.md) §5）。

### 7.5 字幕规范

| 项 | 规范 |
|---|---|
| 字体 / 字号 | 微软雅黑（在意授权换思源黑体 / Noto Sans SC，片尾注明）；解说字幕 44~52、技术标注 40~48、数据卡 48 |
| 颜色 / 位置 | 白字 + 黑描边 3~5 px；解说字幕距下边缘 ≥100 px；技术标注放画面上方或侧边，不挡零件和机械臂 |
| 行数 / 时码 | 解说字幕单行 ≤18 字、最多 2 行；每条 ≥1.5 s；同屏不叠两条解说字幕 |
| 术语 | PL / PS / NPU / SYNC WRITE / Modbus-TCP / RS485 / Cpk 写法统一；禁项同 §8 |

### 7.6 超时删减顺序

剪完超过 180 s，或某个镜头没拍成，按顺序删：① V23 的 PI 前半（−2 s）；② V21 缩到 2 s（−2 s）；③ V02 并入 V01 标签（−3 s）；④ V25 改成 V26 里一行字（−4 s）；⑤ V20 只留终端命令 + 抓取 3 s（−5 s）。**不能删**：V03、V04、V08~V11、V14、V16、V17、V19、V22、V26，这些是硬性要求和核心创新的唯一证据。

### 7.7 素材整理与交付

- 素材只放本机素材目录，不入库：`raw/B1/`~`raw/B7/`（相机 / 手机原片）、`screen/`（S、P 录屏）、`audio/`（配音）、`bgm/`、`data/`（`part_stats.py` 输出）、`edit/`、`out/`。
- 文件名 `<组>_take<N>_<机位>`（例 `B1_take2_C.mp4`），录屏 `S_<内容>.mkv`、`P_<内容>.mkv`，配音 `VO_<段号>_take<N>.wav`；原片不转码、不压缩。
- 场记表（§12）每个镜头写清：用哪个文件、可用片段起止（mm:ss，到秒）、拍手时刻；剪辑按场记取片段。
- BGM 附来源链接；收工前全部素材拷到笔记本 + 移动硬盘两份并比对哈希，原始卡不格式化。

### 7.8 常见问题

| 现象 | 处理 |
|---|---|
| 横向明暗条带（频闪） | 快门改 1/100；补光灯用直流供电、不用 PWM 调光；关顶灯 |
| 摩尔纹 | 改用采集卡录屏；必须拍屏时亮度 70%、夹角 5~10° |
| 反光过曝 | 关顶灯、光 45° 侧打、转零件角度、降一档曝光 |
| 画面发灰 / 颜色不对 | 手机关 HDR 视频后重拍 |
| 果冻 / 画面晃 | 三脚架与皮带架分开放，不让机器振动传上来 |
| 录音底噪 | 关空调风机；麦克风线不与电源线并行；后期轻降噪 |
| 素材打不开 | OBS 录 MKV 后重封装；每段录完回放；卡满换卡不删 |
| 导出过大 / 超时长 | 码率降到 8~10 Mbps；按 §7.6 删减；**不加速解说** |

## 10 风险与现场备选

| 风险 | 预防 | 现场备选 |
|---|---|---|
| 机械臂偶发夹空（步进驱动器干扰舵机总线，软件会重发兜底） | 每组至少 3 条 take | 用去向全对的那条 |
| 挡板没拦住不良品 | 不良品放中线（y 0~+15 mm） | 重拍这一件 |
| 零件太挤 → 跟丢 / 挡板冲突改走复检 | 件距 ≥30 cm | 重拍 |
| 良品没被夹、走了复检 | 良品放中线到偏机械臂侧 3 cm，不超过 4 cm | 记录页看原因后重拍 |
| HDMI 偶发黑屏 | 拍前连录 10 min | 剪掉黑帧；严重时改用 snap 截图 + 手机拍屏 |
| 三色灯一直亮黄（有未确认工单） | 开拍前运维页「全部确认」 | 同左 |
| 运行中关了运维站 → 「PLC 通信中断」+ 黄灯 | 先停线再关运维站 | 运维页「全部确认」 |
| 配方忘了切回 1 | B4 结束立刻切回并在参数页核对 | 之后的镜头重拍 |
| 下发带速后皮带看不出变化 | 空带自动走快档 80，演示调速下发 120 | 有零件过判定线后才回设定带速 |
| 急停后机械臂软掉 | 有人托住小臂；急停排最后 | — |
| 人为故障打断计时窗口 | B6 放到窗口满之后 | — |
