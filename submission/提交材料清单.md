## 3 赛题条目 → 材料对应

赛题四的 6 项硬性要求与领域 / 拓展项逐条对应的证据（报告章节、视频镜头）唯一源是 [参赛材料骨架](../docs/参赛材料骨架.md) 的「赛题条目 → 证据」，不在此复制。交件时只记评分口径：基础必做 6 项 + 发挥拓展项，**「全部功能仅 PS 实现」扣分** → 报告与视频都要讲清 PL 侧硬件实现（[选题指南](../docs/ref/安路赛道选题指南_2026.pdf) p31~33）。

## 6 上传前检查表

- [ ] 报告 / 视频内**没有**学校名称、校徽、指导老师姓名（2026 应用赛道明文规定；FPGA 赛道按最严执行）
- [ ] 报告内每个数字都能在 [测试与验证](../docs/测试与验证.md) 或当日实测输出里找到出处；未实测项写「未测」并标 ⚠
- [ ] 报告为**纯论文式**：无封面、无目录、无页眉；首页第一行为作品标题，与官网报名作品名**完全一致**；页脚居中页码从 1 起（DOCX 转 PDF 后翻一遍）
- [ ] PDF ≤50MB；浏览器 / Adobe 打开正常，图不糊、字体已嵌入；插图等效 dpi ≥300 且落版最小字号 ≥7pt（作图按 ≥7.5pt，`verify_report.py` 会把关）
- [ ] 占位图已全部替换为实物照片：12 张图齐全，图 1、2、7、8、10、11、12 对应的 `ph_*.png` 已清零且 `placeholder_manifest.json` 的 `replaced` 置 true；`python submission/build/verify_report.py --final` 通过
- [ ] 视频 ≤3 分钟、开头 2 秒内进入作品画面；H.264；≤300MB（按 2026 应用赛道更严口径准备）
- [ ] 视频不是 PPT 讲解录屏，重心在实物演示（官方明文）；音乐 / 字体为可商用免费素材，片尾注明来源
- [ ] 作品照片：整机全局 1 张 + 开发板高清特写 1 张以上，能看清主控丝印与接线
- [ ] 代码包解压后能看懂结构、能按 README 构建；无本机绝对路径、无密钥、无 `.env`
- [ ] 第三方代码与来源（报告附录 A）已随代码 / 报告提交，原创性经得起查
- [ ] 文件名与官网作品名一致，上传后官网回执截图留档

## 7 决赛准备（现场）

初赛入围后，决赛为现场评审：**FPGA 基础编程考核 + 作品介绍及演示 + 专家提问**。除初赛材料外还要带：

| 项 | 内容 |
|---|---|
| 演示视频 | 完整版与 3min 版 MP4 各一份，离线可播（现场网络不可靠） |
| 实物与备件 | 整机 + 板卡 + SD 卡（含可用 `BOOT.bin`，另备 `BOOT.bin.prev`）、备用舵机 / 线材 / 保险 / 电源模块 |
| 现场工具 | 逻辑分析仪、卡尺、万用表、螺丝刀、扎带、对射光电备件 |
| 安全 | 急停随手可及；机械臂工作半径清场；新接电源前逐个测舵机 V+~GND 电阻与旷量 |
| FPGA 编程考核 | 官方明确「通过考核才获得决赛评奖资格」——准备 TD / FD 基础操作与 Verilog 时序、状态机类题目 |
| 问辩预案 | ① 第三方代码与来源（报告附录 A）② 每个数字的来源与口径（指向 [测试与验证](../docs/测试与验证.md)）③ 未测项直接说未测 ④ PL / PS 分工边界（「全部功能仅 PS 实现扣分」）⑤ RS485、同步误差等待补项的诚实口径 |
| 展示排练 | 按演示流程排 5~8 分钟；演示动作先在板上跑一遍（现场流程见 [到货联调清单](../docs/到货联调清单.md)「整机」） |
