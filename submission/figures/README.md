# figures/ — 作品报告插图（脚本生成，不手工画）

本目录是报告插图的**唯一位置**：15 张图的生成脚本入库——9 张线稿图（`fig_*.py`）+ 6 张「待插入实物图」占位图（`make_placeholders.py` + `placeholder_manifest.json`）+ 页眉 logo（`logo_header.png`，从官方模板 PDF 渲染、唯一入库的图片）；生成物（SVG / PNG / `fig_meta.json`）由 `make_figures.py` 重画、不入库（见 `.gitignore`）。报告 15 张图按编号：图 1 设计流程、图 2 系统架构、图 3 时间基准、图 4 工位布局、图 5 PL 寄存器与引脚、图 6 系统电气连接、图 7 软件单件处理流程、图 8 抓取 / 导流时序、图 9 整幅与 ROI 对比、图 10 七类缺陷样件、图 11 整机实物正面与斜 45°、图 12 机械臂、图 13 电控盘俯视、图 14 HDMI 界面七页、图 15 七类逐类准确率（图 9~14 为实物图，已全部替换）。只有作品报告用这一套——[技术文档](../技术文档.md) 按 `figures/fig_*.png` 与 `figures/ph_*.png` 引用，[build.ps1](../build/build.ps1) 每次先重画再排进 PDF，[verify_report.py](../build/verify_report.py) 读本目录的 `fig_meta.json` 复核落版字号（只登记报告实际引用的 14 条）。

**其余 2 项实物照片**（导流挡板 / 测试现场）**不进报告版面**：官方提交页已无单独的「作品照片」上传项，报告按官方模板第三部分「实物照片为主」的要求把机械臂 / 开发板 / 界面照片排进 3.2（图 12~14 占位）；这 2 项只作为「决赛展示 + 演示视频」的拍摄清单保留在本目录（`placeholder_manifest.json` 里 `in_report: false` 的 2 项 + 本文「作品照片与视频拍摄清单」一节），**不生成 PNG、不占报告图号**。整机全景同一张照片两用（报告图 11 + 决赛展示主图）。

仓库工程文档用的整机接线图不在这里：它在 [docs/figures/](../../docs/figures/)（`make_system_wiring.py`，给 [硬件与接线](../../docs/硬件与接线.md) 用，不占报告版心）。

## 一条必须守住的规则：按落版尺寸作图

画布单位是 **pt，画布宽固定 447.9pt = 报告落版宽 15.8cm**，所以**图里写的字号就是纸上的字号**。

插图必须**按落版尺寸 1:1 作画**：若按 16in（1152pt）画布作图、再缩到 15.8cm 落版，图里 8pt 的字落到纸面只剩约 3.1pt，整片文字读不动。作图门槛：**任何一张图的最小字号 ≥ 7.5pt**（设计值）；报告侧自检按本目录 `fig_meta.json` 折算的等效落版字号，门禁 **≥ 7pt**（`verify_report.py` 的 `MIN_FIG_PT=7.0`）。配套三条约定：

- 字号只取 `figkit.FS` 的档位：框内正文 8.5pt / 次级与注释 7.5pt / 组标题 9.5pt，不在画图代码里写别的数字（占位图同理：9.5 / 8.5 / 7.5pt 三档）。
- 标签短句化：每行 ≤ 12 个汉字当量，细节写进正文；**不画图内标题**（标题由报告图注承担）。占位图的「说明 / 拍摄要求」两行是交件前照着拍的提示、不是图内标签，按整行排（≤ 40 汉字当量），不受 12 字限制。
- 文字一律用 `figkit.box()` / `text()` / `group()` 画：保存前核对**是否越出盒子或画布**（> 0.5pt 报错，< 2pt 提示「偏紧」），并打印每张图的最小字号与最小盒内余量。排版靠数据，不靠目测。
- 图的**落版高度**还是版面旋钮：插图变高会把下游整块（表格 / 带标题段落）挤到下页、留下半空页，`verify_report.py` 的「无正文页被撑空」会拦——调版面先调图高（图 9 / 10 / 11 的比例在 manifest，图 15 的画布在 `fig_perclass.py` 的 `H`），不动正文。

## 渲染：期刊线稿风（唯一一套）

白底、方框细边、灰色虚线分组框、黑色细箭头、Times 西文 + 宋体中文；颜色不参与信息表达，只用黑 / 灰，分组靠标签与虚线框。数据表型插图（图 5 寄存器段表）用**三线表**（顶线 / 底线 + 行间极浅分隔），列不加竖线、不用行卡；图 15 逐类准确率条形图同为黑 / 灰，柱内标判对数 / 总数。交换协议 / 方向必须说明时才加 7.5pt 标签。占位图沿用同一套观感（白底 + 灰色虚线边框 + 极浅灰填充），只是框里没有图元、换成三行提示字。

## 用法

```powershell
python submission/figures/make_figures.py                # 重画全部 15 张（9 线稿 + 6 报告内占位）
python submission/figures/make_figures.py arch time      # 只重画名字里含 arch / time 的线稿图
python submission/figures/make_figures.py ph             # 只重画 6 张报告内占位图（图 9~14）
python submission/figures/make_figures.py ui             # 只重画 id 含 ui 的占位图（图 14）
python submission/figures/fig_perclass.py                # 单张线稿调试（跑单张 + 打印该图门禁）
python submission/figures/make_placeholders.py           # 单跑报告内占位图（6 张 + 打印每张三行字宽度）
```

导出 SVG（矢量、文字可编辑）+ PNG 宽 3200px（报告满版心 15.8cm 时 ≈514 dpi），同时写 `fig_meta.json`（画布尺寸、`px_per_pt`、最小字号；只登记报告引用的 15 张，已移出报告的旧记录会被清掉）。**改插图后重跑一次即可**（只有一套图）；生成物不入库（重画即得），本目录只提交脚本 + README + 清单 + 页眉 logo。`build.ps1` 每次出报告前会自动先跑本脚本（第 0/3 步），所以改完图脚本直接重出报告也行。

### 拍了实物 / 备好素材之后：只换这几张 PNG，不动正文

正文里的 `![](figures/ph_roi.png)`、`![](figures/ph_samples.png)`、`![](figures/ph_overview.png)`、`![](figures/ph_arm.png)`、`![](figures/ph_board.png)`、`![](figures/ph_ui.png)` 与图注已按最终说明写好，替换时**只动图、不动 [技术文档](../技术文档.md)**：

1. 按上表「目标像素」裁切 / 缩放（图 10 / 11 为 2:1、图 14 为 8:9、图 9 为 12:5、图 12 / 13 为 3:2；等效 322 dpi 即可，交件 PDF ≤50MB），存到本目录、覆盖同名 `ph_*.png`。
2. 打开 `placeholder_manifest.json`，把该项 `"replaced"` 从 `false` 改 `true`。**必须改**：否则下次 `make_figures.py`（`build.ps1` 第 0 步会自动跑）会用占位图把实物图盖掉。改后该项跳过不画，只按实物图实际像素更新 `fig_meta.json` 的尺寸。
3. 重出报告：`pwsh -File submission/build/build.ps1`（其余图照常重画）。注意插图高度变化会牵动下游分页——若出现半空页，先按「按落版尺寸作图」一节调图高或图 9~11 的 manifest 比例。

替换后的实物 PNG 建议入库留档：`.gitignore` 挡的是生成物，实物图要 `git add -f submission/figures/ph_roi.png submission/figures/ph_samples.png submission/figures/ph_overview.png submission/figures/ph_arm.png submission/figures/ph_board.png submission/figures/ph_ui.png` 强制加。

### 替换后怎么验

- `python submission/build/verify_report.py --final`：报告插图等效 dpi ≥ 300、落版最小字号 ≥ 7pt；`--final` 模式下 `in_report=true` 的占位图仍有 `replaced: false` 判 FAIL（交件前必须清零；报告外 2 项不参与该门禁）。
- 只验占位图本身：`python submission/figures/make_placeholders.py` 打印每张的最小字号（7.5pt）与三行字的实测宽度 / 左右余量；有越界或字号不足会打 `ERR` 并以退出码 1 结束。
- 核对 `fig_meta.json`：10 条齐全（6 线稿 + 4 张占位），每条 `px_per_pt × 72 ≈ 514 dpi`（3200 px / 15.8cm）。
