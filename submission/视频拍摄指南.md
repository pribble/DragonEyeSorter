# 视频拍摄指南（怎么拍 / 录屏 / 收音 / 剪辑 / 导出 / 合规）

> 本文件只管**怎么拍**：交付规格、器材、参数、机位、录屏、收音、剪辑、导出、合规与拍摄日安排。
> **分镜 / 解说词 / 字幕 / 时长以 [演示视频脚本](../docs/演示视频脚本.md) 为唯一源**：拍什么看它，怎么拍看本文，本文不重复它的内容。
> 实测数字以 [测试与验证](../docs/测试与验证.md) 为唯一源；官方规格、命名与倒排以 [提交材料清单](提交材料清单.md) 为准。

## 1 交付规格与两版成品

### 1.1 硬规格

| 项 | 要求 | 口径 |
|---|---|---|
| 成品分工 | 素材全量拍；**正式提交只交 3 分钟版**（§1.2）；5 分钟完整版（§1.3）只自留、决赛现场备用，**不主动上传** | 已拍板 |
| 容器 / 编码 | MP4，视频 AVC(H.264)，音频 AAC 48kHz，1920×1080 | **按严口径**：2025 FPGA 赛道明文 |
| 时长 | **≤3 分钟（180s）** | **按严口径**：2025 FPGA 赛道与 2026 应用赛道同为 3min |
| 大小 | **≤300MB**；600MB 只作上限备注 | **按严口径**：取 2026 应用赛道的 300MB，比 2025 的 600MB 严 |
| 画面 | 帧率 60 或 30，全片统一且与录屏一致 | **按严口径**：采集链路与相机同一帧率 |
| 内容 / 封面 | 重点作品演示（实物），**不得做成 PPT 讲解录屏**；2026 应用赛道「统一封面 ≤2s」且开头 2s 内必须出现作品画面 | 官方明文；**不做独立封面卡**，见 §1.2 |
| 2026 正式要求 | 官方「另行通知」，发布后按 [提交材料清单](提交材料清单.md) §7 逐条核对；正式版仍按 ≤300MB / ≤180s 准备 | 不猜，发布后再放宽或加严 |

### 1.2 3 分钟正式版（**唯一上交版**，逐镜头时长建议）

脚本正文按 6~7 分钟设计（全部镜头合计约 415s），**正式版按脚本「保底版」清单压缩**：脚本给的保底版合计 190s，仍超 180s，下表按下限重排到 169s，留 11s 余量。

| 顺序 | 内容 | 脚本保底版 | 正式版建议 | 压缩手法 |
|---|---|---|---|---|
| 1 | V1 全景 | 10s | **8s** | 只留 3 个部件名角标，横移不减速 |
| 2 | V7 分拣闭环（主镜头） | 60s | **55s** | 不删动作，删等待；空档 2~4 倍速 |
| 3 | V2b PL 视觉 | 20s | **20s** | 6 个模式各 3s，片头尾各 1s |
| 4 | V3 界面与存储 | 30s | **25s** | 五页每页 4~5s；V4 并入本段（终端窗口切 3s） |
| 5 | V5 NPU 分类 | 30s | **28s** | 2 件过视野 + 叠加特写，不摆第 3 件 |
| 6 | V6 CAN | 30s | **25s** | 只演启动 / 调速 / 暂停，暂停恢复合并 |
| 7 | V10 数据 | 10s | **8s** | 只留 6 个数字，每个 1.5s 字幕 |
| — | 合计（含 2s 内作品名角标） | 190s | **169s** | 余量 11s，不给任何单镜头加时 |

补充口径：

- 硬性要求①（PL 硬实时）用 V7 的舵机同步动作画面 + 一条 2s 字幕覆盖（帧长数字照脚本 V2 字幕），不单独占镜头时间；V2 的逻辑分析仪素材、V7b 换型、V8 卡尺、V9 急停都留给完整版，正式版只取 3~5s 画面或字幕。
- 封面与开头：不做独立封面卡，第一帧就是 V1 实物画面，作品名做成右下角角标 ≤2s。若官方模板要求封面卡，则封面 ≤2s、第 2 秒内切进实物，总时长 171s，仍在 180s 内。

### 1.3 5 分钟完整版（**只自留**，不主动上传）

按脚本正文全量收镜头，只压时长：V1 12s / V2 30s / V2b 25s / V3 35s / V4 8s / V5 30s / V6 30s / V7 50s / V7b 20s / V8 25s / V9 20s / V10 15s，合计 **300s**。脚本正文全部镜头合计约 415s，多出部分留作备用素材。用途：自留归档、决赛现场备用；**只交 3 分钟正式版**，官方若明确要求再交完整版（交前按 §1.4 降到 7~8Mbps）。

### 1.4 码率与体积（先定时长，再定码率）

1080p60 的 H.264 常用 12~20Mbps；有大小上限时必须反算。体积 ≈ 码率 × 时长 ÷ 8。

| 版本 | 时长 | 码率 | 体积 | 用途 |
|---|---|---|---|---|
| **正式版（唯一上交）** | 169~180s | **10~12Mbps** | 12Mbps × 180s ÷ 8 = 270MB | 上交，稳过 ≤300MB |
| 完整版（只自留） | ≤300s | 12~16Mbps | 12Mbps × 300s ÷ 8 = 450MB | 不主动上传；600MB 是绝对上限 |
| 完整版（官方若要） | ≤300s | 7~8Mbps | 7.5Mbps × 300s ÷ 8 = 281MB | 才可上传，按 ≤300MB |

## 3 拍摄参数（相机 / 手机通用）

| 项 | 设定 |
|---|---|
| 白平衡 | 手动 K 值（5600K 起，按试拍微调），全程锁定；禁用自动白平衡 |
| 曝光 | M 档锁定：先按最亮部不过曝定光圈 / 快门 / ISO，整段沿用 |
| 快门 | **1/100~1/120**（中国 50Hz 灯光避频闪）；画面出现横向明暗条带就改 1/100 |
| ISO | 尽量低（相机 ≤400、手机 ≤200）；宁可加光，不加 ISO |
| 对焦 | 手动对焦锁死（MF + 峰值对焦），用零件对一次后贴胶带固定对焦环 |
| 数码变焦 / 美颜 | 关闭。美颜会抹平缺陷细节，数码变焦会糊 |
| 拍摄中 | 不变焦、不改曝光、不走动；要换景别就停机调机位 |
| 帧率 | 1080p60；相机只能 30 就全片 30（含 OBS），**不混帧率** |
| 防抖 / 色彩风格 | 上脚架就关电子防抖（会裁切画面并抖动），手持才开；全片同一档色彩（标准），中途不换机内风格 |
| 拍屏时 | 屏幕亮度 70%，关动态对比度 / 锐化 / 护眼模式 |

| 镜头 | 机位 | 景别 | 运镜 | 正式版时长 | 注意事项 |
|---|---|---|---|---|---|
| V1 全景 | A | 全景 | 滑轨横移带首 → 带尾，速度 ≤5cm/s；无滑轨改固定 + 后期缓推 | 8s | 起点拍到上料口，终点收在全景；轨道上不放线缆 |
| V2 PL 硬实时 | D + C | 屏幕特写 + 臂中景 | 固定，两画面后期分屏 | 0（用 2s 字幕） | 逻辑分析仪屏幕正对镜头、微俯，探头线不遮屏；房间灯不直射屏幕 |
| V2b PL 视觉 | S | HDMI 全屏 | 不运镜，按脚本切换 PL 显示模式 | 20s | **用采集卡录，不拍屏**；每模式停 3s，右上角帧率要清楚 |
| V3 界面与存储 | S + 鼠标 | HDMI 全屏 | 不运镜，依次点五页 | 25s | 鼠标指针调大；指针不要停在数字上；V4 终端窗口字号 ≥18pt、纯黑底 |

| V6 CAN | 笔记本录屏 + A | 分屏 | 不运镜 | 25s | PC 桌面清空、关通知、不开聊天软件（§8.1） |
| V7 分拣闭环 | A + B + C | 全景 + 俯拍 + 近景 | 三机位各自固定，后期切；**不手持跟拍** | 55s | 俯拍必须横臂垂直向下；机械臂近景在安全半径外；挡板近景用低角度 |
| V7b 换型 | B | 俯拍 | 固定 | 并入 V7 | 换型前后同一机位同一高度，画面可比 |
| V8 测量与卡尺 | B + E | 俯拍 + 微距 | 固定 | 并入 V5 / V3 | 卡尺读数正对镜头；白卡纸做底、双灯 45° 打 |
| V9 可靠性 | C + S + 延时 | 中景 + 界面 | 固定；延时用三脚架 + 间隔拍摄（1 张 / 5s） | 并入 V7 结尾 | 排在最后一个拍（按急停会切动力电）；延时素材提前一天录 |

## 5 录屏：HDMI 采集卡 + OBS

### 5.1 连接

1. 板子 HDMI → 采集卡 IN；采集卡 OUT（环出）→ 显示器（现场操作仍看大屏）。
2. 采集卡 USB → 笔记本 **USB 3.0 口**，不经无源 HUB；需要外接供电的卡要接上，供电不足会周期性掉帧。
3. OBS 里加「**视频采集设备**」源（选采集卡），不要用「显示器采集」。

### 5.2 OBS 设置

| 项 | 值 | 说明 |
|---|---|---|
| 画布 / 输出分辨率 | 1920×1080 / 1920×1080 | 不缩放 |
| 帧率 | 60（与 HDMI 链路一致；相机只能 30 就整体改 30） | 全片唯一帧率 |
| 视频源 | 「视频采集设备」；PC 演示用「窗口采集」 | 不用「显示器采集」接采集卡 |
| 色彩格式 / 空间 | NV12；Rec.709 / 部分（Limited） | 相机也设同一档 |
| 编码器 / 码率控制 | 硬件 NVENC（N 卡），无独显用 x264；CQP 18~23（推荐 20）或 CBR | 录屏留画质，成片再压 |
| 音频 | 48kHz；采集卡无音频就静音该源 | **不开监听**（会啸叫 / 回声） |
| 录制格式 | MKV，录完「重封装录像」成 MP4 | 断电不毁文件 |
| 输出路径 | 笔记本 SSD 单独目录 `screen/` | 不写系统盘、不写存储卡 |
| 录制前 | 状态栏「丢帧 0.0%」，试录 30s 回放确认 | 有丢帧先换 USB 口 / 关其他占用 |

板子侧（**当天单主人规则**）：板上 `autostart.conf` 现为 `ARGS=""`，自启时机械臂不真动，而 V7 抓取需要 `--go`。拍摄当天由**拍摄负责人一人**统一操作：`ssh $BOARD_HOST` → `/root/des/des_service.sh stop` → 手工 `des_app.sh run --can can0 --go`（或按当次镜头需要）→ 拍完 `des_service.sh start` 恢复；**当天另一条线不安排上板操作，也不做长测试、不换 `BOOT.bin`**（见 [AGENTS.md](../AGENTS.md)「Git 与板子」）。每段开拍前 `cat /root/des/autostart.conf` 核对一次 `ARGS` 与预期一致。

### 5.3 无采集卡的降级路径

```bash
ssh $BOARD_HOST 'echo snap > /tmp/des_ui'         # 下一帧存为 /tmp/des_snap_N.png
scp $BOARD_HOST:/tmp/des_snap_1.png ./raw/v3/     # 取回本地
```

- 界面翻页用脚本点击：`ssh $BOARD_HOST 'echo click <X> <Y> > /tmp/des_ui'`；命令与截图命名见 [软件与UI](../docs/软件与UI.md)「脚本输入」，界面布局（画面 1440×780 + 右栏 480×780 + 底栏 1920×300）见 [技术文档](../docs/技术文档.md) §4.6，坐标先用一张 `snap` 截图量像素。
- 截图是静帧：动作类镜头（改带速、翻记录页）用「连续 snap + 逐帧排」做定格动画（2~3 张 / 秒，后期每张排 2~3 帧），或直接手机拍屏。
- 手机拍屏：手机架三脚架正对显示器，屏幕亮度 70%，手机与屏面夹角 5~10°（避摩尔纹），点测光对屏幕白色区域后压一档曝光，关掉所有机内美颜与降噪。

### 5.4 对时与开拍口令

| 目的 | 做法 |
|---|---|
| 音画对齐（单机位） | 每段起录后先拍手一次（手入画 + 声音尖峰），后期按拍手帧对齐 |
| 多机位对齐 | 所有机位都拍到同一次拍手；暗环境用手机闪光灯闪一下代替 |
| 录屏与实物对齐 | 起录后对屏幕做一次可见动作（切一次页）并同时喊口令，用「画面动作帧 + 声音尖峰」对齐 |
| 板子时钟 / CSV | PC 端 PLC 模拟器连上即发 TIME，界面左下显示「已对时」；拍前确认，拍完的 CSV 可与视频时间对账 |
| 开拍口令 | 「OBS 已录制」→ 场记报「三、二、一」→ 第 3 秒执行动作；停录前静止 2s 再停，给剪辑留余量 |

## 6 收音与解说录音

| 项 | 做法 |
|---|---|
| 方案优先级 | 领夹麦 / 无线小蜜蜂 > 录音笔 > 手机（飞行模式） |
| 麦位 | 夹在领口下方 15~20cm，线从衣服内侧走并留一段松弛；套防风毛套 |
| 电平 | 峰值 -6~-12dB，不削顶；开机先试录 10s 回放听 |
| 录法 | **先剪画面、后配音**；逐镜头录，每镜头 1~2 句（照 [演示视频脚本](../docs/演示视频脚本.md)）；念错重念整句，不剪半句 |
| 语速 | 4~5 字/秒；用「字数 ÷ 4.5」估片长，解说占镜头时长 40~70%，其余留给动作声 |
| 环境 | 关空调 / 风扇 / 除湿机；麦克风线不与电源线并行；麦距板子风扇 ≥1m，风扇起风就停 3s 重录 |
| 降噪 / 口水音 | 先剪掉明显噪声段，再上轻降噪（强度 ≤30%），重降噪会发闷、齿音变味；口水音放大波形剪掉尖峰，切口两端加 5~10ms 淡入淡出 |
| 现场声 | 保留 10~20% 皮带 / 舵机动作声（压到 -24dB 左右），比纯 BGM 真实 |
| BGM | 只用可商用免费素材（剪映音乐库标注可商用的曲目 / YouTube Audio Library / Free Music Archive 的 CC0）；音量 -18~-24dB，解说段闪避到 -28dB；不用带人声的 BGM |
| 出处 | 片尾字幕写明「音乐：曲名 — 作者 — 许可 — 来源 URL」；字体若换用思源黑体（SIL OFL）同样注明 |

## 7 剪辑流程

### 7.1 剪映专业版（主用）

1. 新建草稿：比例 16:9、1920×1080、帧率与素材一致（60 或 30），不混帧率。
2. 素材箱：`raw/`（相机与录屏）、`audio/`（解说、BGM）、`graph/`（数据表、角标图）；文件按 `V<镜头号>_take<条>_<机位>.mp4` 命名。
3. 粗剪：按 §1.2 表的顺序摆放，先不管解说；每段掐头去尾各留 0.3s 动作余量，总时长卡到 169s。
4. 对时：找拍手帧把画面与解说对齐；多机位用同一拍手点入点对齐。
5. 字幕：逐条按 [演示视频脚本](../docs/演示视频脚本.md) 的字幕列粘贴（规范见 §7.2），不依赖智能字幕的术语识别。
6. 音量：解说峰值 -6~-9dB；BGM -18~-24dB；解说段用关键帧或「音频闪避」把 BGM 压到 -28dB。
7. 降噪：对解说轨做轻降噪（≤30%），口水音按 §6 处理。
8. 变速：夹取 / 合挡板 / 舵机同步动作 0.5x 慢放（60fps 素材才平滑）；等待段 2~4 倍速；**不整体变速**。
9. 转场：硬切为主；需要时用 0.2~0.3s 叠化；不用花哨转场与抖动特效。
10. 调色：不加滤镜、不套 LUT；只在必要时统一微调亮度，保证六条硬性要求的画面都看得清。
11. 导出：分辨率 1080p、帧率与时间线一致、编码 H.264、码率「自定义」10~12Mbps（正式版）/ 12Mbps（完整版）、音频 AAC 48kHz 320kbps、格式 MP4。

### 7.2 字幕规范

| 项 | 规范 |
|---|---|
| 字体 | 微软雅黑（在意授权可换思源黑体 / Noto Sans SC） |
| 字号 | 1080p 下正文 40~56、标题 64~80、数据字幕 48 |
| 颜色 | 白字 + 深灰 / 黑描边 3~5px；不要纯白无描边压在亮画面上 |
| 位置 | 底部安全区：距下边缘 ≥100px，左右各留 ≥100px；单行 ≤18 字、最多 2 行 |
| 时码 | 每条 ≥1.5s，开头比人声早 2~3 帧；同一屏不叠两条 |
| 内容 / 禁项 | 逐条照脚本字幕列；术语统一（SYNC WRITE / PL / PS / NPU / 挡板 / 复检）；不出现校名、校徽、指导老师姓名、学号、自夸词 |
| 校对 | 导出前逐字对照脚本字幕列 + 术语表；另找一人复读一遍 |

### 7.3 DaVinci Resolve（备选）

时间线 1920×1080、帧率同素材 → 字幕用 Text+ 或导入 SRT → Deliver 选 MP4 / H.264、勾「Restrict to」填 10000~12000 kb/s、音频 AAC 48000Hz。免费版够用，但导出前要在同一台机器上确认编码器可用。

### 7.4 导出后自检

```powershell
ffprobe -v error -show_entries format=duration,size,bit_rate -show_entries stream=codec_name,width,height,r_frame_rate -of default=nw=1 <成片.mp4>
```

期望：`codec_name=h264`、1920×1080、`r_frame_rate=60/1`（或 `30/1`）、`duration` ≤180、`size` ≤300MB。无 ffprobe 就看文件属性 + 播放器「媒体信息」。

四项硬指标：时长 ≤180s、体积 ≤300MB、编码 H.264 + AAC 48kHz 且全片同帧率、拍手点音画偏差 ≤1 帧（60fps 下 16.7ms，全片抽 3 处）；其余逐项打勾见 §11。

## 8 合规与安全

### 8.1 画面 / 音轨禁项（拍前清场）

| 类别 | 要清掉的东西 |
|---|---|
| 学校标识 | 校名、校徽、校服或 T 恤字样、实验室门牌、工牌、文件夹与纸箱封面 |
| 人员信息 / 音轨 | 指导老师姓名、学号、姓名贴、微信 / QQ 弹窗与头像；口播不念学校名、老师名、队友全名（统一用「我们」） |
| PC 桌面 | 桌面文件名、含姓名拼音的用户名路径、书签栏、任务栏图标、壁纸；开「专注助手」关通知 |
| 其他 | 快递单 / 外卖单 / 水杯商标 / 墙上标语 / 无关人员入画（要入画先征得同意） |

### 8.2 数字口径

- 每个数字必须有出处：[测试与验证](../docs/测试与验证.md) 或当天板上实测输出（`pc/report/part_stats.py`），**且必须在 T-1 的「拍摄当天可用数字清单」上**（§9.1）；清单上没有的数字，字幕与解说一律删除，不念、不估。
- 脚本解说 / 字幕里带括号待填的数字若未补进清单：**镜头保留、数字删除**（画面照拍，字幕与口播都不出这个数）。
- 合成数据 / 无负载条件的数（未接舵机的帧长、合成图准确率等）字幕必须带条件，不能只报数字。
- 口播数字、字幕数字、报告数字三处一致；改一处就三处一起改。
- ⚠ 未实测项不进视频。

### 8.3 现场安全

- 急停按钮在手边（拍摄位伸手可及）；拍前按 [到货联调清单](../docs/到货联调清单.md) §1 做电源与急停检查。按急停会切断动力电（步进驱动器 + 舵机电源），V9 排在当天最后，拍完按流程重新启动再收工。
- 机械臂工作半径内清场：不放零件盒、不站人，三脚架与横臂支腿都在半径外；先慢速走一遍轨迹，确认相机最近点不在扫掠范围。
- 供电与线缆防绊：线缆沿墙走并贴地（美纹纸），插排不横在过道；舵机电源限流按 [到货联调清单](../docs/到货联调清单.md) §1.2 设定后才上电。
- 拍摄当天不跑 `soak.sh`、不换 BOOT.bin；长测素材提前一天备好（§9.1）。
- 关机用 `/root/des/shutdown.sh`，之后 2 分钟内断电；不 `poweroff` 后就走人。

### 8.4 素材备份

- 收工前把相机卡、采集卡录像、录音、截图目录全拷到笔记本 + 移动硬盘两份，用 `Get-FileHash` 比对。
- **原始卡不格式化**：只标记「已备份」，卡留在相机里直到成片导出成功。
- 目录结构：`raw/<镜头号>/`（原片）、`audio/`、`screen/`、`edit/`（剪映草稿）、`out/`（成片）；成片命名按 [提交材料清单](提交材料清单.md) §5。

## 10 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯光频闪（横向明暗条带） | 快门与 50Hz 灯光不同步 / 灯具 PWM 调光 | 快门改 1/100；补光灯换直流供电、不用 PWM 调光；关顶灯 |
| 摩尔纹（屏幕彩虹纹） | 拍屏时像素栅格与传感器采样干涉 | 改用采集卡录屏；必须拍屏时亮度 70%、夹角 5~10°、缩短曝光 |
| 反光过曝 | 顶灯或条形光直射亮面 | 关顶灯、光 45° 侧打、加 CPL、转零件角度、降一档曝光 |
| 卷帘果冻（画面歪晃） | CMOS 卷帘快门 + 拍摄中移动 | 三脚架固定；相机支架与皮带架分开，不让机器振动传上来 |
| 对焦呼吸（画面胀缩） | AF 反复找焦 | 手动对焦锁死，胶带固定对焦环；拍摄中不变焦 |
| 录音底噪 / 电流声 | 空调风机、麦克风线与电源线并行、增益过高 | 关风机；线分开走；麦靠近嘴、降增益；后期轻降噪 ≤30% |
| 素材丢失 / 文件打不开 | 录制中断电、卡写满、直接写 MP4 | OBS 输出 MKV 录完重封装；每段录完回放；卡满换卡不删卡；当天双备份 |
| 导出文件过大 | 码率给太高 | 降到 10~12Mbps（正式版）；删空镜；完整版用 7~8Mbps |
| 时长超了 | 舍不得删等待段 | 按 §1.2 表逐镜头卡时；先删 V4 / V9，再压 V1 / V10；**不加速解说** |
| 字幕错别字 | 智能字幕误识别术语 | 手打或识别后逐字校对；建术语表；另找一人复读 |
