===============================================

✓ .env 文件（不入库，每人本机配置）
✓ 自动检测和加载环境变量
✓ 脚本自动从 .env 读取配置
✓ 支持命令行参数覆盖
✓ CI/CD 兼容（通过环境变量）

结果:
✓ 换电脑只需改 .env，不需改脚本
✓ 团队协作不冲突（.env 不入库）
✓ 开发效率提升（自动化配置）
✓ 向后兼容（原有命令仍可用）

使用示例
===============================================

本地开发 (Windows):
  .\scripts\bootbin\make_bootbin.ps1 -Bit path/to/your.bit

本地开发 (WSL):
  source scripts/env_loader.sh
  make -C ps all

编译 PS 应用:
  make -C ps CROSS=$FD_ROOT/toolchain/gcc/aarch64_linux/bin/aarch64-linux-gnu-

CI/CD 环境:
  export FD_ROOT=/opt/anlogic/fd
  export NPU_DEMO=/data/demo
  make -C ps all
